Chapter 3 · Coloring, Ramsey & Extremal Numbers

A lecture course in the spirit of Chapters 1–2: the idea before the formula, the story before the proof, complete proofs inside the narrative. Graded exercises with hints and worked answers, gem and exploration problems, machine-verified labs, and three vector figures. Every theorem arrives with both halves — the forcing argument above, the construction below — and no proof is left as an honest flag: Brooks, the five-color theorem, Rademacher, and Turán's symmetrization and uniqueness are all complete on the page.

How to read this chapter

Three questions drive everything here, and they are secretly the same question asked three ways. How many colors does a graph need? (Coloring.) How big must a party be before perfect disorder is impossible? (Ramsey.) How many edges can a graph hold before a forbidden shape must appear? (Extremal.) In each case the answer has the same architecture: a forcing argument shows you cannot escape above some threshold, and a construction shows you can escape below it. Learn to hear that two-beat rhythm in every proof.

Notation. $n$ vertices, $m$ edges, $\Delta =$ max degree, $\chi =$ chromatic number, $\omega =$ clique number, $\alpha =$ independence number. Exercises are graded ●○○ / ●●○ / ●●●, with hints inline and worked answers at the end. Two marks to know: ◆ marks a gem — a self-contained jewel problem whose full worked answer is at the end (a triangle-free $4$-chromatic graph, a sum-free coloring of $K_{16}$, a circulant dodge); ◐ marks an exploration — a stated question with recorded machine findings, deliberately left unsolved on the page. Take those as far as you can.

Lecture 1 · Six People at a Party

Here is the theorem that gave Ramsey theory its name — prove it before reading any proof of it, then compare. Among any $6$ people, either $3$ are mutual friends or $3$ are mutual strangers.

Model the party as a complete graph $K_6$: each pair joined by an edge, colored red for friendship, blue for strangeness. The claim: some triangle is all one color.

1.1 The forcing half: ask one person

Pick any person $P$. $P$ stands in $5$ relationships, each red or blue. Five objects, two boxes — so some box holds at least three: say $P$ is red-joined to $A, B, C$. (Compute the pigeonhole yourself: $5 = 2+2+1$ fails — one color must appear $\ge 3$ times $\checkmark$.)

Now watch $A, B, C$. If any pair among them is red — say $A\text{--}B$ — then $P, A, B$ is a red triangle, and we are done. If no pair among them is red, then all three pairs are blue, and $A, B, C$ is a blue triangle. Done. There is no third possibility; that is the whole proof. $\blacksquare$ (Pattern P9: the pigeonhole, but note where it bit — at a single vertex, whose $5$ edges could not stay balanced.)

1.2 The dodge: why five people are not enough

Is $6$ forced, or could $5$ escape? Never trust a threshold without testing its underside. On $5$ vertices, color red the edges of a pentagon (the cycle $C_5$) and blue the remaining five edges — which happen to form another pentagon, the pentagram, the five-pointed star.

Now check honestly that no monochromatic triangle exists. Red triangles would be triangles in $C_5$ — a cycle of length $5$ has none. Blue triangles would be triangles in the pentagram — but the pentagram is also a $5$-cycle (trace it: $0\text{--}2\text{--}4\text{--}1\text{--}3\text{--}0$), so it has none either. And any $3$ vertices of the pentagon: at least one pair is adjacent (a red edge — the largest set with no two adjacent in $C_5$ has size $2$) and at least one pair is a diagonal (a blue edge) — so no $3$-subset is single-colored. $\blacksquare$ (Pattern P11: beat the bound by building.)

So $R(3,3)$ — the least $n$ forcing a red or blue triangle in every $2$-coloring of $K_n$ — is exactly $6$. Memorize the shape of what we did, not the numbers: forcing above (pigeonhole at a vertex), construction below (a symmetric dodge). Every Ramsey result in existence has these two halves, and neither half is optional — the "$=$" is the teamwork.

What you now own: the vertex-pigeonhole (P9), the construction-dodge (P11), and the reflex of testing a threshold from both sides.

Lecture 2 · The Engine: Why It Never Stops

The party problem was one cell of an infinite table: $R(s,t) =$ the least $n$ such that every red/blue coloring of $K_n$ contains a red $K_s$ or a blue $K_t$. Does the whole table even exist — is $R(s,t)$ finite for all $s, t$? The answer is the engine that makes Ramsey theory a theory.

The recursion. $R(s,t) \le R(s-1, t) + R(s, t-1)$ for all $s, t \ge 2$.

Proof. Let $n = R(s-1,t) + R(s,t-1)$, take any coloring of $K_n$, and stand at a vertex $v$. Its $n-1 = R(s-1,t) + R(s,t-1) - 1$ edges split into red and blue. If at least $R(s-1,t)$ are red, then $v$'s red neighborhood spans (by definition of $R$) either a red $K_{s-1}$ — which with $v$ makes a red $K_s$, done — or a blue $K_t$, done. If fewer than $R(s-1,t)$ are red, then at least $R(s,t-1)$ are blue, and the same sentence with colors swapped finishes it. $\blacksquare$ (P9 + P4 — the pigeonhole at $v$ feeds an induction.)

Finiteness now falls out by induction on $s+t$: $R(1,t) = R(s,1) = 1$ (a single vertex is both a red $K_1$ and a blue $K_1$), and every cell of the table with $s, t \ge 2$ sits above two smaller-sum cells, so the whole table is finite — every uniform-enough disorder is impossible, at some finite population. Ramsey's theorem is the mathematical statement that perfect disorder cannot be maintained forever.

The binomial bound. Unrolling the recursion: $R(s,t) \le \binom{s+t-2}{s-1}$. Proof: $R(1,t) = 1 = \binom{t-1}{0}$ and $R(s,1) = 1 = \binom{s-1}{s-1}$ $\checkmark$; and for $s, t \ge 2$, the recursion plus Pascal's identity $\binom{a}{b} + \binom{a}{b+1} = \binom{a+1}{b+1}$ gives $R(s,t) \le \binom{s+t-3}{s-2} + \binom{s+t-3}{s-1} = \binom{s+t-2}{s-1}$ $\blacksquare$. In particular $R(k,k) \le \binom{2k-2}{k-1} \sim \frac{4^{k-1}}{\sqrt{\pi k}}$ — large, but finite.

And now the honest embarrassment. For $k \ge 3$, the basic probabilistic lower frontier is $2^{k/2}$: random colorings avoid monochromatic $K_k$ that long (Chapter 4 builds the machine). So the truth of $R(k,k)$ is trapped between $2^{k/2}$ below and $\binom{2k-2}{k-1} \sim \frac{4^{k-1}}{\sqrt{\pi k}}$ above (the binomial bound with its polynomial factor kept) — an exponential gap: the upper estimate exceeds the lower by a factor of about $2^{3k/2}$ ($4^k \div 2^{k/2} = 2^{3k/2}$, the $\sqrt{k}$ barely denting it), one of the most famous open problems in mathematics. Known exact values: $R(3,3)=6$, $R(3,4)=9$, $R(3,5)=14$, $R(4,4)=18$; even $R(5,5)$ is unknown (known to lie between $43$ and $46$ as of recent work). Sixty-plus years of work has moved that interval by almost nothing. Some doors need a new idea, not more effort.

Lecture 3 · Coloring Cheaply

New problem family, same chapter, because it is the same rhythm. A proper coloring assigns colors to vertices so adjacent vertices differ; $\chi(G)$ is the fewest colors that work. Scheduling conflicts, register allocation in a compiler, radio frequencies for neighboring towers — all are $\chi$ in costume.

The greedy guarantee: $\chi \le \Delta + 1$. Method 1 — the algorithm (P15). Order the vertices $v_1,\dots,v_n$ arbitrarily; color them in order, always giving $v_i$ a color unused by its already-colored neighbors. When $v_i$'s turn comes, at most $\Delta$ neighbors have been colored, forbidding at most $\Delta$ colors — among $\Delta+1$ colors one is always free. The procedure never fails; the procedure is the proof. $\blacksquare$ Method 2 — the induction (P4). Delete a vertex, color the rest ($\Delta$ can only shrink), put the vertex back: at most $\Delta$ neighbor colors are forbidden among $\Delta+1$ available. $\blacksquare$

Two engines, one line of substance. But look at what the proof did not do: it never planned ahead. So the guarantee is a ceiling, not a value — and the ceiling is met exactly where you'd expect structure: $K_n$ needs $n = \Delta+1$ colors (every pair clashes). Run the lab's exhaustion: over all $32{,}768$ graphs on $6$ vertices, greedy (in one fixed order) never exceeds $\Delta+1$ — but it equals $\Delta+1$ in only $1{,}155$ of them and does better in $31{,}613$. Order matters (Exercise 9 makes this vivid).

Two lower bounds to keep in your pocket (a $\chi$-user needs both walls): $\chi \ge \omega$ — the vertices of a clique pairwise clash, so each needs its own color. And $\chi \ge n/\alpha$ — the color classes are independent sets, each of size $\le \alpha$, so $n$ vertices need $\ge n/\alpha$ classes. $\blacksquare$ (Both one-liners; do not memorize — see them.)

Brooks' theorem, in full (Lovász's construction)

The greedy ceiling $\chi \le \Delta + 1$ is met exactly where you would expect structure: complete graphs (every pair clashes) and odd cycles (any order walks around the cycle and arrives home to find all $\Delta$ colors taken). Brooks' theorem says that for connected graphs these are the only failures: every connected graph that is neither complete nor an odd cycle has $\chi \le \Delta$. (Connectedness is a real hypothesis, not decoration — apply the theorem componentwise, and one exceptional component can force the ceiling for the whole graph: $K_4 \sqcup K_2$ is neither complete nor an odd cycle, yet $\chi = 4 = \Delta + 1$.)

Proof. First $\Delta \le 2$: a connected graph with $\Delta \le 1$ is $K_1$ or $K_2$ (complete), and a connected graph with $\Delta = 2$ is a path or a cycle; paths and even cycles color with $2 = \Delta$ colors, and odd cycles are the exception, done. So let $\Delta \ge 3$, $G$ connected and not complete. The engine is greedy coloring with a smart order: if the vertices can be lined up $v_1, \dots, v_n$ so that every $v_i$ ($i < n$) has a neighbor later in the line, then greedy uses at most $\Delta$ colors — when $v_i$'s turn comes, that later neighbor is still uncolored, so at most $d(v_i) - 1 \le \Delta - 1$ colors are forbidden. (The arbitrary-order proof of the ceiling was exactly this count, minus the free neighbor.)

Case 1 — $G$ is not $\Delta$-regular. Some vertex $r$ has $d(r) < \Delta$. Line the vertices up by decreasing distance from $r$ in a breadth-first tree: every $v \ne r$ has its tree-parent later in the line, and $r$ comes last, seeing at most $d(r) < \Delta$ colored neighbors. Greedy never runs out. $\blacksquare$

Case 2 — $G$ is $\Delta$-regular with a cut vertex $x$. Let $C_1, \dots, C_k$ ($k \ge 2$) be the components of $G - x$, and $G_i$ the piece induced by $C_i \cup \{x\}$. Every vertex of $C_i$ keeps its neighbors inside its own piece (components cannot share edges), so each $G_i$ still has maximum degree $\Delta$ — but $x$, whose $\Delta$ neighbors are split among the $k$ pieces, has degree at most $\Delta - 1$ in each. So each piece is a Case-1 graph: color it with at most $\Delta$ colors, then permute each piece's palette so that $x$ takes color $1$ throughout. The pieces share only $x$, so the union is a proper coloring of $G$ with at most $\Delta$ colors. $\blacksquare$

Case 3 — $G$ is $\Delta$-regular and $2$-connected. Regular and not complete means no vertex is adjacent to all others (a universal vertex in a regular graph forces $\Delta = n - 1$, the complete graph) — every vertex has a non-neighbor. It is enough to find a Lovász triple: vertices $v_1 \not\sim v_2$, both adjacent to $u$, with $G - \{v_1, v_2\}$ connected. Given the triple: color $v_1$ and $v_2$ both with color $1$ (they do not clash), line up the remaining vertices by decreasing distance from $u$ in a breadth-first tree of $G - \{v_1, v_2\}$ — $u$ comes last. Every other vertex $w$ has its tree-parent later in line, so it sees at most $d(w) - 1 \le \Delta - 1$ colors; and $u$, colored last, sees at most $\Delta - 2$ colors on its other neighbors plus the single color $1$ shared by $v_1$ and $v_2$ — at most $\Delta - 1$ distinct. Greedy completes with $\Delta$ colors. $\blacksquare$ It remains to produce the triple; pick any vertex $x$ (it has a non-neighbor) and split in two.

Case 3a — $G - x$ is $2$-connected. Set $v_1 = x$ and let $v_2$ be a vertex at distance exactly $2$ from $x$ — one exists, because the shortest path from $x$ to any non-neighbor passes through such a vertex — and let $u$ be a common neighbor on that path ($v_1 \not\sim v_2$, both adjacent to $u$ $\checkmark$). Then $G - \{v_1, v_2\} = (G - x) - v_2$ is a $2$-connected graph minus a single vertex: still connected. $\blacksquare$

Case 3b — $G - x$ has a cut vertex. Set $u = x$. A connected graph with a cut vertex has end blocks — maximal $2$-connected pieces (or bridges) attached to the rest through a single cut vertex — and at least two of them. Let $B_1 \ne B_2$ be two end blocks of $H = G - x$, with attachment vertices $a_1, a_2$. $x$ must have a neighbor inside each end block $B_i \setminus \{a_i\}$: the vertices of $B_i \setminus \{a_i\}$ reach the rest of $H$ only through $a_i$, so if $x$ had no neighbor there, deleting $a_i$ would detach them from $G$ entirely — a cut vertex of $G$, forbidden by $2$-connectedness. Choose such neighbors $v_1 \in B_1 \setminus \{a_1\}$ and $v_2 \in B_2 \setminus \{a_2\}$. They are non-adjacent: two blocks share at most their cut vertices, and $v_1, v_2$ are not cut vertices of $H$ (the only cut vertex inside an end block is its attachment), so no edge reaches from one to the other. Finally $G - \{v_1, v_2\}$ is connected: deleting a non-cut vertex from its own block leaves every block connected and every cut vertex in place, so $H - \{v_1, v_2\}$ stays connected — and $x$, whose $\Delta \ge 3$ neighbors all lie in $H$, keeps at least one neighbor other than $v_1, v_2$ and stays attached. $\blacksquare$

That is the whole theorem. (Machine-checked: on all $26{,}283$ connected non-complete graphs with $\Delta \ge 3$ on $6$ vertices, a vertex with two non-adjacent neighbors always exists; on the $11{,}307$ that are $2$-connected, the Lovász triple exists and the breadth-first line-up yields a valid $\le \Delta$-coloring every single time. A separate census over all connected graphs on $n \le 6$ vertices — $1, 1, 4, 38, 728, 26{,}704$ of them for $n = 1, \dots, 6$ — finds $\chi = \Delta + 1$ attained exactly by complete graphs and odd cycles: zero violations.)

A different repair tool — Kempe chains, recoloring along two-colored paths — waits in Lecture 6, where it proves the five-color theorem.

What you now own: greedy + delete-and-extend (P15/P4), the two $\chi$-walls, the smart-order greedy (Brooks' engine — a good order is worth a color), and the habit of asking when is a bound tight?

Lecture 4 · Mantel: The First Density Theorem

Now the third question, and the birth of extremal graph theory. How many edges can a graph on $n$ vertices hold before a triangle becomes unavoidable? Try it on $n = 4, 5$ by hand; guess the shape of the extremal graph. The answer — the complete bipartite graph $K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$, with two camps and all cross-edges — is exactly the "split the party into two rooms" idea wearing a new costume. It holds $\lfloor n^2/4 \rfloor$ edges and not one triangle (triangles need a within-room edge).

Mantel's theorem. A triangle-free graph on $n$ vertices has at most $\lfloor n^2/4 \rfloor$ edges; for even $n$, equality holds only for $K_{n/2,n/2}$.

Method 1 — the flagship: degree identity + Cauchy–Schwarz (P2)

Triangle-free means: no edge lies in a triangle, i.e. for every edge $uv$, the neighborhoods $N(u), N(v)$ are disjoint (a shared neighbor would complete the triangle). Since $N(u) \cup N(v) \subseteq V$, every edge satisfies

$$d(u) + d(v) \le n.$$

Sum this over all edges. Each vertex $v$ contributes $d(v)$ once per incident edge — that is, it contributes $d(v) \cdot d(v)$ times in total. So $\sum_{uv \in E}(d(u)+d(v)) = \sum_v d(v)^2$, and the inequality reads $\sum_v d(v)^2 \le mn$. Now the averaging device (P10 in algebraic form): $\sum_v d(v)^2 \ge (\sum_v d(v))^2/n = (2m)^2/n$ by Cauchy–Schwarz. Chain them: $4m^2/n \le mn$, so $m \le n^2/4$. $\blacksquare$ Equality (even $n$): forces all degrees equal to $2m/n = n/2$ and $d(u)+d(v) = n$ on every edge; picking any edge $uv$, the disjoint independent sets $N(u)$ and $N(v)$ of size $n/2$ partition $V$, and all $(n/2)^2 = n^2/4$ cross-edges must be present — the graph is $K_{n/2,n/2}$.

Learn this chain cold — local constraint $\to$ sum over edges $\to$ degree-squared identity $\to$ Cauchy–Schwarz $\to$ bound on $m$. It reappears in dozens of extremal problems, and it is the engine behind several results in Chapters 6 and 7.

Method 2 — induction, peeling a light vertex (P4)

First a reusable lemma: every triangle-free graph has a vertex of degree $\le \lfloor n/2 \rfloor$. If $G$ is edgeless, every vertex has degree $0 \le \lfloor n/2 \rfloor$; if $G$ has an edge $uv$ and all degrees exceeded $\lfloor n/2 \rfloor$, then $u$ and $v$ would have disjoint neighborhoods of total size $\ge 2(\lfloor n/2 \rfloor + 1) > n$ — impossible. Now induct (base $n = 1$: $0 \le \lfloor 1/4 \rfloor = 0$): delete $v$ (degree $\le \lfloor n/2 \rfloor$); the rest is triangle-free on $n-1$ vertices, so by induction it has $\le \lfloor (n-1)^2/4 \rfloor$ edges; adding back $v$'s $\le \lfloor n/2 \rfloor$ edges: $\lfloor (n-1)^2/4 \rfloor + \lfloor n/2 \rfloor = \lfloor n^2/4 \rfloor$ (check both parities yourself — this floor identity is worth doing once by hand). $\blacksquare$

Method 3 — the largest independent set as a measuring rod (P8 + P10)

(A confession that is also a lesson: in the reference edition this third proof was an honest sketch — a maximum-cut bookkeeping that actually yields only the weaker $m \le n^2/2$. This edition replaces it with a complete argument of a different kind.)

Let $A$ be a largest independent set, $\alpha = |A|$. Three observations, each one line:

  1. Every vertex outside $A$ has a neighbor in $A$ — otherwise $A \cup \{v\}$ would be a larger independent set.
  2. $\Delta \le \alpha$ — because $G$ is triangle-free, every neighborhood $N(v)$ is an independent set, so $|N(v)| \le \alpha$.
  3. Every edge touches a vertex outside $A$ ($A$ has no internal edges), so $m \le \sum_{v \notin A} d(v) \le (n-\alpha)\cdot \Delta \le (n-\alpha)\cdot \alpha$.

And $(n-\alpha)\cdot \alpha \le ((n-\alpha+\alpha)/2)^2 = n^2/4$ by the arithmetic–geometric mean. $m \le n^2/4$. $\blacksquare$

The extremal instinct — take the largest object of its kind and use both what it contains and what it excludes — is the same cornering move as the longest path (Chapter 2), aimed at a set instead of a path.

Lab tie-in (all verified this session): on $6$ vertices, exhaustive search over all $32{,}768$ graphs finds the triangle-free edge maximum is $9 = \lfloor 36/4 \rfloor$ $\checkmark$; exactly $10$ graphs achieve it, and every one is a labeled $K_{3,3}$ — Mantel's equality case, confirmed as unique up to labeling $\checkmark$; and all $3{,}003$ graphs with $10$ edges contain a triangle $\checkmark$. The theorem's two halves, executed by machine.

Rademacher's theorem: one edge over the top forces many triangles

Mantel says a graph with $\lfloor n^2/4 \rfloor$ edges can be triangle-free. Add one edge — and the triangle you now own turns out not to be lonely. Rademacher's theorem: every graph on $n \ge 3$ vertices with $\lfloor n^2/4 \rfloor + 1$ edges contains at least $\lfloor n/2 \rfloor$ triangles — sharp, by the construction of Exercise 13 ($T_2(n)$ plus one edge inside the larger part).

The proof needs a device worth owning on its own — a second helping of the flagship chain (P2 + CS):

Lemma (per-edge count). Every edge $uv$ lies in at least $d(u) + d(v) - n$ triangles. The third vertices of triangles on $uv$ are exactly the common neighbors $N(u) \cap N(v)$, and by inclusion–exclusion $|N(u) \cap N(v)| = d(u) + d(v) - |N(u) \cup N(v)| \ge d(u) + d(v) - n$. $\blacksquare$

Chained (the second-moment bound). Sum the lemma over all $m$ edges. The left side counts every triangle exactly three times (once per edge): $3T$. The right side is $\sum_{uv \in E}(d(u) + d(v)) = \sum_v d(v)^2$ — vertex $v$ contributes $d(v)$ to each of its $d(v)$ incident edges — and Cauchy–Schwarz gives $\sum d(v)^2 \ge (\sum d(v))^2/n = 4m^2/n$. Together: $3T \ge 4m^2/n - mn$, that is, $T \ge m(4m - n^2)/(3n)$. $\blacksquare$ Two sanity checks: at the Mantel threshold $m = n^2/4$ the bound reads zero (consistent — bipartite graphs have no triangles), and at the complete graph it equals $\binom{n}{3}$ exactly. Machine-checked on all $33{,}864$ graphs with $3 \le n \le 6$: zero violations.

Proof of Rademacher's theorem, induction on $n$; $v$ is throughout a vertex of minimum degree $\delta$. Base $n = 3$: $\lfloor 9/4 \rfloor + 1 = 3$ edges is all of $K_3$ — one triangle $= \lfloor 3/2 \rfloor$ $\checkmark$.

Case A — $\delta \ge \lfloor n/2 \rfloor + 1$. Every edge lies in at least $2\delta - n$ triangles (the lemma), so $3T \ge m(2\delta - n)$. For $n = 2k$: $2\delta - n \ge 2$, so $T \ge 2m/3 \ge 2(k^2+1)/3 \ge k$, since $2k^2 - 3k + 2 > 0$. For $n = 2k+1$: $2\delta - n \ge 1$, so $T \ge m/3 \ge (k^2+k+1)/3 \ge k$, since $(k-1)^2 \ge 0$. Both give $T \ge \lfloor n/2 \rfloor$ $\checkmark$.

Induction cases — $\delta \le \lfloor n/2 \rfloor$. Delete $v$ and apply the induction hypothesis to the rest.

$n$ odd, $n = 2k+1$. The rest has $m' \ge m - \delta \ge (k^2+k+1) - k = k^2 + 1 > k^2 = \lfloor (2k)^2/4 \rfloor$ edges, so the hypothesis applies: $T \ge T(G-v) \ge k = \lfloor n/2 \rfloor$ $\checkmark$.

$n$ even, $n = 2k$, $\delta \le k - 1$. The rest has $m' \ge (k^2+1) - (k-1) = k^2 - k + 2 > k^2 - k = \lfloor (2k-1)^2/4 \rfloor$ edges, so $T(G-v) \ge k - 1$. If $v$ lies on a triangle, the deletion destroys it: $T \ge (k-1) + 1 = k$ $\checkmark$. If $v$ lies on no triangle, $T(G) = T(G-v)$, and the second-moment bound on the rest ($n' = 2k-1$ vertices, $m' \ge k^2-k+2$ edges) finishes: $4m' - n'^2 \ge 4(k^2-k+2) - (4k^2-4k+1) = 7$, so $T \ge 7m'/(3n') \ge 7(k^2-k+2)/(3(2k-1)) \ge k$ — the last step being exactly $k^2 - 4k + 14 \ge 0$, that is, $(k-2)^2 + 10 \ge 0$, always true $\checkmark$.

$n$ even, $n = 2k$, $\delta = k$, $v$ on a triangle. The rest has $m' \ge (k^2+1) - k = k^2 - k + 1 = \lfloor (2k-1)^2/4 \rfloor + 1$ edges — the threshold exactly — so $T(G-v) \ge k - 1$, plus the destroyed triangle: $T \ge k$ $\checkmark$.

$n$ even, $n = 2k$, $\delta = k$, $v$ on no triangle. The delicate corner has a clean answer. Let $I = N(v)$: an independent set of $k$ vertices (an edge inside $I$ would make a triangle with $v$). Let $R$ be the remaining $k - 1$ vertices. Every $x \in I$ has degree $\ge \delta = k$, no neighbors inside $I$, and only $v$ outside $R \cup I$ — so $x$ has $\ge k - 1$ neighbors in $R$, and $|R| = k - 1$: $x$ is adjacent to every vertex of $R$. And $R$ contains an edge — otherwise $m \le e(v) + e(I) + e(I,R) \le k + 0 + k(k-1) = k^2 < k^2 + 1$, too few. Now every edge of $R$ together with every $x \in I$ is a triangle — $k$ choices per $R$-edge: $T \ge k \cdot e(R) \ge k$ $\checkmark$.

Every case is covered. $\blacksquare$ (Machine-checked in full: exhaustive search at $n = 3..7$ finds minima $1, 2, 2, 3, 3$ — $\lfloor n/2 \rfloor$ every time — with $1, 6, 30, 60, 210$ witnesses, matching the construction's labeled counts. At $n = 8$, all $21{,}474{,}180$ seventeen-edge graphs were enumerated: minimum $4$, exactly $420$ witnesses, every one $\cong K_{4,4}$ plus one within-part edge — the construction set exactly — and curiously no seventeen-edge graph on $8$ vertices has exactly $5$ triangles. The census even probes further: $2$ and $3$ edges over the top force minima $8$ and $12$ — exactly $q\cdot \lfloor n/2 \rfloor$ — the thread Exploration X1 sends you down.)

Why denser graphs are free — the deletion note. Rademacher's theorem is stated at the exact threshold, but the induction above applied its hypothesis to $G-v$ carrying $m'$ above the threshold for $n-1$ vertices (two of the cases) as well as at it (the third). So the statement must cover denser graphs — and it does, for free: given more than $\lfloor n^2/4 \rfloor + 1$ edges, delete edges until exactly $\lfloor n^2/4 \rfloor + 1$ remain — deleting edges cannot create triangles, so the count only drops — and every triangle the threshold result finds in the remainder was present in the original graph. The guarantee therefore holds for every graph with at least $\lfloor n^2/4 \rfloor + 1$ edges, which is exactly what the induction's above-threshold cases need. (Machine-checked: at $n = 5$, all $176$ graphs with $\ge 7$ edges carry at least $2$ triangles, and at $n = 6$, all $4{,}944$ with $\ge 10$ edges carry at least $3$ — $\lfloor n/2 \rfloor$ throughout, with the sharp examples already sitting at the threshold: $30$ labeled $K_{2,3}$ plus one within-part edge, $60$ labeled $K_{3,3}$ plus one within-part edge.)

What you now own: the flagship chain (P2+CS), the light-vertex lemma (P4), the independent-set rod (P8+P10), the second-moment bound $T \ge m(4m-n^2)/(3n)$, and the bipartite-split instinct for extremal constructions.

Lecture 5 · Turán: The General Ceiling

Mantel forbids triangles. Forbid $K_{r+1}$ instead — a clique of $r+1$ — and the same story should hold with the complete bipartite graph replaced by a complete $r$-partite one, camps as equal as possible. That is Turán's theorem (1941), the first theorem of extremal graph theory: a $K_{r+1}$-free graph on $n$ vertices has at most the number of edges of the Turán graph $T_r(n)$ — the complete $r$-partite graph with parts as equal as possible — which is $(1 - 1/r)\cdot n^2/2$ up to rounding. Two complete proofs follow — symmetrization, which rebuilds any $K_{r+1}$-free graph into a clean multipartite shape without losing edges, and induction, the light-vertex engine again — and then the equality analysis pins the extremal graph down exactly: $T_r(n)$, unique up to labeling.

Method 1 — Symmetrization by cloning (P20)

Here is the key device, proven in full so you can hold it: the cloning lemma. If $u \not\sim w$ and $d(w) \ge d(u)$, replace $u$'s neighborhood by a copy of $w$'s (delete $u$'s edges; join $u$ to every neighbor of $w$). Then: (i) the graph stays $K_{r+1}$-free — any new $K_{r+1}$ using $u$ would contain a $K_r$ inside $N(w)$, and that $K_r$ together with $w$ was already a $K_{r+1}$, contradiction $\blacksquare$; (ii) the edge count does not decrease (it grows by $d(w) - d(u) \ge 0$).

Now fire the device in one batch. Let $v$ be a vertex of maximum degree $\Delta$, let $N = N(v)$, and let $B$ be the set of $v$'s non-neighbors. Clone every $b \in B$ onto $v$, one clone at a time. Each clone keeps the graph $K_{r+1}$-free and loses no edges (since $v$'s edges are untouched, $d(v) = \Delta$ stays fixed while the degree of any remaining $b' \in B$ can only drop if an edge inside $B$ is deleted, so $d(v) \ge d(b')$ holds at every step), and no clone ever disturbs the setup: $v$'s own edges are never touched (only the edges of the vertex being cloned change), and $b$'s new neighborhood $N$ contains neither $v$ nor any other member of $B$ (they are all non-adjacent to $v$, so none of them sits in $N$) — so the vertices being cloned stay non-adjacent to $v$ and to each other throughout. When the dust settles:

$S = B \cup \{v\}$ is an independent set, every vertex of $S$ is adjacent to exactly the vertices of $N$, and the edges inside $N$ are untouched. The edge count now reads $e(G) \le e(G') = |S|\cdot |N| + e(G'[N]) = (n - \Delta)\Delta + e(G'[N])$.

One more forcing step: $G'[N]$ is $K_r$-free. A $K_r$ inside $N$, plus any vertex of $S$ — which is adjacent to all of $N$ — would be a $K_{r+1}$ in $G'$. Forbidden. So the $\Delta$ vertices of $N$ carry a $K_r$-free graph, and the theorem at $r - 1$ applies to them: $e(G'[N]) \le t_{r-1}(\Delta)$. (The base of this induction on $r$ is $r = 1$: a $K_2$-free graph has no edges at all, and $t_1(n) = 0$.) Chaining:

$$e(G) \le (n - \Delta)\Delta + t_{r-1}(\Delta) =: f(\Delta).$$

The convexity brick. What is $f(\Delta)$? Exactly the edge count of a complete $r$-partite graph: split $\Delta$ vertices into $r - 1$ parts as equally as possible (that is $T_{r-1}(\Delta)$, worth $t_{r-1}(\Delta)$ edges) and add one more part of $n - \Delta$ vertices joined to everything before (worth $(n - \Delta)\Delta$ edges). So maximizing $f(\Delta)$ is the question "how many edges can a complete $r$-partite graph on $n$ vertices have?" — and that has a clean answer. With part sizes $s_1, \dots, s_r$, every cross-pair is joined and no inside-pair is: $e = \frac{1}{2}(n^2 - \sum s_i^2)$, so maximizing edges means minimizing $\sum s_i^2$. If two parts differ by two or more, $s_i \ge s_j + 2$, move one vertex from the bigger to the smaller: $\sum s_i^2$ changes by $(s_i-1)^2 + (s_j+1)^2 - s_i^2 - s_j^2 = 2(s_j - s_i) + 2 \le -2$, a strict improvement. So $\sum s_i^2$ is minimized exactly when the parts are as equal as possible — and therefore $f(\Delta) \le t_r(n)$ for every $\Delta$, with equality exactly when the $f(\Delta)$-configuration is balanced. And a balanced configuration can occur at two values of $\Delta$: $\Delta = n - \lceil n/r \rceil$ always works, and when $r$ does not divide $n$ so does $\Delta = n - \lfloor n/r \rfloor$ ($n = 5, r = 3$: $\Delta = 3$ gives parts $(2, 2, 1)$, $\Delta = 4$ gives parts $(1, 2, 2)$, and both are worth $8 = t_3(5)$; when $r$ divides $n$ the two values coincide and the maximizer is unique). Turán's bound is proved. $\blacksquare$ (Machine-checked: the batch construction preserves $K_{r+1}$-freeness and never loses edges — and it is a no-op on every extremal graph, but not only on them (the star $K_{1,4}$ at $r = 2$ has nothing to clone: four edges, six needed); extremality is the bound's conclusion, not the clone's behavior. The inequality $f(\Delta) \le t_r(n)$ holds for every $\Delta$, with the maximum attained exactly at $\Delta = n - \lceil n/r \rceil$ and $\Delta = n - \lfloor n/r \rfloor$ — one value when $r$ divides $n$, two otherwise — verified on all $n \le 100, r \le 8$.)

Method 2 — Induction (P4) — the edge bound in full

Three steps: a light-vertex lemma with the right bound, the exact increment of the Turán numbers, and the induction itself.

The light-vertex lemma. Every $K_{r+1}$-free graph on $n$ vertices has a vertex of degree at most $n - \lceil n/r \rceil = \lfloor (1 - 1/r)n \rfloor$. Proof. Suppose not — every degree is strictly greater than $n - \lceil n/r \rceil$, and since degrees are integers, every vertex satisfies $d(v) \ge n - \lceil n/r \rceil + 1 > (1 - 1/r)n$. (If $n \le r$ this is already absurd: it demands a degree above $n - 1$.) Build a clique greedily: pick any $v_1$; having picked a clique $v_1, \dots, v_k$ with $k \le r$, take the next vertex from the common neighborhood $N(v_1) \cap \dots \cap N(v_k)$. A vertex outside $N(v_i)$ is one of the $n - d(v_i)$ non-neighbors of $v_i$ ($v_i$ included — nothing is its own neighbor), so by the union bound the common neighborhood still holds at least $n - \sum_{i=1}^k (n - d(v_i)) > n(1 - k/r)$ vertices — at least one for every $k \le r$ (and the chosen vertices themselves are never candidates: $v_i$ is not its own neighbor). The clique grows to size $r$, and its common neighborhood still holds a fresh vertex — the $(r+1)$-th member. A forbidden $K_{r+1}$: contradiction. $\blacksquare$ (At $r = 2$ this is Mantel's light-vertex lemma in its sharp form: a triangle-free graph has a vertex of degree $\le \lfloor n/2 \rfloor$. The bound is honest — $K_{3,3}$ has $\delta = 3 = 6 - \lceil 6/2 \rceil$ exactly.)

The exact increment. Let $t_r(n)$ be the edge count of $T_r(n)$. The $n$-th vertex of the Turán graph joins its largest part (of size $\lceil n/r \rceil$ in $T_r(n)$, having grown from a part of size $\lceil n/r \rceil - 1$ in $T_r(n-1)$) and is adjacent to exactly the $n - \lceil n/r \rceil$ vertices outside it: $t_r(n) - t_r(n-1) = n - \lceil n/r \rceil$.

The induction. Delete a vertex of degree $\le n - \lceil n/r \rceil$ — the lemma supplies one. The remainder is $K_{r+1}$-free on $n - 1$ vertices, so by induction it carries at most $t_r(n-1)$ edges; restore the vertex and count: $e(G) \le t_r(n-1) + n - \lceil n/r \rceil =$ $t_r(n)$. $\blacksquare$ (Base: $n \le r$ — no clique of $r+1$ vertices fits, and $t_r(n) = \binom{n}{2}$ is all the edges there are.)

The induction above delivers the edge bound; Method 1's convexity brick already shows that among complete multipartite graphs only the balanced ones are maximizers. The remaining gap is that a wild, non-multipartite extremal graph might exist. The next section closes it.

The extremal graph is unique (equality analysis)

Claim. If $G$ is $K_{r+1}$-free on $n$ vertices with $e(G) = t_r(n)$, then $G \cong T_r(n)$.

Proof, induction on $n$. Base $n \le r$: $t_r(n) = \binom{n}{2}$ — every pair is an edge, so $G = K_n$, which is exactly $T_r(n)$ with its $n$ one-vertex parts. Step, $n > r$. Take a light vertex $v$ — the light-vertex lemma supplies one with $d(v) \le n - \lceil n/r \rceil$ — and delete it. Then $e(G-v) = t_r(n) - d(v) \ge t_r(n) - (n - \lceil n/r \rceil) = t_r(n-1)$ by the exact increment, while $G-v$, being $K_{r+1}$-free on $n-1$ vertices, carries at most $t_r(n-1)$ edges. Both inequalities are therefore equalities: $d(v) = n - \lceil n/r \rceil$ exactly, and $e(G-v) = t_r(n-1)$, so by induction $G-v \cong T_r(n-1)$ — complete multipartite, parts as equal as possible.

Where are $v$'s missing edges? Let $X$ be the non-neighbors of $v$ inside $G-v$; the count is forced: $|X| = (n-1) - d(v) = \lceil n/r \rceil - 1$.

$X$ must swallow an entire part. If not, every part of the Turán structure on $G-v$ keeps a vertex outside $X$ — that is, adjacent to $v$. One such vertex from each of the $r$ parts: $r$ pairwise-adjacent vertices (different parts are fully joined), all adjacent to $v$ — a $K_{r+1}$. Forbidden.

And the size arithmetic forces $X$ to be exactly one part. Write $n = qr + s$ with $0 \le s < r$. If $s \ge 1$, the parts of $T_r(n-1)$ come in sizes $q+1$ (when $s \ge 2$) and $q$, and $|X| = \lceil n/r \rceil - 1 = q$; if $s = 0$ they come in sizes $q$ and $q-1$, and $|X| = q-1$. In both cases the smallest part size equals $|X|$ exactly. A part contained in $X$ has size $\le |X|$, hence at most the smallest part size, hence exactly it — and since it fills $X$, $X$ is precisely one part $P_0$ of $G-v$.

Complete the picture: $v$ is adjacent to everything outside $X \cup \{v\}$ — that is, fully joined to every other part — and $X \cup \{v\} = P_0 \cup \{v\}$ is independent ($P_0$ is a part; $v$ is non-adjacent to all of it). So $G$ is complete $r$-partite with parts $P_0 \cup \{v\}$ and the $r-1$ untouched parts of $G-v$. Count sizes: for $s \ge 1$, that is $s$ parts of $q+1$ and $r-s$ parts of $q$; for $s = 0$, it is $r$ parts of $q$. Those are exactly the part sizes of $T_r(n)$ — and a complete $r$-partite graph with those sizes is $T_r(n)$. $\blacksquare$

(Machine-checked: exhaustive census over all $K_{r+1}$-free graphs on $n \le 6$ vertices, every $r$ — every graph attaining the extremal count is isomorphic to $T_r(n)$, and the labeled counts $3, 3, 6, 10, 15, 10, 10, 15, 45, 15$ match $n! / (\prod s_i! \cdot \prod m_a!)$ — the count of labeled copies of $T_r(n)$, where $m_a$ is the number of parts of size $a$ and the equal-sized parts' permutations are divided out — exactly: for $K_{3,3}$ on six labeled vertices, $6!/(3!\cdot 3!\cdot 2!) = 10$, not $40$.)

Where this leads. Turán is the tip of an iceberg: the Erdős–Stone theorem extends it to any forbidden subgraph $H$ — asymptotically $(1 - 1/(\chi(H)-1))\cdot n^2/2$ edges — and exact results for specific $H$ are a thriving industry. Chapter 4 will return with the probabilistic method's own contribution to these numbers.

Lecture 6 · Flatland: Planar Graphs

Can a graph be drawn in the plane with no crossings? A planar graph can. The land of the flat has three theorems, each an application of something you already own.

6.1 Euler's formula: $v - e + f = 2$ (P4)

For a connected planar graph with $v$ vertices, $e$ edges, $f$ faces (including the unbounded face): $v - e + f = 2$. Proof: build the graph up from one vertex ($v=1, e=0, f=1$: invariant $2$ $\checkmark$). Each new edge either (a) hangs from one existing vertex (a tree edge): $v$ and $e$ both grow — invariant preserved; or (b) attaches at both ends, splitting a face into two: $e$ and $f$ both grow — invariant preserved. At the end, all additions preserved $2$. $\blacksquare$ (The same build-it-edge-by-edge engine as Chapter 2's handshaking proof.)

6.2 Flat graphs are thin: $e \le 3v - 6$ (P2)

Count face–edge incidences. Work in a connected simple plane graph with $v \ge 3$. Each face's boundary walk has length at least $3$ — counting edge-sides, so that a bridge (an edge with the same face on both sides) is walked twice, once along each side; summing over all faces counts every edge-side exactly once, so $3f \le 2e$. Substitute $f = e - v + 2$ (Euler's formula, which needs the connectedness): $3(e - v + 2) \le 2e \implies$ $e \le 3v - 6$. $\blacksquare$ A disconnected planar graph with $v \ge 3$ is handled componentwise — or by first adding noncrossing edges to join its components, which raises $e$ without changing $v$ and can only help the inequality. Two one-line corollaries, both worth saying aloud: $K_5$ has $10 > 3\cdot 5-6 = 9$ edges — not planar; and $K_{3,3}$, being bipartite, has all facial walks of $\ge 4$ sides, so $4f \le 2e$ gives $e \le 2v - 4$ (Exercise 8), and $9 > 8$ — not planar either. (These two graphs are, remarkably, the only obstacles: Kuratowski's theorem, stated with one direction proved in §6.5.)

6.3 Six colors suffice (P10 + P4)

Planar graphs always have a vertex of degree $\le 5$: for $v < 3$ this is immediate, and for $v \ge 3$ having all degrees $\ge 6$ gives $\sum d = 2e \ge 6v$ against $e \le 3v - 6 < 3v$ — contradiction. Now induct: delete such a vertex, color the rest (still planar), put it back — at most $5$ neighbor colors are forbidden among $6$. $\blacksquare$ Averaging says a thin graph has a cheap corner; induction exploits it.

6.4 Five colors suffice: repair instead of delete (P4 + Kempe chains)

Six colors came from pure deletion. Five takes repair. Induct as before: delete the low-degree vertex $v$ (§6.3 supplies one with $d(v) \le 5$), $5$-color the rest, put $v$ back. If $d(v) \le 4$, or if two neighbors share a color, some color among the five is missing at $v$'s neighborhood — done. The only hard case: $d(v) = 5$ and the five neighbors carry five different colors. Name the neighbors $v_1, \dots, v_5$ in their cyclic order around $v$ in the plane drawing, $v_i$ wearing color $i$.

Kempe chains. The subgraph induced by the vertices of colors $\{1, 3\}$ — the $(1,3)$-subgraph — splits into connected components, its Kempe components: each is bipartite with colors $1$ and $3$ alternating across every edge, and swapping $1 \leftrightarrow 3$ throughout any single component is again a proper coloring — the swap never leaves the component. Two vertices of colors $1$ and $3$ in the same component are joined by an alternating $1,3,1,3,\dots$ path inside it. A component need not be a path or a cycle — a color-$1$ vertex with three color-$3$ neighbors branches it — but only the component facts are used below. $v_1$ and $v_3$ each sit in one component (their Kempe chains). Two cases:

Case 1 — $v_1$ and $v_3$ lie in different components. Swap colors $1 \leftrightarrow 3$ throughout $v_1$'s component only: still a proper coloring (the swap is an involution inside a component), but now no neighbor of $v$ has color $1$ — $v_3$ is in the other component, untouched. Color $v$ with $1$. Done.

Case 2 — $v_1$ and $v_3$ lie in the same component. Then a path of colors $1,3,1,3,\dots$ joins $v_1$ to $v_3$, and together with the two edges $v\text{--}v_1, v\text{--}v_3$ it closes a curve in the plane — with $v_2$ on one side and $v_4$ on the other. Any path of colors $\{2,4\}$ from $v_2$ to $v_4$ would have to cross that curve; but the curve is made of graph edges, edges do not cross in a plane drawing, and the curve's vertices carry only colors $1, 3$, and $v$'s (missing) color — never $2$ or $4$. So no such path exists: $v_2$ and $v_4$ lie in different components of the $(2,4)$-subgraph. Swap $2 \leftrightarrow 4$ in $v_2$'s component; now no neighbor of $v$ has color $2$. Color $v$ with $2$. Done.

Either way $v$ gets its color: every planar graph is $5$-colorable. $\blacksquare$ (Heawood, 1890 — who found the flaw in Kempe's 1879 "proof" of four colors and salvaged this much.) The machine census confirms the shape of the argument: among all $32{,}647$ graphs on $6$ vertices satisfying the planar edge bound, every one is $5$-colorable; and on $7$ vertices, where $232$ graphs satisfy $\delta \ge 5$ and $21$ of them need $6$ colors, not one is $6$-critical — the only $6$-critical graph on $\le 7$ vertices is $K_6$, which is not planar ($15$ edges $> 3\cdot 6-6$). The minimal counterexample the proof dismantles never actually materializes below the non-planar $K_6$.

6.5 Kuratowski's theorem: the only two obstacles

A subdivision of a graph is what you get by replacing edges with internally disjoint paths — stretching edges into threads, planting extra vertices along them. Kuratowski's theorem (1930): a graph is planar if and only if it contains no subgraph that is a subdivision of $K_5$ or of $K_{3,3}$. The hard direction (planarity can always be certified by avoiding just these two shapes) is a longer journey — a minimal counterexample dismantled into $3$-connected pieces — honestly left beyond this chapter's scope. But the easy direction is yours already: any graph containing a subdivision of $K_5$ or $K_{3,3}$ is not planar. Proof. Contracting an edge preserves planarity: in a plane drawing, slide one endpoint along the edge into the other — every other edge merely deforms, nothing crosses. Now suppose $G$ were planar and contained a subdivided $K_5$. Contract each subdivision path back to an edge: planarity survives every contraction, so $K_5$ itself would be planar — against §6.2 ($10 > 9$ edges). Same for $K_{3,3}$ against the bipartite bound ($9 > 8$). $\blacksquare$ So the two graphs of §6.2 are not merely non-planar; they are contagiously non-planar — every graph that threads them into itself inherits it.

The rest of the story. The four-color theorem took a century: Appel–Haken 1976, by computer, checking $1{,}936$ configurations — and in 2005 Georges Gonthier formally verified it, machine-checked end to end, in a proof assistant. Hold that thought: the most famous theorem of this chapter is now known precisely because it was formalized — the philosophy of the Lean formal track (the Atlas's unnumbered companion), vindicated at full scale.

What you now own: Euler's build-proof, the incidence-counting habit ($3f \le 2e$), low-degree corners from averaging, the Kempe-chain repair (recolor along a two-colored chain; separation wins when chains collide), contraction preserving planarity, and the flat-land bounds.

A6. $R(2,4)$: a red $K_2$ is any red edge; to dodge red entirely, color all blue, which forces a blue $K_4$ exactly at $n = 4$ ($n = 3$: all-blue $K_3$ dodges both). So $R(2,4) = 4$. A7. Greedy uses at most $\Delta+1$ colors (Lecture 3), producing a proper coloring in which every color class is an independent set. Since $n$ vertices are distributed among $\le \Delta+1$ classes, the largest class has $\ge n/(\Delta+1)$ vertices (pigeonhole), and it is independent. $\alpha \ge n/(\Delta+1)$. $\blacksquare$

A8. Bipartite $\implies$ no odd cycle $\implies$ every closed walk has even length, so each facial boundary walk has length $\ge 4$ (a bridge contributes its two sides to the same face's walk, and the count stays even). Counting face–edge incidences in a connected plane bipartite graph: $4f \le 2e$. Euler: $f = 2 - v + e$, so $4(2 - v + e) \le 2e \implies$ $e \le 2v - 4$. $\blacksquare$ (A disconnected bipartite planar graph: join the components with noncrossing edges — choosing the bipartition sides compatibly — or argue componentwise.)

A9. The crown on $\{a_1,\dots,a_n, b_1,\dots,b_n\}$: join $a_i\text{--}b_j$ iff $i \ne j$. It is bipartite ($\chi = 2$). Order $a_1, b_1, a_2, b_2, \dots$: by induction on $i \in \{1,\dots,n\}$, both $a_i$ and $b_i$ receive color $i$. For $i = 1$, $a_1$ gets $1$, and $b_1$ is not adjacent to $a_1$, so $b_1$ gets $1$. For $i > 1$, when $a_i$ is colored, its already-colored neighbors are $b_1,\dots,b_{i-1}$, which by the induction hypothesis carry colors $1,\dots,i-1$, so $a_i$ gets $i$; when $b_i$ is colored, its already-colored neighbors are $a_1,\dots,a_{i-1}$ (since $b_i \not\sim a_i$), which carry colors $1,\dots,i-1$, so $b_i$ also gets $i$. Greedy uses $n$ colors on a $2$-colorable graph. The moral: greedy is order-blind, and orders can be adversarial.

A10. The Petersen graph has $v = 10, e = 15$, girth $5$ (no triangles, no $4$-cycles — check the standard drawing: outer $5$-cycle, inner star, spokes). Every face would be bounded by $\ge 5$ edges, so $5f \le 2e = 30, f \le 6$. But Euler demands $f = 2 - v + e = 7$. Contradiction — non-planar. $\blacksquare$ (Equivalently: $5(2-10+15) = 35 > 2\cdot 15 = 30$.)

A11. Order the vertices uniformly at random and call $v$ a winner if it precedes all its neighbors. Winners form an independent set: if $u \sim v$ both won, one of them precedes the other — say $u$ before $v$ — but then $v$ has a neighbor ($u$) before it, so $v$ lost. Contradiction. Now $\mathbb{E}[\#\text{winners}]$: $v$ wins iff $v$ is first among its closed neighborhood of $d(v)+1$ vertices; by symmetry each of the $d(v)+1$ orderings of that little set is equally likely, so $\mathbb{P}(v\text{ wins}) = 1/(d(v)+1)$. Linearity of expectation: $\mathbb{E} = \sum_v 1/(d(v)+1)$. Some ordering achieves at least the expectation. $\alpha \ge \sum_v 1/(d(v)+1)$. $\blacksquare$ This is Chapter 4's probabilistic method in miniature — existence by expectation — and (by the AM–HM inequality, $\sum 1/x \ge n^2/\sum x$) it implies the handy $\alpha \ge n^2/(2m+n)$.

The vertices are the $16$ vectors of $\mathbb{Z}_2^4$; the edge $xy$ ($x \ne y$) carries the difference $x+y \in \mathbb{Z}_2^4 \setminus \{\bar{0}\}$ ($x+y \ne \bar{0}$ exactly because $x \ne y$). Partition the $15$ nonzero vectors into three classes, each sum-free — no $a + b = c$ inside a class: $C_1 = \{0001, 0010, 0100, 1000, 1111\}$, $C_2 = \{0011, 0101, 0111, 1010, 1011\}$, $C_3 = \{0110, 1001, 1100, 1101, 1110\}$ ($5 + 5 + 5 = 15$ $\checkmark$) — and color edge $xy$ by the class of $x+y$. A19. Pigeonhole at a vertex (P9): in a red/blue coloring of $K_N$ with $N = R(s-1,t) + R(s,t-1)$ vertices, fix $v$. Its $N - 1 = R(s-1,t) + R(s,t-1) - 1$ incident edges split into red and blue: if $v$ has at least $R(s-1,t)$ red neighbors, the red graph on them contains either a red $K_{s-1}$ — which with $v$ makes a red $K_s$ — or a blue $K_t$, done. Otherwise $v$ has fewer than $R(s-1,t)$ red neighbors, so at least $(N-1) - (R(s-1,t) - 1) = R(s,t-1)$ blue neighbors, and the blue argument runs the same way: a blue $K_{t-1}$ grows to a blue $K_t$ with $v$, or a red $K_s$ appears. Either way a monochromatic $K_s$ or $K_t$ exists, so $R(s,t) \le R(s-1,t) + R(s,t-1)$. For the ceiling, induct on $s + t$ (P4): $R(s,2) = s = \binom{s}{s-1}$ and $R(2,t) = t = \binom{t}{1}$ anchor the base for $s, t \ge 2$ (and $R(1,t) = R(s,1) = 1$), and the recursion is Pascal's identity — $R(s,t) \le \binom{s+t-3}{s-2} + \binom{s+t-3}{s-1} = \binom{s+t-2}{s-1}$ $\checkmark$. Numbers: $R(3,3) = 6 = \binom{4}{2}$ (the ceiling is tight there); $R(3,4) = 9 \le 10$; $R(3,5) = 14 \le 15$; $R(4,4) = 18 \le 20$ — the machine-checked table agrees everywhere $\checkmark$. Notice Exercise 6's "off by exactly one": the recursion gives $10$ for $R(3,4)$, the truth is $9$ — ceilings are honest but not always tight, which is exactly why Exercise 14 had to close the gap by hand.

A20. Throw every vertex independently left or right with probability $1/2$ (P12's coin). An edge crosses the cut exactly when its ends landed on opposite sides — probability $1/2$ — so the expected number of crossing edges is $m/2$ (P10: expectation adds over edges). An expectation is a promise: some partition has at least $m/2$ edges crossing it, and the crossing edges form a bipartite subgraph (the two sides are the parts). $\blacksquare$ The derandomized version (P18) is a greedy repair: start anywhere; a vertex whose own-side neighbors outnumber its across-side neighbors switches sides, gaining the cut at least one edge each move — the process must stop (the cut is bounded above by $m$), and it stops only when every vertex sees at least as many across as home, so at least $m/2$ edges cross. Machine check: over all $33{,}866$ graphs on $n = 2..6$ vertices, the exact maximum cut is $\ge m/2$ in every single one; equality $m/2$ happens only for the five edgeless graphs ($m = 0$), every graph with edges cuts strictly more than $m/2$, and $70$ of those sit tight at the ceiling $\lceil m/2 \rceil$ — the triangle among them, its best split keeping exactly two of its three edges $\checkmark$. The moral for the chapter: bipartiteness is $2$-colorability, and half of every graph's edges can always be $2$-colored — a first hint that $\chi$ is not just about cliques (Lecture 3's second wall).

A21. The extremal reflex (P8): pass to a subgraph $H \subseteq G$ that is $k$-critical — $\chi(H) = k$ but every proper subgraph is $(k-1)$-colorable (keep deleting edges and vertices; $\chi$ never rises, so stop at the last subgraph still needing $k$). $H$ has minimum degree $\ge k-1$: delete a lighter vertex $v$, $(k-1)$-color $H - v$, then put $v$ back with a free color (it has fewer than $k-1$ neighbors, so some color is unused among them) — contradicting criticality. Also $H$ has at least $k$ vertices ($\chi(H) \le |V(H)|$). Now the degree-sum machine (Lecture 1 of Chapter 2, P2/P7): $m(H) \ge \frac{1}{2}(k-1)|V(H)| \ge k(k-1)/2 = \binom{k}{2}$, and $m(G) \ge m(H)$. $\blacksquare$ Equality: retrace — $|V(H)| = k$ and $\delta(H) = k-1$ force $H = K_k$ (every vertex adjacent to every other); and $G$ may add only isolated vertices (any extra edge would push $m$ past $\binom{k}{2}$). So $m = \binom{\chi}{2}$ exactly on $K_k$-plus-isolated-vertices. Machine check: over all $33{,}867$ graphs on $n \le 6$ vertices, no graph violates $m \ge \binom{\chi}{2}$, and all $105$ equality cases are exactly $K_\chi$ plus isolated vertices (the edgeless graph is the $\chi = 1$ case) $\checkmark$. The honest lesson: the machine found the equality classification first — a bare "equality iff complete" is false (a single edge on three vertices is not complete), and the repair is the family above.

A22. The encoding (P1): vertices $1, \dots, 6$; give the edge between $i < j$ the color of the integer $j - i$. Lecture 1's theorem says the resulting coloring of $K_6$ contains a monochromatic triangle, on vertices $i < j < l$. Monochromatic means the three differences $j - i, l - j, l - i$ all carry one color — and the first two sum to the third. So the integers $x = j - i, y = l - j, z = l - i = x + y$ all share a color, all lie in $\{1,\dots,5\}$: every $2$-coloring of $\{1,\dots,5\}$ contains a monochromatic solution of $x + y = z$. $\blacksquare$ The dodge at $n = 4$: color $\{1, 4\}$ red and $\{2, 3\}$ blue — every solution $x + y = z$ inside $\{1,\dots,4\}$ (namely $1+1 = 2, 1+2 = 3, 1+3 = 4, 2+2 = 4$) mixes colors $\checkmark$ (machine check: the census of all $32$ colorings confirms $\{1,\dots,4\}$ is the last sum-free zone and every one of the $32$ colorings of $\{1,\dots,5\}$ fails $\checkmark$). The encoding is a pattern for a whole world: arithmetic statements (sums, progressions) hide inside Ramsey statements about complete graphs; Volume II's Ramsey chapter reuses this bridge for van der Waerden and Schur's general theorem, and it is the same bridge ◆16 crossed in the other direction ($\mathbb{Z}_2^4$'s vector sums built the $R(3,3,3) > 16$ dodge).

from itertools import combinations

def triangle_free_colorings(n):
    if n < 3:
        return 1 << (n * (n - 1) // 2), 1 << (n * (n - 1) // 2)
    edges = list(combinations(range(n), 2))
    eidx = {e: i for i, e in enumerate(edges)}
    tris = [(eidx[(a,b)], eidx[(a,c)], eidx[(b,c)])
            for a, b, c in combinations(range(n), 3)]
    good = 0
    for mask in range(1 << len(edges)):
        ok = True
        for x, y, z in tris:
            if ((mask >> x) & 1) == ((mask >> y) & 1) == ((mask >> z) & 1):
                ok = False; break
        good += ok
    return good, 1 << len(edges)

def greedy_color_count(adj, n):
    if n == 0:
        return 0
    color = [-1] * n
    for v in range(n):
        used = {color[u] for u in range(v) if adj[u][v]}
        c = 0
        while c in used: c += 1
        color[v] = c
    return max(color) + 1

def is_complete_bipartite_balanced(adj, n):
    if n == 0:
        return True
    side = [-1] * n
    side[0] = 0
    queue = [0]
    while queue:
        u = queue.pop(0)
        for v in range(n):
            if adj[u][v]:
                if side[v] == -1:
                    side[v] = 1 - side[u]
                    queue.append(v)
                elif side[v] == side[u]:
                    return False
    if -1 in side:
        return False
    s0 = [u for u in range(n) if side[u] == 0]
    s1 = [u for u in range(n) if side[u] == 1]
    if sorted([len(s0), len(s1)]) != [n // 2, (n + 1) // 2]:
        return False
    return all(adj[u][v] for u in s0 for v in s1)
