Lecture 1 · Sperner's Theorem: The Middle Level, Three Ways

Problem. The largest family of subsets of $[n]$ with no two comparable (an antichain) has size $\binom{n}{\lfloor n/2 \rfloor}$ — the middle level(s).

1.1 Method 1 — Counting maximal chains (P2, full)

A maximal chain is $\emptyset \subset \{x_1\} \subset \{x_1, x_2\} \subset \dots \subset [n]$. It is determined by the order in which elements enter, so there are exactly $n!$ chains. A chain passes through a fixed $k$-set $A$ in $k!(n - k)!$ orders: order $A$'s $k$ elements first ($k!$ ways), then the remaining $n - k$ (that many ways).

Now count pairs $(\text{chain}, \text{member of } \mathcal{F} \text{ on that chain})$. Each chain meets an antichain at most once — two members on one chain would be comparable. So:

$$\sum_{A \in \mathcal{F}} |A|!(n - |A|)! \le n!.$$

Divide by $n!$:

LYM inequality. $$\sum_{A \in \mathcal{F}} \frac{1}{\binom{n}{|A|}} \le 1.$$

Finish: $\binom{n}{k} \le \binom{n}{\lfloor n/2 \rfloor}$ for every $k$, so each term satisfies $1/\binom{n}{|A|} \ge 1/\binom{n}{\lfloor n/2 \rfloor}$, and therefore

$$|\mathcal{F}| = \sum_{A \in \mathcal{F}} 1 \le \binom{n}{\lfloor n/2 \rfloor} \sum_{A \in \mathcal{F}} \frac{1}{\binom{n}{|A|}} \le \binom{n}{\lfloor n/2 \rfloor}. \quad \blacksquare$$

Equality. Take the middle level itself: every term lands at exactly $1/\binom{n}{\lfloor n/2 \rfloor}$, and the LYM sum is exactly $1$. (When $n$ is odd there are two middle levels, both of size $\binom{n}{(n-1)/2} = \binom{n}{(n+1)/2}$; each saturates alone.) A worthwhile ✎: check that the full union of the two middle levels when $n$ is odd is not an antichain — the smaller sets sit inside the bigger ones across levels — while partial mixes can be ($\{\{1\}, \{2, 3\}\}$ at $n = 3$ is one).

1.2 Method 2 — The symmetric chain decomposition, actually built (full)

The second proof needs a structure the reference edition only cited: a partition of $2^{[n]}$ into chains that each run from some level $r$ straight up to level $n - r$, one set per level along the way. This is the symmetric chain decomposition (SCD) of de Bruijn–Tengbergen–Kruyswijk — and it has a two-line recursive construction that we can verify, not just believe.

The doubling construction. Suppose $2^{[n-1]}$ has an SCD. Each chain $C = (A_1 \subset A_2 \subset \dots \subset A_l)$ is symmetric: $|A_1| + |A_l| = n - 1$, and sizes grow by exactly one per step. From $C$, keep:

  • the extended chain $A_1 \subset \dots \subset A_l \subset A_l \cup \{n\}$, and (when $l \ge 2$)
  • the reflected chain $A_1 \cup \{n\} \subset A_2 \cup \{n\} \subset \dots \subset A_{l-1} \cup \{n\}$.

Every subset of $[n]$ lands in exactly one new chain. A set $S$ avoiding $n$ lies in exactly one old chain, as some $A_i$; if $i < l$ it appears only in the extended chain (the reflected chain only carries sets that contain $n$); if $i = l$ it is the second-to-top of the extended chain — again exactly once. A set $S$ containing $n$ is $T \cup \{n\}$ for exactly one $T \subseteq [n-1]$: if $T = A_l$ it is the top of the extended chain; if $T = A_i$ with $i \le l - 1$ it sits in the reflected chain. One home for everybody: a partition. ✓

Symmetry survives. Extended chain: $|A_1| + |A_l \cup \{n\}| = |A_1| + |A_l| + 1 = n$. Reflected chain: $|A_1 \cup \{n\}| + |A_{l-1} \cup \{n\}| = |A_1| + 1 + |A_{l-1}| + 1$, and $|A_{l-1}| = |A_l| - 1$ (sizes step by one), so this is $|A_1| + |A_l| + 1 = n$. Both start at level $r$ and end at level $n - r$. ✓

Base case. $2^{[1]}$: the single chain $\emptyset \subset \{1\}$, symmetric ($0 + 1 = 1$). Induction up, and $2^{[n]}$ has an SCD for every $n$. $\blacksquare$

How many chains? $\binom{n}{\lfloor n/2 \rfloor}$ — the middle binomial itself. Count chain starts by level: a chain starting at level $r$ ends at $n - r$, so it passes through level $j$ exactly when $r \le j \le n - r$, i.e. $r \le \min(j, n - j)$. Every set at level $j$ lies on exactly one chain, so $\sum_{r \le \min(j, n-j)} \operatorname{starts}(r) = \binom{n}{j}$. Subtracting the equation for $j - 1$: $\operatorname{starts}(j) = \binom{n}{j} - \binom{n}{j-1}$ for $j \le n/2$. Telescoping: total chains $= \sum_{r=0}^{\lfloor n/2 \rfloor} \operatorname{starts}(r) = \binom{n}{\lfloor n/2 \rfloor}$. ✓ (✎: run the telescoping for $n = 5$ by hand — starts $1, 4, 5$ at levels $0, 1, 2$, total $10 = \binom{5}{2}$.)

Sperner, second proof. An antichain meets each chain at most once, so $|\mathcal{F}| \le \text{number of chains} = \binom{n}{\lfloor n/2 \rfloor}$. $\blacksquare$ Same bound, and now the extremal structure is vivid: the middle level works because it is a full transversal of the chains — one set per chain, no waste.

1.3 Erdős's generalization: banning chains of length $k+1$ (full)

Suppose $\mathcal{F}$ contains no $k+1$ pairwise comparable sets (an antichain is the $k = 1$ case). Both proofs adapt, and the SCD route needs no exchange argument.

Weighted LYM (P2). A maximal chain meets $\mathcal{F}$ in at most $k$ members — the members along one chain are pairwise comparable, and $k + 1$ of them would make a chain of length $k + 1$. The pair-counting of §1.1 now reads $\sum_{A \in \mathcal{F}} |A|!(n - |A|)! \le k \cdot n!$, i.e.

$$\sum_{A \in \mathcal{F}} \frac{1}{\binom{n}{|A|}} \le k.$$

The size bound, via the SCD. Each chain $c$ contributes at most $\min(k, |c|)$ members — a chain of length $|c|$ can host at most $|c|$ members anyway, and more than $k$ would make a $(k+1)$-chain:

$$|\mathcal{F}| \le \sum_{c} \min(k, |c|).$$

Now evaluate the sum. Write $\min(k, |c|) = \sum_{j=1}^{k} [|c| \ge j]$. A symmetric chain starting at level $r$ has length $|c| = n - 2r + 1$, so $|c| \ge j$ holds iff $r \le \lfloor (n + 1 - j)/2 \rfloor$. Summing over chains and telescoping exactly as in §1.2 (for each $j \le n + 1$, the number of chains starting at level $\le \lfloor (n + 1 - j)/2 \rfloor$ is $\binom{n}{\lfloor (n + 1 - j)/2 \rfloor}$):

$$\sum_{c} \min(k, |c|) = \sum_{j=1}^{k} \binom{n}{\lfloor (n + 1 - j)/2 \rfloor} \quad \text{— the } k \text{ middle binomial coefficients.}$$

Indeed, as $j$ runs from $1$ to $k$ (for $k \le n + 1$), the index $m_j = \lfloor (n + 1 - j)/2 \rfloor$ steps down through $\lfloor n/2 \rfloor, \lfloor (n-1)/2 \rfloor, \dots$; whenever the same value $m$ appears twice (for consecutive $j$ where $n + 1 - j$ is odd and then even), using the level symmetry $\binom{n}{m} = \binom{n}{n - m}$ pairs one copy of $\binom{n}{m}$ with level $m$ and the other with its complementary level $n - m$, so the sum is the exact sum of the sizes of the $k$ middle levels of $2^{[n]}$.

Sharpness. Any union of $k$ levels of $2^{[n]}$ contains no chain of length $k + 1$ — a chain can take at most one set per level — and choosing the $k$ middle levels achieves the exact sum $\sum_{j=1}^{k} \binom{n}{\lfloor (n + 1 - j)/2 \rfloor}$. $\blacksquare$

For $n = 4, k = 2$: bound $6 + 4 = 10$, achieved by levels $1$ and $2$ (or levels $2$ and $3$). For $n = 5, k = 2$: $10 + 10 = 20$, achieved by levels $2$ and $3$. The exhaustive census in the lab confirms these maxima over all families, not just the constructions, for $n = 4$ and every $k$.

1.4 What to learn

LYM is a weighted pigeonhole: every set costs at least the middle-level price $1/\binom{n}{\lfloor n/2 \rfloor}$, and the total budget is $1$. The SCD converts the same statement into an unweighted one — one member per chain — which is why it survives the generalization to banned long chains so gracefully. And the doubling construction is worth remembering as a pattern: build the recursive object explicitly, then let the counting verify it. Dozens of theorems in extremal set theory are LYM in disguise; the next lecture shows the master example.

Lecture 2 · Bollobás's Two-Families Theorem

Problem. Pairs of sets $(A_1, B_1), \dots, (A_m, B_m)$ with $A_i \cap B_i = \emptyset$ for all $i$, and $A_i \cap B_j \ne \emptyset$ for all $i \ne j$. Write $a_i = |A_i|$ and $b_i = |B_i|$. Then

$$\sum_{i=1}^{m} \frac{1}{\binom{a_i + b_i}{a_i}} \le 1.$$

2.1 The permutation proof (P2, full)

Take a uniform random permutation of the ground set $X = \bigcup_{i=1}^m (A_i \cup B_i)$ and let $E_i$ be the event that all of $A_i$ precedes all of $B_i$ in it. Among the $a_i + b_i$ relevant elements of $A_i \cup B_i$, every relative order is equally likely, and the orders that work are exactly those with the $a_i$ elements of $A_i$ first; so

$$\mathbb{P}(E_i) = \frac{a_i! \, b_i!}{(a_i + b_i)!} = \frac{1}{\binom{a_i + b_i}{a_i}}.$$

The events are disjoint. Suppose $E_i$ and $E_j$ both hold for $i \ne j$. By hypothesis pick $x \in A_i \cap B_j$ and $y \in A_j \cap B_i$ (both intersections are nonempty). Event $E_i$ forces every element of $A_i$ before every element of $B_i$ — in particular $x$ before $y$. Event $E_j$ forces every element of $A_j$ before every element of $B_j$ — in particular $y$ before $x$. No permutation does both. $\blacksquare$

So $\mathbb{P}(\bigcup_{i=1}^m E_i) = \sum_{i=1}^m \mathbb{P}(E_i) \le 1$ — the theorem. $\blacksquare$ Complete, and short enough to hold in your head.

2.2 LYM as a corollary (P17, full)

Given an antichain $\mathcal{F} \subseteq 2^{[n]}$, set $A = A$ and $B = [n] \setminus A$ for each member $A \in \mathcal{F}$. Then $A \cap B = \emptyset$ ✓. Incomparability says $A \setminus A' \ne \emptyset$ and $A' \setminus A \ne \emptyset$ for distinct members $A, A' \in \mathcal{F}$ — that is, $A \cap B' = A \setminus A' \ne \emptyset$ and $A' \cap B = A' \setminus A \ne \emptyset$ ✓. Bollobás applies with $a + b = n$:

$$\sum_{A \in \mathcal{F}} \frac{1}{\binom{n}{|A|}} \le 1$$

— the LYM inequality, and Sperner follows as in §1.1. One theorem, three shadows (Bollobás, LYM, Sperner); the pattern-index dream, live.

2.3 Tightness, saturation, and a warning

Tight. Let the ground set be $[m]$ and take the $m$ pairs $A_i = \{i\}$, $B_i = [m] \setminus \{i\}$. Then $A_i \cap B_i = \emptyset$ ✓, and for $i \ne j$ the element $i$ lies in $A_i \cap B_j$ ✓. The sum is $m \cdot 1/\binom{m}{1} = 1$ — exactly $1$. The lab verifies this and an exhaustive sweep of small instances; the bound is never exceeded and is attained by the star-like arrangements.

A warning about weakenings. If you keep only the “forward” cross-conditions $A_i \cap B_j \ne \emptyset$ for $i < j$ (dropping $i > j$), the theorem as stated is false — the sum can exceed $1$: take $A_1 = \{1\}, B_1 = \emptyset$ and $A_2 = \{2\}, B_2 = \{1\}$. The forward condition $A_1 \cap B_2 = \{1\} \ne \emptyset$ holds, yet $1/\binom{1}{1} + 1/\binom{2}{1} = 3/2$. And the obvious rescue attempt fails too: keeping the sizes small does not help. On $[3]$ the pairs $(A_1, B_1) = (\{1\}, \{2\})$, $(A_2, B_2) = (\{2\}, \{1\})$, $(A_3, B_3) = (\{3\}, \{1, 2\})$ satisfy every skew condition and $A_i \ne \emptyset$ and $|A_i| \le |B_i|$ for all three, yet $\sum 1/\binom{|A_i| + |B_i|}{|A_i|} = 1/2 + 1/2 + 1/3 = \mathbf{4/3}$ (Exercise 10 asks you to verify this by hand). What survives is the honest landscape, stated in full in the Trick Bag: the uniform skew bound — all $|A_i| = a, |B_i| = b$ gives $m \le \binom{a+b}{a}$ (Frankl 1982; also Kalai 1984) — and, for non-uniform pairs on the ground set $[n]$, the Hegedüs–Frankl bound $\sum 1/\binom{|A_i| + |B_i|}{|A_i|} \le n + 1$ (2023), sharp at the complement pairs. The machine census is the referee: the exhaustive maxima are $n + 1$ with no hypotheses, $n$ with $A_i \ne \emptyset$, and $1, 4/3, 2$ at $n = 2, 3, 4$ under $A_i \ne \emptyset$ and $|A_i| \le |B_i|$ — the sum genuinely grows, and no size condition brings it back to $1$.

2.4 What to learn

Bollobás is the strongest form of the “one budget per witness” principle in this chapter: the budget $\sum 1/\binom{a+b}{a}$ is spent by pairs, and the witness arrangements are permutations. Note the asymmetry with L1: there, chains are deterministic objects counted twice; here, a single random permutation pays for every pair at once, and disjointness of events is the whole proof. When a problem hands you set pairs with a disjointness condition inside each pair and intersection conditions across pairs, this is the theorem to try first.

Lecture 3 · The Circle Method: Katona's Interval Lemma and EKR

Problem (Erdős–Ko–Rado). Let $\mathcal{F}$ be a family of $k$-subsets of $[n]$, pairwise intersecting, with $n \ge 2k$. Then $|\mathcal{F}| \le \binom{n-1}{k-1}$ — achieved by the star (all $k$-sets containing a fixed element).

The proof arranges $[n]$ on a circle at random and counts. The engine is a lemma about arcs, and this lecture proves it completely — including the mixed sub-case that the reference edition had to flag.

3.1 Arcs and their starts (P8, full)

Put the $n$ points on a circle $\mathbb{Z}_n$ and fix a clockwise direction. A $k$-arc is a set of $k$ consecutive points; identify it by its start. For two $k$-arcs with starts $s, t \in \mathbb{Z}_n$:

Claim. The arcs intersect $\Longleftrightarrow \operatorname{dist}(s, t) \le k - 1$.

Proof. ($\Leftarrow$) Say the clockwise distance from $s$ to $t$ is $d \le k - 1$ (the other case is symmetric). Then $t \equiv s + d \pmod{n}$ itself lies in the arc starting at $s$ (which covers $s, s + 1, \dots, s + k - 1 \pmod{n}$), and $t$ lies in its own arc. A shared point. ($\Rightarrow$) Let $z$ be a shared point of the two $k$-arcs starting at $s$ and $t$. Then $z \equiv s + u \pmod{n}$ and $z \equiv t + v \pmod{n}$ for integers $u, v \in \{0, 1, \dots, k - 1\}$. Subtracting gives $s - t \equiv v - u \pmod{n}$ with $-(k - 1) \le v - u \le k - 1$, so the cyclic distance between $s$ and $t$ is $\operatorname{dist}(s, t) = |v - u| \le k - 1$. $\blacksquare$

So an intersecting family of arcs is exactly a set $S \subseteq \mathbb{Z}_n$ of start points with pairwise cyclic distances $\le k - 1$. Geometry has become arithmetic on a cycle.

3.2 The interval lemma, complete (the mixed sub-case included)

Katona's interval lemma. If $S \subseteq \mathbb{Z}_n$ has pairwise cyclic distances $\le k - 1$, then $|S| \le k$. (Requires $n \ge 2k$.)

Proof. If $S = \emptyset$ the bound is trivial; otherwise fix an anchor $s_0 \in S$. Every other point of $S$ lies in the window $[s_0 - k + 1, s_0 + k - 1] \pmod{n}$ — the $2k - 1$ positions within cyclic distance $k - 1$ of $s_0$ — because all pairwise distances to $s_0$ are $\le k - 1$. (Here $n \ge 2k$ matters: $2k - 1 \le n - 1$, so the window's $2k - 1$ positions are all distinct on the cycle.) Split the window's interior into:

  • forward offsets $A = \{a \in [1, k - 1] : s_0 + a \in S\}$,
  • backward offsets $B = \{b \in [1, k - 1] : s_0 - b \in S\}$.

Take $a \in A$ and $b \in B$. The two points $s_0 + a$ and $s_0 - b$ have cyclic distance $\min(a + b, n - a - b)$. Now $a + b = k$ is forbidden: it would give cyclic distance $\min(k, n - k) = k > k - 1$ (using $n \ge 2k$). So no $a \in A$ pairs with any $b \in B$ at sum $a + b = k$:

$$A \cap (k - B) = \emptyset, \quad \text{where } k - B = \{k - b : b \in B\}.$$

Both $A$ and $k - B$ live inside the $k - 1$ slots $[1, k - 1]$, disjointly:

$$|A| + |B| = |A| + |k - B| \le k - 1, \quad \text{and} \quad |S| = 1 + |A| + |B| \le k. \quad \blacksquare$$

That is the whole proof — the “mixed sub-case” (forward and backward starts coexisting) is exactly the $A \cap (k - B) = \emptyset$ step, and it costs one line once the window and the reflected set $k - B$ are on the table. Without the reflection trick, the naive bound is $|A|, |B| \le k - 1$ each, giving $2k - 1$; the reflection $k - B$ is what fuses the two groups into one budget.

Figure 1 draws the proof: an equality configuration on the circle, the window, and the offset strip where $A$ and $k - B$ tile $[1, k - 1]$ disjointly.

The verification record checks the lemma exhaustively: for every $2k \le n \le 16$ ($k \ge 2$), the maximum size of a start set with pairwise distances $\le k - 1$ is exactly $k$ — $0$ violations across every subset of every cycle.

3.3 Equality: consecutive starts and the unique common point ($n > 2k$)

Equality analysis drives uniqueness, so we do it now, completely.

Lemma (structure of equality). Suppose $n > 2k$ and $|S| = k$ in the interval lemma. Then $S$ is a set of $k$ consecutive points of the cycle, and the $k$ arcs starting at $S$ share exactly one common point.

Proof. Equality gives $|A| + |B| = k - 1$ with $A$ and $k - B$ disjoint subsets of $[1, k - 1]$ — so they tile it: $A \sqcup (k - B) = [1, k - 1]$. The extra room $n \ge 2k + 1$ bans one more sum: $a + b = k + 1$ gives cyclic distance $\min(k + 1, n - k - 1)$, and $n - k - 1 \ge k$, so the distance is $\ge k > k - 1$ — forbidden. Hence also $A \cap (k + 1 - B) = \emptyset$.

Now let $b \in B$ with $b \ge 2$, and suppose $b - 1 \notin B$. From the tiling, $k - b + 1 = k - (b - 1) \notin k - B$, so $k - b + 1 \in A$. But $(k - b + 1) + b = k + 1$ — a forbidden sum with $b \in B$, contradicting $A \cap (k + 1 - B) = \emptyset$. So $B$ is downward-closed: $b \in B, b \ge 2 \implies b - 1 \in B$, i.e. $B = \{1, \dots, \beta\}$ for some $\beta \ge 0$ (with $B = \emptyset$ when $\beta = 0$). The tiling then forces $A = \{1, \dots, k - 1 - \beta\}$.

So $S = \{s_0\} \cup \{s_0 + 1, \dots, s_0 + k - 1 - \beta\} \cup \{s_0 - 1, \dots, s_0 - \beta\} = \{s_0 - \beta, \dots, s_0 + k - 1 - \beta\} \pmod{n}$: $k$ consecutive points on the cycle. Write these $k$ consecutive starts as $u_i \equiv s_0 - \beta + i \pmod{n}$ for $i = 0, 1, \dots, k - 1$, where the arc starting at $u_i$ is $A_{u_i} = \{u_i + r \pmod{n} : 0 \le r \le k - 1\}$. Every arc $A_{u_i}$ contains the point $z \equiv u_0 + (k - 1) \equiv s_0 + k - 1 - \beta \pmod{n}$, since $z \equiv u_i + (k - 1 - i) \pmod{n}$ and $0 \le k - 1 - i \le k - 1$. Conversely, any point in $A_{u_0}$ has the form $u_0 + r \pmod{n}$ with $0 \le r \le k - 1$ (and since $n > 2k > k$, these $k$ points are distinct modulo $n$). For any $r < k - 1$, its clockwise offset from $u_{k-1} \equiv u_0 + k - 1 \pmod{n}$ is $r - (k - 1) \equiv n - (k - 1 - r) \pmod{n}$. Because $1 \le k - 1 - r \le k - 1$ and $n \ge 2k + 1$, we have $n - (k - 1 - r) \ge n - (k - 1) \ge k + 2 > k - 1$, so $u_0 + r \pmod{n} \notin A_{u_{k-1}}$. Thus $A_{u_0} \cap A_{u_{k-1}} = \{z\}$, and the $k$ arcs share exactly one common point $z$. $\blacksquare$

At exactly $n = 2k$ the tiling still holds but the $(k + 1)$-ban disappears, and non-consecutive equality configurations exist: for $(n, k) = (6, 3)$, the starts $\{0, 2, 4\}$ give three pairwise-intersecting arcs with no common point — the lab census counts $8$ equality configurations there, $2$ of them non-consecutive; for $(8, 4)$ it counts $16$, of which $8$ are non-consecutive. The uniqueness theorem in the next lecture will have to treat $n = 2k$ separately, and it does.

3.4 EKR by double counting (P2, full)

Call a pair $(\sigma, A)$ a witness if $\sigma$ is a circular arrangement of $[n]$ (there are $(n - 1)!$ of them, modulo rotation) and $A \in \mathcal{F}$ appears as an arc of $\sigma$.

Per set. A fixed $k$-set $A$ is an arc of exactly $k!(n - k)!$ circular arrangements: treat $A$ as a single block — $k!$ internal orders of $A$, and $(n - k)!$ circular arrangements of the block together with the other $n - k$ elements.

Per arrangement. The $\mathcal{F}$-arcs of one circle $\sigma$ are pairwise intersecting ($\mathcal{F}$ is), so their starts have pairwise cyclic distances $\le k - 1$, so there are at most $k$ of them (Katona's interval lemma).

So $|\mathcal{F}| \cdot k!(n - k)! \le k \cdot (n - 1)!$, and dividing:

$$|\mathcal{F}| \le \frac{k \cdot (n - 1)!}{k!(n - k)!} = \frac{(n - 1)!}{(k - 1)!(n - k)!} = \binom{n - 1}{k - 1}. \quad \blacksquare$$

Tight. The star: all $k$-sets through a fixed point $x$ have size $\binom{n-1}{k-1}$ ✓ and are pairwise intersecting ✓.

3.5 What to learn

The circle method is double counting with a geometric engine: the interval lemma is what makes “per arrangement $\le k$” true, and its complete proof is a lesson in reflections — map the backward offsets by $b \mapsto k - b$ so both directions compete for the same $k - 1$ slots, and the mixed case dies of overcrowding. Watch where $n \ge 2k$ and $n \ge 2k + 1$ were used: the first makes the window non-degenerate and bans the sum $k$; the second bans $k + 1$ and unlocks the structure of equality. Hypotheses in extremal theorems are usually the exact fingerprints of the proof steps.

Lecture 4 · Uniqueness: Why Only Stars

EKR says $|\mathcal{F}| \le \binom{n-1}{k-1}$. The sharp question: who achieves equality? The answer: at $n = 2k$, many families; at $n > 2k$, only stars. This lecture proves both regimes completely: the $n = 2k$ complementary-pair characterization and the $n > 2k$ star-uniqueness theorem across the entire range $n \ge 2k + 1$.

4.1 Equality forces every circle to be full (full)

Lemma. $|\mathcal{F}| = \binom{n-1}{k-1} \Longleftrightarrow$ every circular arrangement $\sigma$ carries exactly $k$ $\mathcal{F}$-arcs.

Proof. The witness count of §3.4 is $|\mathcal{F}| \cdot k!(n - k)! = \sum_{\sigma} (\text{# of }\mathcal{F}\text{-arcs of }\sigma)$, and each term is $\le k$. Equality in the bound is equality in this count: since $\binom{n-1}{k-1} \cdot k!(n - k)! = k \cdot (n - 1)!$ exactly, $|\mathcal{F}|$ maximal forces the sum to reach its cap $k \cdot (n - 1)!$, which with every term $\le k$ forces every term to equal $k$. Conversely, if every circle carries $k$ $\mathcal{F}$-arcs, the double count recovers $|\mathcal{F}| = \binom{n-1}{k-1}$. $\blacksquare$

So an extremal family is rigid: on every single arrangement, its arcs must realize the interval lemma's equality case. Rigidity is what uniqueness proofs feed on.

4.2 What a full circle looks like (full)

For $n > 2k$, §3.3 applies to every circle $\sigma$: its $k$ $\mathcal{F}$-arcs start at $k$ consecutive points and share exactly one common point $z(\sigma)$. For $n = 2k$ this fails — non-consecutive configurations exist — which is why the two regimes must be separated, and why $n = 2k$ admits many extremal families:

Theorem (equality at $n = 2k$, complete). At $n = 2k$, a $k$-uniform intersecting family $\mathcal{F}$ is extremal ($|\mathcal{F}| = \binom{2k-1}{k-1}$) iff $\mathcal{F}$ contains exactly one set from each complementary pair $\{S, [2k] \setminus S\}$.

Proof. First, two members of $\mathcal{F}$ cannot be complementary (they would be disjoint), so $\mathcal{F}$ takes at most one set from each of the $\frac{1}{2}\binom{2k}{k} = \binom{2k-1}{k-1}$ pairs — that is the EKR bound in this regime, reproved. Conversely, if $\mathcal{F}$ takes exactly one from each pair it is automatically intersecting: two $k$-sets of $[2k]$ that are disjoint are complements of each other — the only way to fit $2k$ points into two disjoint $k$-sets — so they would form one of the pairs, and $\mathcal{F}$ never holds both ends of a pair. Size: $\binom{2k-1}{k-1}$ ✓. $\blacksquare$

For $(n, k) = (6, 3)$ the lab enumerates all of them: exactly $2^{10} = 1024$ maximum families, one per choice of one-from-each-complementary-pair — the $6$ stars among them, and $1018$ others; the census confirms both the count and that every one of the $1024$ choices really is intersecting. At $n > 2k$ the party ends, and the next section proves why.

4.3 The transport to a global center (complete for all $n \ge 2k+1$)

Theorem (EKR uniqueness for $n > 2k$, complete). Suppose $n \ge 2k + 1$ and $\mathcal{F} \subseteq \binom{[n]}{k}$ is pairwise intersecting with $|\mathcal{F}| = \binom{n-1}{k-1}$. Then $\mathcal{F} = \operatorname{star}(x^*)$ for some $x^* \in [n]$.

Proof. If $k = 1$, then $|\mathcal{F}| = \binom{n-1}{0} = 1$ and the single $1$-set is a star. Assume $k \ge 2$ and $n \ge 2k + 1$. By §4.1 and §3.3, on every circular arrangement $\sigma$ of $[n]$ the family $\mathcal{F}$ realizes exactly $k$ arcs, and these $k$ arcs start at $k$ consecutive positions of $\sigma$ and share a unique common point $z(\sigma)$ — specifically, if we label the circle positions $0, 1, \dots, n - 1$ clockwise with $z(\sigma)$ placed at position $0$, the $k$ $\mathcal{F}$-arcs of $\sigma$ are precisely the $k$ arcs containing position $0$:

$$A_i(\sigma) = \{\sigma(i), \sigma(i+1), \dots, \sigma(i+k-1)\} \quad \text{for } i \in \{-(k-1), -(k-2), \dots, 0\} \pmod{n}.$$

Fix a reference circular arrangement $\sigma_0$, let $x^* = z(\sigma_0)$, and represent every circular arrangement $\sigma$ by anchoring $x^*$ at position $0$, so $(\sigma(1), \sigma(2), \dots, \sigma(n-1))$ ranges over all $(n - 1)!$ permutations of $[n] \setminus \{x^*\}$. We prove that $z(\sigma) = x^*$ for every $\sigma$. Since the symmetric group on $\{1, 2, \dots, n - 1\}$ is generated by adjacent transpositions $\tau_m = (m, m + 1)$ for $1 \le m \le n - 2$, it suffices to show that if $z(\sigma) = x^*$, then $\sigma' = \sigma \circ \tau_m$ also satisfies $z(\sigma') = x^*$.

Suppose $z(\sigma) = x^*$, so $\sigma$ carries the $k$ $\mathcal{F}$-arcs $A_i(\sigma)$ for $i \in \{-(k-1), \dots, 0\}$. When we swap the adjacent positions $m$ and $m + 1$ (where $1 \le m \le n - 2$, so position $0$ is untouched), an arc $A_i(\sigma)$ changes as a set if and only if the swapped pair $\{m, m + 1\}$ straddles an endpoint of $A_i(\sigma)$. Since the left endpoint of $A_i(\sigma)$ lies in $\{n - k + 1, \dots, n - 1\} \cup \{0\}$ and the right endpoint lies in $\{0, 1, \dots, k - 1\}$:

  • If $1 \le m \le k - 1$, then $m \le k - 1 < n - k$ (as $n \ge 2k + 1$), so $\{m, m + 1\}$ cannot straddle any left endpoint and straddles the right endpoint of $A_i(\sigma)$ only when $i + k - 1 = m$, i.e. for the single arc $i = m - k + 1$. Thus the other $k - 1$ arcs $A_i(\sigma)$ ($i \ne m - k + 1$) are unchanged as sets: $A_i(\sigma') = A_i(\sigma) \in \mathcal{F}$.
  • If $k \le m \le n - k - 1$, then $\{m, m + 1\}$ lies strictly outside $[-(k-1), k-1] \pmod{n}$, so all $k$ arcs $A_i(\sigma)$ are unchanged: $A_i(\sigma') = A_i(\sigma) \in \mathcal{F}$.
  • If $n - k \le m \le n - 2$, then $\{m, m + 1\}$ straddles only the left endpoint $i \equiv m + 1 \pmod{n}$, so again at least $k - 1$ of the arcs $A_i(\sigma)$ are unchanged: $A_i(\sigma') = A_i(\sigma) \in \mathcal{F}$.

In every case, at least $k - 1$ of the $k$ arcs through position $0$ on $\sigma'$ already belong to $\mathcal{F}$:

  • If $k \ge 3$: whenever $1 \le m \le k - 2$ (or $n - k + 1 \le m \le n - 2$), both extreme arcs $A_{-(k-1)}(\sigma') = \{\sigma'(n-k+1), \dots, \sigma'(0)\}$ and $A_0(\sigma') = \{\sigma'(0), \dots, \sigma'(k-1)\}$ belong to $\mathcal{F}$. Their intersection on $\sigma'$ is the single point $\{\sigma'(0)\} = \{x^*\}$ (since $n \ge 2k + 1$). Because all $k$ $\mathcal{F}$-arcs of $\sigma'$ share the unique point $z(\sigma')$, we must have $z(\sigma') \in A_{-(k-1)}(\sigma') \cap A_0(\sigma') = \{x^*\}$, so $z(\sigma') = x^*$. What if $m = k - 1$, where the missing arc is $A_0(\sigma')$? Then $A_{-(k-1)}(\sigma'), \dots, A_{-1}(\sigma') \in \mathcal{F}$, so the $k$ consecutive $\mathcal{F}$-arcs of $\sigma'$ must either be $\{A_{-(k-1)}(\sigma'), \dots, A_0(\sigma')\}$ (giving $z(\sigma') = x^*$) or $\{A_{-k}(\sigma'), A_{-(k-1)}(\sigma'), \dots, A_{-1}(\sigma')\}$, where $A_{-k}(\sigma') = \{\sigma'(n-k), \dots, \sigma'(n-1)\}$. In the latter case $A_{-k}(\sigma') \in \mathcal{F}$; but $m = k - 1 \le n - k - 2$ (since $n \ge 2k + 1$), so $\tau_{k-1}$ does not touch positions $\{n - k, \dots, n - 1\}$, meaning $A_{-k}(\sigma') = A_{-k}(\sigma)$ was already an $\mathcal{F}$-arc on $\sigma$ — contradicting the fact that $\sigma$ has only $k$ $\mathcal{F}$-arcs! By symmetry, $m = n - k$ (missing $A_{-(k-1)}(\sigma')$) is ruled out because $\tau_{n-k}$ does not touch positions $\{1, \dots, k\}$ ($k < n - k$ as $n \ge 2k + 1$), so $A_1(\sigma') = A_1(\sigma) \notin \mathcal{F}$.
  • If $k = 2$: for $m = 1$, $A_{-1}(\sigma') = \{\sigma(n-1), x^*\} \in \mathcal{F}$, and the second $\mathcal{F}$-arc on $\sigma'$ is either $A_0(\sigma') = \{x^*, \sigma(2)\}$ (giving $z(\sigma') = x^*$) or $A_{-2}(\sigma') = \{\sigma(n-2), \sigma(n-1)\}$. Since $n \ge 5$, position $1$ is disjoint from $\{n - 2, n - 1\}$, so $A_{-2}(\sigma') = A_{-2}(\sigma) \notin \mathcal{F}$; hence $z(\sigma') = x^*$. Symmetrically, for $m = n - 2$, $A_0(\sigma') = \{x^*, \sigma(1)\} \in \mathcal{F}$ and $A_1(\sigma') = \{\sigma(1), \sigma(2)\} = A_1(\sigma) \notin \mathcal{F}$ (as $n - 2 \ge 3$), so $z(\sigma') = x^*$.

Thus $z(\sigma) = x^*$ for every circular arrangement $\sigma$. Finally, every $U \in \mathcal{F}$ appears as an arc of at least one circular arrangement $\sigma$, and every $\mathcal{F}$-arc of $\sigma$ contains $z(\sigma) = x^*$; therefore $x^* \in U$ for all $U \in \mathcal{F}$. Thus $\mathcal{F} \subseteq \operatorname{star}(x^*)$, and $|\mathcal{F}| = \binom{n-1}{k-1} = |\operatorname{star}(x^*)|$ forces $\mathcal{F} = \operatorname{star}(x^*)$. $\blacksquare$

Historical note and census check. Katona's original 1972 block-circle transport fixes a $k$-set $T \in \mathcal{F}$ as a contiguous block and permutes the $n - k$ outside elements, which directly covers $n \ge 3k - 2$ and leaves the “thin range” $2k < n \le 3k - 2$ to either the position-$0$ transposition argument above or the Kruskal–Katona shadow-cascade uniqueness proof in Chapter 9. The lab census confirms star uniqueness exhaustively wherever brute force reaches: $(5, 2)$ has $5$ maximum families (all stars), $(7, 3)$ has $7$ (all stars), $(8, 3)$ has $8$ (all stars), and Exploration 13 probes $(9, 4)$.

4.4 What to learn

Uniqueness proofs are rigidity arguments: equality in a double count forces every local configuration to be extremal too, and extremal local configurations are so constrained that a global structure falls out. The gap between “every circle has a common point $z(\sigma)$” and “one point $x^*$ serves every circle” is closed by connectedness under local moves: anchoring $x^*$ at position $0$ and applying a single adjacent transposition on the remaining $n - 1$ positions leaves at least $k - 1$ of the $k$ arcs through position $0$ intact, and the room $n \ge 2k + 1$ prevents the missing arc from sliding off position $0$ into a position untouched by the swap. When you meet a uniqueness claim in the wild, ask: what is being double-counted, and how do local moves connect the extremal witnesses?

Lecture 5 · Shifting: Deforming Families Toward the Star

The circle method proves EKR by averaging over arrangements. Shifting takes the opposite philosophy: deform the family itself toward a canonical shape, without changing its size or losing the intersecting property — and read the theorem off the deformed family (P23).

5.1 The $(i, j)$-shift (definition)

For $1 \le i < j \le n$, the shift $S_{ij}$ replaces a set $A \in \mathcal{F}$ containing $j$ but not $i$ by $A' = (A \setminus \{j\}) \cup \{i\}$ — swapping the larger element for a smaller one — provided the target $A'$ is not already in $\mathcal{F}$; if $A' \in \mathcal{F}$, then $A$ stays put — and leaves every other set alone. Applied to a family: $S_{ij}(\mathcal{F}) = \{S_{ij}(A) : A \in \mathcal{F}\}$. The proviso is what keeps the image a set of the same cardinality: no duplicate can arise, because a set is only ever replaced by a target absent from the family. A family is shifted (or left-compressed) when no shift changes it: whenever $A \in \mathcal{F}$, $j \in A$, $i \notin A$, and $i < j$, then also $(A \setminus \{j\}) \cup \{i\} \in \mathcal{F}$.

Size is preserved (full). A shift fires only when the target set is absent from $\mathcal{F}$, so the map $A \mapsto S_{ij}(A)$ is injective on $\mathcal{F}$: two sets cannot collapse onto one target, because an unshifted set is its own image in $\mathcal{F}$ and a shifted set's image is not in $\mathcal{F}$ (and determines its preimage uniquely by swapping $i$ back to $j$). So $|S_{ij}(\mathcal{F})| = |\mathcal{F}|$, and $k$-uniformity is preserved because every image has the same size as its source. ✓

5.2 Intersecting is preserved (full)

Suppose $\mathcal{F}$ is $k$-uniform and intersecting, and let $C, D \in S_{ij}(\mathcal{F})$ be disjoint — we derive a contradiction.

Both cannot contain $i$ (they would meet at $i$), so one of them, say $C$, misses $i$. Any shifted image contains $i$, so $C$ was not shifted: $C \in \mathcal{F}$ with $i \notin C$. If $D \in \mathcal{F}$ too, then $C \cap D = \emptyset$ contradicts $\mathcal{F}$ being intersecting. Hence $D \notin \mathcal{F}$, which means $D$ is a shifted copy: $D = (D^* \setminus \{j\}) \cup \{i\}$ for some $D^* \in \mathcal{F}$ with $j \in D^*$ and $i \notin D^*$. Since $C \cap D = \emptyset$ and $D \setminus \{i\} = D^* \setminus \{j\}$, the unshifted part of $D^*$ misses $C$ entirely: $C \cap (D^* \setminus \{j\}) = \emptyset$.

Case $j \notin C$. Then $C \cap D^* = (C \cap (D^* \setminus \{j\})) \cup (C \cap \{j\}) = \emptyset \cup \emptyset = \emptyset$ — two members $C, D^* \in \mathcal{F}$, disjoint. Contradiction.

Case $j \in C$. Then $C \in \mathcal{F}$ has $j \in C$ and $i \notin C$, and $C$ survived the shift unmoved — which happens only when its own shift target $C' = (C \setminus \{j\}) \cup \{i\}$ was already present in $\mathcal{F}$. Now compute $C' \cap D^*$: every piece is empty — $i \notin D^*$ (since $D^*$ was shifted); $j \notin C'$ (removed by the shift); and $(C \setminus \{j\}) \cap (D^* \setminus \{j\}) \subseteq C \cap (D^* \setminus \{j\}) = \emptyset$. So $C' \cap D^* = \emptyset$ with $C', D^* \in \mathcal{F}$. Contradiction. $\blacksquare$

The proof is a template for every shifting-preservation argument in the field: chase which of the conflicting sets were actually moved, split on whether the shift's target was already present, and land the contradiction back in the original family.

5.3 Termination and the closing induction (full)

Shifting terminates. Each effective shift strictly decreases the total weight $w(\mathcal{F}) = \sum_{A \in \mathcal{F}} \sum_{x \in A} x$ — each swap replaces $j$ by $i < j$ — and $w(\mathcal{F})$ is a nonnegative integer. So after finitely many shifts the family is shifted, and it is still $k$-uniform, still intersecting, and still of size $|\mathcal{F}|$.

The closing induction for EKR (complete). Once $\mathcal{F} \subseteq \binom{[n]}{k}$ is shifted, we prove $|\mathcal{F}| \le \binom{n-1}{k-1}$ for all $n \ge 2k$ by induction on $n + k$. The base cases $k = 1$ ($|\mathcal{F}| \le 1 = \binom{n-1}{0}$) and $n = 2k$ ($|\mathcal{F}| \le \frac{1}{2}\binom{2k}{k} = \binom{2k-1}{k-1}$ by complementary pairs, §4.2) hold for all intersecting families without even shifting. Now suppose $k \ge 2$ and $n \ge 2k + 1$, and split the shifted family $\mathcal{F}$ on the largest element $n$:

$$\mathcal{F}_0 = \{A \in \mathcal{F} : n \notin A\} \subseteq \binom{[n-1]}{k}, \qquad \mathcal{F}_1 = \{A \setminus \{n\} : n \in A \in \mathcal{F}\} \subseteq \binom{[n-1]}{k-1}.$$

First, $\mathcal{F}_0$ is a $k$-uniform intersecting family on $[n - 1]$, and since $n \ge 2k + 1$ we have $n - 1 \ge 2k$, so the induction hypothesis for $(n - 1, k)$ gives $|\mathcal{F}_0| \le \binom{n-2}{k-1}$.

Second, we claim that $\mathcal{F}_1$ is a $(k - 1)$-uniform intersecting family on $[n - 1]$ (where $n - 1 \ge 2(k - 1)$ holds automatically). Suppose for contradiction that $B_1, B_2 \in \mathcal{F}_1$ are disjoint. Then $A_1 = B_1 \cup \{n\}$ and $A_2 = B_2 \cup \{n\}$ belong to $\mathcal{F}$ and meet only at $n$: $A_1 \cap A_2 = \{n\}$. Their union inside $[n - 1]$ has size $|B_1 \cup B_2| = (k - 1) + (k - 1) = 2k - 2 \le n - 3$ (since $n \ge 2k + 1$). Hence there is an element $i \in [n - 1] \setminus (B_1 \cup B_2)$. Because $\mathcal{F}$ is shifted and $i < n$ with $n \in A_1$ and $i \notin A_1$, the shifted set $A_1' = (A_1 \setminus \{n\}) \cup \{i\} = B_1 \cup \{i\}$ must also belong to $\mathcal{F}$. Wait: $A_1' \cap A_2 = (B_1 \cup \{i\}) \cap (B_2 \cup \{n\}) = \emptyset$ because $B_1 \cap B_2 = \emptyset$, $i \notin B_2 \cup \{n\}$, and $n \notin B_1 \cup \{i\}$. That gives two disjoint sets $A_1', A_2 \in \mathcal{F}$ — contradiction! Thus $\mathcal{F}_1$ is indeed intersecting, so the induction hypothesis for $(n - 1, k - 1)$ gives $|\mathcal{F}_1| \le \binom{n-2}{k-2}$. Adding the two parts via Pascal's identity closes the induction:

$$|\mathcal{F}| = |\mathcal{F}_0| + |\mathcal{F}_1| \le \binom{n-2}{k-1} + \binom{n-2}{k-2} = \binom{n-1}{k-1}. \quad \blacksquare$$

Notice why splitting on the top element $n$ (rather than $1$) is so clean: the sets avoiding $n$ already live on $[n - 1]$, and shiftedness lets us swap $n$ down to a free element $i \in [n - 1]$ whenever two sets through $n$ try to meet only at $n$. In Chapter 9's shadow lecture you will meet a third complete proof of EKR — Daykin's complement mirror, which applies Kruskal–Katona directly to the complement family.

5.4 What to learn

Shifting is the most portable deformation tool in extremal set theory: it preserves size and uniformity automatically, and with modest case analysis it preserves intersecting-ness, cross-intersecting-ness, and most “forbidden configuration” properties. And once a family is shifted, peeling the largest coordinate $n$ reduces $(n, k)$ directly to $(n - 1, k)$ and $(n - 1, k - 1)$ with Pascal's identity paying the sum. Its philosophy (canonical forms first, counting second) complements the circle method's (averaging first, structure second). The lab verifies preservation and termination exhaustively on $[4]$ and $[6]$; every family shifts to stability with size, uniformity, and intersecting-ness intact.

    return best

def shift_ij(F, i, j):                        # (i, j)-shift on a family of frozensets
    out = set()
    for A in F:
        if j in A and i not in A:
            target = (A - {j}) | {i}
            out.add(target if target not in F else A)
        else:
            out.add(A)
    return frozenset(out)

def full_shift(F, n):
    cur = frozenset(F)
    while True:
        nxt = cur
        for i, j in combinations(range(1, n + 1), 2):
            nxt = shift_ij(nxt, i, j)
        if nxt == cur: return cur
        cur = nxt

A1. View the $2$-subsets of $[5]$ as the edges of $K_5$: a pairwise-intersecting family is a set of edges no two of which are disjoint. If every two edges share the same vertex, the family sits inside a star — at most $4 = \binom{4}{1}$ edges. Otherwise two edges $\{v, a\}, \{v, b\}$ share $v$ and some edge avoids $v$; to meet both it must be $\{a, b\}$ — the triangle. Any further edge must then meet all three triangle edges: through $v$ it fails on $\{a, b\}$ unless it is one of $\{v, a\}, \{v, b\}$; avoiding $v$ it must sit inside $\{a, b\}$ — $\{a, b\}$ itself. So a non-star family caps at the triangle's $3$ edges, and the maximum is $4$, attained exactly by the five stars. Machine check: the Part 2 census prints (5, 2): max 4, families 5.

A2. The complement map $S \mapsto [2k] \setminus S$ is an involution on the $k$-subsets with no fixed point ($S = \bar{S}$ would force $S = \emptyset$ by disjointness), so the $\binom{2k}{k}$ $k$-sets split into $\frac{1}{2}\binom{2k}{k}$ pairs; and $\frac{1}{2}\binom{2k}{k} = \binom{2k-1}{k-1}$ because $\binom{2k}{k} = \frac{2k}{k}\binom{2k-1}{k-1} = 2\binom{2k-1}{k-1}$. Choosing one set per pair: two chosen sets $A, B$ cannot be disjoint — $B \subseteq \bar{A}$ would force $B = \bar{A}$ (both have size $k$), the very pair $A$ was chosen from. So every one-per-pair family is intersecting, of size $\binom{2k-1}{k-1} =$ the EKR bound: at $n = 2k$ the bound is attained by every such choice.

A3. For an antichain $A_1, \dots, A_m \subseteq [n]$ set $B_i = [n] \setminus A_i$. Then $A_i \cap B_i = \emptyset$, and for $i \ne j$: $A_i \cap B_j = A_i \setminus A_j$, which is nonempty because the family is an antichain — $A_i \subseteq A_j$ is forbidden, so $A_i$ has an element outside $A_j$ (and symmetrically $A_j \cap B_i = A_j \setminus A_i \ne \emptyset$). Bollobás gives $\sum_{i=1}^m 1/\binom{|A_i| + (n - |A_i|)}{|A_i|} = \sum_{i=1}^m 1/\binom{n}{|A_i|} \le 1$: LYM. For a merely intersecting family the cross-intersection hypothesis fails at comparable pairs: $A_i \subsetneq A_j$ makes $A_i \cap B_j = A_i \setminus A_j = \emptyset$ even when $A_i \cap A_j = A_i \ne \emptyset$ — intersection is not incomparability.

A4. Naive bound: pick any start $s_0 \in S$; every other start is within cyclic distance $k - 1$ of it (arcs intersect $\Longleftrightarrow$ start distance $\le k - 1$), so all starts lie in the window $\{s_0 - k + 1, \dots, s_0 + k - 1\}$: at most $2k - 1$ of them. The loss: the forward starts (offsets $A \subseteq [1, k - 1]$) and backward starts (offsets $B \subseteq [1, k - 1]$) are budgeted separately as $(k - 1) + 1 + (k - 1) = 2k - 1$. The sharp proof reflects the backward budget — $k - B$ lives in the same interval $[1, k - 1]$ as $A$, and the two are disjoint ($a + b = k$ would put two starts at cyclic distance $\min(k, n - k) = k > k - 1$), so $|A| + |B| \le k - 1$ and $|S| \le k$. One substitution, one budget: that is the entire content of the “mixed sub-case”.

A5. Let $\mathcal{F} \subseteq 2^{[n]}$ have no chain of length $k + 1$ ($1 \le k \le n + 1$), and write $x_j = |\mathcal{F} \cap \binom{[n]}{j}|$ for the level counts ($0 \le j \le n$). Each maximal chain $\emptyset = C_0 \subset C_1 \subset \dots \subset C_n = [n]$ meets $\mathcal{F}$ in at most $k$ sets, so the double count of $(C, A \in \mathcal{F} \cap C)$ gives the weighted LYM inequality $\sum_{j=0}^{n} x_j / \binom{n}{j} \le k$, together with the level capacity constraints $0 \le x_j \le \binom{n}{j}$. Order the $n + 1$ levels $j_1, j_2, \dots, j_{n+1}$ so that $\binom{n}{j_1} \ge \binom{n}{j_2} \ge \dots \ge \binom{n}{j_{n+1}}$; then $B_r = \binom{n}{j_r} = \binom{n}{\lfloor (n + 1 - r)/2 \rfloor}$ are the middle binomial coefficients from the inside out. For any feasible vector $(x_0, \dots, x_n)$, suppose there exist indices $r \le k < s$ with $x_{j_r} < B_r$ and $x_{j_s} > 0$. Since $B_r \ge B_s$, replacing $\delta = \min(B_r - x_{j_r}, x_{j_s}) > 0$ units of mass at level $j_s$ by $\delta$ units at level $j_r$ keeps the total count $\sum_{j=0}^n x_j$ unchanged, respects $0 \le x_j \le \binom{n}{j}$, and changes the LYM weight by $\delta (1/B_r - 1/B_s) \le 0$, so the LYM inequality remains satisfied. Repeating this finite exchange pushes all weight into the first $k$ levels $\{j_1, \dots, j_k\}$ until either no mass remains outside $\{j_1, \dots, j_k\}$ (in which case $\sum_{j=0}^n x_j = \sum_{r=1}^k x_{j_r} \le \sum_{r=1}^k B_r$) or every level $j_1, \dots, j_k$ is completely full ($x_{j_r} = B_r$ for $1 \le r \le k$), which spends the entire LYM budget $\sum_{r=1}^k B_r / B_r = k$ and forces $x_{j_s} = 0$ for all $s > k$. In both cases $|\mathcal{F}| = \sum_{j=0}^n x_j \le \sum_{r=1}^k \binom{n}{\lfloor (n + 1 - r)/2 \rfloor}$. A6. For $1 \le i < j \le n$, the $(i, j)$-shift $S_{ij}$ maps $A \in \mathcal{F}$ to $A' = (A \setminus \{j\}) \cup \{i\}$ when $j \in A$, $i \notin A$, and $A' \notin \mathcal{F}$, and fixes $A$ otherwise. Every image $S_{ij}(A)$ has $|S_{ij}(A)| = |A|$, preserving $k$-uniformity. To see injectivity on $\mathcal{F}$, suppose $S_{ij}(A) = S_{ij}(B)$ for $A, B \in \mathcal{F}$. If neither was moved, $A = B$; if both were moved, then $A = (S_{ij}(A) \setminus \{i\}) \cup \{j\} = B$; and if $A$ was moved while $B$ was fixed, then $S_{ij}(A) = A' \notin \mathcal{F}$ whereas $S_{ij}(B) = B \in \mathcal{F}$, impossible. Thus $|S_{ij}(\mathcal{F})| = |\mathcal{F}|$. Whenever $S_{ij}(\mathcal{F}) \ne \mathcal{F}$, at least one set $A \in \mathcal{F}$ is replaced by $A' = (A \setminus \{j\}) \cup \{i\}$, which changes $w(\mathcal{F}) = \sum_{A \in \mathcal{F}} \sum_{x \in A} x$ by $i - j < 0$ per moved set. Since $w(\mathcal{F})$ is a nonnegative integer, any sequence of nontrivial shifts terminates.
