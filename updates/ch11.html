Chapter 11 · Algorithms & Complexity of Combinatorics

Part of the Combinatorics & Graph Theory Atlas (see the Atlas canvas for the chapter map and progress report).

The Atlas has been running two engines since Chapter 2: proofs that things exist, and procedures that find them. This chapter asks the question both engines have been dodging: how fast can the procedure go? The answer splits combinatorics into three worlds, and the chapter walks all three. The easy world: greedy when the structure is a matroid (Kruskal is exact, and the chapter proves why), flows with costs (min-cost flow and the assignment problem, by successive shortest paths), and matching in general graphs — Edmonds' blossoms and Tutte's theorem, the backlog Chapter 5 honestly deferred, paid here in full. The hard world: NP-completeness, where the Atlas's favorite pattern — reduction — turns against us and proves that no fast algorithm exists at all, unless P = NP. The spine runs in full, 3-SAT through independent set, clique, and vertex cover, every step proved, every gadget machine-verified on its own body: the satisfiable instance's five assignments and twelve independent sets, the unsatisfiable instance's clean zero. The surviving world: what remains reachable when exactness is lost — approximation with guarantees. Greedy set cover within a harmonic number of optimal, and the proof that this is the best any polynomial algorithm can promise; the traveling salesman within 3/2 by Christofides, with the matching lemma machine-checked to exact tightness on a five-point instance; MaxCut within 0.878 by semidefinite programming, the exact constant computed, its optimality tied to the Unique Games Conjecture. And the final twist: hardness in n can coexist with tractability in k — vertex cover in $O(2^k \cdot (n+m))$, the bounded search tree that this chapter runs on all 33,866 labeled graphs up to six vertices, its worst case hitting the theory's bound of $2^{k+1} - 1$ nodes exactly. Every number in this chapter is machine-verified by the lab, proved in the text, or carries its source; the census counts are the chapter's own.

Notation. Lecture 1 · P, NP, and the Reduction Spine

Chapter 2 drew Euler circuits and Hamilton cycles side by side and promised (§5.3) that a later chapter would make their difference precise. Chapter 5 built matching and flow engines that always terminate, always certifiably. This lecture is the reckoning: a framework in which "no good algorithm exists" is a theorem, proved the same way as any other — by reduction, pattern P25 turned inside out. The spine runs from 3-SAT through independent set to clique to vertex cover, every reduction proved in full and every gadget run on the lab's two witness instances before being trusted. Then the twist that saves the chapter from despair: the same vertex cover that is NP-hard in n is solvable in time $O(2^k \cdot (n+m))$ when you only care about solutions of size at most k — and the census says the bound is honest, because the worst tree the lab ever grew hits it exactly.

1.1 What "hard" means

A decision problem is a question with a yes/no answer on each instance: does this graph have a Hamilton cycle, does this formula have a satisfying assignment. An algorithm is polynomial-time (polytime) if on instances of size n it halts within $O(n^c)$ steps for a fixed constant c. P is the class of decision problems solvable in polytime: the Euler test (parity and connectivity), shortest paths, maximum flow, matching — Chapters 2 and 5 built these.

NP is defined by certificates. A problem is in NP if every yes-instance has a proof, checkable in polytime, that convinces a skeptic. A Hamilton cycle instance answers "yes" exactly when someone can hand you the cycle — checking that the handed-over list visits every vertex once and uses only real edges is $O(n^2)$. A satisfying assignment checks in $O(m)$. A claimed perfect matching checks in $O(m)$. Note what this definition does not say: it says nothing about finding the certificate, only about checking one. That asymmetry — verification seems easy, discovery seems hard — is the entire subject.

A problem is NP-complete if (i) it is in NP, and (ii) every problem in NP reduces to it: for every NP problem A there is a polytime map carrying instances of A to instances of our problem, preserving the answer. If any NP-complete problem has a polytime algorithm, then every NP problem does — P = NP.

Theorem (Cook–Levin; statement). Satisfiability of Boolean formulas is NP-complete. Every problem in NP reduces to satisfiability in polynomial time. (Cook 1971, independently Levin; the reduction encodes the verifier's entire computation as a Boolean formula.)

Karp (1972) then showed that twenty-one natural problems — including clique, vertex cover, Hamilton cycle, and set cover — are NP-complete by direct reduction, and the industry was born: thousands of problems since, each hardness claim a reduction, each reduction a combinatorial construction you can check by hand. The Atlas's stance: a reduction is a proof like any other, and we run its gadgets through the machine before printing them. Whether P = NP is open — the Clay Mathematics Institute prices it at one million dollars — and nothing in this chapter depends on the answer being either way. The theorems have the honest form: unless P = NP, no polytime algorithm does X.

1.2 The spine, in full: 3-SAT $\to$ Independent Set $\to$ Clique $\to$ Vertex Cover

The spine deserves to be walked once with every joint visible. 3-SAT: given a formula in conjunctive normal form, m clauses, each a disjunction of exactly three literals (a variable or its negation), decide whether some assignment makes every clause true.

Theorem. 3-SAT reduces to Independent Set: there is a polytime map from 3-clause formulas to graphs such that the formula is satisfiable if and only if the graph has an independent set of size m.

Construction. For each clause, create a triangle: three fresh vertices, one per literal occurrence, all three edges present. Then connect every pair of complementary literal occurrences across the whole graph: every vertex labeled x is adjacent to every vertex labeled $\neg x$, wherever they sit. The graph has 3m vertices.

($\Leftarrow$) From an assignment to an independent set. Suppose the assignment satisfies the formula. From each clause pick one literal true under the assignment. The chosen vertices, one per clause, are m in number; no two sit in one triangle (one per clause, and within a clause all pairs are adjacent), and no two are complementary (both would have to be true, impossible). So they form an independent set of size m.

($\Rightarrow$) From an independent set to an assignment. An independent set of size m contains at most one vertex per triangle (within a triangle everything is adjacent), and there are m triangles, so it contains exactly one per clause. No complementary pair sits in the set, so reading the chosen labels gives a consistent partial assignment — set each variable true or false as its chosen occurrence demands. The chosen occurrence in each clause is true under this assignment, so every clause is satisfied. $\blacksquare$

The lab runs both directions on two witness instances before this chapter believed them. The satisfiable instance $(x \lor y \lor \neg z)(\neg x \lor y \lor z)(x \lor \neg y \lor z)$ has exactly 5 satisfying assignments (000, 011, 101, 110, 111 — every one of which yields an independent set by the construction) and exactly 12 independent sets of size 3 in its 9-vertex gadget — and all twelve pick one literal per clause, as the proof says they must: same-clause vertices are adjacent, so the shape is automatic. The unsatisfiable instance $(x \lor y)(\neg x \lor y)(x \lor \neg y)(\neg x \lor \neg y)$ — four 2-literal clauses, its gadget built the same way with edges in place of triangles — has 0 satisfying assignments and 0 independent sets of size 4. Two clean zeros: the equivalence is not a coincidence of small numbers.

✎ Checkpoint 1. Verify the unsatisfiable instance by hand first — four clauses, two cases: $x$ true forces $y$ true (from $\neg x \lor y$) and $y$ false (from $\neg x \lor \neg y$): contradiction; $x$ false forces $y$ true (from $x \lor y$) and $y$ false (from $x \lor \neg y$): contradiction again. Eight assignments, none surviving. Then convince yourself the gadget's $8$ vertices cannot host an independent set of size $4$ without the theorem: the four $2$-literal clauses form four disjoint edges, so any independent set of size $4$ must pick exactly one vertex from each clause-edge. Because complementary literals are joined by edges across the gadget, the chosen vertices can include at most one sign of $x$ (either $x$ or $\neg x$, never both) and at most one sign of $y$ (either $y$ or $\neg y$, never both) — at most two allowed literal labels in total. Since the four clauses exhaust all four sign pairs $(\pm x \lor \pm y)$, the unique clause whose two literals are the negations of the two allowed labels has neither of its vertices available, so at most three clauses can contribute a vertex and $\alpha(G) \le 3 < 4$.

From Independent Set to Clique is one word: complement. An independent set in G is a clique in the complement $\overline{G}$, edge for non-edge. So a polytime algorithm for clique would solve independent set.

From Clique to Vertex Cover is one identity, and the identity deserves its own line. Recall $\tau(G)$ is the minimum size of a vertex cover — a set touching every edge — and $\alpha(G)$ the maximum independent set.

Theorem (Gallai). $\alpha(G) + \tau(G) = n$ for every graph.

Proof. If S is independent, every edge has at least one endpoint outside S (both endpoints inside would be an edge inside S), so $V \setminus S$ is a vertex cover: $\tau \le n - \alpha$. Conversely if C is a vertex cover, no edge lies entirely inside $V \setminus C$, so $V \setminus C$ is independent: $\alpha \ge n - \tau$. Chain the two inequalities and the sandwich closes: $\alpha + \tau = n$. $\blacksquare$

So G has a clique of size k iff $\overline{G}$ has an independent set of size k iff $\overline{G}$ has a vertex cover of size n − k: a polytime algorithm for vertex cover would solve clique, hence independent set, hence 3-SAT. The spine is closed, and the lab verified Gallai's identity by brute force on all 33,866 labeled graphs on 2 to 6 vertices: zero violations. Three problems — one structure. That is the lesson of the spine, and it is P25 promoted from proof technique to worldview: the reduction does not just transport the answer, it declares the two problems the same problem wearing different signs.

1.3 Two more doors, and a census

Two NP-completeness statements complete the map this chapter needs; both are cited, not re-proved — their constructions are longer than the spine's and teach no new idea. 3-coloring (deciding whether a graph's vertices can be colored with three colors, adjacent vertices differently) is NP-complete: Stockmeyer 1973, with the now-standard simplified construction of Garey–Johnson–Stockmeyer 1976. Hamiltonian cycle is NP-complete (Karp 1972). Here is the Chapter 2 promise paid: no local, checkable criterion like Euler's parity condition can characterize Hamiltonicity, unless P = NP — because a polytime characterization would be a polytime algorithm for an NP-complete problem. The twins of §5.3 are twins no more.

Yet the news is not all subtraction, and one census puts the border on a map. Dirac's theorem (Chapter 2's Lecture 6) guarantees a Hamilton cycle whenever $n \ge 3$ and every degree is at least $n/2$, and the guarantee is certifiable: the tour is its own certificate, which is exactly why Hamiltonicity is in NP while non-Hamiltonicity has no known short certificate. The lab's census of all labeled graphs on five and six vertices: at n = 5, 26 Dirac graphs, all Hamiltonian, alongside 192 non-Dirac graphs that are Hamiltonian anyway and 806 that are not; at n = 6, 1,858 Dirac graphs, all Hamiltonian (zero exceptions, as the theorem demands), 8,220 non-Dirac Hamiltonian, 22,690 not. The hardness lives entirely in the wilderness below the Dirac line — the theorem is sufficient, genuinely not necessary, and NP-completeness is a statement about the wilderness, not about the guaranteed zone. Hardness theorems and sufficient conditions are not rivals; they are two answers to different questions, and the census shows the space between them is almost the whole space.

1.4 The twist: exponential in k, polynomial in n

Here is the paragraph that keeps this chapter from being a story about walls. Vertex cover is NP-hard in n — and easy in a different parameter. Suppose we only need to know whether $\tau(G)$ $\le$ k for a small k, and want the cover if so.

The bounded search tree. If any edge uv is uncovered, every vertex cover contains u or v — there is no third option. So: pick any uncovered edge uv, and branch: either u is in the cover (delete u, solve for k − 1) or v is (delete v, solve for k − 1). At a branch both children carry k − 1; when k reaches 0 with edges still uncovered, that leaf dies. The tree has depth at most k, branching factor 2, so at most $2^{k+1} - 1$ nodes, each doing $O(m)$ work: total time $O(2^k \cdot (n + m))$ plus the same to verify the result. Recurrence T(k) $\le$ 2T(k − 1) + $O(m)$, unrolled — pattern P4 with the induction sitting in the exponent.

The lab ran this exact procedure on all 33,866 labeled graphs on 2 to 6 vertices, k set to the true cover size. Every run returned a valid cover of optimal size. The census's worst tree: 31 nodes — exactly $2^{k+1} - 1$ at k = 4, attained by $K_6$ with one edge deleted (cover size 4; the missing edge creates a "wrong branch" that must be explored to exhaustion before the right one wins). The bound is not slack; the machine found its tight case on its own. This is the fixed-parameter tractability paradigm of Downey and Fellows: exponential in the parameter k, polynomial in the data n — a different contract than NP-hardness forbids, and for many atlas problems the honest one. The chapter's last lecture returns to what survives; the exercise set builds the tree by hand.

What to learn. Definitions that bite: NP is about checking, not finding. The spine is one structure seen three ways — the reductions are easy because the problems share a skeleton, and that shared skeleton is what resists speed. Gallai's $\alpha + \tau = n$ is the hinge. Hardness is a theorem with a proof you can audit, not an opinion. And the parameter world is real: $2^k \cdot n$ is a kind of polynomial, whenever k is small. One question runs the chapter: what exactly is the price of this problem, and in which currency?

Lecture 2 · Set Cover and the Harmonic Ceiling

Vertex cover's twin name haunts this lecture, but the problem is different and older than the spine: given a universe U of u elements and a family of sets, choose the fewest sets whose union is U. Set cover is NP-complete (Karp's original twenty-one), so we ask the surviving question: how well does the obvious algorithm do? The obvious algorithm is greedy: repeatedly take the set covering the most still-uncovered elements. This lecture proves the answer — greedy is within a factor $H_u = 1 + 1/2 + \dots + 1/u$ of optimal — and then proves the darker half: no polynomial algorithm can do substantially better, unless P = NP. The pair of theorems is the chapter's cleanest specimen of an approximation ceiling — a problem where the reachable guarantee is known exactly, and where the natural greedy turns out to be essentially the best possible.

2.1 The problem, the algorithm, and a census to keep us honest

An instance is a universe U with |U| = u and sets $S_1, \dots, S_t \subseteq U$ whose union is U. A cover is a subfamily with union U; OPT is the minimum cover size. Greedy: while uncovered elements remain, take the set adding the most new ones. Nothing could be more natural — and nothing about it promises anything. So the lab ran a census first: every covering system of at most three distinct nonempty sets over universes of size u = 1 to 5 — all 3,093 of them (1 + 5 + 45 + 361 + 2,681 by universe size) — computing greedy's picks against the true optimum, with ties broken toward the earliest set in the family's printed order. Result: zero violations of the bound this lecture is about to prove, and a maximum observed ratio of exactly 1.5 — witnessed by the family {[0,1], [0,2], [1,3]} on the universe {0,1,2,3}: greedy takes [0,1] (two new), then [0,2] (one new), then [1,3] (the last element) — three sets, while {[0,2], [1,3]} covers everything in two. Ratio 3/2, and 3/2 = $H_2$ exactly. The census says the bound is already tight at its floor; the theory to come will say the census never had a chance to violate it — and Exercise 4's ladder will show that the same census never had a chance to see the true ceiling either.

2.2 The harmonic bound, proved

Theorem (Chvátal 1979; Lovász 1975). Greedy set cover uses at most $H_d \cdot \mathrm{OPT}$ sets, where d is the size of the largest set — in particular at most $H_u \cdot \mathrm{OPT}$.

Proof (charging). Run greedy. When a greedy move covers c new elements, charge each of them cost 1/c; each greedy move then contributes exactly 1 to the total cost, so the total charge over all elements equals the number of sets greedy used.

Now fix an optimal cover $O_1, \dots, O_{\mathrm{OPT}}$, and prune it into a partition: assign every element of U to exactly one $O_i$ containing it, and let $O_i'$ be the elements assigned to $O_i$. The $O_i'$ are disjoint, their union is U, and $|O_i'| \le |O_i| \le d$. Claim: the total charge landing on $O_i'$ is at most $H_{|O_i'|}$.

Order $O_i'$'s elements $e_1, e_2, \dots, e_s$ by the time greedy covers them (every element gets covered — greedy ends with the universe covered). When greedy covers $e_j$, look at that moment: the elements of $O_i'$ not yet covered are $e_j, e_{j+1}, \dots, e_s$ — exactly $s - j + 1$ of them, all currently uncovered, all sitting in one set $O_i$. Greedy covers the most uncovered elements of any set, so its move covers at least $s - j + 1$ new elements: $c \ge s - j + 1$, and the charge to $e_j$ is at most $1/(s - j + 1)$. Summing over j = 1, …, s: the charge on $O_i'$ is at most $\sum_{j=1}^{s} 1/(s - j + 1) = H_s$. $\blacksquare$ (One line of averaging, pattern P10 — every element is priced by the crowd it arrived with.)

So greedy's count = total charge = $\sum_i (\text{charge on } O_i') \le \mathrm{OPT} \cdot H_d \le \mathrm{OPT} \cdot H_u$. For the record and the lab: $H_2 = 1.5$, $H_4 \approx 2.0833$, $H_8 \approx 2.7179$, $H_{16} \approx 3.3807$, $H_{32} \approx 4.0585$, $H_{100} \approx 5.1874$ — the harmonic numbers grow like ln u, so the honest slogan is greedy $\le$ ln u + 1.

✎ Checkpoint 1. Run the charging proof on the census's witness by hand: $\{[0,1], [0,2], [1,3]\}$ on $\{0,1,2,3\}$, greedy order $[0,1], [0,2], [1,3]$. Charges: $1/2$ each to elements $0$ and $1$ on the first move, then $1$ to element $2$ on the second move, then $1$ to element $3$ on the third move (total charge $1/2 + 1/2 + 1 + 1 = 3 =$ greedy's count). Under the optimal partition $O_1' = \{0, 2\}$ and $O_2' = \{1, 3\}$, each optimal piece has size $d = 2$ and receives charge $1/2 + 1 = 3/2 = H_2$, so the sharper bound $H_d \cdot \mathrm{OPT} = H_2 \cdot 2 = 3$ is tight with zero slack; the looser bound $H_4 \cdot \mathrm{OPT} \approx 2.0833 \times 2 \approx 4.17$ loses the extra $1.17$ entirely when weakening $H_d = H_2$ to $H_u = H_4$.

2.3 The ceiling is real

Two results convert the bound from a comfort into a complete answer.

First, the bound describes greedy exactly: Slavík (1996) pinned greedy's worst-case ratio at $\ln n - \ln \ln n + \Theta(1)$ — asymptotically tight for the algorithm itself, not just for the proof. The $H_u$ $\approx$ ln u shape is not slack in the analysis; it is the algorithm's true face.

Second, no polynomial algorithm can pass substantially below it: Dinur and Steurer (2014) proved that approximating set cover within $(1 - \varepsilon) \ln n$ is NP-hard for every $\varepsilon > 0$ — improving on the breakthrough threshold of Feige (1998), which reached the same barrier under the weaker assumption that NP has no quasi-polynomial algorithms. Read the two together: greedy achieves ln n + 1; the barrier says $(1 - \varepsilon) \ln n$ is unreachable; the additive gap is the constant 1 (and Slavík's $-\ln \ln n$ correction). Unless P = NP, no polynomial algorithm — however clever, however ungreedy — beats the natural heuristic by more than a lower-order term. This is the theorem form of the lore that hard problems have prices, and the price is sometimes posted exactly.

The census's $H_2$ witness shows the ceiling at its smallest scale: inside that tiny world — at most three sets, universes of at most five elements — greedy never beat 1.5 on any of the 2,166 opt-2 systems. Read that scope honestly: it is the small census's ceiling, not a bound in OPT. Exercise 4's ladder baits greedy to five sets at OPT = 2 on a sixteen-element universe (ratio 2.5), and it telescopes without end — the ceiling that is real is the harmonic one, priced in set sizes, which §2.2 proved. For contrast, keep vertex cover in mind from Lecture 1: there the best ratio is 2 (maximal matching's cover — the Chapter 5 backfill proved it), and improving to $2 - \varepsilon$ is impossible assuming the Unique Games Conjecture (Khot–Regev 2008) — a hardness claim one confidence level softer than set cover's, which Lecture 5 revisits.

2.4 What to learn

Greedy is an algorithm with a theorem attached: the charging argument is the whole proof, and it turns a heuristic into a guarantee. The harmonic number is the exact shape of the price. And the Dinur–Steurer barrier is the modern face of NP-hardness: hardness not of solving, but of approximating — proved, as always, by a reduction (P25 again, this time constructing instances whose optimums encode constraint satisfaction). The pattern to keep: when exactness dies, demand a ratio; when a ratio is achieved, ask whether the ceiling is lower.

Lecture 3 · Matroids: Where Greedy Is Exact

Set cover's greedy is a 1.5-factor sometimes-loser. Kruskal's greedy — sort edges by weight, take an edge if it does not close a cycle — is never wrong: it always returns a minimum spanning tree. Same algorithmic shape, opposite reliability. What exactly separates them? The answer is one of the most beautiful structures in combinatorics, and this lecture builds it: the matroid, the environment where greedy is provably exact, with a theorem (Rado–Edmonds) that closes the question in both directions.

3.1 Kruskal, and the question his algorithm begs

The lab's census first: all 770 connected labeled graphs on 3, 4, and 5 vertices (4 + 38 + 728 by size), each with seeded integer weights (1 to 100, drawn in edge order by the lab's Lehmer generator — Part 3 reproduces them bit-for-bit). For every graph, Kruskal's total weight was compared against an exhaustive minimum spanning tree. Agreements: 770 of 770. Zero mismatches. Kruskal's greedy is exact, always, and the census is the ritual before the theorem. The question: what property of "forests" makes greed infallible here and fallible for set cover?

3.2 The exchange axiom

An independence system on a ground set E is a family I of "independent" subsets with (I1) $\emptyset \in I$ and (I2) heredity: subsets of independent sets are independent. Forests of a graph (edge sets with no cycle) are the running example. A matroid adds the axiom that gives the lecture its title:

(I3) Exchange. If $A, B \in I$ with $|A| < |B|$, then some $e \in B \setminus A$ has $A \cup \{e\} \in I$.

Forests satisfy it — the lab verified the graphic matroid of $K_4$ exhaustively: 38 forests among the $64$ edge subsets, 463 ordered pairs $A, B$ with $|A| < |B|$, and every single pair admits an augmenting edge — zero counterexamples. The hand-sized instance to feel it: $A =$ the $2$-edge path $0\text{--}1\text{--}2$, $B =$ the $3$-edge star at $0$. $B \setminus A = \{0\text{--}2, 0\text{--}3\}$. Adding $0\text{--}2$ to $A$ closes the triangle $0\text{--}1\text{--}2$ — not independent. But $0\text{--}3$ does not: the star's second option saves the axiom. The proof that forests on $V$ always satisfy (I3) is an exact component count: a forest $F$ on $n = |V|$ vertices has exactly $c(F) = n - |F|$ connected components. Since $|A| < |B|$, the forest $(V, A)$ has strictly more connected components than $(V, B)$: $c(A) = n - |A| > n - |B| = c(B)$. If every edge $e \in B \setminus A$ had both endpoints inside the same connected component of $(V, A)$, then every edge of $B$ would lie inside a single $A$-component, so every $B$-component would be contained in a single $A$-component, forcing $c(B) \ge c(A)$ — a contradiction. Therefore at least one edge $e \in B \setminus A$ joins two distinct connected components of $(V, A)$, and adding $e$ to $A$ merges those two components without closing a cycle, so $A \cup \{e\} \in I$. The exercise set revisits this count from the vertex side.

The non-example earns its place in the lab too: the family $\{\emptyset, \{a\}, \{b\}, \{c\}, \{b, c\}\}$ is hereditary but fails exchange — A = {a}, B = {b, c}: neither b nor c augments {a}. One missing edge of the axiom; watch what it does to greedy in §3.3.

Two more examples to keep the concept honest: the uniform matroid (independent = all sets of size $\le$ k, every k-element set exchangeable); the partition matroid (a ground set split into blocks, independent = at most one element per block — matching's natural habitat, and Lecture 4's currency).

3.3 Rado–Edmonds: greedy optimal if and only if matroid

Theorem (Rado 1957; Edmonds). Let (E, I) be an independence system and consider weights $w: E \to \mathbb{R}$. Greedy (sort descending, take an element if it keeps the set independent) maximizes total weight over all independent sets for every nonnegative weight function if and only if (E, I) is a matroid. (Nonnegativity is the honest domain, and it is load-bearing: on the uniform matroid $U_{2,3}$ — independent = size $\le$ 2 — with weights (1, −5, −5), greedy takes the 1, then a −5 that keeps the set independent: total −4 against the optimum +1, the single weight-1 element. With negative weights in play, greedy fails on a genuine matroid — take-if-independent never refuses — and the theorem's domain is w $\ge$ 0.)

The "if" direction, proved. First, greedy's output G is maximal — it stops only when nothing augments — and in a matroid all maximal independent sets have the same size (the standard consequence of exchange: if $|A| < |B|$ both maximal, some e $\in$ $B \setminus A$ augments A, contradicting maximality). Fix r = |G| and let O be any independent set with |O| = r — an optimal solution, which exists because with weights nonnegative an optimum may be taken maximal (extending an independent set never lowers the total), and in a matroid all maximal independent sets share the size r = |G|; take O of maximum weight among size-r independent sets.

Claim: for every $k \le r$, the sum of greedy's first $k$ weights is at least the weight of any independent $k$-set. Induction on $k$. $k = 1$: greedy's first pick $g_1$ has maximum weight among all elements (any single element is independent by heredity from $\emptyset$). Step: let $A$ be any independent set with $|A| = k$; greedy's prefix is $B = \{g_1, \dots, g_{k-1}\}$, $|B| = k - 1 < k = |A|$. Exchange (I3) hands us an element $a \in A \setminus B$ with $B \cup \{a\}$ independent. By heredity (I2), every earlier prefix $B' \subseteq B$ also had $B' \cup \{a\} \in I$, so $a$ could not have been inspected and rejected before step $k$; thus at step $k$, $a$ was still available to greedy, and greedy chose the heaviest available element: $w(g_k) \ge w(a)$. By induction, $\sum_{i \le k-1} w(g_i) \ge w(A \setminus \{a\})$ (an independent $(k-1)$-set), hence $\sum_{i \le k} w(g_i) \ge w(A \setminus \{a\}) + w(a) = w(A)$. At $k = r$ this reads $\sum_{i \le r} w(g_i) \ge w(O)$: greedy is optimal. $\blacksquare$

The proof is the exchange axiom running forward in time — every greedy choice is certified against the eventual optimum at the moment it is made. That is what "greedy is exact" means mechanically, and why the axiom is exactly the right statement: P18 in its purest form, an algorithmic proof where the invariant is future-proof.

The "only if" direction, constructed. Suppose exchange fails: $A, B \in I$, $|A| < |B|$, no element of $B \setminus A$ augments $A$. Choose weights with $1 < c/c' < |B|/|A|$: weight $c$ on $A$'s elements, $c'$ on $B \setminus A$'s elements, and $0$ on $E \setminus (A \cup B)$. Greedy — which prefers the heavier class — takes all of $A$ (every subset of $A$ is independent by heredity), then tries $B \setminus A$ element by element: every attempt fails, by the failed exchange, and weight-$0$ elements add nothing. Greedy's total is therefore $c|A| < c'|B| \le c|B \cap A| + c'|B \setminus A| = w(B)$, the weight of the independent set $B$. Greedy is suboptimal for these weights. $\blacksquare$

The lab's witness is this construction with $|A| = 1, |B| = 2, c/c' = 3/2$: the family $\{\emptyset, \{a\}, \{b\}, \{c\}, \{b,c\}\}$ with weights a = 3, b = c = 2. Greedy takes a (weight 3); b fails ({a, b} is not in the family); c fails; total 3. Optimal: {b, c}, total 4. Machine-verified — and now understood: the failure of greedy is exactly the failure of the axiom, element for element. Set cover sits on the far side of this boundary: its greedy optimizes a moving target — elements newly covered, a different objective after every step — not a fixed weight function over an independence system, and no exchange-style structure survives to rescue it; the census's 3/2 witness is the smallest symptom of the difference.

One theorem more, stated: matroid intersection — the common independent sets of two matroids — is solvable in polynomial time (Edmonds), and bipartite matching is the intersection of two partition matroids (one per side of the bipartition, "at most one edge at each left vertex" $\cap$ "at most one at each right vertex"). The assignment problem of Lecture 4 is weighted bipartite matching — a hint of how far this theory reaches.

3.4 What to learn

The matroid axioms are not abstract decoration; they are the exact boundary of greedy's reliability, in both directions, with proofs that construct the correspondence edge by edge. Kruskal is exact because forests exchange; set cover is a 3/2-loser at OPT = 2 because its structure does not. When you meet a greedy algorithm in the wild, the honest first question is now: what is the independence system, and does it satisfy exchange? The answer decides whether you owe the world a proof of optimality or an apology with a ratio attached.

Lecture 4 · Flows with Costs: Successive Shortest Paths and the Assignment Problem

Chapter 5 moved flow: the maximum volume from s to t, with the min-cut theorem pricing the ceiling. This lecture adds a currency. Each arc now has a capacity and a cost per unit of flow, and the question becomes: send a prescribed value v from s to t as cheaply as possible. The engine is Chapter 5's residual network wearing a price tag, and the algorithm — successive shortest paths — is the cleanest example in the Atlas of a proof-carrying algorithm: at every moment it maintains a certificate that no cheaper flow of the same value exists.

4.1 The problem, and the engine

An instance is a directed network with arc capacities $c(e) \ge 0$ and costs w(e) (possibly negative — discounts are legal), a source s, a sink t, and a demand v. A feasible flow of value v respects conservation at every internal vertex and every capacity; the cost is $\sum f(e) \cdot w(e)$ over arcs. Min-cost flow: minimize cost.

The engine, successive shortest paths (SSP): start at the zero flow; while the value is below v, find a cheapest s–t path in the residual network — forward along each arc with unused capacity, at cost w(e); backward along each arc carrying flow, at cost −w(e), representing the right to change your mind and take a refund — and push as much as the path allows, capped by the remaining demand. Backward arcs are pattern P16's whole point: augmentation is not accumulation but correction, and the residual network keeps every correction available at its honest price.

The lab's witness network has nine arcs on five vertices (Part 4 prints them all): among them $0 \to 1$ (capacity 1, cost 1), two parallel arcs $0 \to 2$ (costs 3 and 1), two parallel $2 \to 3$ (costs 9 and 3), $1 \to 4$ (cost 4), $3 \to 4$ (capacity 1, cost 2), and a return arc $3 \to 0$. Demand 2. SSP's run, machine-verified end to end: the first shortest path is $0 \to 1 \to 4$ at cost 5, pushing the single unit of arc $0 \to 1$; the second is $0 \to 2$ (the cost-1 parallel) $\to$ $2 \to 3$ (the cost-3 parallel) $\to$ $3 \to 4$ at cost 6. Two iterations, total cost 11, final arc flows [1, 1, 0, 0, 1, 0, 1, 0, 1] — the two expensive-looking parallel arcs (costs 9 and 8) untouched, their cheap siblings used to capacity. Note what the greedy eye would have missed: the first unit's cheapest route costs 5, but the second unit's costs 6 — prices rise as the cheap capacity fills, and the algorithm that grabs shortest paths in the residual network is pricing exactly this changing market.

4.2 Why SSP is safe: integrality, termination, and the certificate

Three facts, each visible in the witness run.

Integrality. Every push moves the minimum of integer capacities along a path, so every arc flow stays an integer: min-cost flow with integer capacities has an integer optimum. (The Chapter 5 lesson, inherited wholesale — and the reason Lecture 4.3's assignment problem becomes a flow problem at all.)

Termination. Each iteration pushes at least 1 unit (integrality again, assuming integer capacities and demand), so at most v iterations: polynomial.

The optimality certificate (pattern P17). A feasible flow $f$ of value $v$ is minimum-cost if and only if its residual network $G_f$ contains no negative-cost directed cycle. In particular, if vertex potentials $d(\cdot)$ exist such that every residual arc $(u, w)$ of $G_f$ has nonnegative reduced cost $c_d(u, w) = c_f(u, w) + d(u) - d(w) \ge 0$, then $f$ is minimum-cost. To prove this, let $f'$ be any other feasible flow of the same value $v$. The difference $\Delta f = f' - f$ has net flow zero at every vertex (including $s$ and $t$, since both flows have value $v$) and respects the residual capacities of $G_f$ (putting $\Delta f(u, w) = f'(u, w) - f(u, w) > 0$ on forward residual arcs where $f' > f$, and $\Delta f(w, u) = f(u, w) - f'(u, w) > 0$ on backward residual arcs where $f' < f$). Thus $\Delta f$ is a nonnegative circulation in $G_f$, and its cost in $G_f$ is exactly $\mathrm{cost}(f') - \mathrm{cost}(f)$. Because every vertex has net inflow equal to net outflow under $\Delta f$, the telescoping sum $\sum_{(u,w) \in G_f} \Delta f(u, w)(d(u) - d(w))$ vanishes identically, so

$$\mathrm{cost}(f') - \mathrm{cost}(f) = \sum_{(u,w) \in G_f} \Delta f(u, w)\, c_f(u, w) = \sum_{(u,w) \in G_f} \Delta f(u, w)\, c_d(u, w) \ge 0,$$

since $\Delta f(u, w) \ge 0$ and $c_d(u, w) \ge 0$ on every residual arc. Hence $\mathrm{cost}(f') \ge \mathrm{cost}(f)$. The witness's final flow carries potentials $d = (-6, -4, -5, -2, 0)$ on vertices $0$ through $4$: every unsaturated forward arc has nonnegative reduced cost (the cost-$1$ arc $0 \to 2$ gets reduced cost exactly $0$, as do the used cost-$4$ and cost-$3$ arcs — the arcs a tight optimum must use), and every arc carrying flow has nonpositive reduced cost in the forward direction — the complementary-slackness picture in miniature, machine-checked arc by arc. SSP maintains such potentials by construction: it augments along shortest paths, so the shortest-path distances themselves serve as the next round's potentials — which is why the search must be Bellman–Ford and not Dijkstra whenever initial costs go negative.

The chapter's appendix records the wider census: forty designed feasible five-vertex networks, SSP against an exhaustive minimum on every one — 40 of 40 agreements, every final residual negative-cycle-free, on average 1.68 iterations.

4.3 The assignment problem, paid in flow

The assignment problem: n rows, n columns, a cost matrix; choose one cell per row and per column, minimizing the total. It is the oldest scheduled problem in optimization and the cleanest demonstration that a combinatorial question becomes a flow question the moment you draw the right picture.

The flow model: a source joined to each row (capacity 1, cost 0), each row joined to each column by an arc of capacity 1 and cost c(row, column), each column joined to the sink (capacity 1, cost 0). Flows of value n are exactly the legal assignments — integrality makes the 0/1 structure automatic — and min-cost flow of value n is the optimum assignment. The lab's worked witness is the matrix

whose optimum is 24, achieved by the permutation [1, 3, 0, 2] — row 0 takes column 1 (cost 11), row 1 takes column 3 (cost 3), row 2 takes column 0 (cost 8), row 3 takes column 2 (cost 2). SSP on the flow model found exactly this assignment in four augmentations, one per row, and the brute-force sweep over all 24 permutations agrees: 24 is optimal. The classical direct algorithm — the Hungarian method (Kuhn 1955) — solves the same problem by exactly these potentials, maintained by hand a decade before flow theory explained what they were. And the matroid lens of Lecture 3 explains the boundary: assignment is weighted bipartite matching, the intersection of two partition matroids, polynomial by Edmonds' intersection theory — the non-bipartite version is Lecture 6's mountain.

4.4 The frontier, honestly

Two statements record where the asymptotics stand, so the chapter does not teach its students a museum piece as if it were the news. For maximum flow: the preflow-push algorithm of Goldberg and Tarjan runs in $O(V^2 E)$ — the standard text bound, with faster special-purpose results known. And the genuine news: min-cost flow is solvable in almost-linear time — the 2022 breakthrough of Chen, Kyng, Liu, Peng, Probst Gutenberg, and Sachdeva (FOCS 2022), with a deterministic version in 2023 — "almost-linear" meaning within subpolynomial factors of the input size. The chapter still teaches SSP, and says why: SSP is the algorithm whose every run carries a checkable certificate (integrality, potentials, no negative cycle), whose proof is four paragraphs, and whose structure — the residual network as a market in past mistakes — is the idea that generalizes. The frontier algorithms trade that transparency for asymptotics; an Atlas reader should know both prices. What to learn. Costs ride the residual network; backward arcs price regret; potentials are duality made computable; integrality is the bridge between continuous-looking optimization and combinatorial objects; and the assignment problem was a flow problem all along, waiting for its picture to be drawn.

Lecture 5 · The Traveling Salesman, Priced: Approximation with Guarantees

Hardness, met honestly, changes the question rather than ending the conversation: if the exact optimum is out of reach, what can be guaranteed? This lecture builds the two classical guarantees for the metric traveling salesman — the factor 2 of the doubled tree and the factor 3/2 of Christofides, each proved in full — and then the modern cautionary tale: MaxCut's 0.878, the one approximation constant in this chapter you can compute to five decimals yourself, and the conjecture that says it cannot be beaten.

5.1 The doubling argument, and the factor 2

The traveling salesman problem: given n points with distances, find the cheapest tour visiting each once. It is NP-hard in brutal generality — set every distance to 1 and a cost-n tour exists exactly when the graph has a Hamilton cycle, so the spine of Lecture 1 already covers it — but the metric case (distances obeying the triangle inequality) is a different country, and its guarantees start from one observation:

Theorem. In the metric TSP, the minimum spanning tree has weight at most OPT.

Proof. Delete one edge from the optimal tour: what remains is a spanning path — connected, acyclic, visiting everything — hence a spanning tree, of weight OPT − (a nonnegative edge). The minimum spanning tree weighs no more. $\blacksquare$

The 2-approximation. Take a minimum spanning tree T, double every edge: all degrees become even, so the multigraph has an Euler circuit (the lab's Hierholzer walk — Chapter 2's splicing, upgraded to carry weights). Walk the circuit, and shortcut past revisited vertices: the triangle inequality makes each shortcut no dearer than the segment it replaces. The resulting tour costs at most the walk, which costs $2 \cdot w(T) \le 2 \cdot \mathrm{OPT}$. $\blacksquare$

The lab's census (Part 5): twelve instances — the witness plus eleven seeded, n = 5 to 8, lattice points drawn by the lab's Lehmer generator, Manhattan distances, exact optima by exhaustive permutation search. Every instance: 2-approx ratio $\le$ 2, worst observed 1.5 — practice runs far inside the guarantee, and the exercise set asks you to think about why. The chapter's witness instance — the five points (4,2), (5,0), (1,1), (0,5), (0,6) — has MST weight 13 and optimum 22, and the doubled-tree tour lands on cost 22: the ratio is exactly 1 here, the shortcutting luckiest possible. The guarantee is 2; the instance says do not confuse the worst case with the case.

5.2 Christofides: the odd vertices, matched

The doubling argument wastes half its material — every tree edge walked twice. Christofides' repair uses the matching theory of Chapter 5 at exactly one point.

The parity fact. The set of odd-degree vertices of any tree is even in size (the degree sum 2(n − 1) is even, so odd degrees pair off — pattern P9 as bookkeeping).

The matching lemma, proved. Let T be a minimum spanning tree, O its odd-degree vertex set, and let M be a minimum perfect matching on O. Then $w(M) \le \mathrm{OPT}/2$.

Proof. Take the optimal tour and read off the order in which it visits the vertices of $O$: $o_1, o_2, \dots, o_{2k}$, cyclically. The tour segments between consecutive $O$-vertices — the stretches of tour between $o_1$ and $o_2$, $o_2$ and $o_3$, and so on — number $2k$, and they partition the tour's edges. Now alternate: the odd-numbered segments form one perfect matching on $O$ (each $o_i$ reached by exactly one odd segment and left by one — the cyclic alternation guarantees the pairing is a genuine perfect matching), the even-numbered segments a second. By the triangle inequality, each matching's cost is at most the cost of its own segments; together the two matchings cost at most $\mathrm{OPT}$; so the cheaper one costs at most $\mathrm{OPT}/2$ — and the minimum matching $M$ costs no more. $\blacksquare$

The 3/2-approximation (Christofides 1976; Serdyukov 1978). Union T with the minimum perfect matching M on its odd vertices: connected, all degrees even — an Euler circuit exists. Walk it, shortcut: cost $\le$ $w(T) + w(M) \le \mathrm{OPT} + \mathrm{OPT}/2 = (3/2) \cdot \mathrm{OPT}$. $\blacksquare$

The lemma is exactly tight, and the lab's witness is the proof: the five-point instance above has odd set {1, 4} (vertices (5,0) and (0,6)), whose single-pair perfect matching costs |5 − 0| + |0 − 6| = 11 = OPT/2 exactly — the tour's two O-segments both cost 11, both matchings tie, and there is no slack anywhere. Yet the resulting Christofides tour costs 24 (ratio 24/22 $\approx$ 1.091): the tight lemma, the comfortable final guarantee. Across the twelve-instance census: perfect matching $\le$ OPT/2 with 12 of 12 holding, worst Christofides ratio 1.125, odd sets even every time. For forty-five years 3/2 stood as the final word; in 2021 Karlin, Klein, and Oveis Gharan crossed it — a randomized algorithm with expected ratio 3/$2 - \varepsilon$ for an $\varepsilon > 10^{-36}$ (yes, thirty-six zeros: the first improvement, and a hair's width). Deterministically, 3/2 is still the frontier.

✎ Checkpoint 1. Compute the witness instance's MST by hand (Prim from $(4,2)$ works; the answer is $13$ with odd vertices $(5,0)$ and $(0,6)$) and verify the matching arithmetic: $|5-0| + |0-6| = 11$, twice $11 = 22 = \mathrm{OPT}$. The lemma's proof needs the cyclic order of $O$ along the tour because the $2k$ vertices $o_1, o_2, \dots, o_{2k}$ divide a closed cycle into $2k$ edge-disjoint segments (including the wrap-around segment from $o_{2k}$ back to $o_1$), which split into two complete matchings of $k$ pairs each: $\{o_1 o_2, \dots, o_{2k-1} o_{2k}\}$ and $\{o_2 o_3, \dots, o_{2k} o_1\}$. A merely linear path from $o_1$ to $o_{2k}$ has only $2k - 1$ segments, so its even-numbered segments leave $o_1$ and $o_{2k}$ unpaired and fail to form a second perfect matching on $O$.

5.3 MaxCut and the exact constant 0.878

One more problem, the modern emblem of approximation theory. MaxCut: split a graph's vertices into two camps to maximize the number of edges crossing. NP-hard (statement). The trivial floor: cut each vertex by independent fair coin flips — every edge crosses with probability 1/2, so the expected cut is at least half the optimum (pattern P10 in its cheapest form).

The Goemans–Williamson algorithm (1995), statement. Relax to a semidefinite program: place a unit vector per vertex, maximize the sum over edges of $(1 - \langle u_i, u_j \rangle)/2$; solve the SDP; round by a uniformly random hyperplane through the origin. The guarantee: the expected cut is at least $0.87857$ times the optimum, and the constant is computable, not mysterious: for an edge whose SDP unit vectors make angle $\theta \in (0, \pi]$, the hyperplane separates its endpoints with probability $\theta/\pi$, while the SDP objective prices the edge at $(1 - \cos\theta)/2 = \sin^2(\theta/2)$ — so the per-edge ratio is $\theta/(\pi \sin^2(\theta/2))$, whose minimum over $0 < \theta \le \pi$ the lab locates at $\theta \approx 2.3311$, value $0.87857$ (Exercise 11 makes you derive every piece; the machine only checks the calculus).

And the optimality half, one confidence level softer than set cover's: assuming the Unique Games Conjecture (Khot 2002 — a hardness conjecture about a certain constraint system, still open), no polynomial algorithm approximates MaxCut within any factor above 0.878 (Khot–Regev 2008). Set cover's ceiling is unconditional (unless P = NP); MaxCut's is conditional (unless UGC fails); the honest atlas prints both with their price tags. If the conjecture falls, 0.878 may yet be beaten — the watermark tells you exactly what to watch.

5.4 What to learn

Approximation is not consolation; it is a different contract with the same rigor: a ratio, proved. The doubling argument converts a spanning structure into a tour and pays a factor of 2 for the conversion; Christofides pays only 1/2 more by repairing parity with matching — the whole chapter's cast (trees, parity, matching, shortcuts) assembled in one bound. The tight witness teaches the difference between a tight lemma and a tight guarantee. And MaxCut shows the modern endgame: exact constants, computed not looked up, with optimality conjectured on record. The meta-pattern, worth more than any single bound: when a problem's exact solution is provably unreachable, the mathematics does not stop — it changes currency, and the exchange rate becomes the theorem.

Lecture 6 · Matching in General Graphs: the Search That Stops Lying

Chapter 5 built the bipartite matching engine and then told the truth about its frontier (§3.3): beyond bipartite graphs, Berge's lemma still guarantees that every nonmaximum matching has an augmenting path — but the parity-labeled search can falsely report that none exists, and Exploration X2 sent you hunting the lie. This lecture is the promised payment in full. First the lie, caught in the act, with its exact labels on the table. Then Edmonds' blossoms — the contraction that repairs the search, the first polynomial-time algorithm for a problem that had resisted every attempt, and the birth of polyhedral combinatorics. Then Tutte's 1-factor theorem, the min–max obstruction to a perfect matching, proved in full — the chapter's last long proof, and the one that turns "no augmenting path" from an algorithm's report into a structural theorem with a certificate you can check by hand. The lecture closes the chapter's books: what the matching story now covers, and what the Atlas still owes.

6.1 The search that lies, caught in the act

Recall the engine (Chapter 5's Lecture 2). Given a matching M and an exposed vertex r, grow the alternating tree: label r A; repeatedly, from every A-vertex cross every unmatched edge to label a new vertex B; from every B-vertex cross its matched edge to label the partner A. Two exits: an unmatched edge from an A-vertex to an exposed vertex reads off an M-augmenting path — augment and restart — or the tree stops growing and the search reports "no augmenting path from r". In a bipartite graph the second exit is honest, and Chapter 5 built the certificate that proves it. In a general graph it can be a lie — and Berge's lemma (Chapter 5, L3.3) is what makes the lie detectable: if M is not maximum, an augmenting path does exist, so a "not found" report is a failure of the search, not a fact about the graph.

Figure 1 shows the smallest lying state. The paw — the triangle 0-1-2 with a pendant vertex 3 at 0 — with M = {0–1} and root 2: the labels run 2A, then 1B and 0B (the unmatched edges 2–1 and 2–0), and there is the tell: 0's matched partner is 1 — the matched edge 0–1 lies inside side B, the $B \to A$ step cannot fire, and the tree dies with A = {2}. No unmatched edge from 2 reaches an exposed vertex, so the search reports stuck. The report is false: 2-1-0-3 alternates (unmatched 2–1, matched 1–0, unmatched 0–3) and ends at the exposed 3 — an M-augmenting path three edges long, sitting in plain sight. The mirror state (M = {0–2}, root 1) lies identically.

Figure 1. The paw's lying state: M = {0–1}, root 2. The matched edge 0–1 joins two B-labeled vertices, the tree cannot grow, the search reports "no augmenting path" — and the alternating path 2-1-0-3 (dashed) augments the matching anyway.

One edge up, the pendant $C_5$ — the cycle 0-1-2-3-4-0 plus pendant 5 at 0 — supplies the second kind of tell. With M = {2–3, 4–0} and root 1: labels 1A; 0 and 2 become B (unmatched edges from 1); 4 becomes A (0's matched partner) and 3 becomes A (2's matched partner). Now side A contains the unmatched edge 3–4 — an unmatched edge inside side A, the second tell — and no A-vertex touches the exposed 5, whose only edge goes to 0, a B-vertex. Stuck, says the search; stuck it is not: 1-2-3-4-0-5 alternates (unmatched, matched, unmatched, matched, unmatched) and augments. The mirror state (M = {0–1, 2–3}, root 4) lies the same way.

The lab enumerated every state exhaustively on both graphs — every nonmaximum matching, every root — and there are exactly four lying states, two per graph, one per symmetry class each: the paw's two (matched edge inside B) and the pendant $C_5$'s two (unmatched edge inside A). Both tells are the same event: an odd alternating cycle closing inside the tree. Around an odd cycle the alternating structure runs out of room — parity cannot be assigned consistently around an odd loop — and the labels the tree hands out stop meaning what they mean in bipartite graphs. That is the entire wall Chapter 5's bipartite proofs lean on, seen at zero distance.

6.2 Edmonds' blossoms: contraction as the repair

The repair is Edmonds' (1965), and it is one move. A blossom is an odd alternating cycle found by the search — in the pendant $C_5$ state above, the cycle 1-2-3-4-0-1 (three unmatched edges, two matched, odd length, based at the root). Edmonds' move: contract the blossom to a single pseudovertex and keep searching in the contracted graph; when an augmenting path turns up there, lift it back through the blossom. The mathematical content of the repair is a two-line parity fact, worth stating as a lemma because it is the whole engine.

Lemma (parity switching). Let C be an odd alternating cycle in G with respect to M. For any two vertices u, v of C there is an alternating u–v path along C starting with an unmatched edge, and another starting with a matched edge: walk one way around C or the other, and the odd length is exactly what makes the two walks' parities differ.

Proof. The two u–v arcs of the cycle partition it into walks of opposite parity sum (their lengths add to |C|, which is odd). Alternation is preserved along the cycle because the cycle alternates: each arc, read from u, is an alternating walk, and its first edge is the cycle edge at u on one arc and the other cycle edge at u on the other arc — opposite types, since the cycle alternates at every vertex, u included. $\blacksquare$

So whatever parity the rest of an augmenting path demands at the point where it enters a contracted blossom, the inside can supply it: the blossom is a parity switcher, and contraction plugs it in. More precisely, a blossom $C$ discovered during the alternating-tree search has a unique base $b$ (the unique vertex of $C$ not incident to any matched edge of $C$) connected to the tree's exposed root by an even-length alternating stem $P_0$; if we first switch $M$ along $P_0$ to reduce to the case where $b$ itself is exposed, then $M$ has an augmenting path in $G$ if and only if the contracted matching $M/C$ has an augmenting path in $G/C$ — any augmenting path in $G/C$ visiting the pseudovertex $v_C$ leaves $v_C$ along an unmatched edge incident to some vertex $w \in C$, and the parity-switching lemma supplies the even-length alternating path inside $C$ from the exposed base $b$ to $w$ that lifts the path back to $G$. Consequently, the search may contract $C$ and continue without losing or inventing augmentability. The remaining bookkeeping (that a completed Hungarian forest with no further blossoms or augmenting steps certifies maximality, the certificate machinery now known as the Tutte–Berge–Edmonds theory) is a careful induction that this chapter cites to Edmonds' two 1965 papers — "Paths, Trees, and Flowers" and the matching polyhedron paper, the birth of polyhedral combinatorics — rather than re-proving; the perfect-matching case of the certificate is §6.3's theorem, proved in full below. What this chapter proves is the parity core, and what the lab does is check the implementation against the truth.

The lab's engine (a faithful port of the classical algorithm, adjacency scanned in ascending order) runs the repair on the chapter's specimens. The paw from the empty matching: the first search finds the single-edge augmenting path 0–1 at once; the second search, rooted at 2, meets the blossom 2-0-1 (unmatched 2–0, matched 0–1, unmatched 1–2 — labels 2A, 0B, 1B with the matched edge inside B), contracts it, finds the pseudovertex joined to the exposed 3, and lifts back through the cycle to the true path 2-1-0-3 — augmenting to the perfect matching {0–3, 1–2}. The pendant $C_5$ from the empty matching returns the perfect matching {0–5, 1–2, 3–4}, the last augmentation through a contraction. The Petersen graph — the outer 5-cycle on 0–4, the inner star joining i+5 to ((i+2) mod 5)+5, spokes i–(i+5) — returns the perfect matching {0–1, 2–3, 4–9, 5–7, 6–8}: the star's 5-cycle of inner vertices is one big blossom in the middle of the run, and the engine steps through it. And the census: against an exact bitmask dynamic program on all 33,866 labeled graphs on 2 to 6 vertices, zero mismatches and zero invalid matchings — plus thirty seeded instances on 10 and 12 vertices, all agreeing. Implementation reality matches the cited theory everywhere the machine can see. For practice, tuned implementations have made the engine fast — Blossom V (Kolmogorov 2009) is the standard modern one — and the algorithm's polynomial running time, unremarkable now, was the shock of 1965: a problem that looked irreducibly exponential fell to parity bookkeeping, and the lesson (clever certificates can beat brute force provably) is the founding document of this chapter's entire worldview.

6.3 Tutte's 1-factor theorem, proved in full

Blossoms find matchings; Tutte's theorem says when a perfect matching — a 1-factor — exists at all, and the statement is the perfect instance of pattern P17: an obstruction that is exactly tight, every failing graph failing for a visible structural reason.

Theorem (Tutte 1947). A graph G has a perfect matching if and only if for every set S of vertices, the number odd(G − S) of odd-order components of G − S is at most |S|.

The lab census first: every labeled graph on 4 and on 6 vertices — 32,832 of them (64 + 32,768). On 4 vertices, 37 have a perfect matching and 27 do not; on 6, 24,823 and 7,945. The census checked the equivalence both ways on every graph: zero violations. Now the proof.

($\Rightarrow$) Necessity, by pigeonhole. Let $M$ be a perfect matching and $S$ any vertex set. Take any odd component $C$ of $G - S$: the edges of $M$ that lie completely inside $C$ pair up an even number of vertices of $C$, and because $|C|$ is odd, at least one vertex of $C$ must be matched by $M$ to a vertex outside $C$. Since components of $G - S$ have no edges between them in $G$, any edge leaving $V(C)$ must have its other endpoint in $S$; thus at least one vertex of $C$ is matched to a partner in $S$. Because $M$ is a matching, two distinct odd components cannot share the same partner in $S$, so the odd components of $G - S$ inject into $S$: $\mathrm{odd}(G - S) \le |S|$. $\blacksquare$

($\Leftarrow$) Sufficiency, by induction on n = |V|. Suppose the condition holds throughout. The base n = 0 is the empty matching, perfect. For the induction, three moves and an assembly.

Move 1: the vertex count is even. S = $\emptyset$ gives $\mathrm{odd}(G) \le 0$: G has no odd-order components, so n is even. In particular $\emptyset$ is a set with $\mathrm{odd}(G - \emptyset) = |\emptyset| = 0$, so equality sets exist. Choose S maximal by inclusion among the sets with $\mathrm{odd}(G - S) = |S|$.

Move 2: every component of G − S is odd. Suppose not: let C be an even-order component and x any vertex of C. In G − (S $\cup$ {x}), everything outside C is untouched, so its odd components are exactly the |S| odd components of G − S other than C (C contributed none, being even); and C − x has odd order, so it has at least one odd component. Hence $\mathrm{odd}(G - (S \cup \{x\})) \ge |S| + 1 = |S \cup \{x\}|$, while the hypothesis caps it at |S $\cup$ {x}|: equality — contradicting the maximality of S, since S $\cup$ {x} is a strictly larger equality set. So all components of G − S are odd, and there are exactly |S| of them.

Move 3: every component of G − S is factor-critical (deleting any one of its vertices leaves a graph with a perfect matching). Let C be a component and x $\in$ C; suppose C − x has no perfect matching. The graph C − x has fewer than n vertices, so the induction hypothesis applies to it, and its failure gives a set T with $\mathrm{odd}((C - x) - T) > |T|$. Parity sharpens this: |C − x| is even, so $\mathrm{odd}((C - x) - T)$ has the same parity as |T|, and the strict inequality forces $\mathrm{odd}((C - x) - T) \ge |T| + 2$. Now set $W = S \cup T \cup \{x\}$ and count G − W: the components of G − S other than C survive untouched (odd, |S| − 1 of them), and the components of (C − x) − T appear inside; so $\mathrm{odd}(G - W) \ge (|S| - 1) + (|T| + 2) = |S| + |T| + 1 = |W|$. The hypothesis caps it at |W|: equality again — and $W \supsetneq S$ contradicts maximality. So C − x has a perfect matching for every x, which is factor-criticality.

The assembly: a matching saturating S, then the pieces. Build the auxiliary bipartite graph H: left side S, right side the odd components of G − S, and s adjacent to component C iff s has a neighbor in C. Hall's condition holds: for any nonempty $T \subseteq S$, let $U = S \setminus T$ and look at G − U. Every component of G − S with no neighbor in T survives intact as an odd component of G − U (it has no edges to T, and deleting U cannot connect anything to it), and there are |S| − |N(T)| of them, where N(T) is T's neighborhood in H. If $|N(T)| < |T|$, then $\mathrm{odd}(G - U) \ge |S| - |N(T)| > |S| - |T| = |U|$ — violating the hypothesis. So $|N(T)| \ge |T|$ throughout, Hall gives a matching of H saturating S, and since the components number exactly |S| (Move 2), the matching pairs every s $\in$ S with a distinct component $C_s$. For each s pick a neighbor $v_s \in C_s$ (one exists, by adjacency), delete $v_s$ from $C_s$, and take the perfect matching of $C_s - v_s$ that factor-criticality provides (Move 3). The union — the edges $s\text{--}v_s$ together with the internal perfect matchings — covers every vertex exactly once: a perfect matching of G. $\blacksquare$

Two remarks the proof begs to make. First, the proof is constructive in structure: the equality set S, the factor-critical components, and the auxiliary bipartite matching are exactly what the blossom algorithm's terminated forest computes — Tutte's theorem is the certificate the engine's silence reports. Second, maximality of S is load-bearing, and the lab's worked instance shows where.

The worked instance. Take two 5-cycles — 0-1-2-3-4-0 and 5-6-7-8-9-5 — bridged by the single edge 0–5: ten vertices, and the theorem's anatomy is visible end to end. The graph has perfect matchings ({1–2, 3–4, 0–5, 6–7, 8–9} is one), and the machine finds the maximal equality sets: {0,1,3}, {0,2,3}, {0,2,4}, {5,6,8}, {5,7,8}, {5,7,9} — six of them, all with $\mathrm{odd}(G - S) = |S| = 3$. Run the proof on S = {0,1,3}: G − S has components {2}, {4}, and the second $C_5$ on {5,…,9} — all odd, three of them (Moves 1–2 hold with equality, maximality confirmed: adding any vertex collapses the count below the size, since it splits or shrinks odd components into even remainders). Each component is factor-critical (Move 3): the singletons trivially, the $C_5$ machine-verified — delete any vertex and the remaining four form a path with a perfect matching. The auxiliary bipartite graph: 0 is adjacent to the {4}-component (edge 0–4) and to the $C_5$ (edge 0–5); 1 to {2} (edge 1–2); 3 to {2} (edge 3–2) and to {4} (edge 3–4). The matching saturating S pairs 1 $\to$ {2}, 3 $\to$ {4}, 0 $\to$ $C_5$; the assembly picks neighbors 1–2, 3–4, 0–5, deletes 2, 4, 5 from their components, and matches the $C_5$'s remainder: {6–7, 8–9}. The result is the perfect matching {1–2, 3–4, 0–5, 6–7, 8–9} — built by the proof, not found by search. Now the trap: {0,1} is also an equality set (G − {0,1} has the path 2-3-4 and the $C_5$, both odd: 2 = |{0,1}|), but it is not maximal, and its component 2-3-4 — the three-vertex path — is not factor-critical: delete the middle vertex 3 and two isolated vertices remain, no perfect matching. Move 3's contradiction is unavailable there, and that is precisely why the proof takes S maximal: the non-maximal equality set is where factor-criticality goes to die.

✎ Checkpoint 1. Run necessity by hand on the worked instance's perfect matching: with S = {0,1,3}, check that each of the three odd components sends exactly one matched edge across to S — {2} sends 2–1, {4} sends 4–3, the $C_5$ sends 5–0 — three distinct partners in S, exactly as the pigeonhole proof demands. Then find the second $C_5$'s own equality set structure: what are the components of G − {5,7,9}, and why does the bridge edge 0–5 make 0 the vertex that saturates the far component?

What to learn. The bipartite engine failed in general graphs for exactly one reason — odd alternating cycles break parity bookkeeping — and the repair was not to abandon the engine but to make the obstruction a first-class object and contract it. That is the deepest algorithmic move in the Atlas: when a search lies, do not trust it harder or discard it; find what it cannot say, name it, and build the saying into the machine. Tutte's theorem is the same lesson at the level of structure: the obstruction to a perfect matching is not a mystery but a set S with too many odd components, a certificate a skeptic can check with a pencil — the min–max pattern's final form in this book. And the consolidation table is the chapter's thesis in one glance: the same combinatorial objects — paths, matchings, covers — live in all three worlds at once; the world is decided by the question you ask, and every border crossing has a proof at the gate.

def greedy_cover(u, fam):             # ties -> earliest set in printed order
    if u <= 0: return 0

            if g > bg: bg, best = g, i

def ssp(arcs, demand, s, t):          # Bellman-Ford on the residual network
    if not arcs or demand <= 0: return [0] * len(arcs), 0, 0, []

        iters += 1
        INF = float('inf')
        dist = [INF] * n; dist[s] = 0
        par = [None] * n
        for _ in range(n):
            for i, (u, v, cap, c) in enumerate(arcs):
                if flow[i] < cap and dist[u] + c < dist[v]:
                    dist[v] = dist[u] + c; par[v] = (i, 1)

        val += push
        log.append((dist[t], push, [(arcs[i][0], arcs[i][1], arcs[i][3]) for i, d in path]))
    return flow, sum(f * a[3] for f, a in zip(flow, arcs)), iters, log

def mst(n, D):                        # Kruskal; ties -> lexicographic pair
    if n <= 1: return [], 0
    order = sorted(combinations(range(n), 2), key=lambda e: (D[e[0]][e[1]], e))

def euler(n, mult):                   # greedy Hierholzer from 0, ascending neighbor

def has_pm(n, em):                    # exact perfect-matching DP, bitmask recursion
    if n % 2 or n < 0: return False
    def rec(mask):
        if mask == 0: return True
        v = (mask & -mask).bit_length() - 1
        rest = mask & ~(1 << v)
        for w in range(n):
            if rest >> w & 1 and em[v] >> w & 1 and rec(rest & ~(1 << w)):
                return True
        return False
    return rec((1 << n) - 1)

def tutte_census(n):

def lying_states(n, em):              # naive parity search vs brute-force truth
    edges = [(a, b) for a in range(n) for b in range(a + 1, n) if em[a] >> b & 1]
    lying = []

        ism = lambda a, b: (a, b) in match or (b, a) in match

                if dfs(w, not want_un): return True
            return False

def max_matching(n, em):              # Edmonds' blossom, classical port

            a = base[a]; vis[a] = True
            if match[a] == -1: break

            b = base[b]
            if vis[b]: return b
            b = p[match[b]]

            bl[base[v]] = bl[base[match[v]]] = True
            p[v] = child; child = match[v]; v = p[match[v]]
    def find_path(root):

        used[root] = True; q.append(root); qh = 0
        while qh < len(q):
            v = q[qh]; qh += 1
            for to in range(n):       # adjacency scanned in ascending order
                if not adj[v][to] or base[v] == base[to]: continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    cb = lca(v, to)
                    for i in range(n): bl[i] = False
                    mark(v, cb, to); mark(to, cb, v)
                    for i in range(n):
                        if bl[base[i]]:
                            base[i] = cb
                            if not used[i]: used[i] = True; q.append(i)
                elif p[to] == -1:
                    p[to] = v

                            match[u] = pv; match[pv] = u; u = ppv
                        return True

        return False
    for i in range(n):
        if match[i] == -1: find_path(i)
        q.clear()
    return sorted((i, v) for i, v in enumerate(match) if i < v)

def max_match_dp(n, em):              # exact bitmask DP for the census
    if n <= 1: return 0
    memo = [-1] * (1 << n)
    def rec(mask):
        if mask == 0: return 0
        if memo[mask] >= 0: return memo[mask]
        v = (mask & -mask).bit_length() - 1
        rest = mask & ~(1 << v)
        best = rec(rest)
        for w in range(n):
            if rest >> w & 1 and em[v] >> w & 1:
                best = max(best, 1 + rec(rest & ~(1 << w)))
        memo[mask] = best
        return best
    return rec((1 << n) - 1)
