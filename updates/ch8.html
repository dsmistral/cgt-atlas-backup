Chapter 8 · Spectral Methods and the Modern Toolkit

The spectrum of a graph knows its extremal answers before the witnesses are found: the largest eigenvalue averages the edges and caps them by the clique number, dimension-priced polynomials cap a point configuration's distances, and the smallest eigenvalue — read through interlacing, semidefinite duality, and linear programming — prices independence, chromatic number, zero-error capacity, and code size. Lecture 1 · Eigenvalues as Averaging Machines: Mantel, and the Expander-Mixing Lemma

Henceforth $G$ has $n$ vertices, $m$ edges, adjacency matrix $A$ with eigenvalues $\lambda_1 \ge \dots \ge \lambda_n$. Because $A$ is real symmetric and entrywise nonnegative, Perron–Frobenius applied to the connected components gives $\lambda_1 = \max_i |\lambda_i| \ge 0$, with an entrywise nonnegative unit eigenvector $x \ge 0$ — every lemma below only needs that.

1.1 The two-lemma sandwich (P21)

Lemma 1 (Rayleigh = averaging). $\lambda_1 \ge 2m/n$.
Proof. $\lambda_1 = \max_{\|x\|=1} x^T A x \ge (\mathbf{1}/\sqrt{n})^T A (\mathbf{1}/\sqrt{n}) = (\sum_v d(v))/n = 2m/n$. $\blacksquare$

Lemma 2 (triangle-free $\implies \lambda_1 \le \sqrt{m}$).
Proof. Let $x$ be a unit eigenvector for $\lambda_1$ ($\|x\| = 1$). For each vertex $u$: $\lambda_1 x_u = \sum_{v \sim u} x_v$, so by Cauchy–Schwarz $\lambda_1^2 x_u^2 \le d(u) \sum_{v \sim u} x_v^2$. Sum over $u$: $$\lambda_1^2 \le \sum_u d(u) \sum_{v \sim u} x_v^2 = \sum_v x_v^2 \cdot \left(\sum_{u \sim v} d(u)\right) \le \max_v e(N(v)),$$ where $e(N(v)) = \sum_{u \sim v} d(u)$ counts, with multiplicity, the edges incident to the neighborhood of $v$. Triangle-free $\implies N(v)$ is independent $\implies$ every edge has at most one endpoint in $N(v) \implies e(N(v)) \le m$. Hence $\lambda_1^2 \le m$. $\blacksquare$

Mantel, spectrally. $(2m/n)^2 \le \lambda_1^2 \le m \implies 4m^2 \le mn^2 \implies \mathbf{m \le n^2/4}$ — and integrality gives $m \le \lfloor n^2/4 \rfloor$, the fourth proof of Chapter 3's §3.4. $\blacksquare$

Equality, and the extremal graph found twice. For $K_{a,b}$: $\lambda_1 = \sqrt{ab}$ (Exercise 1 — eigenvector $\sqrt{b}$ on one side, $\sqrt{a}$ on the other) and $m = ab$, so Lemma 2 is tight for every complete bipartite graph; Lemma 1 is tight only when $a = b$, since $2ab/(a+b) = \sqrt{ab} \iff (a-b)^2 = 0$. The sandwich finds the unique even-$n$ extremal graph $K_{n/2,n/2}$ directly, and for odd $n$ integrality $m \le \lfloor n^2/4 \rfloor = \lfloor n/2 \rfloor \lceil n/2 \rceil$ pins the balanced $K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$. Machine check: on every triangle-free graph on 5 or 6 vertices (full census), both lemmas and $m \le \lfloor n^2/4 \rfloor$ hold; the two-lemma sandwich is a theorem about all of them, not a lucky example.

1.2 The expander-mixing lemma — pseudorandomness, quantified

Problem. $G$ is $d$-regular on $n$ vertices, $\mu = \max(|\lambda_2|, |\lambda_n|)$. Show that for all disjoint $S, T \subseteq V$:

$$\left| e(S,T) - \frac{d \cdot |S||T|}{n} \right| \le \mu \cdot \sqrt{ |S||T| \left(1 - \frac{|S|}{n}\right)\left(1 - \frac{|T|}{n}\right) }.$$

("A graph with small $\mu$ behaves randomly: every two large vertex sets carry about the expected number of edges between them.")

Proof. Decompose against the all-ones vector: $\mathbf{1}_S = (|S|/n)\mathbf{1} + z_S$ with $z_S \perp \mathbf{1}$, so $\|z_S\|^2 = |S| - |S|^2/n = |S|(1 - |S|/n)$ — and likewise for $T$. Count edges through the adjacency matrix: $e(S,T) = \mathbf{1}_S^T A \mathbf{1}_T = (|S||T|/n^2)\cdot \mathbf{1}^T A \mathbf{1} + z_S^T A z_T$, the two cross terms vanishing because $A\mathbf{1} = d\mathbf{1}$ and $z \perp \mathbf{1}$. Now $A\mathbf{1}$: $\mathbf{1}^T A \mathbf{1} = dn$, so the first term is exactly $d|S||T|/n$. On $\mathbf{1}^\perp$ the symmetric matrix $A$ has eigenvalues $\lambda_2, \dots, \lambda_n$, so its operator norm there is $\mu$: $|z_S^T A z_T| \le \mu \|z_S\| \cdot \|z_T\|$. Combine. $\blacksquare$

The $\sqrt{(1 - |S|/n)(1 - |T|/n)}$ factors are the sharp form of the classical statement (which reads $\le \mu \sqrt{|S||T|}$); they matter exactly when $S$ or $T$ is a large fraction of $V$.

Tightness, machine-checked over all disjoint pairs. On the Petersen graph ($d = 3$, spectrum $\{3, 1^5, -2^4\}$, $\mu = 2$) the ratio of violation to bound attains $\mu$ exactly — the lemma cannot be improved there. On $K_{3,3}$ the eigenvalue $-d = -3$ is present, so $\mu = 3$ and the bound is again tight — the bipartite degeneracy: any connected $d$-regular bipartite graph carries $-d$, and the lemma degenerates with it. On $C_5$ the largest ratio is $4/3$, short of $\mu = \varphi \approx 1.618$: some instances are rigid, some have slack. (Jacobi eigenvalues and maximum mixing ratios for all three: computed and validated in the lab, Part 1.)

What these names buy. (1) Quasi-randomness (Chung–Graham–Wilson): several "looks random" properties are equivalent to $\mu = o(n)$. (2) Expanders: the spectral gap $d - \lambda_2$ measures connectivity strong enough to power derandomization, codes, and communication complexity. (3) Discrepancy control: with $\mu$ small, no two large vertex sets are unusually tightly connected — a deterministic randomness statement. The two-lemma sandwich of §1.1 — Rayleigh lower bound from the average, upper bound from local structure — is the template of spectral extremal graph theory.

Lecture 2 · Motzkin–Straus: The Clique Polynomial, and Spectral Turán

Both lemmas of Lecture 1 bound $\lambda_1$ on triangle-free graphs. Capping $\lambda_1$ in terms of the clique number is a general game — and its engine, the Motzkin–Straus theorem, is a pure optimization statement with a beautiful weight-shifting proof (P20).

2.1 The Motzkin–Straus theorem

Theorem. For a graph $G$ with clique number $\omega$, the maximum over the simplex $\sum_v x_v = 1, x \ge 0$ of

$$f(x) = \sum_{uv \in E} x_u x_v$$

is exactly $\mathbf{(1 - 1/\omega)/2}$.

Proof. The value $(1-1/\omega)/2$ is attained: put weight $1/\omega$ on each vertex of a maximum clique — $f = \binom{\omega}{2}/\omega^2 = (1 - 1/\omega)/2$.

For the upper bound, take a maximizer $x$ with smallest possible support, and suppose the support contains two non-adjacent vertices $u \not\sim v$. Write $d_x(w) = \sum_{z \sim w} x_z$. Merge $v$ into $u$: $x'_u = x_u + x_v$, $x'_v = 0$, all else unchanged. Only edges at $u$ and $v$ change, and ($u \not\sim v$, so the pair itself contributes nothing) the change is

$$f(x') - f(x) = x_v ( d_x(u) - d_x(v) ).$$

If $d_x(u) \ge d_x(v)$, merge $v$ into $u$; otherwise merge $u$ into $v$ (same formula, roles swapped). Either way $f$ does not decrease, $x'$ is still a maximizer — and its support is strictly smaller. Contradiction to the minimal-support choice. So the support of $x$ is a clique — every pair of support vertices adjacent.

2.3 Spectral Turán — the clique number caps $\lambda_1$

Theorem. $\lambda_1 \le (1 - 1/\omega)\cdot n$.
Proof. If $E = \emptyset$, then $\omega = 1$ and $\lambda_1 = 0 = (1 - 1/1)n$. Otherwise let $x$ be a unit Perron eigenvector of a connected $G$ (entrywise $\ge 0$ — this is where Perron–Frobenius earns its keep, since Motzkin–Straus needs $x$ in the simplex; for disconnected $G$ apply the argument to a component achieving $\lambda_1$). Let $s = \sum_v x_v > 0$. Then

$$\lambda_1 = x^T A x = 2 \sum_{uv \in E} x_u x_v = 2 s^2 f(x/s) \le 2 s^2 \cdot \frac{1 - 1/\omega}{2} = s^2\left(1 - \frac{1}{\omega}\right),$$

by Motzkin–Straus applied to the normalized vector $x/s$; and Cauchy–Schwarz gives $s^2 \le n \cdot \|x\|^2 = n$. So $\lambda_1 \le (1 - 1/\omega)n$. $\blacksquare$

Turán recovered. Combine with Rayleigh (Lemma 1): $m \le n\lambda_1/2 \le (1 - 1/\omega)n^2/2$ — the Turán bound $m \le (1 - 1/r)n^2/2$ for $K_{r+1}$-free graphs, arriving by way of optimization. Machine check: on all 33,792 graphs on 5 and 6 vertices (the full censuses), $\lambda_1 \le (1 - 1/\omega)n$ holds without exception, and $K_{3,3}$ attains equality: $\lambda_1 = 3 = (1 - 1/2)\cdot 6$.

What you now own: weight shifting as an optimization engine (P20), the merge lemma with its adjacent-merge correction, and the chain Perron $\to$ simplex $\to$ Motzkin–Straus $\to$ Cauchy–Schwarz $\to$ spectral Turán $\to$ Turán — five ideas, one line of inequality.

Lecture 3 · Two-Distance Sets: A Capstone in Three Bounds

Problem. How many points can fit in $\mathbb{R}^d$ if all pairwise distances take at most $\mathbf{s}$ distinct values? The two-distance case ($s = 2$) is the classic; the answer weaves together every pattern of the chapter — Gram matrices, polynomials, and a sharp dichotomy between spherical and unrestricted configurations.

3.1 Warm-up: equidistant points — the centered Gram

Lemma. At most $d + 1$ points in $\mathbb{R}^d$ can be pairwise equidistant.
Proof. Let $p_1, \dots, p_k$ be pairwise at distance $\delta > 0$, and center them: $c = (1/k)\sum p_i$, $w_i = p_i - c$, so $\sum w_i = 0$. On the centered configuration two facts hold: first, summing $\|w_i - w_j\|^2$ over all $j$ gives $(k-1)\delta^2 = \sum_{j=1}^k \|w_i - w_j\|^2 = k\|w_i\|^2 + \sum_{j=1}^k \|w_j\|^2$, and summing that over $i$ gives $k(k-1)\delta^2 = 2k \sum_{j=1}^k \|w_j\|^2$, whence $\|w_i\|^2 = (k-1)\delta^2/(2k)$ for every $i$; second, $w_i \cdot w_j = (\|w_i\|^2 + \|w_j\|^2 - \delta^2)/2 = -\delta^2/(2k)$ for $i \ne j$. The $k \times k$ Gram matrix of the $w_i$ is then

$$G = \frac{\delta^2}{2}\left(I - \frac{J}{k}\right),$$

whose spectrum is $\delta^2/2$ on $\mathbf{1}^\perp$ (multiplicity $k - 1$) and $0$ on $\mathbf{1}$ — in particular $G$ kills $\mathbf{1}$ and has rank $k - 1$. But $G = W W^T$ for the $k \times d$ matrix $W$ whose rows are the centered vectors $w_i^T$, so $k - 1 = \operatorname{rank} G = \operatorname{rank} W \le d$: $\mathbf{k \le d + 1}$. $\blacksquare$

Tight: the standard simplex, $w_i = e_i - \mathbf{1}/k$, has pairwise $\text{distance}^2 = 2$ and $\|w_i\|^2 = (k-1)/k$ — $k = d + 1$ points in the hyperplane $\sum x = 0 \subset \mathbb{R}^{d+1}$ (isometric to $\mathbb{R}^d$). (Machine: the centered Gram's spectrum $\{1 \times (k-1), 0\}$ verified for $k = 2 \dots 9$; the simplex vectors' distances and norms verified exactly.)

✎ Checkpoint — the tempting shortcut. Why not skip the centering and call $(\delta^2/2)(J + I)$ "the Gram matrix"? It is positive definite — $\det(J_k + I_k) = k + 1$ (checked for $k = 2 \dots 9$) — and full rank $k$, which would suggest $k \le d$, even better! The catch: those entries are the inner products of vectors of norm $\delta$ from the origin, and nothing in the hypothesis says the points are equidistant from anywhere. The uncentered configuration the shortcut secretly assumes does not exist in general; the centered Gram, rank $k - 1$, is the honest one, and the theorem it proves — $k \le d + 1$ — is tight.

3.2 The general bound: polynomials on the paraboloid

Theorem. A set of $k$ points in $\mathbb{R}^d$ with at most $s$ distinct pairwise distances satisfies $k \le \binom{d + s + 1}{s}$.
Proof. Let $D$ be the realized squared-distance values ($|D| \le s$) and $p_1, \dots, p_k$ the points. To each point assign the polynomial in $y \in \mathbb{R}^d$:

$$f_i(y) = \prod_{\ell \in D}\left(\|y - p_i\|^2 - \ell\right).$$

Then $f_i(p_j) = 0$ for $j \ne i$ (some distance factor vanishes — note $0 \notin D$, distances between distinct points are positive) and $f_i(p_i) = \prod_{\ell \in D}(-\ell) \ne 0$. The evaluation matrix is diagonal: the $f_i$ are linearly independent as functions on the point set. Now count the room they live in. Write $\|y - p_i\|^2 = \|y\|^2 - 2p_i \cdot y + \|p_i\|^2$: each $f_i$ is a polynomial of degree $\le s$ in the $d + 1$ "variables" $(y_1, \dots, y_d, \|y\|^2)$ — a function on the paraboloid $t = \|y\|^2$ in $\mathbb{R}^{d+1}$. The space of such functions $\sum_{q=0}^s \|y\|^{2q} g_q(y)$ with $\deg g_q \le s - q$ has dimension at most $\sum_{q=0}^{s} \binom{d + s - q}{s - q} = \binom{d + s + 1}{s}$ (hockey-stick identity — machine-checked for $d \le 6, s \le 4$). Independent functions, finite room: $k \le \binom{d+s+1}{s}$. $\blacksquare$

3.3 The spherical bound — Delsarte–Goethals–Seidel

If all points lie on a sphere of radius $r$, the paraboloid collapses: $\|y - p_i\|^2 = 2r^2 - 2p_i \cdot y$ there, so each $f_i$ agrees on the sphere with an ordinary polynomial of degree $\le s$ in $y$ — and distinct polynomials can agree on the sphere, an ambiguity that is exactly computable:

Theorem (DGS). A set of $k$ points on a sphere in $\mathbb{R}^d$ with at most $s \ge 1$ pairwise distances satisfies $k \le \binom{d+s}{s} - \binom{d+s-2}{s-2} = \binom{d+s-1}{s} + \binom{d+s-2}{s-1}$ (with $\binom{n}{m} = 0$ for $m < 0$).
Proof. The restriction map $\Pi_{\le s}$ (polynomials of degree $\le s$ in $y$, dimension $\binom{d+s}{s}$) $\to$ functions on the sphere has a kernel containing every polynomial $(r^2 - \|y\|^2)\cdot h(y)$ with $\deg h \le s - 2$ — these vanish identically on the sphere $\|y\|^2 = r^2$, and multiplication by $(r^2 - \|y\|^2)$ is injective on polynomials (a product of nonzero polynomials over $\mathbb{R}$ is nonzero). So the image has dimension $\le \binom{d+s}{s} - \binom{d+s-2}{s-2}$; the independent $f_i$ live in that image. For $s = 2$ the bound is $d(d+3)/2$. $\blacksquare$

For $s = 2$ the honest comparison: general $\binom{d+3}{2}$ versus spherical $d(d+3)/2$ — e.g. $d = 2$: $10$ versus $5$; $d = 3$: $15$ versus $9$. The sharp general bound is in fact $\binom{d+s}{s}$ (Bannai–Bannai–Stanton 1983; a short proof by Petrov–Pohoata 2019) — tighter than the paraboloid bound and cited here, not re-proved: the chapter's own proved bound is $\binom{d+s+1}{s}$.

3.6 Grids: two-distance sets under lattice discipline

How much of this geometry survives on the integer lattice? Machine censuses, exhaustive:

  • The 9-point line $\{0, \dots, 8\}$: maximum two-distance subset has 3 points ($\{0,1,2\}$-type — and any 4 collinear lattice points already span 3 distances).
  • The $7 \times 7$ grid $[-3..3]^2$: no 5-point two-distance subset exists (all $\binom{49}{5} = 1{,}906{,}884$ five-subsets checked); 4 is attained by the square $(\pm 1, \pm 1)$ with squared distances $\{4, 8\}$.   • The $3 \times 3 \times 3$ grid $[-1..1]^3$: no 7-point two-distance subset (all $\binom{27}{7} = 888{,}030$ checked); 6 is attained by the octahedron $\{\pm e_1, \pm e_2, \pm e_3\}$ with squared distances $\{2, 4\}$ — the octahedron is lattice-realizable, where the pentagon is not.

Lecture 4 · The Modern Toolkit: Interlacing, Hoffman, Theta, and Delsarte's Program

Chapter 6's four lectures and Lectures 1–3 here built one machine — encode combinatorics as vectors, then let dimension and spectrum do the counting — and pointed it at seven problem families. This lecture upgrades the machine to its modern form, in an order that is almost a story. Interlacing says that substructures inherit eigenvalues, and it explains retroactively why the spectral moves of Chapter 6's Lecture 4 and Lectures 1–2 here were legal at all. Hoffman's bound turns the smallest eigenvalue into a quantitative cap on independent sets and a lower bound on the chromatic number. Lovász theta is a single number sandwiched between $\alpha$ and $\chi(\bar{G})$; computing it exactly for the five-cycle — $\theta(C_5) = \sqrt{5}$ — is the theorem that carried semidefinite programming into combinatorics. 4.1 Interlacing: submatrices inherit the spectrum

Everything rests on one lemma about symmetric matrices, proved once and reused three ways.

Lemma (min–max). For a real symmetric matrix $A$ with eigenvalues $\lambda_1 \ge \dots \ge \lambda_n$ and Rayleigh quotient $R(x) = (x^T A x)/(x^T x)$:

$$\lambda_k = \max_{\dim T = k} \min_{x \in T \setminus \{0\}} R(x) = \min_{\dim S = n-k+1} \max_{x \in S \setminus \{0\}} R(x).$$

Proof. For the max–min: any $k$-dimensional $T$ meets the span of the eigenvectors $v_k, \dots, v_n$ (dimensions add to $n + 1$), and on that span $R$ never exceeds $\lambda_k$ — so $\min_T R \le \lambda_k$. Equality: on $T = \operatorname{span}(v_1, \dots, v_k)$ the quotient never drops below $\lambda_k$. The min–max is the mirror argument: any $(n-k+1)$-dimensional $S$ meets $\operatorname{span}(v_1, \dots, v_k)$, where $R$ is at least $\lambda_k$; equality on $\operatorname{span}(v_k, \dots, v_n)$. $\blacksquare$

Theorem (Cauchy interlacing). Let $B$ be the $m \times m$ principal submatrix of the symmetric $A$ (delete some rows and the same columns), with eigenvalues $\mu_1 \ge \dots \ge \mu_m$. Then for every $i$:

$$\lambda_i \ge \mu_i \ge \lambda_{i+n-m}.$$

Proof. $B$ is the quadratic form of $A$ restricted to a coordinate subspace $U$ of dimension $m$ — padded vectors preserve Rayleigh quotients. Upper: $\mu_k = \max_{\dim T = k, T \subseteq U} \min R_B = \max_{\dim T = k, T \subseteq U} \min R_A \le \max_{\dim T = k} \min R_A = \lambda_k$. Lower: apply the upper bound to $-A$ and $-B$, whose $k$-th largest eigenvalues are $-\mu_{m+1-k}$ and $-\lambda_{n+1-k}$: $-\mu_{m+1-k} \le -\lambda_{n+1-k}$, i.e. $\mu_i \ge \lambda_{i+n-m}$ for $i = m+1-k$. $\blacksquare$

Two remarks make the theorem usable. First, the proof never used that $U$ is a coordinate subspace: the same interlacing holds for the matrix of the form restricted to any $m$-dimensional subspace $W$ — this is compression, and it is how partitions enter. Second, taking induced subgraphs is exactly taking principal submatrices of the adjacency matrix, so graph-theoretic conclusions fall out immediately.

Corollary (monotonicity). Adding an edge cannot decrease $\lambda_1$: the unit Perron vector $x \ge 0$ of the smaller graph, tested against both adjacency matrices, gives $\lambda_1(A + E) \ge x^T(A + E)x \ge x^T A x = \lambda_1(A)$.

Corollary (the inertia bound). $\alpha(G) \le n - p(A)$ and $\alpha(G) \le n - q(A)$, where $p, q$ are the counts of positive and negative eigenvalues of $A$.

Proof. An independent set $S$ makes $A_S$ — the principal submatrix on $S$ — the zero matrix, whose $|S|$ eigenvalues are all $0$. Interlacing reads this twice: $\mu_\alpha = 0$ forces $\lambda_\alpha \ge 0$ (at least $\alpha$ eigenvalues are nonnegative: $\alpha \le p + z$), and $\mu_1 = 0$ forces $\lambda_{1+n-\alpha} \le 0$ (at least $\alpha$ are nonpositive: $\alpha \le q + z$); $z$ is the zero count, and $p + z = n - q$, $q + z = n - p$. $\blacksquare$

✎ Checkpoint. Petersen: spectrum $\{3, 1^5, -2^4\}$ — $p = 6$, so $n - p = 4 = \alpha$, tight. $C_5$: spectrum $\{2, 0.618^2, -1.618^2\}$ — $p = 3$, $q = 2$, and $n - p = 2 = \alpha$, also tight. The lab (Part 3) runs the bound over all 1,099 graphs with $n \le 5$: never violated, tight 633 times on $n - p$ (954 on $n - q$, and 966 on $\min(n - p, n - q)$).

Partitions: compression and quotients. Let $V = C_1 \cup \dots \cup C_m$ be a partition of the vertex set into nonempty cells, $U$ its indicator matrix (column $j$ is $\mathbf{1}_{C_j}$), and $Q = U(U^T U)^{-1/2}$ the orthonormalized version. Then $B = Q^T A Q$ is the compressed matrix, and its eigenvalues interlace $A$'s by the remark above. When the partition is equitable — every vertex of $C_i$ has exactly $b_{ij}$ neighbors in $C_j$ — something stronger happens:

Theorem (equitable quotients). For an equitable partition, the quotient matrix $B_{\text{quot}} = (b_{ij})$ has its entire spectrum inside $A$'s: every eigenvalue of $B_{\text{quot}}$ is an eigenvalue of $A$.

Proof. If $B_{\text{quot}} w = \mu w$ with $w \ne 0$, lift $w$ to the nonzero vector $x$ with $x_v = w_{\text{cell}(v)}$. Then $(Ax)_v = \sum_j b_{\text{cell}(v),j}\cdot w_j = \mu \cdot w_{\text{cell}(v)} = \mu \cdot x_v$: an eigenvector. $\blacksquare$

This is Chapter 6's Exercise 6 computation, licensed. The windmill $W_t$ with the partition $\{\text{hub}\} \cup \{\text{everything else}\}$ is equitable (the hub has $2t$ neighbors in the second class; every blade vertex has one neighbor in each), and its $2 \times 2$ quotient $\begin{bmatrix} 0 & 2t \\ 1 & 1 \end{bmatrix}$ has eigenvalues $(1 \pm \sqrt{1+8t})/2$ — exactly the two exotic eigenvalues that Chapter 6's A6 hunted down. ✎ The lab verifies both quotients inside the full Jacobi spectra of $W_2$ and $W_3$.

The unification. Look back with new eyes: Chapter 6's Lecture 4 spectral lemma diagonalized on invariant subspaces; L1's Rayleigh tools are the min–max lemma; L2's $s^2 \le n$ bounded a linear form via Cauchy–Schwarz. Each spectral restriction — to a coordinate block, an invariant subspace, or a partition span — is a compression: restrict the matrix to a well-chosen subspace, then bound. Interlacing is the general theorem that makes every such restriction honest, and it is the tool the next two sections use.

4.2 Hoffman's bound: the smallest eigenvalue prices independence

The inertia bound of §4.1 counts eigenvalues — how many sit on each side of zero. Hoffman's bound makes the sizes of the eigenvalues do the work, and its engine is a construction the next section will reuse at full power: a degenerate inner product.

Lemma (PSD semi-inner products). If $M$ is a real symmetric positive semidefinite matrix, then $\langle x, y \rangle_M = x^T M y$ is a symmetric bilinear form with $\langle x, x \rangle_M \ge 0$ for all $x$, and it satisfies Cauchy–Schwarz: $\langle x, y \rangle_M^2 \le \langle x, x \rangle_M \langle y, y \rangle_M$.

Proof. Symmetry and nonnegativity are the definition of PSD. For Cauchy–Schwarz, complete the square: for any real $t$, $0 \le \langle x - ty, x - ty \rangle_M = \langle x, x \rangle_M - 2t\langle x, y \rangle_M + t^2\langle y, y \rangle_M$. If $\langle y, y \rangle_M > 0$, take $t = \langle x, y \rangle_M/\langle y, y \rangle_M$ and read off the discriminant. If $\langle y, y \rangle_M = 0$, then $\langle x - ty, x - ty \rangle_M = \langle x, x \rangle_M - 2t\langle x, y \rangle_M$ is nonnegative for every $t$, forcing $\langle x, y \rangle_M = 0$, and the inequality reads $0 \le 0$. $\blacksquare$

Degeneracy — the possibility $\langle x, x \rangle_M = 0$ with $x \ne 0$ — is not a bug but the mechanism: the null directions of $M$ are exactly what an extremal independent set exploits.

Theorem (Hoffman's bound). Let $G$ be $d$-regular on $n$ vertices with smallest eigenvalue $\lambda_n < 0$. Then

$$\alpha(G) \le \frac{n \cdot (-\lambda_n)}{d - \lambda_n}.$$

Proof. Set $M = A - \lambda_n I$; it is PSD, since every eigenvalue of $M$ is $\lambda_i - \lambda_n \ge 0$. Take the semi-inner product $\langle \cdot, \cdot \rangle_M$ and let $S$ be a nonempty independent set of size $s$, with $x = \mathbf{1}_S$. Three inner products:

  • $\langle x, x \rangle_M = \mathbf{1}_S^T A \mathbf{1}_S - \lambda_n s = 2e(S) - \lambda_n s = -\lambda_n s$, because $S$ independent means $\mathbf{1}_S^T A \mathbf{1}_S = 2e(S) = 0$;
  • $\langle x, \mathbf{1} \rangle_M = \mathbf{1}_S^T A \mathbf{1} - \lambda_n s = ds - \lambda_n s = s(d - \lambda_n)$, because $d$-regularity counts every edge leaving $S$;
  • $\langle \mathbf{1}, \mathbf{1} \rangle_M = 2m - \lambda_n n = n(d - \lambda_n)$.

Cauchy–Schwarz gives $s^2(d - \lambda_n)^2 \le (-\lambda_n s)\cdot n(d - \lambda_n)$; divide by $s(d - \lambda_n) > 0$. $\blacksquare$

Theorem (Hoffman's chromatic bound). With the same hypotheses, $\chi(G) \ge 1 + d/|\lambda_n|$.

Proof 1 (through $\alpha$). The color classes of a $\chi$-coloring partition $V$ into $\chi$ independent sets, so $\chi \cdot \alpha \ge n$. Feeding in Hoffman's bound: $\chi \ge n/\alpha \ge (d + |\lambda_n|)/|\lambda_n| = 1 + d/|\lambda_n|$. $\blacksquare$

Proof 2 (compression, no $\alpha$ needed). Let $C_1, \dots, C_k$ be the nonempty classes of any proper $k$-coloring, $Q$ the orthonormalized indicator matrix of §4.1, and $B = Q^T A Q$ the compression. Three facts, in order. (i) Each diagonal entry $B_{ii} = q_i^T A q_i = 2e(C_i)/|C_i| = 0$ — the classes are independent — so $\operatorname{tr} B = 0$. (ii) For $w = (\sqrt{|C_1|}, \dots, \sqrt{|C_k|})$ we have $Qw = \mathbf{1}$, so $w^T B w = \mathbf{1}^T A \mathbf{1} = nd$ and $w^T w = n$: the Rayleigh quotient is $d$, giving $\mu_1 \ge d$; interlacing gives $\mu_1 \le \lambda_1 = d$, so $\mu_1 = d$ exactly. (iii) The remaining $k - 1$ eigenvalues sum to $\operatorname{tr} B - \mu_1 = -d$, and each satisfies $\mu_i \ge \lambda_n$ by interlacing. Hence $-d = \sum_{i \ge 2} \mu_i \ge (k - 1)\lambda_n$, i.e. $k \ge 1 + d/|\lambda_n|$. $\blacksquare$

Proof 2 is worth the detour: it never mentions independent sets, it runs entirely on the compression machine of §4.1, and its chain — $\operatorname{tr} B = 0$, $\mu_1 = d$, then $\sum_{i \ge 2}\mu_i = -d$ pinned below by $(k-1)\lambda_n$ — is exactly the kind of bookkeeping the lab can check on real colorings.

Petersen ($d = 3, \lambda_n = -2$). The bound reads $\alpha \le 10 \cdot 2/(3+2) = 4$ — tight, and the five witnesses are the stars of Chapter 6's Exercise ◆12 census. Each star $S$ attains equality in Cauchy–Schwarz: $\langle \mathbf{1}_S, \mathbf{1}_S \rangle_M = 8$, $\langle \mathbf{1}_S, \mathbf{1} \rangle_M = 20$, $\langle \mathbf{1}, \mathbf{1} \rangle_M = 50$, and $8 \cdot 50 = 400 = 20^2$. Equality is explained by direct computation: $M\mathbf{1}_S = 2\mathbf{1}$ and $M\mathbf{1} = 5\mathbf{1}$, so $M(\mathbf{1}_S - (2/5)\mathbf{1}) = 0$ — the difference vector is null for $M$, which is precisely what equality in a degenerate Cauchy–Schwarz demands. The chromatic bound: $\chi \ge 1 + 3/2 = 2.5$, so $\chi \ge 3$, and $3$ it is.

$C_5$ ($d = 2, \lambda_n = -\varphi, \varphi = (1+\sqrt{5})/2$). The bound is $5\varphi/(2 + \varphi)$, and this simplifies exactly: $\varphi\sqrt{5} = (5+\sqrt{5})/2 = 2 + \varphi$, so $5\varphi/(2+\varphi) = \sqrt{5}$. Thus $\alpha \le \sqrt{5} \approx 2.236$ against the true $\alpha = 2$. Hold that number: the next section computes $\theta(C_5) = \sqrt{5}$ exactly — Hoffman and theta agree on the pentagon, from opposite directions.

Three calibrations. $K_n$: $d = n-1, \lambda_n = -1, \alpha \le 1$ and $\chi \ge n$ — both exact. Bipartite $d$-regular: $\lambda_n = -d$, so $\alpha \le n/2$ (structural equality: each side of the bipartition is independent) and $\chi \ge 1 + 1 = 2$ — the bound reads bipartiteness straight off the spectrum. The cocktail party $K_6$ minus a perfect matching ($d = 4$, spectrum $\{4, 0^3, -2^2\}$): $\alpha \le 6 \cdot 2/6 = 2$, tight — the three deleted pairs — and $\chi \ge 3$, exact again.

✎ Checkpoint. The lab sweeps the bound over all 1,122 $d$-regular graphs on $n = 4 \dots 7$ vertices with $\lambda_n < 0$: not once is it violated, and it is tight 225 times (7 of 7 at $n = 4$, 1 of 13 at $n = 5$, 111 of 171 at $n = 6$, 106 of 931 at $n = 7$). The chromatic bound was checked on all 191 regular graphs with $n = 4 \dots 6$ — zero violations — with Proof 2's chain verified coloring by coloring.

4.3 Lovász theta: one number between $\alpha$ and $\chi(\bar{G})$

Hoffman caps $\alpha$ from above with the spectrum, but the cap is one-sided: $\alpha$ can fall well short of it ($C_5$: cap $\sqrt{5}$, truth $2$). Lovász's theta is a different kind of object — a single number that always sits between $\alpha(G)$ and $\chi(\bar{G})$, computable in polynomial time by semidefinite programming, and on the pentagon exactly computable by hand: $\theta(C_5) = \sqrt{5}$.

Definition (orthogonal representation). An orthogonal representation (OR) of $G$ assigns unit vectors $u_1, \dots, u_n$ to the vertices so that $u_i \perp u_j$ whenever distinct vertices $v_i \ne v_j$ are non-adjacent — orthogonality on non-edges, the reverse of the graph's own logic. For a unit handle $c$, the value of the pair $(\{u_i\}, c)$ is $\max_i 1/(c \cdot u_i)^2$, and

$$\theta(G) = \min_{\text{ORs } \{u_i\}, \text{ unit } c} \max_i \frac{1}{(c \cdot u_i)^2}.$$

Calibrations. $\theta(K_n) = 1$: no non-edges means no constraints; take all $u_i = c$ for value $1$, and nothing can beat $1$ since $|c \cdot u_i| \le 1$ for unit vectors always. $\theta(E_n) = n$: the empty graph forces the $u_i$ pairwise orthogonal, so Bessel gives $1 = \|c\|^2 \ge \sum_i (c \cdot u_i)^2$, and some $i$ has $(c \cdot u_i)^2 \le 1/n$ — every representation has value at least $n$. An orthonormal basis with handle $c = \mathbf{1}/\sqrt{n}$ attains it: $c \cdot u_i = 1/\sqrt{n}$ for all $i$.

Theorem (the sandwich). $\alpha(G) \le \theta(G) \le \chi(\bar{G})$.

Proof, lower bound. An independent set $S$ is pairwise non-adjacent, so in any OR the vectors $\{u_i : i \in S\}$ are pairwise orthogonal and Bessel gives $\sum_{i \in S}(c \cdot u_i)^2 \le 1$. Some $i \in S$ has $(c \cdot u_i)^2 \le 1/|S|$, so every representation has value $\ge |S|$; the minimum over representations is at least $\alpha$. $\blacksquare$

Proof, upper bound. A $k$-coloring of the complement $\bar{G}$ is a partition of $V$ into $k$ cliques of $G$. Set $u_i = e_{\text{color}(i)} \in \mathbb{R}^k$ and $c = \mathbf{1}/\sqrt{k}$. Non-adjacent vertices of $G$ are adjacent in $\bar{G}$, so they carry different colors — different standard basis vectors, orthogonal. And $c \cdot u_i = 1/\sqrt{k}$ for every $i$, so the value is exactly $k$. Minimizing over $k = \chi(\bar{G})$. $\blacksquare$

Both ends of the sandwich are NP-hard to compute; $\theta$ itself is not — that is the point (semidefinite programming, cited). On perfect graphs the sandwich collapses to $\theta = \alpha = \chi(\bar{G})$ (cited), which is what makes the pentagon — the smallest imperfect graph — the interesting case: all three numbers differ.

The umbrella. Label $C_5$'s vertices $0, \dots, 4$ cyclically; the non-edges are the five distance-2 pairs. Take an umbrella: five unit vectors at azimuths $2\pi i/5$ around an axis, all tilted by the same angle $\psi$ from it,

$$u_i = (\sin \psi \cdot \cos(2\pi i/5), \sin \psi \cdot \sin(2\pi i/5), \cos \psi), \quad \text{so} \quad u_i \cdot u_j = \sin^2 \psi \cdot \cos(2\pi(i-j)/5) + \cos^2 \psi.$$

Demand orthogonality on the distance-2 pairs: $\sin^2 \psi \cdot \cos(4\pi/5) + \cos^2 \psi = 0$, i.e. $\cos^2 \psi = \cos(\pi/5)/(1 + \cos(\pi/5))$. Now the golden ratio $\varphi = (1+\sqrt{5})/2$ — which already owned $\lambda_n = -\varphi$ in §4.2 — enters twice: $\cos(\pi/5) = \varphi/2$, and $\varphi\sqrt{5} = 2 + \varphi$. So

$$\cos^2 \psi = \frac{\varphi/2}{1 + \varphi/2} = \frac{\varphi}{2 + \varphi} = \mathbf{\frac{1}{\sqrt{5}}, \text{ exactly}}.$$

The machine check confirms it: distance-2 products vanish (to $1.7 \times 10^{-16}$ in floating point). What the umbrella buys is a constant handle price: $c \cdot u_i = \cos \psi = 5^{-1/4}$ for every $i$, so the value is $1/\cos^2 \psi$:

$$\mathbf{\theta(C_5) \le \sqrt{5}.}$$

The adjacent pairs come along for free: $u_i \cdot u_{i+1} = \sin^2 \psi \cdot \cos(2\pi/5) + \cos^2 \psi = (\sqrt{5}-1)/2 = 1/\varphi$. The inner products draw a golden pentagon — $1/\varphi$ on edges, $0$ on non-edges — echoing L3's pentagon, whose squared distances $\{4\sin^2 36^\circ, 4\sin^2 72^\circ\} = \{1.38197, 3.61803\}$ were $\varphi$-fractions too.

Certificates: the dual side. The umbrella bounds $\theta$ from above. For the reverse direction, dual feasible points are matrices one can check by hand.

Lemma (certificate lemma). Let $X$ be a real symmetric $n \times n$ matrix with (i) $X \succeq 0$, (ii) $X_{ij} \ge 0$ entrywise, (iii) $X_{ij} = 0$ on every edge of $G$, (iv) $\operatorname{tr} X = 1$. Then $J \bullet X \le \theta(G)$, where $J$ is the all-ones matrix and $\bullet$ is the entrywise inner product $\sum_{i,j} A_{ij} B_{ij}$.

Proof. Fix any OR $\{u_i\}$ with handle $c$ and value $t$, so $(c \cdot u_i)^2 \ge 1/t$ for every $i$. Let $M$ be the Gram matrix ($M_{ij} = u_i \cdot u_j$) and $v$ the vector $(c \cdot u_i)_i$.

Step 1: $X \bullet M = \operatorname{tr} X$. Expand $X \bullet M = \sum_{i,j} X_{ij}(u_i \cdot u_j)$. The off-diagonal terms die two ways: on edges $X_{ij} = 0$, and on non-edges $u_i \perp u_j$. The diagonal terms are $X_{ii}\cdot \|u_i\|^2 = X_{ii}$ (the $u_i$ are unit). So $X \bullet M = \sum_i X_{ii} = 1$.

Step 2: $M \succeq v v^T$. $M - v v^T$ is the Gram matrix of the residual vectors $u_i - (c \cdot u_i)c$ — hence PSD. Since the Frobenius inner product of two PSD matrices is nonnegative, $0 \le X \bullet (M - v v^T) = 1 - v^T X v$, so $v^T X v \le 1$.

Step 3: an entrywise Cauchy–Schwarz. Every $c \cdot u_i$ is nonzero (it squares to at least $1/t$), and flipping the sign of any $u_i$ preserves both the OR property and all $|c \cdot u_i|$ — so WLOG $v_i > 0$. Then

$$(J \bullet X)^2 = \left(\sum_{i,j} X_{ij}\right)^2 = \left(\sum_{i,j} \sqrt{\frac{X_{ij}}{v_i v_j}}\cdot \sqrt{X_{ij} v_i v_j}\right)^2 \le \left(\sum_{i,j} \frac{X_{ij}}{v_i v_j}\right)\cdot (v^T X v),$$

and since $1/(v_i v_j) \le \max_i(1/v_i^2)$ by AM–GM while $X_{ij} \ge 0$, the first factor is at most $\max_i(1/v_i^2)\cdot (J \bullet X)$. Dividing by $J \bullet X > 0$ (it is at least $\operatorname{tr} X = 1$):

$$J \bullet X \le (v^T X v)\cdot \max_i \frac{1}{v_i^2} \le 1 \cdot t. \quad \blacksquare$$

The circulant certificate, and $\theta(C_5) = \sqrt{5}$. On $C_5$ set $X_{ii} = 1/5$, $X_{ij} = b = (\sqrt{5}-1)/10$ on the five distance-2 pairs, and $X_{ij} = 0$ on the five edges. The four conditions, checked: entrywise nonnegative ✓; zero on edges ✓; $\operatorname{tr} X = 5 \cdot (1/5) = 1$ ✓; and PSD because $X$ is a circulant whose five eigenvalues are

$$\mathbf{\left\{\frac{\sqrt{5}}{5}, \frac{5-\sqrt{5}}{10}, \frac{5-\sqrt{5}}{10}, 0, 0\right\}} \text{ — all nonnegative.}$$

(The trace reads $\sqrt{5}/5 + 2(5-\sqrt{5})/10 = 1$, as it must.) The payoff: $J \bullet X = 1 + 10b = 1 + (\sqrt{5}-1) = \mathbf{\sqrt{5}}$. Machine check: the five eigenvalues, the trace, and $J \bullet X = \sqrt{5}$ verify to $10^{-12}$. So the lemma gives $\theta(C_5) \ge \sqrt{5}$, and with the umbrella:

$\theta(C_5) = \sqrt{5}$ — exactly. The sandwich on the pentagon is strict on both sides: $\alpha = 2 < \theta = \sqrt{5} \approx 2.236 < \chi(\bar{C}_5) = 3$. Note the echo: Hoffman's cap (§4.2) produced the same $\sqrt{5}$ on $C_5$ — the smallest eigenvalue and the semidefinite dual agree on the pentagon, and the truth $2$ sits strictly below both.

The capacity of the pentagon. Shannon's zero-error capacity of $G$ is $\Theta(G) = \sup_k \alpha(G^{\boxtimes k})^{1/k}$, where $\boxtimes$ is the strong product — $(u, v)$ adjacent to $(u', v')$ when each coordinate is equal-or-adjacent and at least one is adjacent. Lovász proved $\theta$ multiplicative under the strong product, $\theta(G \boxtimes H) = \theta(G)\cdot \theta(H)$ (cited); since $\alpha \le \theta$ always, $\alpha(G^{\boxtimes k}) \le \theta(G)^k$, and taking roots:

$$\mathbf{\Theta(G) \le \theta(G)} \text{ — theta caps capacity.}$$

For $C_5$ the interesting floor is the square: $\alpha(C_5 \boxtimes C_5) = 5$, not $4 = \alpha^2$ — machine-checked exhaustively. None of the $\binom{25}{6} = 177{,}100$ six-subsets is independent, and exactly ten five-subsets are; a clean witness is the diagonal $\{(i, 2i \bmod 5) : i = 0..4\}$, independent because doubling turns adjacent pairs into distance-2 pairs and vice versa, so every pair fails adjacency in at least one coordinate. So $\sqrt{5} \le \Theta(C_5) \le \theta(C_5) = \sqrt{5}$, and

$$\mathbf{\Theta(C_5) = \sqrt{5}}$$ — the exact value Shannon's own bounds could not reach; the umbrella and the certificate met it from both sides.

4.4 Delsarte's program: the polynomial method on the Hamming cube

Theta ran Chapter 6's Lecture 3 polynomial thinking through semidefinite geometry; Delsarte's linear program runs it through the Hamming cube — and on the cube, hand-checkable polynomials certify exact code sizes.

Problem. A (binary) code is a subset $C \subseteq \{0,1\}^n$ in which any two distinct words differ in at least $d$ positions (minimum distance $d$); $A(n,d)$ is the largest possible size. Same forbidden-configuration shape as Chapter 6's Lectures 1–3, new ambient space.

The distance distribution. For a nonempty code of size $M$ set $A_i = (1/M)\cdot \#\{\text{ordered pairs } (c, c') \text{ with } d(c, c') = i\}$, $i = 0..n$. Then $A_0 = 1$, $A_i = 0$ for $1 \le i < d$, all $A_i \ge 0$, and $\sum_i A_i = M$. The whole game is to bound $\sum_i A_i$.

Krawtchouk polynomials, two faces. For $0 \le k \le n$,

$$K_k(i) = \sum_{j=0}^k (-1)^j \binom{i}{j}\binom{n-i}{k-j}.$$

Polynomial face: a degree-$k$ polynomial in $i$. Character face: if $x \in \{0,1\}^n$ has $|x| = i$, then $K_k(i) = \sum_{|y| = k} (-1)^{x \cdot y}$ — the character $\chi_y(x) = (-1)^{x \cdot y}$, summed over all $y$ of weight $k$. The two faces agree; the lab checks the identity for $n = 5..8$, every $(i, k)$.

Theorem (Delsarte inequalities). For every code and every $k$: $\sum_i A_i \cdot K_k(i) \ge 0$.

Proof. Multiply by $M$ and use the character face:

$$M \cdot \sum_i A_i K_k(i) = \sum_{c,c'} K_k(d(c, c')) = \sum_{c,c'} \sum_{|y|=k} (-1)^{(c \oplus c') \cdot y}.$$

Now the parity move: $|y \cap (c \oplus c')| \equiv |y \cap c| + |y \cap c'| \pmod 2$, so $(-1)^{(c \oplus c') \cdot y} = (-1)^{c \cdot y}\cdot (-1)^{c' \cdot y}$, and every term factors:

$$\sum_{c,c'} K_k(d(c,c')) = \sum_{|y|=k} \left(\sum_c (-1)^{c \cdot y}\right)^2 \ge 0. \quad \blacksquare$$

A sum of squares — the polynomial method of Chapter 6's Lecture 3, with "vanishes on the other sets" replaced by "is a square when summed".

Lemma (certificates). Let $F = \sum_k f_k K_k$ with $f_0 = 1$, $f_k \ge 0$, and suppose $F(i) \le 0$ for $d \le i \le n$. Then $A(n,d) \le F(0)$.

Proof. Sum $F$ over all ordered pairs of a code of size $M$. Lower bound — only the $k = 0$ square, using Delsarte's proof:

$$\sum_{c,c'} F(d(c,c')) = \sum_k f_k \sum_{|y|=k} \left(\sum_c (-1)^{c \cdot y}\right)^2 \ge f_0 \cdot \left(\sum_c 1\right)^2 = M^2.$$

Upper bound — split the pairs: $c = c'$ contributes $M \cdot F(0)$, and $c \ne c'$ contributes $F(d(c,c')) \le 0$ since $d(c,c') \ge d$. Together $M^2 \le M \cdot F(0)$, i.e. $M \le F(0)$. $\blacksquare$

Plotkin, one line. $F = 1 + K_1/(2d-n)$ (when $2d > n$): since $K_1(i) = n - 2i$, $F(i) = 2(d-i)/(2d-n) \le 0$ for $i \ge d$, so

$$A(n,d) \le F(0) = \frac{2d}{2d-n} \text{ — Plotkin's bound as a single certificate.}$$

Answers to the Exercises

A1. The vector $x$ with $x_u = \sqrt{b}$ on the $A$-side and $x_v = \sqrt{a}$ on the $B$-side is an eigenvector: for $u \in A$, $(Ax)_u = \sum_{v \sim u} x_v = b\sqrt{a} = \sqrt{ab}\cdot \sqrt{b} = \sqrt{ab}\cdot x_u$, and symmetrically on $B$. So $\lambda_1 = \sqrt{ab}$ (Perron–Frobenius: entrywise-nonnegative eigenvectors belong to $\lambda_1$). Against L1: $m = ab$, so Lemma 2 ($\lambda_1 \le \sqrt{m}$) is tight for every complete bipartite graph; Lemma 1 ($\lambda_1 \ge 2m/n$) is tight iff $2ab/(a+b) = \sqrt{ab} \iff (a-b)^2 = 0$, i.e. $a = b$. The sandwich thus singles out the balanced case $a = b = n/2$ for even $n$ directly, and for odd $n$ integrality $m \le \lfloor n^2/4 \rfloor$ selects $K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$.

A2. Center: $w_i = p_i - \text{mean}$, $\sum w_i = 0$. Summing $\|w_i - w_j\|^2$ over $j$ gives $(k-1)\delta^2 = k\|w_i\|^2 + \sum_j \|w_j\|^2$, and summing over $i$ gives $k(k-1)\delta^2 = 2k\sum_j \|w_j\|^2$, whence $\|w_i\|^2 = (k-1)\delta^2/(2k)$, $w_i \cdot w_j = -\delta^2/(2k)$ for $i \ne j$, and $G = (\delta^2/2)(I - J/k)$ — spectrum $\{\delta^2/2 \times (k-1), 0\}$, rank $k - 1$ (the $\mathbf{1}$ direction is killed by centering). Since $G = W W^T$ with $W$ of $k$ rows in $\mathbb{R}^d$: $k - 1 = \operatorname{rank} G = \operatorname{rank} W \le d$, so $k \le d + 1$. Attainment: the standard simplex $w_i = e_i - \mathbf{1}/k$ in the hyperplane $\sum x = 0 \subset \mathbb{R}^k$ (dimension $k - 1 = d$): pairwise $\text{distance}^2 = 2$, $\text{norms}^2 = (k-1)/k$ — $d + 1$ equidistant points in $\mathbb{R}^d$. Machine check: the centered Gram's spectrum $\{1 \times (k-1), 0\}$ and the simplex data verified for $k = 2 \dots 9$.

A3. Let $x$ be a unit Perron vector of a component carrying $\lambda_1$ (entrywise $\ge 0$; for disconnected $G$ the component argument applies verbatim, and if $E = \emptyset$ then $\lambda_1 = 0 = (1-1/1)n$). With $s = \sum x_v > 0$: $\lambda_1 = x^T A x = 2\sum_{uv \in E} x_u x_v = 2s^2 \cdot f(x/s)$, and Motzkin–Straus caps $f(x/s)$ at $(1-1/\omega)/2$; Cauchy–Schwarz caps $s^2 \le n\|x\|^2 = n$. Chained: $\lambda_1 \le (1 - 1/\omega)n$. Rayleigh (L1.1) then gives $m \le n\lambda_1/2 \le (1 - 1/\omega)n^2/2$; for $K_{r+1}$-free graphs $\omega \le r$, so $m \le (1 - 1/r)n^2/2$: Turán. Machine check: all 33,792 graphs on 5 and 6 vertices satisfy $\lambda_1 \le (1-1/\omega)n$; $K_{3,3}$ has $\lambda_1 = 3 = (1 - 1/2)\cdot 6$ — equality.

A4. An independent $S$ of size $\alpha$ makes the principal submatrix $A_S$ the zero matrix: $\alpha$ eigenvalues $\mu$, all equal $0$. Interlacing reads this twice: $\mu_\alpha = 0$ with $\mu_i \le \lambda_i$ gives $\lambda_\alpha \ge 0$ — at least $\alpha$ eigenvalues are nonnegative, $\alpha \le p + z$; and $\mu_1 = 0$ with $\mu_i \ge \lambda_{i+n-\alpha}$ gives $\lambda_{1+n-\alpha} \le 0$ — at least $\alpha$ are nonpositive, $\alpha \le q + z$ ($z =$ zero count). Since $p + z = n - q$ and $q + z = n - p$: $\alpha \le n - q$ and $\alpha \le n - p$. Petersen $\{3, 1^5, -2^4\}$: $p = 6, q = 4$ — $n - p = 4 = \alpha$, tight (the $n - q$ side says $6$, slack). $C_5$ $\{2, 0.618^2, -1.618^2\}$: $p = 3, q = 2$ — $n - p = 2 = \alpha$, tight. Census (all 1,099 graphs with $n \le 5$, Part 3(a)): zero violations on either side; the $n - p$ reading is tight 633 times, the $n - q$ reading 954 — the weaker of the two bounds is met more often, as it should be — and the honest combined bound $\alpha \le \min(n-p, n-q)$ is tight 966 times. The two sides agree exactly when $p = q$, in particular for every graph whose components are all bipartite.

A5. Petersen ($d = 3, \lambda_n = -2$): the bound is $10 \cdot 2/5 = 4 = \alpha$ — tight, witnesses the five stars. A10. A closed walk of length 3 is a triangle traversed from a chosen start vertex in a chosen direction: every triangle contributes $3 \cdot 2 = 6$ walks, and $(A^3)_{vv}$ counts the length-3 closed walks starting at $v$. So $\operatorname{tr}(A^3) = \sum_v (A^3)_{vv} = 6t$. And $\operatorname{tr}(A^3) = \sum_i \lambda_i^3$, since $A = Q\Lambda Q^T$ makes $A^3 = Q\Lambda^3 Q^T$ — the triangle count is a symmetric function of the spectrum, readable without ever looking at the edges. Machine check, three engines agreeing on all six graphs: $K_4 \to 4$, the paw $\to 1$, the diamond $\to 2$, $C_5 \to 0$, $K_{3,3} \to 0$, Petersen $\to 0$; direct triangle count, $\operatorname{tr}(A^3)/6$, and $\sum_i \lambda_i^3/6$ identical throughout. $K_{3,3}$'s spectrum is $\{3, 0^4, -3\}$: $\sum_i \lambda_i^3 = 27 - 27 = 0$. The cube is an odd function, so the $+3$ and the $-3$ cancel — bipartiteness pairs every eigenvalue with its negation, and the pairing kills the count. That is the moral: no single eigenvalue sees triangles; the sum of cubes does. Exercise 11 spends exactly this identity.

A11. First $\lambda_n < 0$: if all eigenvalues were $\ge 0$, then $\operatorname{tr}(A^3) \ge d^3 > 0$ would force a triangle. For $i \ge 2$: if $\lambda_i \ge 0$ then $\lambda_i^3 \ge 0 \ge \lambda_n \cdot \lambda_i^2$; if $\lambda_i < 0$ then $\lambda_i \ge \lambda_n$ gives $\lambda_i^3 = \lambda_i \cdot \lambda_i^2 \ge \lambda_n \cdot \lambda_i^2$. Either way $\lambda_i^3 \ge \lambda_n \cdot \lambda_i^2$, so $0 = \operatorname{tr}(A^3) = d^3 + \sum_{i \ge 2}\lambda_i^3 \ge d^3 + \lambda_n \cdot \sum_{i \ge 2}\lambda_i^2$ — and $\sum_{i \ge 2}\lambda_i^2 = \operatorname{tr}(A^2) - d^2 = 2m - d^2 = d(n-d)$, the same bookkeeping that priced $K_{3,3}$'s degeneracy in the formula box. Hence $0 \ge d^3 + \lambda_n \cdot d(n-d)$, i.e. $|\lambda_n| \ge d^2/(n-d)$, and $\mu \ge |\lambda_n|$ closes the claim. def chi_color(adj, n):
    for k in range(1, n+1):
        color = [-1]*n
        def bt(v):
            if v == n: return True
            used = {color[w] for w in range(n) if adj[v] >> w & 1 and color[w] >= 0}
            for c in range(k):
                if c not in used:
                    color[v] = c
                    if bt(v+1): return True
                    color[v] = -1
            return False
        if bt(0): return k, color

def solve(Mo, b):                     # exact solution of a square system
    n = len(Mo); A = [r[:] + [b[i]] for i, r in enumerate(Mo)]
    for c in range(n):
        p = next((r for r in range(c, n) if A[r][c] != 0), None)
        if p is None: return None
        A[c], A[p] = A[p], A[c]
        pv = A[c][c]; A[c] = [v/pv for v in A[c]]
        for r in range(n):
            if r != c and A[r][c] != 0:
                A[r] = [v - A[r][c]*w for v, w in zip(A[r], A[c])]
    return [A[i][n] for i in range(n)]

def lp_extreme(rows, rhs, obj, maximize):
    nv = len(rows[0])
    cons = [(row, r) for row, r in zip(rows, rhs)]
    cons += [([Fr(int(i == t)) for i in range(nv)], Fr(0)) for t in range(nv)]
    best = None
    for basis in combinations(range(len(cons)), nv):
        sol = solve([cons[k][0] for k in basis], [cons[k][1] for k in basis])
        if sol is None or any(x < 0 for x in sol): continue
        if any(sum(a*b for a, b in zip(row, sol)) < r for row, r in cons): continue
        val = sum(a*b for a, b in zip(obj, sol))
        if best is None or (maximize and val > best) or (not maximize and val < best):
            best = val
    return best

def brute(n, d):                       # A(n, d) by backtracking
    far = lambda a, b: bin(a ^ b).count("1") >= d
    best = 0
    def extend(code, cand):
        nonlocal best
        if len(code) + len(cand) <= best: return
        if not cand: best = max(best, len(code)); return
        w = cand[0]
        extend(code + [w], [c for c in cand[1:] if far(w, c)])
        extend(code, cand[1:])
    extend([], list(range(1 << n)))
    return best
