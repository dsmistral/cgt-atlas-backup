Chapter 2 planted a seed you have been carrying ever since. Cayley's formula says $n^{n-2}$ trees grow on $n$ labeled vertices — and then the exploration X1 asked: how many shapes? Not trees, tree types — two trees counted once if some relabeling carries one onto the other. The labeled count explodes; the shape count limps along as $1, 1, 1, 2, 3, 6, 11, 23$. The exploration named the tool that answers such questions — Pólya's machine — and deferred it. This is the chapter where the debt is paid. Symmetry (Lectures 1–2) is the discipline of counting orbits — objects up to relabeling, colorings up to rotation, molecules up to the symmetries of their frame — and it comes in two acts: Burnside's lemma averages a group over its fixed points, and Möbius inversion runs the same averaging idea backwards, recovering the individual counts that a pile of sums has smeared together. Design (Lectures 3–4) is the second half: combinatorial objects — Steiner triple systems, projective planes, the schoolgirls' walking schedule — whose existence is governed by pure arithmetic divisibility. The through-line is a counting question asked three ways: when you average over symmetry, what are you really counting; when you invert an average, what survives; and when you demand that every pair of points sit in exactly one block, which universes of points are even possible? Codes (Lectures 5–6) close the circle: the error-correcting codes of Chapter 8 return with their Singleton and Plotkin bounds, and the Golay codes — the best single page in coding theory, Berlekamp called their 1949 announcement — turn out to be designs in disguise: their weight supports are the Witt systems $S(4,5,11)$, $S(5,6,12)$, and $S(5,8,24)$, whose automorphism groups are the sporadic Mathieu groups.

Notation. A group action of a group $G$ on a set $X$ is a map $G \times X \to X$, written $g\cdot x$, with $e\cdot x = x$ and $g\cdot(h\cdot x) = (gh)\cdot x$; the orbit of $x$ is $G\cdot x = \{g\cdot x : g \in G\}$; $X/G$ is the set of orbits, and $\operatorname{Fix}(g) = \{x : g\cdot x = x\}$. A cycle type is the multiset of cycle lengths in a permutation's disjoint-cycle decomposition; $c(g)$ is its number of cycles. The cycle index of an action on $n$ points is the polynomial $Z_G(x_1,\dots,x_n) = \frac{1}{|G|}\sum_{g\in G} x_1^{c_1(g)}\cdots x_n^{c_n(g)}$, where $c_i(g)$ is the number of $i$-cycles in $g$. A poset $(P, \le)$ is a partially ordered set; $\mu(x,y)$ is its Möbius function, defined by $\mu(x,x) = 1$ and $\sum_{x\le z\le y} \mu(x,z) = 0$ for $x < y$. A $t$-$(v,k,\lambda)$ design is a $v$-point set with a family of $k$-subsets (blocks) such that every $t$-subset of points lies in exactly $\lambda$ blocks; Steiner system $S(t,k,v) =$ a $t$-$(v,k,1)$ design; $b =$ number of blocks, $r =$ number through a fixed point; a design is resolvable when its blocks partition into parallel classes, each class partitioning the point set. A projective plane of order $q$ is a design with $q^2+q+1$ points, $q+1$ points per line, any two points on exactly one line (so $S(2, q+1, q^2+q+1)$). An $[n,k,d]_q$ code is a $q$-ary linear code of length $n$ with $q^k$ codewords and minimum distance $d$; MDS $=$ meeting the Singleton bound $d = n-k+1$; $A_q(n,d)$ is the largest size of any $q$-ary $(n,d)$-code.

Lecture 1 · The Orbit-Counting Machine: Burnside, Pólya, and the Shapes of Trees

1.1 The question Chapter 2 left open

Cayley's formula counts trees on labeled vertices: $16$ of them at $n = 4$, $125$ at $n = 5$, $1{,}296$ at $n = 6$, $16{,}807$ at $n = 7$. But the number of shapes — unlabeled trees, isomorphism classes — is $2, 3, 6, 11$ at those sizes. The labeled count is a pile of copies: every shape on $n$ vertices contributes exactly $n!/|\operatorname{Aut}(\text{shape})|$ labelings (its automorphisms fold labelings onto each other), so the labeled world and the shape world are related by a sum you cannot read backwards:

$$n^{n-2} = \sum_{\text{shapes } S} \frac{n!}{|\operatorname{Aut}(S)|}.$$

Two shapes with different automorphism groups contribute differently, and nothing about the equation lets you pull the shape count out. What is missing is a machine that counts orbits — equivalence classes under a group action — directly. Burnside's lemma is that machine, and it is almost embarrassingly simple once you see the double counting that powers it.

1.2 Burnside: averaging as an exact identity

Lemma (Burnside — actually Cauchy 1845, Frobenius 1887; Burnside popularized it in his 1897 textbook, always with credit to Frobenius). For a finite group $G$ acting on a finite set $X$, the number of orbits is the average number of fixed points:

$$|X/G| = \frac{1}{|G|} \sum_{g\in G} |\operatorname{Fix}(g)|.$$

Proof. Count pairs $(g, x)$ with $g\cdot x = x$, two ways. Summing over group elements gives $\sum_{g\in G} |\operatorname{Fix}(g)|$. Summing over points gives $\sum_{x\in X} |\operatorname{Stab}(x)|$, and each point's orbit has size $|G|/|\operatorname{Stab}(x)|$ — the cosets of its stabilizer — so the points of one orbit contribute $|G|$ in total. Orbits therefore each contribute exactly $|G|$ to the second sum, and dividing by $|G|$ counts orbits. Both sums equal, divide, done. $\blacksquare$

This is Stigler's law in its purest form — the lemma that is not Burnside's — and the proof shows why the averaging works: it is not an estimate, it is bookkeeping. The orbit count falls out of a double count of pairs.

The machine: the rotation group $C_4$ acts on the $16$ colorings. The identity fixes $16$; the rotations by one and three beads fix only the $2$ constant colorings; rotation by two fixes $4$. Burnside: $(16 + 2 + 4 + 2)/4 = 6$. The answer $6$ — not $4$ — is the orbit count, and the all-white and all-black necklaces are exactly the orbits whose small stabilizers made the division naive. Run the same computation for $n = 1..12$ and the census is $2, 3, 4, 6, 8, 14, 20, 36, 60, 108, 188, 352$ — each value machine-checked two ways in this chapter's lab: brute-force canonicalization of every one of the $2^n$ strings against the same formula $\frac{1}{n}\sum_{k=0}^{n-1} 2^{\gcd(n,k)}$, agreement at every $n$.

1.3 Pólya: the cycle index turns the lemma into a polynomial

Burnside's sum demands $|\operatorname{Fix}(g)|$ for each group element, and for coloring problems that is a one-liner: a coloring is fixed by $g$ exactly when it is constant on each cycle of $g$, so a $k$-coloring has $k^{c(g)}$ fixed colorings, $c(g)$ the cycle count. Substitute and you have Pólya's enumeration theorem:

$$\text{number of orbits of } k\text{-colorings} = Z_G(k, k, \dots, k), \quad \text{where } Z_G(x_1, \dots, x_n) = \frac{1}{|G|} \sum_{g \in G} \prod_{i=1}^n x_i^{c_i(g)}.$$

The polynomial $Z_G$ — the cycle index — is worth computing once and keeping: it answers the coloring question for every $k$ at the same time. (History's honest note: J. H. Redfield published the essence of this in 1927, in a paper so obscure that Pólya's 1937 independent rediscovery — motivated by counting chemical isomers — gave the theorem its name; “Redfield–Pólya” is the fair hyphenation.)

The cube. Color the six faces of a cube with $k$ colors, up to rotation. The rotation group of the cube has $24$ elements — machine-verified in this chapter's lab by generating the closure of two quarter-turns — with five cycle types on faces, machine-tallied as $1^6:1$, $2^2 1^2:3$, $2^3:6$, $3^2:8$, $4\cdot 1^2:6$ (identity; $180^\circ$ turns about face axes; $180^\circ$ turns about edge axes; $120^\circ$ turns about vertex axes; quarter-turns about face axes — the counts sum to $24$). A coloring fixed by a rotation is constant on each cycle, so each type contributes $k^{\text{\#cycles}}$: $k^6$, $k^4$, $k^3$, $k^2$, $k^3$ respectively, and the cycle index collapses to

$$\frac{k^6 + 3k^4 + 12k^3 + 8k^2}{24},$$

and for $k = 1, 2, 3, 4, 5$ the counts are $1, 10, 57, 240, 800$ — every value machine-verified against brute-force canonicalization of all $k^6$ labeled colorings under all $24$ rotations. Pólya's original motivation was exactly this kind of question — counting chemical isomers, where a molecule's mirror-symmetric carbon framework turns equivalent labelings into one compound — and the closed form explains at a glance why the count at $k = 2$ is $10$ rather than anything near the naive $2^6/24$: the two constant colorings ride through all $24$ rotations fixed, inflating their orbits' share of the average.

1.4 Paying Chapter 2's debt: tree shapes by multiset closure

The tree-shape sequence — the X1 counts $1, 1, 1, 2, 3, 6$ extended to $n = 8$ — is not a Pólya application in the direct sense (the “group” would act on an infinite set), but it is the same philosophy: count orbits by building each exactly once. The engine that does it is recursive and canonical. A rooted tree of size $n$ is a multiset of rooted trees of sizes summing to $n-1$, so rooted shapes are generated by multisets of smaller ones, deduplicated by generating multisets in sorted order — every shape produced exactly once, no isomorphism test needed. The unrooted version splits by centroid: a tree has either one centroid (count: rooted multisets of total size $n-1$ with every branch at most $\lfloor(n-1)/2\rfloor$) or two ($n$ even: an unordered pair of rooted trees of size $n/2$), and the two cases are disjoint.

The census, machine-run twice (multiset generation, and full Prüfer-sequence enumeration over all $n^{n-2}$ labeled trees with canonical-form dedup — the two agree at every $n$): unrooted shapes $n = 1..8$ are $1, 1, 1, 2, 3, 6, 11, 23$; rooted, $1, 1, 2, 4, 9, 20, 48, 115$. Chapter 2's first six values are exactly the opening of these sequences, and the automorphism-group subtlety that broke the naive division — why $1{,}296$ labeled $6$-vertex trees do not divide by $720$ into an integer count of shapes — is now visible in the machine: the shapes' $|\operatorname{Aut}|$ values range from $2$ to $120$ and the sum $\sum_S n!/|\operatorname{Aut}(S)| = n^{n-2}$ balances term by term.

1.5 What to learn

Symmetry counting is double counting in disguise. Burnside's lemma is proved in two lines by counting pairs; Pólya's theorem packages the fixed-point counts into a polynomial that answers a whole family of questions at once; and the way to generate orbits directly — never produce two representatives of the same orbit, rather than produce and deduplicate — scales to the tree-shape census where the group is too wild to enumerate. The averaging pattern (P10) here upgrades from “some object beats the average” to “the average is the answer.”

Lecture 2 · Möbius Inversion: Running the Sieve Backwards

2.1 The averaging problem, inverted

Burnside computes one aggregate (the orbit count) from many local counts (the fixed points). Averaging has a mirror problem, and number theory lived in it for a century: every positive integer $n$ carries the divisor sum

$$\sum_{d\mid n} 1 = \tau(n), \quad \text{the number of divisors of } n.$$

Fine — but suppose you know $\tau$ and want something behind it. The classic behind-the-scenes function is the Möbius function $\mu(n)$, the number-theoretic bellows: $\mu(n) = (-1)^k$ if $n$ is a product of $k$ distinct primes, $\mu(n) = 0$ if any prime divides $n$ twice, $\mu(1) = 1$. Its whole job is the inversion formula:

$$\text{if } g(n) = \sum_{d\mid n} f(d) \text{ for all } n \ge 1, \quad \text{then } f(n) = \sum_{d\mid n} \mu(d)\,g(n/d).$$

Read it as recovering the individual from the pile of sums. Why does $\mu$ do this? Because $\sum_{d\mid n} \mu(d) = 0$ unless $n = 1$, when it is $1$ — the Möbius function sums to an identity over the divisors of any $n > 1$, which is exactly what an inverse needs. Specifically, first verify the divisor sum $\sum_{d \mid n} \mu(d) = [n = 1]$: for $n = 1$, $\mu(1) = 1$; for $n > 1$ with prime factorization $n = p_1^{a_1} \cdots p_r^{a_r}$ ($r \ge 1$), only squarefree divisors $d = \prod_{i \in S} p_i$ ($S \subseteq \{1,\dots,r\}$) have $\mu(d) \ne 0$, so $\sum_{d \mid n} \mu(d) = \sum_{k=0}^r \binom{r}{k} (-1)^k = (1 - 1)^r = 0$. Substituting $g(n/d) = \sum_{c \mid (n/d)} f(c)$ into the inversion sum and setting $m = cd$ (so $c \mid n$ and $d \mid (n/c)$) gives $$\sum_{d \mid n} \mu(d)\,g(n/d) = \sum_{d \mid n} \mu(d) \sum_{c \mid (n/d)} f(c) = \sum_{c \mid n} f(c) \sum_{d \mid (n/c)} \mu(d) = \sum_{c \mid n} f(c)\,[n/c = 1] = f(n).$$

The identity $\sum_{d\mid n} \mu(d) = [n = 1]$ and the sibling identities $\sum_{d\mid n} \varphi(d) = n$ and $\sum_{d\mid n} d\,\mu(n/d) = \varphi(n)$ are all machine-verified in this chapter's lab over every $n \le 10{,}000$ — zero mismatches; spot values: $\tau(60) = 12$, $\varphi(60) = 16$, $\varphi(100) = 40$.

2.2 Rota's move: the poset is the thing

In 1964 Gian-Carlo Rota asked the question that turned a number-theory trick into a combinatorial theory: where does $\mu$ really live? Answer: on the divisor lattice — the poset of divisors of $n$ ordered by divisibility, where $d \le e$ means $d \mid e$. Number-theoretic $\mu(d)$ is a value attached to the pair $(1, n)$ of that poset, filtered through the pairs $(d, e)$ with $e/d$ squarefree. And the definition that generalizes is this:

Poset Möbius function. On a finite poset $P$, define $\mu(x, y)$ for $x \le y$ by $\mu(x, x) = 1$ and, for $x < y$,

$$\mu(x, y) = -\sum_{x \le z < y} \mu(x, z).$$

The recursion runs upward: to know $\mu(x, y)$ you need $\mu$ on the interval strictly below $y$. (Two traps for the implementer, both caught by the lab's own consistency checks: the sum excludes $z = y$ — including it makes the recursion self-referential and silently wrong; and the recursion accumulates from $x$ upward, not from $y$ downward.) The inversion theorem is then pure algebra:

Theorem (Möbius inversion on posets). Let $P$ be a locally finite poset with minimum element $\hat{0}$ (or fix any lower bound $x_0 \in P$). If $g(y) = \sum_{x_0 \le z \le y} f(z)$ for all $y \ge x_0$, then $$f(y) = \sum_{x_0 \le z \le y} g(z)\,\mu(z, y).$$ Dually, if $P$ is finite and $h(x) = \sum_{z \ge x} f(z)$ for all $x \in P$, then $f(x) = \sum_{z \ge x} \mu(x, z)\,h(z)$.

Proof. In the incidence algebra of $P$, where convolution of two interval functions $\alpha, \beta$ is defined by $(\alpha * \beta)(x, y) = \sum_{x \le z \le y} \alpha(x, z)\,\beta(z, y)$, the identity element is the Kronecker delta $\delta(x, y) = [x = y]$ and the zeta function is $\zeta(x, y) = [x \le y]$. By the defining recursion of $\mu$, for any $x \le y$ we have $(\mu * \zeta)(x, y) = \sum_{x \le z \le y} \mu(x, z) = [x = y] = \delta(x, y)$, so $\mu$ is the left (and hence two-sided, in the associative incidence algebra) inverse of $\zeta$, giving $(\zeta * \mu)(w, y) = \sum_{w \le z \le y} \mu(z, y) = \delta(w, y)$. Substituting $g(z) = \sum_{x_0 \le w \le z} f(w)$ yields $$\sum_{x_0 \le z \le y} g(z)\,\mu(z, y) = \sum_{x_0 \le w \le y} f(w) \sum_{w \le z \le y} \mu(z, y) = \sum_{x_0 \le w \le y} f(w)\,\delta(w, y) = f(y). \quad \blacksquare$$ Rota's 1964 paper (“On the foundations of combinatorial theory I. Theory of Möbius functions”) made this the founding observation of modern enumerative combinatorics: choose the poset, get a $\mu$, get an inversion.

2.3 Three posets, three $\mu$'s

  • The divisor lattice of $n$. $\mu(1, n)$ is the classical Möbius $\mu(n)$; $\mu(d, e) = \mu(e/d)$ filtered as above. The whole of elementary number-theory sieving is one poset.
  • The Boolean lattice $B_k$. Every proper extension of the empty set flips sign: $\mu(\emptyset, S) = (-1)^{|S|}$ (and more generally $\mu(T, S) = (-1)^{|S \setminus T|}$ for $T \subseteq S$, proved by induction on $m = |S \setminus T|$ using $\sum_{j=0}^m \binom{m}{j}(-1)^j = [m = 0]$), machine-verified for $k \le 6$ in the lab (all $64$ intervals $[\emptyset, S]$ of $B_6$ checked against the recursion). Inclusion-exclusion — the oldest trick in the counting book — is Möbius inversion on $B_k$; the pattern map's averaging entry and this lecture are the two faces of one coin.
  • The partition lattice $\Pi_n$ (set partitions ordered by reverse refinement: the single-block whole set is the bottom $\hat{0}$, singletons-only is the top $\hat{1}$; note that under dualization to standard refinement where singletons are $\hat{0}$ and the whole set is $\hat{1}$, $\mu_{\text{dual}}(\hat{0}_{\text{dual}}, \hat{1}_{\text{dual}}) = \mu(\hat{0}, \hat{1})$ is identical). This one is genuinely nontrivial: $|\Pi_n| = 1, 2, 5, 15, 52$ for $n = 1..5$, and the machine census of $\mu(\hat{0}, \hat{1})$ — the Möbius value of the whole lattice, bottom to top — is $1, -1, 2, -6, 24$: that is, $\mu(\hat{0}, \hat{1}) = (-1)^{n-1}(n-1)!$. To see why for every $n \ge 1$: for any positive integer $\lambda$, let $g(\pi) = \lambda^{|\pi|}$ be the number of ways to color the $n$ elements with $\lambda$ colors so that each block of $\pi$ is monochromatic, and let $f(\sigma)$ be the number of colorings whose exact color-class partition is $\sigma$ (which is $\lambda(\lambda-1)\cdots(\lambda - |\sigma| + 1)$). Since a coloring is constant on each block of $\pi$ if and only if its color-class partition $\sigma$ is coarser than or equal to $\pi$ ($\sigma \le \pi$ in our order where the $1$-block partition is $\hat{0}$ and singletons $\hat{1}$), we have $g(\pi) = \sum_{\hat{0} \le \sigma \le \pi} f(\sigma)$. By Möbius inversion at $\pi = \hat{1}$ (where $f(\hat{1}) = \lambda(\lambda-1)\cdots(\lambda - n + 1)$ counts injective colorings), $$\lambda(\lambda - 1)\cdots(\lambda - n + 1) = \sum_{\hat{0} \le \sigma \le \hat{1}} \lambda^{|\sigma|}\,\mu(\sigma, \hat{1}).$$ Since both sides are polynomials in $\lambda$ agreeing for all $\lambda \in \mathbb{Z}_{\ge 1}$, equating the coefficient of $\lambda^1$ (which comes solely from the $1$-block partition $\sigma = \hat{0}$ on the right, and equals $(-1)^{n-1}(n-1)!$ on the left) proves $\mu(\hat{0}, \hat{1}) = (-1)^{n-1}(n-1)!$.

2.4 What to learn

Averaging hides individuals; inversion buys them back. The structure that makes inversion possible is a poset with a $\mu$ attached — and once the incidence algebra is in hand, inclusion-exclusion, the divisor identities, and the partition-lattice sign pattern all become one theorem read off three lattices. The “recover what was averaged” pattern is the proposed registry entry; Burnside and Möbius, Lectures 1 and 2, are the two directions of the same coin.

Lecture 3 · Designs I: Steiner's Question, Fisher's Inequality, and the Planes That Cannot Exist

3.1 The schoolgirl's diary and Steiner's question

In 1844 Woolhouse posed, in the Lady's and Gentleman's Diary, the problem of arranging triples so that no pair repeats; Kirkman solved the existence question for triples in 1846 (the paper sits in the journal's 1847 volume — cite Kirkman 1846/47), and in 1850 posed his famous walking problem: fifteen schoolgirls, seven days, rows of three, every pair together exactly once per week. Steiner asked the abstract version for $k$-subsets in 1853, unaware of Kirkman, and the objects carry Steiner's name. Definitions:

A $t$-$(v, k, \lambda)$ design is a $v$-point set $X$ and a family $\mathcal{B}$ of $k$-subsets (blocks) such that every $t$-subset of $X$ lies in exactly $\lambda$ blocks. $\lambda = 1$ gives a Steiner system $S(t, k, v)$. For $t = 2, k = 3$: a Steiner triple system $\operatorname{STS}(v)$. Counting constants: a $t$-design with $v$ points, $b$ blocks, $r$ blocks through a fixed point, satisfies $\lambda\binom{v}{t} = b\binom{k}{t}$ and $r\binom{k-1}{t-1} = \lambda\binom{v-1}{t-1}$ (which for $t = 2$ gives $r = \lambda(v-1)/(k-1)$) — double counting the (block, $t$-subset) pairs two ways. For an $\operatorname{STS}$: $b = v(v-1)/6$ and $r = (v-1)/2$.

3.2 The arithmetic gate: $v \equiv 1, 3 \pmod{6}$, and the exhibit that cannot exist

Integrality of $b$ and $r$ forces $v \equiv 1 \text{ or } 3 \pmod{6}$. The gate has two leaves, both machine-walked in the lab: $r = (v-1)/2$ integer says $v$ is odd, leaving $v \equiv 1, 3, 5 \pmod{6}$; then $b = v(v-1)/6$ needs $3 \mid v(v-1)$, which fails exactly when $v \equiv 2 \pmod{3}$ — that is, at $v \equiv 5 \pmod{6}$ — leaving $v \equiv 1 \text{ or } 3 \pmod{6}$. The remarkable theorem (Kirkman's constructions, completed by Bose 1939 and Skolem 1958): $\operatorname{STS}(v)$ exists if and only if $v \equiv 1 \text{ or } 3 \pmod{6}$ ($v \ge 3$) — the arithmetic gate is the whole story.

And here is the chapter's worked non-existence exhibit, the one the scope sheet nearly fumbled: $S(2,3,6)$ does not exist. The formula gives $r = (6-1)/2 = 5/2$ — not an integer, so no system. The lab makes this a machine proof, not an algebra shrug: over all $\binom{20}{5} = 15{,}504$ candidate $5$-block families from the $20$ triples on $6$ points, exactly zero exact covers exist. Divisibility is not a technicality; it is the admission fee, and $v = 6$ cannot pay.

3.3 Fisher's inequality: $b \ge v$

For nontrivial $2$-designs, block count can never duck below point count:

Theorem (Fisher 1940). In a $2$-$(v, k, \lambda)$ design with $2 \le k < v$ and $\lambda \ge 1$, $b \ge v$.

Chapter 6 proved this two ways — the Gram determinant of the block incidence vectors (a square $v \times v$ Gram matrix whenever $b = v$, with $\det(NN^T) = (r-\lambda)^{v-1}\cdot(r+(v-1)\lambda)$; the Fano-plane instance prints $(3-1)^6\cdot 9 = 576 = 24^2$) and Bose's linear-algebra argument. What this chapter adds is the census view: Fisher is tight at the bottom and slack immediately above. The Fano plane $\operatorname{STS}(7)$: $b = v = 7$, tight. $\operatorname{STS}(9)$ — the machine census finds exactly $840$ labeled systems, all isomorphic (one orbit; the affine plane $\operatorname{AG}(2,3)$): $b = 12 > 9$. The projective plane of order $3$ (next section): $b = v = 13$, tight again — and this is no accident: the equality case $b = v$ of Fisher is precisely the symmetric designs, where any two distinct blocks also meet in exactly $\lambda$ points, duality everywhere.

3.4 Projective planes, and the orders that cannot exist

A projective plane of order $q$ is a design with $v = q^2+q+1$ points, blocks (lines) of size $q+1$, every pair of points on exactly one line — that is, $S(2, q+1, q^2+q+1)$. Finite field arithmetic builds one for every prime power $q$: points $=$ $1$-dimensional subspaces of $\mathbb{F}_q^3$, lines $=$ $2$-dimensional ones. The machine instance this chapter carries everywhere is $\operatorname{PG}(2,3)$: $13$ points, $13$ lines of $4$ points, every pair on exactly one line (all $78$ pairs machine-checked) — an $S(2,4,13)$, Fisher-tight with $b = v = 13$. The affine plane $\operatorname{AG}(2, q)$ — $\operatorname{STS}(9)$ at $q = 3$ — is the projective plane minus a line and its points.

Do planes exist at every order? Here the story becomes one of combinatorics' great campaigns. The order-$2$ plane (the Fano plane, $v = 7$) is unique; order $3$ unique; and then:

Theorem (Bruck–Ryser 1949; generalized to symmetric designs by Bruck–Ryser–Chowla 1950). If a projective plane of order $q \equiv 1 \text{ or } 2 \pmod{4}$ exists, then $q$ is a sum of two integer squares.

The lab runs the census: $q = 6$ and $q = 14$ are $2 \pmod{4}$ and not sums of two squares — no plane of order $6$, none of order $14$. $q = 10$ is $2 \pmod{4}$ but $10 = 1^2 + 3^2$, so Bruck–Ryser is silent; the true obstruction took until 1989, when Lam, Thiel and Swiercz closed order $10$ by coding theory plus one of the largest computer searches of its era. And $q = 12$ — $0 \pmod{4}$, outside Bruck–Ryser entirely — is the smallest open order today. The chapter says this in those words: nobody knows whether a plane of order $12$ exists.

3.5 How many systems? The census ladder

Uniqueness at $7$ and $9$, then a fork: the lab's orderly-generation search — branching on the lowest uncovered pair, canonicalizing candidates under the stabilizer of the partial system, and discarding nothing — visits $41{,}621$ search states and $560$ leaves, all valid, collapses them to isomorphism classes, and returns $\operatorname{STS}(13) = 2$: one system with $8$ Pasch configurations (four triples on six points, the “quadrilateral” $\{a,b,c\},\{a,d,e\},\{f,b,d\},\{f,c,e\}$ up to labels), one with $13$ — automorphism groups of order $6$ and $39$, labeled counts $1{,}037{,}836{,}800 + 159{,}667{,}200 = 1{,}197{,}504{,}000 = 13!/6 + 13!/39$, as it must. The Fano plane has $7$ Pasches, $\operatorname{STS}(9)$ has $0$; the two $\operatorname{STS}(13)$s split the difference, and the lab's leaves sort cleanly into buckets $468$ ($8$-Pasch) $+ 92$ ($13$-Pasch). Beyond reach of this chapter's machines and honest to say so: $\operatorname{STS}(15) = 80$ systems; $\operatorname{STS}(19) = 11{,}084{,}874{,}829$ (the Kaski–Östergård classification of 2004).

3.6 What to learn

Designs live or die by double counting. The two counting constants ($b, r$) are forced by $\lambda\binom{v}{t} = b\binom{k}{t}$ before any construction begins; divisibility is the gate; Fisher's $b \ge v$ is the global shadow of linear independence; and the equality cases — Fano, $\operatorname{PG}(2,3)$ — are exactly the symmetric, self-dual worlds where the design looks the same from the block side. The census ladder ($1, 1, 2, 80$, eleven billion) shows how fast “count the objects” outruns “prove the theorems.”

Lecture 4 · Designs II: The Existence Theorems — Wilson, Keevash, and the Schoolgirls

4.1 Resolvability: Kirkman's problem, solved on the smallest stage

Kirkman's walking problem asks for more than an $\operatorname{STS}(15)$: the $35$ triples must partition into $7$ parallel classes of $5$ disjoint triples each, every class a partition of the $15$ girls, so no two girls walk together twice across the week. A design with such a class structure is resolvable. The lab constructs the answer on the smallest geometric stage — $\operatorname{PG}(3,2)$, the projective $3$-space over $\mathbb{F}_2$: its $15$ points are the nonzero $4$-bit vectors, its lines the triples $\{a, b, a \oplus b\}$, and its $35$ lines are precisely an $\operatorname{STS}(15)$ (every one of the $105$ pairs lies in exactly one line — machine-checked). A spread is a set of $5$ lines partitioning the points; the space has exactly $56$ spreads (machine census). The parallelism the schoolgirls need is a set of $7$ spreads sharing no line; the search finds it, and the schedule is printed in the lab verbatim — Monday through Sunday, every class a clean partition, all $35$ lines used exactly once. The full record: $\operatorname{STS}(15)$ has $80$ isomorphism classes and exactly how many resolvable ones was settled only in the computer era; the lab's resolvable witness is the classical one and its verification is line-by-line.

(Sylvester's harder 1850 question — partition all $\binom{15}{3} = 455$ triples of the $15$ schoolgirls into $13$ disjoint weekly Kirkman schedules of $35$ triples each, so that every pair walks together once per week and every three girls walk together exactly once across the entire $13$-week term, i.e., a large set of resolvable $\operatorname{STS}(15)$ — was settled by Denniston in 1974 using seven hours of Elliott 4130 computer time; whether his solution is unique up to isomorphism remains open. The chapter cites and moves on.)

4.2 Wilson: existence up to finitely many exceptions

For a fixed $k$, does a $2$-$(v, k, 1)$ design exist for all large admissible $v$? Wilson's theorem chain of the early 1970s (“An existence theory for pairwise balanced designs” I–III) answers yes: for each $k$, all but finitely many $v$ satisfying the divisibility conditions $v - 1 \equiv 0 \pmod{k-1}$ and $v(v-1) \equiv 0 \pmod{k(k-1)}$ actually carry a $2$-$(v, k, 1)$ design. The proof engine — pairwise balanced designs with one block size at a time, glued via Wilson's fundamental construction — is beyond this chapter's scope to prove; what the chapter keeps is the shape of the answer: divisibility is a finite check, non-existence is confined to a finite exceptional set, and the exceptional set is computable in principle for every fixed $k$.

4.3 Keevash: divisibility is the only obstruction, at last

The finishing theorem is recent and is one of the great results of modern combinatorics:

Theorem (Keevash 2014, “The existence of designs,” arXiv:1401.3665). For every $t$ and $k$, there is $n_0$ such that for all $n \ge n_0$ satisfying the divisibility conditions — $\binom{n-i}{t-i}/\binom{k-i}{t-i} \in \mathbb{Z}$ for every $0 \le i < t$ — a Steiner system $S(t, k, n)$ exists.

Steiner's 1853 question, open for $160$ years, closes: for large systems, the arithmetic gate that blocked $S(2,3,6)$ at a glance is the only obstruction. The proof is non-constructive (randomized algebraic construction — a subtle blend of the probabilistic method of Chapter 4 with algebraic structure), and it further settled the existence of nontrivial Steiner systems for $t \ge 6$ and infinitely many $t = 4, 5$.

The lab runs the divisibility check where the chapter can hold it in its hands, on quadruple systems $S(3,4,n)$: the conditions are $\binom{n}{3}/4$, $\binom{n-1}{2}/3$, and $(n-2)/2$ all integral. $n = 10$: $30, 12, 4$ — $\operatorname{SQS}(10)$ exists (the lab builds it: $2{,}520$ labeled systems, one orbit, uniqueness — Barrau's 1908 theorem machine-confirmed; $|\operatorname{Aut}| = 1{,}440$). $n = 12$: fails at $\binom{11}{2}/3 = 55/3$ — no $\operatorname{SQS}(12)$, arithmetic gate closed before any search. And the census over $n = 4..60$: divisibility holds exactly when $n \equiv 2 \text{ or } 4 \pmod{6}$ — Hanani's iff theorem (1960/1963), with the machine checking the arithmetic half.

4.4 The small-quadruple ladder, honestly

$S(3,4,8)$: the lab finds $30$ labeled systems, one orbit — unique, with $|\operatorname{Aut}| = 1{,}344 = |\operatorname{AGL}(3,2)|$ (the $30$ labeled copies each with $1{,}344$ automorphisms: $8! = 30\cdot 1{,}344$). $S(3,4,10)$: unique as above, with $|\operatorname{Aut}| = 1{,}440 = |\operatorname{P\Gamma L}(2,9)|$ ($10! = 2{,}520\cdot 1{,}440$). $\operatorname{SQS}(16)$: $1{,}054{,}163$ isomorphism classes (cited; the honest lab note says why: at $v = 16$ even a single system's labeled orbit census is an industrial computation, and the count belongs to the classification literature, not to this chapter's machines). $S(4,5,v)$: unique at $v = 11$ (the Witt small system — Lecture 6's ternary Golay will be it), nonexistent at $15$ and $17$, known at $23, 35, 47, 71, \dots$, and the smallest open order is $21$. The ladder's shape: after the first two rungs, counting collapses from “uniqueness” to “census by industrial machine,” and by the third rung into open problems — the design universe thickens as fast as the existence theory thins.

4.5 What to learn

Existence at scale is the divisibility conditions plus one theorem. Kirkman's resolvable $\operatorname{STS}(15)$ shows constructions can be pure geometry ($\operatorname{PG}(3,2)$); Wilson confines exceptions to finite sets; Keevash erases them entirely for large $v$. The pattern entry proposed: double-counting/divisibility — integrality as the admission fee, existence as the theorem that the fee is sufficient.

Lecture 5 · Coding Beyond the Sphere: Singleton, Plotkin, and Gilbert–Varshamov

5.1 Where Chapter 8 left the cube

Chapter 8 built the Hamming theory: the $[7,4,3]$ code — $16$ words, minimum distance $3$, the weight distribution $A = [1, 0, 0, 7, 7, 0, 0, 1]$ (one zero word, seven of weight $3$, seven of weight $4$, one all-ones) — and Delsarte's linear program on the cube. This lecture takes the three bounds that shape every code family: Singleton from the outside, Plotkin from the outside when distances are dense, Gilbert–Varshamov from the inside. The lab re-derives the Hamming $[7,4,3]$ from the parity-check view (columns $=$ the seven nonzero $3$-bit vectors) and machine-verifies its perfectness: $16$ radius-$1$ balls of size $8$ tile $\mathbb{F}_2^7$, $16\cdot 8 = 128 = 2^7$ — every word within distance $1$ of exactly one codeword, the sphere-packing identity made literal.

5.2 Singleton and MDS

Theorem (Singleton bound; standard citation Singleton 1964 — though proven earlier by Joshi in 1958 and Komamiya in 1953, a priority the chapter records honestly). Any $q$-ary code of length $n$, size $M$, minimum distance $d$ ($1 \le d \le n$) satisfies $M \le q^{n-d+1}$. Proof in one move: puncture $d-1$ coordinates; surviving words remain distinct, and there are only $q^{n-d+1}$ of them. $\blacksquare$

Linear codes meeting the bound with equality — $[n, k, n-k+1]_q$ — are MDS (maximum distance separable). The binary census is a desert: the lab enumerates every binary linear code up to $n = 7$ by canonical subspace enumeration (Gaussian cross-checks on the row-reduced keys) and finds no nontrivial binary MDS — the only $[n, k, n-k+1]_2$ codes are the trivial three families (whole space $k = n$, repetition $k = 1$, and even-weight parity $k = n-1$). Over larger alphabets the desert blooms: Reed–Solomon codes take the messages $(a, b) \in \mathbb{F}_q^2$ and evaluate $a + bx$ at $n$ distinct field points. The lab's witnesses over $\mathbb{F}_5$: evaluations at $4$ points give $[4,2,3]_5$ ($25$ words, all distinct, machine minimum pairwise distance exactly $3 =$ Singleton) and at all $5$ points $[5,2,4]_5$ (distance $4 =$ Singleton). A degree-$1$ polynomial has at most $1$ root, so two distinct messages differ in at least $n-1$ positions — Singleton tight for every $n \le q$ (and $n \le q+1$ with the point at infinity), and the whole family rides one polynomial fact.

How far can MDS go? The MDS conjecture (posed as a question by Segre in 1955): a nontrivial $[n,k]_q$ MDS code ($2 \le k \le q-1$) has $n \le q+1$, except when $q$ is even with $k = 3$ or $k = q-1$, where $n \le q+2$. The prime-field case is now a theorem — Ball 2012, with Ball–De Beule 2012 giving $k \le 2p-2$ for $q = p^h$ — and the general case is open. Another honest frontier entry.

5.3 Plotkin: dense distance caps size

Theorem (Plotkin 1960). A binary code of length $n$ and minimum distance $d$ with $2d > n$ has at most $\lfloor 2d/(2d-n) \rfloor$ codewords, and when $d$ is even, at most $2\lfloor d/(2d-n) \rfloor$ codewords; in the boundary case $n = 2d$ ($d$ even), $A_2(2d, d) \le 4d$.

Proof shape (the chapter's full proof is by averaging — the pattern map's P10 in its purest code-theoretic use): sum the pairwise distances two ways. On one hand, every pair is $\ge d$ apart, contributing at least $d\binom{M}{2}$. On the other, column by column: if a column has $z$ zeros and $M-z$ ones it contributes $z(M-z) \le M^2/4$ (and $z(M-z) \le (M^2-1)/4$ when $M$ is odd), so the total is $\le M^2 n/4$. Comparing: $d M(M-1)/2 \le M^2 n/4$, which rearranges ($M \ge 2$) to $M \le 2d/(2d-n)$; when $M = 2m$ is even, $m \le \lfloor d/(2d-n)\rfloor$ gives $M \le 2\lfloor d/(2d-n)\rfloor$, and when $M$ is odd and $d$ is even, $d M(M-1)/2 \le n(M^2-1)/4$ gives $M \le n/(2d-n) = 2d/(2d-n) - 1$, which is bounded by the same even integer $2\lfloor d/(2d-n)\rfloor$. $\blacksquare$ (Chapter 8 already owns the Delsarte-certificate form of Plotkin — the certificate $F = 1 + K_1/(2d-n)$ — the two routes agree and the cross-reference stands.)

The bound is tight in the dense corner where Singleton is slack: the lab exhibits $A_2(6,4) = 4$ (Plotkin bound $2\lfloor 4/2 \rfloor = 4$, met by a machine-constructed code of $4$ words) and $A_2(7,4) = 8$ (bound $2\lfloor 4/(8-7) \rfloor = 8$, met by the $[7,3,4]$ simplex code — the dual of the Hamming code: all seven nonzero codewords have weight exactly $4$, so every pair sits at distance $4$, machine-verified). Simplex structure saturates Plotkin exactly as polynomial structure saturates Singleton: the extremal witness teaches the bound.

5.4 Gilbert–Varshamov: existence from greed

Theorem (Gilbert 1952; the linear-code version Varshamov 1957). $A_q(n, d) \ge q^n / \sum_{j=0}^{d-1} \binom{n}{j}(q-1)^j$.

Proof: greed. Throw balls of radius $d-1$ around a maximal code; maximality says they cover the whole cube, so $M \cdot (\text{ball volume}) \ge q^n$. $\blacksquare$ The lab runs the greedy construction itself and prints honest witnesses at four binary points — $(7,3)$: $16 \ge \lceil 128/29 \rceil = 5$; $(8,3)$: $16 \ge \lceil 256/37 \rceil = 7$; $(10,4)$: $32 \ge \lceil 1024/176 \rceil = 6$; $(12,4)$: $128 \ge \lceil 4096/299 \rceil = 14$ — each a machine-constructed code and a count that clears the bound with room, because the ball-volume denominator over-counts overlaps near the covering boundary.

5.5 What to learn

The three bounds are three geometries of the Hamming cube: Singleton slices coordinates away (algebra), Plotkin averages distances (geometry), Gilbert–Varshamov covers (volume). MDS codes live where algebra is richest (polynomials over fields); Plotkin-tight codes where combinatorial designs are (the simplex); and the GV bound is the guarantee that good codes are easy to find — greed suffices. The frontier ledger: binary MDS trivial (census), general MDS bounded by a conjecture with the prime case proved, Plotkin's corner exactly charted by simplex witnesses.

Lecture 6 · The Golay Bridge: Codes as Designs

6.1 The best single published page

Marcel Golay's 1949 note “Notes on Digital Coding” (Proceedings of the IRE, vol. 37, page 657 — half a column, one table) announced two codes: a binary $[23,12,7]$ and a ternary $[11,6,5]$. Berlekamp's verdict is the standard quip: it is the best single published page in coding theory. (The ternary code had been printed even earlier — Virtakallio, 1947, in the Finnish football-pool magazine Veikkaaja; priority is recorded.) Both codes are perfect: their radius-$t$ error balls tile their cubes exactly, the sphere-packing identity holding with equality — the $[7,4,3]$ Hamming code of Chapter 8 has exactly two nontrivial siblings in the multiple-error-correcting perfect family, and Golay's page contains both. Perfectness here is machine-verified in this chapter's lab, word by word: $729$ ternary balls of radius $2$ partition $\mathbb{F}_3^{11}$ ($729\cdot 243 = 177{,}147 = 3^{11}$), and $4{,}096$ binary balls of radius $3$ partition $\mathbb{F}_2^{23}$ ($4{,}096\cdot 2{,}048 = 8{,}388{,}608 = 2^{23}$).

6.2 The ternary Golay code and the Witt system $S(4,5,11)$

Take $\Phi_{11}(x) = 1 + x + x^2 + \dots + x^{10}$, the cyclotomic factor of $x^{11} - 1$ over $\mathbb{F}_3$. It splits into two monic quintics, and the lab factors it by machine:

$$\Phi_{11}(x) = (x^5 + x^4 + 2x^3 + x^2 + 2)(x^5 + 2x^3 + x^2 + 2x + 2) \pmod{3}$$

(verify the coefficient arithmetic $\bmod 3$ — the product is $1 + x + \dots + x^{10}$ with zero remainder, machine-checked). Either factor generates a cyclic code of length $11$, dimension $6$, and the machine census prints, for both: $729$ codewords, minimum distance $5$ — the $[11,6,5]_3$. The weight distribution (identical for both factors):

$$A_0 = 1, \quad A_5 = 132, \quad A_6 = 132, \quad A_8 = 330, \quad A_9 = 110, \quad A_{11} = 24.$$

Now the bridge: look only at the supports of the $132$ weight-$5$ words. Two ternary words can share a support (a sign flip on all coordinates changes the word $c \mapsto 2c$, not the support), and here the $132$ words pair up onto $66$ supports, every $4$-subset of the $11$ coordinates lying in exactly one of them — the supports form the Steiner system $S(4,5,11)$, the small Witt design. Extend the code by an overall-parity coordinate to $[12,6,6]_3$ (machine-verified self-dual, weights $A = 1, 264, 440, 24$ at $0, 6, 9, 12$): now the $264$ weight-$6$ words pair up onto $132$ weight-$6$ supports forming $S(5,6,12)$ — the $5$-design of the small Witt pair — with automorphism group $M_{12}$.

6.3 The binary Golay code and $S(5,8,24)$

The binary twin: over $\mathbb{F}_2$, $(x^{23}+1)/(x+1)$ factors into exactly two monic degree-$11$ polynomials (machine-found, not remembered):

$$g_0(x) = x^{11} + x^9 + x^7 + x^6 + x^5 + x + 1, \qquad g_1(x) = x^{11} + x^{10} + x^6 + x^5 + x^4 + x^2 + 1.$$

Either generates the $[23,12,7]_2$: $4{,}096$ words, minimum distance $7$ — verified by the machine over all $8{,}386{,}560$ codeword pairs, with the weight distribution

$$A_0 = 1, \quad A_7 = 253, \quad A_8 = 506, \quad A_{11} = 1288, \quad A_{12} = 1288, \quad A_{15} = 506, \quad A_{16} = 253, \quad A_{23} = 1$$

— the all-ones word included, the eight values summing to $4{,}096$.

Extend by parity to the $[24,12,8]_2$ — self-dual, and the weight enumerator is the famous five-term line

$$A_0 = 1, \quad A_8 = 759, \quad A_{12} = 2576, \quad A_{16} = 759, \quad A_{24} = 1.$$

The $759$ weight-$8$ words — octads — are the blocks of $S(5,8,24)$: the lab machine-verifies that each of the $\binom{24}{5} = 42{,}504$ five-subsets of coordinates lies in exactly one octad. The octad arithmetic that makes the count inevitable is the exercise: every octad carries $\binom{8}{5} = 56$ of the five-subsets, so $759\cdot 56 = 42{,}504 = \binom{24}{5}$ — the design's defining property is the weight enumerator's arithmetic shadow.

6.4 Assmus–Mattson: how a code hands you a design

Why do the weight supports of these codes suddenly satisfy $t$-design conditions? The Assmus–Mattson theorem (1969) is the machine behind the bridge: for a linear code with few distinct weights and a dual with few weights, the words of any given weight carry a $t$-design on their supports. The theorem is stated (its proof — an incidence-counting argument via the dual code — is cited, and the chapter does not pretend otherwise); the Golay instances are the classic application, and Assmus–Mattson's own paper mined exactly these: the $5$-designs on $12$ and $24$ points. The general pattern — words-as-designs — is the proposed registry entry: pick a code with rigid weight structure, read a design off its supports, and the code's automorphism group acts on the design's block set.

6.5 The Mathieu groups, and the chapter in one table

The automorphism group of $S(5,8,24)$ is $M_{24}$, of order

$$24\cdot 23\cdot 22\cdot 21\cdot 20\cdot 48 = 244{,}823{,}040 = 2^{10}\cdot 3^3\cdot 5\cdot 7\cdot 11\cdot 23,$$

machine-multiplied and machine-factored; the point stabilizer is $M_{23}$ of order $10{,}200{,}960 = |M_{24}|/24$, whose point stabilizer is $M_{22}$ of order $443{,}520$, and the octad stabilizer has order $|M_{24}|/759 = 322{,}560$ — the ladder the lab prints exactly. The $S(5,6,12)$ system carries $M_{12}$ of order $95{,}040$ (its stabilizer arithmetic: $|M_{12}|/132\text{ hexads} = 720$), point stabilizer $M_{11}$ of order $7{,}920$. $M_{24}$ and $M_{12}$ are $5$-transitive — $M_{12}$ sharply so — and by the classification of finite simple groups the Mathieu groups are the only $4$-transitive permutation groups beyond the symmetric and alternating ones. They are the first five sporadic simple groups ever found (Mathieu, 1861 and 1873), and the honest historical arrow runs backwards: the designs were constructed first as abstract systems, and the codes — Golay 1949 — gave them their most usable incarnation.

import math

def necklaces_and_bracelets(n: int, k: int = 2) -> tuple[int, int]:
    """Burnside/Polya orbit counts for k-ary necklaces (C_n) and bracelets (D_n)."""
    if n <= 0:
        return 1, 1
    rot = sum(k ** math.gcd(n, r) for r in range(n))
    if n % 2 == 1:
        refl = n * (k ** ((n + 1) // 2))
    else:
        refl = (n // 2) * (k ** (n // 2 + 1) + k ** (n // 2))
    return rot // n, (rot + refl) // (2 * n)

def tree_shapes(max_n: int = 8) -> tuple[list[int], list[int]]:
    """Computes rooted and unrooted unlabeled tree counts for n = 1..max_n."""
    if max_n <= 0:
        return [], []
    r = [0] * (max_n + 1)
    r[1] = 1
    for n in range(2, max_n + 1):
        dp = [1] + [0] * (n - 1)
        for s in range(1, n):
            new_dp = dp[:]
            for tot in range(s, n):
                for c in range(1, (tot // s) + 1):
                    new_dp[tot] += dp[tot - c * s] * math.comb(r[s] + c - 1, c)
            dp = new_dp
        r[n] = dp[n - 1]
    u = [0] * (max_n + 1)

def partition_lattice_mobius(n: int) -> tuple[int, int]:
    """Enumerates the partition lattice Pi_n and computes mu(0_hat, 1_hat) via upward recursion."""
    if n <= 1:
        return 1, 1
    parts: list[tuple[tuple[int, ...], ...]] = []
    def gen(i: int, cur: list[list[int]]) -> None:
        if i == n:
            parts.append(tuple(sorted(tuple(sorted(b)) for b in cur)))
            return
        for b in cur:
            b.append(i); gen(i + 1, cur); b.pop()
        cur.append([i]); gen(i + 1, cur); cur.pop()
    gen(0, [])
    parts.sort(key=len)  # 1-block bottom (0_hat) to n-block singletons top (1_hat)
    m = len(parts)
    mu = [1] + [0] * (m - 1)
    for j in range(1, m):
        mu[j] = -sum(
            mu[i] for i in range(j)
            if all(any(set(bj).issubset(bi) for bi in parts[i]) for bj in parts[j])
        )
    return m, mu[-1]

def verify_s236_nonexistence() -> int:
    """Exhaustively checks all C(20, 5) = 15,504 5-triple families on 6 points."""

        for m in comb:
            if acc & m:
                ok = False
                break
            acc |= m
        if ok:
