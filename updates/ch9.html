Lecture 1 · The Staircase and Cauchy–Davenport

The sumset thread begins: instead of families of sets, sets of numbers, and the question becomes how small a sumset can be. The integer answer is a one-line staircase; the modular answer is a real theorem with two beautiful proofs — one by periodicity, one by the polynomial method of Chapter 6.

Problem. Nonempty finite $A, B \subseteq \mathbb{Z}$: $|A + B| \ge |A| + |B| - 1$, where $A + B = \{a + b : a \in A, b \in B\}$.

1.1 The integer staircase (P4, full)

Write $A = \{a_1 < \dots < a_s\}$ and $B = \{b_1 < \dots < b_t\}$. The witness chain

$$a_1 + b_1 < a_2 + b_1 < a_3 + b_1 < \dots < a_s + b_1 < a_s + b_2 < a_s + b_3 < \dots < a_s + b_t$$

is strictly increasing throughout — first climb the $b_1$ column, then walk the $a_s$ row — and exhibits $s + t - 1$ distinct sums. $\blacksquare$

Tightness: when $|A| = 1$ or $|B| = 1$, equality $|A + B| = |A| + |B| - 1$ holds for every finite nonempty partner set; when $|A|, |B| \ge 2$, equality holds if and only if $A$ and $B$ are arithmetic progressions with the same common difference $d > 0$, i.e. $A = \{a_0, a_0 + d, \dots, a_0 + (s-1)d\}$ and $B = \{b_0, b_0 + d, \dots, b_0 + (t-1)d\}$. The structure theory of equality and near-equality in general abelian groups is Kneser's business, next lecture.

1.2 Modulo a prime: Cauchy–Davenport, by periodicity (full)

Theorem (Cauchy–Davenport). Let $A, B \subseteq \mathbb{F}_p$ be nonempty subsets ($p$ prime). Then

$$|A + B| \ge \min(p,\, |A| + |B| - 1).$$

Proof (periodicity and the $e$-transform). First observe the basic periodicity fact in $\mathbb{F}_p$: if a nonempty subset $S \subseteq \mathbb{F}_p$ satisfies $|S + d \cup S| = |S|$ (i.e. $S + d = S$) for some $d \ne 0$, then $S = \mathbb{F}_p$. Indeed, since $p$ is prime and $d \not\equiv 0 \pmod p$, the multiples $0, d, 2d, \dots, (p-1)d$ exhaust $\mathbb{F}_p$; picking any $s_0 \in S$, invariance under $d$ gives $s_0 + md \in S$ for all $m \ge 0$, so $S = \mathbb{F}_p$.

We now prove $|A + B| \ge \min(p, |A| + |B| - 1)$ by induction on $|B| \ge 1$. If $|B| = 1$, then $|A + B| = |A| = \min(p, |A| + 1 - 1)$. Suppose $|B| \ge 2$. If $|A| = p$, then $A = \mathbb{F}_p$ and $|A + B| = p \ge \min(p, |A| + |B| - 1)$. Otherwise $\emptyset \ne A \subsetneq \mathbb{F}_p$. Choose two distinct elements $b_0, b_1 \in B$, and set $d = b_1 - b_0 \ne 0$. By the periodicity fact, $A + d \ne A$, so there exists $a \in A$ with $a + b_1 - b_0 \notin A$. Set $e = a - b_0$ and form the deformed pair

$$A' = A \cup (B + e), \qquad B' = B \cap (A - e).$$

Then $b_0 \in B'$ (since $b_0 + e = a \in A$) and $b_1 \notin B'$ (since $b_1 + e = a + b_1 - b_0 \notin A$), so $1 \le |B'| < |B|$. Every sum $x + y$ with $x \in A', y \in B'$ lies in $A + B$ (if $x \in A$, then $y \in B \implies x + y \in A + B$; if $x = b + e \in B + e$, then $y + e \in A \implies x + y = (y + e) + b \in A + B$), so $A' + B' \subseteq A + B$. Moreover, $|B'| = |(B + e) \cap A|$, so inclusion–exclusion gives $|A'| + |B'| = |A \cup (B + e)| + |A \cap (B + e)| = |A| + |B + e| = |A| + |B|$. By the inductive hypothesis on $(A', B')$,

$$|A + B| \ge |A' + B'| \ge \min(p,\, |A'| + |B'| - 1) = \min(p,\, |A| + |B| - 1). \quad \blacksquare$$

The periodicity engine also drives the iterated merge $S_0 = A$, $S_i = S_{i-1} \cup (S_{i-1} + b_i)$ for $b_1, \dots, b_{t-1} \in B \setminus \{0\}$, which builds the multi-summand sumset $S_{t-1} = A + \{0, b_1\} + \dots + \{0, b_{t-1}\}$: a step $|S_i| = |S_{i-1}|$ forces $S_{i-1} + b_i = S_{i-1}$ and hence $S_{i-1} = \mathbb{F}_p$. The lab runs this merge monitor across all pairs of subsets of $\mathbb{F}_5$ and $\mathbb{F}_7$ (with $0 \in B$): across $8,624$ processes and $9,759$ zero-gain steps, a zero-gain step occurs only when the running set $S_{i-1}$ has already become all of $\mathbb{F}_p$, and simultaneously verifies $|A + B| \ge \min(p, |A| + |B| - 1)$ on all $8,624$ pairs.

1.3 The polynomial method proof (P22, full)

The second proof is the Chapter 6 engine running on a grid, and it is worth seeing in its purest form. One ingredient does all the work.

Ingredient (the weighted-sum identity). Let $F$ be any field, and let $A, B \subseteq F$ be finite nonempty subsets of sizes $|A| = a$ and $|B| = b$. Define $\Pi_A(x) = \prod_{c \in A}(x - c)$ with formal derivative $\Pi_A'(x) = \sum_{c \in A} \prod_{d \in A \setminus \{c\}}(x - d)$, so that $\Pi_A'(x_0) = \prod_{c \in A \setminus \{x_0\}}(x_0 - c) \ne 0$ for each $x_0 \in A$, and define $\Pi_B, \Pi_B'$ likewise. For any polynomial $f(x, y) \in F[x, y]$ of total degree $\deg f \le a + b - 2$,

$$\sum_{x \in A,\, y \in B} \frac{f(x, y)}{\Pi_A'(x)\,\Pi_B'(y)} = [x^{a-1} y^{b-1}] f.$$

Proof. First we establish the univariate identity: for every integer $0 \le i \le a - 1$,

$$\sum_{x_0 \in A} \frac{x_0^i}{\Pi_A'(x_0)} = [i = a - 1].$$

For each $x_0 \in A$, the Lagrange basis polynomial

$$L_{x_0}(x) = \frac{\Pi_A(x)}{\Pi_A'(x_0)(x - x_0)} = \prod_{c \in A \setminus \{x_0\}} \frac{x - c}{x_0 - c} \in F[x]$$

has degree $a - 1$, leading coefficient $[x^{a-1}]L_{x_0}(x) = 1/\Pi_A'(x_0)$, and satisfies $L_{x_0}(x_1) = [x_1 = x_0]$ for all $x_1 \in A$. For any $0 \le i \le a - 1$, the difference $g(x) = x^i - \sum_{x_0 \in A} x_0^i L_{x_0}(x)$ has degree at most $a - 1$ and vanishes at all $a$ distinct points of $A$, so $g(x) = 0$ identically in $F[x]$. Comparing the coefficient of $x^{a-1}$ on both sides of $x^i = \sum_{x_0 \in A} x_0^i L_{x_0}(x)$ yields $[i = a - 1] = \sum_{x_0 \in A} x_0^i / \Pi_A'(x_0)$.

Now expand $f(x, y) = \sum_{i + j \le a + b - 2} f_{ij} x^i y^j$. By linearity, the weighted sum splits over monomials and factors across $A$ and $B$:

$$\sum_{x \in A,\, y \in B} \frac{f(x, y)}{\Pi_A'(x)\,\Pi_B'(y)} = \sum_{i + j \le a + b - 2} f_{ij} \left(\sum_{x \in A} \frac{x^i}{\Pi_A'(x)}\right)\left(\sum_{y \in B} \frac{y^j}{\Pi_B'(y)}\right).$$

Fix a pair $(i, j)$ with $i + j \le a + b - 2$. If $i \le a - 2$, the $x$-sum is $0$ by the univariate identity on $A$. If $i \ge a$, then $j \le a + b - 2 - i \le b - 2$, so the $y$-sum is $0$ by the univariate identity on $B$. If $i = a - 1$, then $j \le b - 1$, so the $x$-sum is $1$ and the $y$-sum is $[j = b - 1]$. Thus only $(i, j) = (a - 1, b - 1)$ survives, contributing $f_{a-1, b-1} = [x^{a-1}y^{b-1}]f$. $\blacksquare$

(Companion fact — the grid lemma, D1. A polynomial $f(x, y) \in F[x, y]$ with $\deg_x f < a$ and $\deg_y f < b$ vanishing on all of $A \times B$ is identically zero: write $f(x, y) = \sum_{i=0}^{a-1} c_i(y) x^i$; for each $y_0 \in B$, $f(x, y_0)$ has degree $< a$ and $a$ roots in $A$, so $c_i(y_0) = 0$ for all $y_0 \in B$, and since $\deg_y c_i < b$, each $c_i(y) \equiv 0$. D1 is the engine of the classical variant of this proof — where one starts from a higher-degree polynomial and reduces it to the grid — and is the two-variable echo of Chapter 6's multilinear lemma. Our $f$ has total degree $a + b - 2$, so the weighted-sum identity alone finishes; the lab verifies D1 on $184$ exact grid reconstructions.)

The proof of Cauchy–Davenport. If $a + b \ge p + 1$, then for every $c \in \mathbb{F}_p$ we have $|A| + |c - B| = a + b > p$, so $A \cap (c - B) \ne \emptyset$, meaning $c \in A + B$ and hence $|A + B| = p = \min(p, a + b - 1)$. Assume now that $a + b \le p + 1$, so $a + b - 2 \le p - 1$, and suppose for contradiction that $|A + B| \le a + b - 2$ (which forces $a + b - 2 \ge 1$). Since $a + b - 2 \le p - 1 < p$, we may choose a subset $C \subseteq \mathbb{F}_p$ with

$$A + B \subseteq C \subseteq \mathbb{F}_p, \qquad |C| = a + b - 2.$$

Set $f(x, y) = \prod_{c \in C}(x + y - c) \in \mathbb{F}_p[x, y]$, of total degree $a + b - 2$.

  • $f$ vanishes on $A \times B$: for $x \in A, y \in B$, the sum $x + y$ lies in $A + B \subseteq C$, so one factor is zero.
  • Therefore the weighted sum $\sum_{x \in A, y \in B} f(x, y)/(\Pi_A'(x)\Pi_B'(y))$ is $0$ in $\mathbb{F}_p$.
  • By the weighted-sum identity, this sum equals $[x^{a-1}y^{b-1}]f = [x^{a-1}y^{b-1}](x + y)^{a+b-2} = \binom{a+b-2}{a-1}$. Since $a + b - 2 \le p - 1$, every positive integer factor in $(a + b - 2)!$ is strictly less than $p$, so $\binom{a+b-2}{a-1} \not\equiv 0 \pmod p$.

Thus $0 \equiv \binom{a+b-2}{a-1} \not\equiv 0 \pmod p$, a contradiction. $\blacksquare$

Every ingredient is machine-checked: the partial-fraction identity ($15,011$ checks over $\mathbb{F}_5\text{–}\mathbb{F}_{13}$), the weighted-sum identity including the dying logic ($900$ random polynomials), the grid lemma's interpolation ($184$ reconstructions), the binomial non-vanishing (all $m \le p - 1$), and the vanishing step $f(a,b) = 0 \iff a + b \in C$ ($450$ checks).

1.4 The $m$-fold corollary (full)

$m$-fold Cauchy–Davenport. For nonempty subsets $A_1, A_2, \dots, A_m \subseteq \mathbb{F}_p$ ($m \ge 1$),

$$|A_1 + A_2 + \dots + A_m| \ge \min\!\left(p,\, \sum_{i=1}^m |A_i| - m + 1\right).$$

Proof. We induct on $m \ge 1$. For $m = 1$, $|A_1| = \min(p, |A_1|)$ holds since $A_1 \subseteq \mathbb{F}_p$. For $m \ge 2$, set $S = A_2 + \dots + A_m$ and $s = \sum_{i=2}^m |A_i| - (m - 1) + 1$. By the inductive hypothesis, $|S| \ge \min(p, s)$. Applying the two-summand Cauchy–Davenport theorem to $A_1$ and $S$ gives

$$|A_1 + S| \ge \min(p,\, |A_1| + |S| - 1) \ge \min\!\big(p,\, |A_1| + \min(p, s) - 1\big).$$

If $s \ge p$, then $\min(p, s) = p$, and since $|A_1| \ge 1$ we have $|A_1| + p - 1 \ge p$ and $|A_1| + s - 1 \ge p$, so both sides equal $p$. If $s < p$, then $\min(p, s) = s$, and the right side is $\min(p, |A_1| + s - 1) = \min(p, \sum_{i=1}^m |A_i| - m + 1)$. $\blacksquare$ (The lab stress-tests this on random $m \le 4$ families over $\mathbb{F}_5, \mathbb{F}_7, \mathbb{F}_{11}$ — $600$ trials, zero violations; Lecture 2 uses it twice.)

1.5 What to learn

Two proofs, two philosophies again. The periodicity argument is dynamic: deform the pair or grow the sumset and show the only way to stop is to finish. The polynomial argument is static: build one polynomial that vanishes on the grid, and price its top coefficient two ways. The grid lemma D1 is the polynomial method's workhorse — the same "small degree + many roots $\implies$ zero" move as Chapter 6's multilinear lemma, in two variables. And note the exact fingerprint: the contradiction needed $a + b - 2 \le p - 1$, the same boundary the theorem itself respects.

Lecture 2 · Kneser's Theorem and the Zero-Sum Capstone

Cauchy–Davenport lives in $\mathbb{F}_p$, and the staircase lives in $\mathbb{Z}$. Both are shadows of one master theorem: Kneser's theorem, which prices a sumset by its period — the translations that leave it alone. This lecture states Kneser, builds the $e$-transform toolkit that powers its proof (both properties proved in full), proves the quotient reduction completely, and hands the aperiodic step to the next lecture, which builds it in full. Then, as a capstone, the chapter's two threads — sets and sums — fuse in the Erdős–Ginzburg–Ziv theorem, proved here in full: pairing in the prime case, block extraction in the composite case, with the $m$-fold Cauchy–Davenport from Lecture 1 doing the arithmetic.

2.1 The statement, and what a stabilizer is

Problem. Let $A, B$ be nonempty finite subsets of an abelian group $G$. How small can $A + B$ be?

In $\mathbb{Z}$ the answer is $|A| + |B| - 1$ and the witness is an arithmetic-progression-like pair (Lecture 1's staircase). In $\mathbb{F}_p$ the answer is $\min(p, |A| + |B| - 1)$ (Lecture 1, two proofs). In $\mathbb{Z}_6$, take $A = B = \{0, 2, 4\}$: then $A + B = \{0, 2, 4\}$ again — size 3, not $5$, not $3 + 3 - 1 = 5$. What broke? The sumset is periodic: adding $2$ to every element of $\{0, 2, 4\}$ gives $\{0, 2, 4\}$ back. Periods are not a pathology; they are the third parameter of the subject.

Definition. For $S \subseteq G$, the stabilizer of $S$ is $\operatorname{stab}(S) = \{g \in G : g + S = S\}$.

Lemma (the stabilizer is a subgroup; $S$ is a union of cosets). $\operatorname{stab}(S)$ is a subgroup of $G$, and if $H = \operatorname{stab}(S)$, then $S$ is a union of $H$-cosets: $s \in S \implies s + H \subseteq S$.

Proof. $0 \in \operatorname{stab}(S)$ ($0 + S = S$). If $g, h$ stabilize $S$, then $(g + h) + S = g + (h + S) = g + S = S$, so $g + h$ stabilizes $S$. And $g + S = S$ implies $S = (-g) + S$ by translating both sides by $-g$, so $-g$ stabilizes $S$ too: a subgroup. For the coset claim, $s \in S$ and $h \in H$ give $h + s \in h + S = S$. $\blacksquare$

Theorem (Kneser, 1953). Let $A, B$ be nonempty finite subsets of the abelian group $G$, and let $H = \operatorname{stab}(A + B)$. Then

$$|A + B| \ge |A + H| + |B + H| - |H| \ge |A| + |B| - |H|.$$

Both forms hold; the strong form $|A + B| \ge |A + H| + |B + H| - |H|$ is never weaker than the weak form $|A + B| \ge |A| + |B| - |H|$, since $A \subseteq A + H$ and $B \subseteq B + H$. Sanity checks: in $\mathbb{Z}$ the only finite set with a nonzero period is $\emptyset$, so $H = \{0\}$ and Kneser is the staircase; in $\mathbb{F}_p$ the group has only two subgroups, $\{0\}$ (where both forms give $|A + B| \ge |A| + |B| - 1$) and $H = \mathbb{F}_p$ (which occurs when $A + B = \mathbb{F}_p$; there the weak bound $|A + B| \ge |A| + |B| - p$ is slack whenever $|A| + |B| < 2p$, whereas the strong bound gives $|A + H| + |B + H| - |H| = p + p - p = p = |A + B|$ with equality). The theorem specializes correctly everywhere. (Checkpoint: in $\mathbb{Z}_6$ with $A = B = \{0, 2, 4\}$, verify $H = \{0, 2, 4\}$, $|A + B| = 3 = 3 + 3 - 3$, and that $A + B$ is a single $H$-coset — $H$ itself.)

2.2 Tight examples and the census

Three regimes, three shapes:

  • $H = \{0\}$, tight: $A = B = \{0, 1, \dots, k - 1\}$ in $\mathbb{Z}_n$ with $n > 2k - 2$: $A + B = \{0, \dots, 2k - 2\}$, size $2k - 1 = k + k - 1$, no period. The staircase is tight in every group that has room for it.
  • $H$ nontrivial, tight: the coset $A = B = H = \{0, 2, 4\}$ in $\mathbb{Z}_6$ above; more generally $A = B = a + H$ for any finite subgroup $H$: $A + B = 2a + H$, size $|H| = |H| + |H| - |H|$. Subgroups are the atoms of small sumsets.
  • Full group: if $A + B = G$, then $H = G$: the strong form $|A + H| + |B + H| - |H| = |G| + |G| - |G| = |G|$ is tight for every such pair, while the weak form $|G| \ge |A| + |B| - |G|$ is slack unless $A = B = G$.

The lab runs a census with the stabilizer computed exactly: all of $\mathbb{Z}_6, \mathbb{Z}_7, \mathbb{Z}_8, \mathbb{Z}_9$ ($3,969$ / $16,129$ / $65,025$ / $261,121$ pairs) — zero violations, with every tight case accounted for by a subgroup exactly as above (an arithmetic progression when $H = \{0\}$, a coset structure when $H \ne \{0\}$); the wider gate sampling — $\mathbb{Z}_{10}$ up to size $5$ ($405,769$ pairs), $\mathbb{Z}_{12}$ up to size $4$ ($628,849$), all of $\mathbb{Z}_3^2$ ($261,121$), and $40,000$ sampled pairs of $\mathbb{Z}_4^2$ — is verification-basis record, not the printed lab.

2.3 The $e$-transform: the toolkit, proved (P23)

The engine behind the hard half of Kneser is Dyson's $e$-transform — a cousin of Chapter 7's shifting lecture: replace $(A, B)$ by a deformed pair that is easier to analyze while the sumset only shrinks and the total size is preserved. Compression, not counting (P23 again).

Definition. For $e \in G$:

$$A(e) = A \cup (B + e), \qquad B(e) = B \cap (A - e),$$

where $A - e = \{a - e : a \in A\}$. Note the shape: one set grows by a translate of the other, the other shrinks to what matches that translate.

Property 1 (the sumset only shrinks): $A(e) + B(e) \subseteq A + B$.

Proof. Take $x \in A(e), y \in B(e)$; show $x + y \in A + B$. Two cases.

  • $x \in A$: then $y \in B(e) \subseteq B$, so $x + y \in A + B$ directly.
  • $x = b_1 + e$ with $b_1 \in B$: then $y \in B \cap (A - e)$, so $y + e \in A$, and $x + y = b_1 + (y + e) \in B + A = A + B$. $\blacksquare$

The second case is the whole trick: the translate $e$, which created $x$, is refunded by $B(e)$'s membership test $y + e \in A$. What the transform gives with one hand it claws back with the other.

Property 2 (the total size is preserved): $|A(e)| + |B(e)| = |A| + |B|$.

Proof. First, $B(e) + e = (B \cap (A - e)) + e = (B + e) \cap A$: indeed, $x \in (B \cap (A - e)) + e \iff x - e \in B \text{ and } x - e \in A - e \iff x \in B + e \text{ and } x \in A$. Because translation by $e$ is a bijection on $G$, $|B(e)| = |B(e) + e| = |A \cap (B + e)|$. Since $A(e) = A \cup (B + e)$ and $|B + e| = |B|$, inclusion–exclusion gives

$$|A(e)| + |B(e)| = |A \cup (B + e)| + |A \cap (B + e)| = |A| + |B + e| = |A| + |B|. \quad \blacksquare$$

Monotonicity and termination. $A \subseteq A(e)$ always; $B(e) \subseteq B$ always. If additionally $B + e \not\subseteq A$, the inclusion $A \subseteq A(e)$ is strict — some element of $B + e$ lies outside $A$ — so by Property 2, $|B(e)| < |B|$ strictly: the pair traded a unit of $B$ for a unit of $A$. Since $|B|$ is a positive integer that strictly decreases, the iteration terminates. Each step keeps $A_i + B_i \subseteq A + B$ (Property 1) and $|A_i| + |B_i| = |A| + |B|$ (Property 2).

The lab machine-checks both properties on every $e \in G$ for random $A, B$ in $\mathbb{Z}_6, \mathbb{Z}_8, \mathbb{Z}_3^2$ — $6,900$ checks, zero violations.

2.4 The assembly: the two moves

Here is the architecture of the full proof, in two moves.

Move 1 (the aperiodic case). If $\operatorname{stab}(A + B) = \{0\}$, then $|A + B| \ge |A| + |B| - 1$. For $\mathbb{Z}$ this is the staircase (Lecture 1, proved); for $\mathbb{F}_p$ it is Cauchy–Davenport (Lecture 1, proved twice). For a general abelian group this is a real theorem, and the next lecture builds it in full. The engine is the $e$-transform of §2.3 — the toolkit above is complete — but one honest warning belongs here already: the transform preserves the sumset only up to containment, and the deformed pair can be more periodic than the original (the machine found a pair in $\mathbb{Z}_6$ whose sumset is aperiodic while a perfectly legal transform of it is not — §3.2). So the aperiodic hypothesis must be handled with care: a two-case recursion carries the weak form (§3.1), and the strong form rides DeVos's intersection–union induction (§3.3). Sources: Kneser's original 1953 paper (Math. Z. 58), Dyson's 1945 transform argument, the self-contained treatment in Nathanson's Additive Number Theory (GTM 165), and Tao–Vu's Additive Combinatorics; the recent survey arXiv:2407.12253 traces the transform's history, and DeVos's short proof carries the strong form.

Move 2 (the quotient reduction — proved in full). Suppose Move 1 holds as a black box for every abelian group. Let $H = \operatorname{stab}(A + B)$. Since $A$ and $B$ are nonempty and finite, $A + B$ is nonempty and finite, and for any $s_0 \in A + B$ the coset $s_0 + H$ lies in $A + B$, so $H$ is a finite subgroup with $|H| \le |A + B|$. By §2.1, $A + B$ is a union of $H$-cosets, and so are $A + H$ and $B + H$. Pass to the quotient group $G/H$: the finite nonempty images $\bar{S} = (A + B)/H$, $\bar{A} = (A + H)/H$, and $\bar{B} = (B + H)/H$ satisfy $\bar{S} = \bar{A} + \bar{B}$, and

  • $|\bar{S}| = |A + B|/|H|$, $|\bar{A}| = |A + H|/|H|$, $|\bar{B}| = |B + H|/|H|$ (each set is a disjoint union of $H$-cosets);
  • $\operatorname{stab}(\bar{S})$ is trivial in $G/H$: if a coset $g + H \in G/H$ satisfies $(g + H) + \bar{S} = \bar{S}$, then for every $s \in A + B$ the coset $g + s + H$ belongs to $\bar{S}$, so $g + s \in A + B$; thus $g + (A + B) \subseteq A + B$, and since $A + B$ is finite, $|g + (A + B)| = |A + B|$ forces $g + (A + B) = A + B$, so $g \in H = 0_{G/H}$.

Apply Move 1 to $\bar{A}, \bar{B}$ in $G/H$: $|\bar{S}| \ge |\bar{A}| + |\bar{B}| - 1$. Multiply through by $|H|$:

$$|A + B| \ge |A + H| + |B + H| - |H| \ge |A| + |B| - |H|. \quad \blacksquare$$

Both Kneser forms at once, and the aperiodic black box is the only flagged input. Note the pleasing division of labor: the hard content is all in Move 1 (structure), and Move 2 is pure bookkeeping with cosets — the same "pass to the quotient where the obstruction vanishes" move that solved the Petersen graph's equitable quotient in Chapter 8.

2.5 The capstone: Erdős–Ginzburg–Ziv, in full

Theorem (EGZ, 1961). Any $2n - 1$ integers contain $n$ whose sum is divisible by $n$.

Forty years of additive combinatorics in one sentence: $2n - 1$ is the cap ($2n - 2$ can fail: $n - 1$ zeros and $n - 1$ ones). The proof below is complete.

Step 1 — the prime case, $n = p$. Represent the $2p - 1$ residues by their canonical integers in $\{0, 1, \dots, p - 1\}$.

Trivial case. Some residue occurs $\ge p$ times: those $p$ copies sum to $p \cdot v \equiv 0 \pmod p$. Done. So assume every residue occurs $\le p - 1$ times (in particular, this forces $p \ge 3$, as $2p - 1 = 3$ residues in $\mathbb{F}_2$ always fall into the trivial case).

Pairing lemma. A multiset of $2m$ integers in which no value occurs more than $m$ times can be split into $m$ pairs, each consisting of two distinct integers.

Proof. Sort the elements in $\mathbb{Z}$ as $e_1 \le e_2 \le \dots \le e_{2m}$ and pair $e_i$ with $e_{i+m}$ for $i = 1, \dots, m$. If a pair had $e_i = e_{i+m}$, then the sorted run $e_i, e_{i+1}, \dots, e_{i+m}$ would be $m + 1$ equal elements — forbidden. $\blacksquare$

Now remove any single element $x$ from the multiset. The remaining $2p - 2 = 2(p - 1)$ elements still have every multiplicity $\le p - 1 = m$, so the pairing lemma splits them into $p - 1$ pairs $\{a_i, b_i\}$ with $a_i \not\equiv b_i \pmod p$ — each pair a $2$-element subset of $\mathbb{F}_p$. The $m$-fold Cauchy–Davenport theorem (§1.4) applied to these $p - 1$ two-element subsets gives

$$\big|\{a_1, b_1\} + \dots + \{a_{p-1}, b_{p-1}\}\big| \ge \min\!\big(p,\, 2(p - 1) - (p - 1) + 1\big) = \min(p, p) = p.$$

Every residue in $\mathbb{F}_p$ is achievable as a choice-sum — including $-x \pmod p$. Adjoining $x$ to the $p - 1$ chosen elements yields $p$ elements summing to $0 \pmod p$. $\blacksquare$

Watch how the book's patterns stack: the greedy pairing is compression (P23), the counting engine is $m$-fold C–D (P22/P4), and the conclusion is a reachability statement — the same "the achievable set is everything" move as the Hoffman-bound arguments of Chapter 8. The lab verifies the whole chain: exhaustive search over all multisets for $n = 3\text{–}7$ ($21$ / $120$ / $715$ / $4,368$ / $27,132$ multisets) — every one contains a zero-sum $n$-subset (the $20,000$-sample sweeps at $n = 9, 10$ are gate record, not the printed lab); the pairing lemma on $800$ random constrained multisets; and $900$ full prime-case runs in which the choice-sumset always covered $\mathbb{F}_p$ and $-x$ was always reachable ($44$ runs settled by the trivial case, counted separately).

Step 2 — the multiplicative step from $n$ and $m$ to $nm$. Suppose EGZ holds for $n$ and for $m$; we prove it for $nm$. Given $2nm - 1$ integers, extract disjoint $n$-blocks, each with sum $\equiv 0 \pmod n$, using $\text{EGZ}(n)$ repeatedly: after $j$ blocks, $2nm - 1 - nj$ elements remain, and one more extraction is possible whenever

$$2nm - 1 - nj \ge 2n - 1, \quad\text{i.e.}\quad n(2m - j) \ge 2n, \quad\text{i.e.}\quad j \le 2m - 2.$$

So we extract $2m - 1$ disjoint blocks $B_1, \dots, B_{2m-1}$, each of size $n$ with sum $s_i \equiv 0 \pmod n$. The quotients $t_i = s_i / n$ are $2m - 1$ integers, so $\text{EGZ}(m)$ selects $m$ indices $i_1 < \dots < i_m$ with $t_{i_1} + \dots + t_{i_m} \equiv 0 \pmod m$. The union $B_{i_1} \cup \dots \cup B_{i_m}$ has $nm$ elements with total sum $n(t_{i_1} + \dots + t_{i_m}) \equiv 0 \pmod{nm}$. Thus $\text{EGZ}(nm)$ holds. $\blacksquare$

Step 3 — assembly. $\text{EGZ}(1)$ is trivial ($1$ divides any single integer), $\text{EGZ}(p)$ is Step 1, and Step 2 builds $\text{EGZ}$ of any composite integer from its factors. Induction on the number of prime factors (with multiplicity) establishes $\text{EGZ}(n)$ for every integer $n \ge 1$. $\blacksquare$

The lab runs the composite chain end-to-end on $300$ random instances over $(n, m) = (2,3), (3,2), (2,2), (2,5), (3,3)$: every instance yields its $2m - 1$ disjoint zero-sum-$n$ blocks, and the $\text{EGZ}(m)$ selection on the scaled block sums produces a genuine zero-sum-$nm$ subset. (One lab bug is worth recording as a lesson: the verifier initially checked the final sum mod $nm$ via the scaled sums, i.e. mod $m$, rather than mod $nm$ — the fixed check confirms divisibility by $nm$ itself.)

Lecture 3 · The Assembly, Completed: Dyson's Recursion and DeVos's Proof

Lecture 2 proved Kneser's quotient move and left the aperiodic case as a flagged input. This lecture builds that input, twice. First the weak theorem — every pair with $|A| + |B| \le |G|$ admits a proper subgroup $H$ with $|A + B| \ge |A| + |B| - |H|$ — by a two-case recursion on Dyson's $e$-transform, the §2.3 toolkit doing exactly the work it was built for. The recursion is honest about its own reach: a plain induction cannot deliver the strong form, and a small example in $\mathbb{Z}_6$ says why (§3.2). The strong form then rides DeVos's short intersection–union induction, presented in full (§3.3): one new notion — a portion of a sumset — and three counting equations close what the transform alone could not. With §2.4's quotient move, this completes the book's proof of Kneser's theorem and retires the appendix's third flag.

3.1 The weak form: a two-case recursion (P4, full)

Theorem (weak Kneser). Let $A, B$ be nonempty finite subsets of the abelian group $G$ with $|A| + |B| \le |G|$. Then there is a proper finite subgroup $H \subsetneq G$ with

$$|A + B| \ge |A| + |B| - |H|.$$

Proof. The recursion runs on the pair $(A, B)$, preserving three invariants — $A + B$ contains every later sumset, the total size never changes, $B$ never empties — and it stops in one of two cases, each of which produces a proper subgroup.

The base: $|B| = 1$. Take $H = \{0\}$: $|A + B| = |A| = |A| + |B| - 1$, and $\{0\} \subsetneq G$ because $|A| + |B| \le |G|$ with both sets nonempty rules out the trivial group.

Case 1 (no witness). Scan the pair for a witness: a triple $(a, b', b) \in A \times B \times B$ with $a + b - b' \notin A$. If none exists, then $A + (b - b') \subseteq A$ for every $b, b' \in B$. Because $A$ is finite and translation by $d = b - b'$ is injective, $A + d \subseteq A$ forces $|A + d| = |A|$ and hence $A + d = A$, so $B - B \subseteq \operatorname{stab}(A)$. Since $\operatorname{stab}(A)$ is a subgroup of $G$ (§2.1), the subgroup $H' = \langle B - B \rangle$ generated by $B - B$ satisfies $H' \subseteq \operatorname{stab}(A)$. Moreover, picking any $a_0 \in A$, the map $h \mapsto a_0 + h$ injects $\operatorname{stab}(A)$ into $A$, so $H'$ is finite with $|H'| \le |\operatorname{stab}(A)| \le |A|$. Now four facts follow:

  • $B \subseteq b_0 + H'$ for any fixed $b_0 \in B$ (since every $b - b_0$ lies in $B - B \subseteq H'$), so $|B| \le |H'|$;
  • $H'$ stabilizes $A + b_0$, so $A + b_0 \subseteq A + B \subseteq A + (b_0 + H') = (A + b_0) + H' = A + b_0$, and the sumset collapses to a single translate: $|A + B| = |A|$;
  • $\operatorname{stab}(A) \subseteq \operatorname{stab}(A + B)$ (since $g + A = A \implies g + (A + B) = (g + A) + B = A + B$), so $H' \subseteq \operatorname{stab}(A + B)$;
  • $H'$ is a proper finite subgroup of $G$: $|H'| \le |A| \le |G| - |B| \le |G| - 1 < |G|$.

The bound reads $|A + B| = |A| = |A| + |B| - |B| \ge |A| + |B| - |H'|$, with $H' \subsetneq G$ finite. Done.

Case 2 (a witness exists). Take the canonical one — the lexicographically first $(a, b') \in A \times B$ ($a$ ascending, then $b'$ ascending) admitting some $b \in B$ with $a + b - b' \notin A$, and the first such $b$ — and set $e = a - b'$,

$$A' = A \cup (B + e), \qquad B' = B \cap (A - e).$$

The §2.3 properties do the work:

  • Containment: $A' + B' \subseteq A + B$ (Property 1) — the first invariant survives.
  • Size preservation: $|A'| + |B'| = |A| + |B|$ (Property 2) — so the hypothesis $|A| + |B| \le |G|$ survives, and so does nonemptiness: $b' + e = a \in A$, so $b' \in B'$, and $A \subseteq A'$.
  • Strict decrease: the witness says $b + e \notin A$, so $B + e \not\subseteq A$, and §2.3's monotonicity remark gives $|B'| < |B|$.

Recurse on $(A', B')$. $|B|$ is a positive integer that strictly decreases, so the recursion stops — at the base or at Case 1, whichever comes first. Unrolling: the terminal pair $(A^*, B^*)$ has $|A^*| + |B^*| = |A| + |B|$ and its own proper subgroup $H$ (either $\{0\}$ or its Case-1 $H^*$), with $|A^* + B^*| \ge |A^*| + |B^*| - |H|$; containment chains the bound up:

$$|A + B| \ge |A^* + B^*| \ge |A^*| + |B^*| - |H| = |A| + |B| - |H|. \quad \blacksquare$$

Corollary (Cauchy–Davenport, recovered whole). In $\mathbb{F}_p$ the only proper subgroup is $\{0\}$, so the weak form gives $|A + B| \ge |A| + |B| - 1$ whenever $|A| + |B| \le p$. And if $|A| + |B| \ge p + 1$, then for every $c \in \mathbb{F}_p$ the sets $A$ and $c - B$ meet (their sizes sum to more than $p$), so $c \in A + B$ and $A + B = \mathbb{F}_p$. Together: $|A + B| \ge \min(p, |A| + |B| - 1)$, Lecture 1's theorem — recovered without reopening either of its proofs. $\blacksquare$

3.2 An honesty interlude: why the recursion stops at the weak form

The tempting overreach: run the recursion to the end, then claim the terminal $H'$ stabilizes $A + B$ and read off the strong form. The containment $H' \subseteq \operatorname{stab}(A) \subseteq \operatorname{stab}(A + B)$ is proved — but for the terminal pair, and the recursion only preserved the original sumset up to containment. Nothing stops the deformed pair from being more periodic than the original, and on a small example in $\mathbb{Z}_6$ it happens: $A = \{0, 1, 3\}, B = \{0, 2\}$. Here $\operatorname{stab}(A + B) = \{0\}$ — the sumset $A + B = \{0, 1, 2, 3, 5\}$ is aperiodic — yet the perfectly legal transform with witness $(a, b', b) = (0, 2, 0), e = 4$ produces $A' = \{0, 1, 3, 4\}$ and $B' = \{2\}$, whose sumset $A' + B' = \{0, 2, 3, 5\}$ is stabilized by $\{0, 3\}$: aperiodicity is destroyed by the transform. Of the six $(a, b')$ pairs, four are genuine transforms (containment, size preservation, and strict decrease all hold); the canonical rule picks the first of them — $(a, b') = (0, 0)$ with $b = 2, e = 0$, giving $A' = \{0, 1, 2, 3\}$ and $B' = \{0\}$, stabilizer still trivial — while the period-creating $(0, 2)$ with $e = 4$ is legal but not canonical. The weak form survives because it never asks about $\operatorname{stab}(A + B)$ — it produces its own proper subgroup at the terminal pair, whichever pair that is. The strong form prices the original sumset's period, so it needs an argument that keeps the original in view throughout. DeVos's induction does exactly that, with no transforms at all.

3.3 The strong form: DeVos's intersection–union induction (full)

Theorem (Kneser, strong form — DeVos's route). Let $X, Y$ be nonempty finite subsets of an abelian group $G$, and let $K = \operatorname{stab}(X + Y)$. Then

$$|X + Y| \ge |X + K| + |Y + K| - |K|.$$

Proof. Since $X$ and $Y$ are nonempty and finite, $X + Y$ is nonempty and finite, and for any $s_0 \in X + Y$ the map $k \mapsto s_0 + k$ injects $K$ into $X + Y$, so $K$ is a finite subgroup with $|K| \le |X + Y|$. We induct on the positive integer measure $|X + Y| + |X|$. (The argument follows M. DeVos, A short proof of Kneser's addition theorem for abelian groups, 2007.)

The quotient branch: $K \ne \{0\}$. Since $K$ is finite and nontrivial, $|K| \ge 2$. Pass to the quotient group $G/K$ (§2.4, Move 2): the images $\bar{X} = (X + K)/K$ and $\bar{Y} = (Y + K)/K$ have sumset $\bar{X} + \bar{Y} = (X + Y)/K$ with trivial stabilizer $\operatorname{stab}(\bar{X} + \bar{Y}) = \{0_{G/K}\}$. Moreover, $|\bar{X} + \bar{Y}| = |X + Y|/|K| \le |X + Y|/2 < |X + Y|$, and since $X + K = \bigcup_{x \in X}(x + K)$ is a union of at most $|X|$ cosets of $K$, $|\bar{X}| = |X + K|/|K| \le |X|$. Thus $|\bar{X} + \bar{Y}| + |\bar{X}| < |X + Y| + |X|$, so the inductive hypothesis applies in $G/K$ to give $|\bar{X} + \bar{Y}| \ge |\bar{X}| + |\bar{Y}| - 1$. Multiplying by $|K|$ yields $|X + Y| \ge |X + K| + |Y + K| - |K|$.

The aperiodic branch: $K = \{0\}$. Assume henceforth that $K = \operatorname{stab}(X + Y) = \{0\}$; we must prove $|X + Y| \ge |X| + |Y| - 1$. If $|X| = 1$, then $|X + Y| = |Y| = |X| + |Y| - 1$ and we are done. Suppose $|X| \ge 2$ and choose distinct $x, x' \in X$. Since $\operatorname{stab}(Y) \subseteq \operatorname{stab}(X + Y) = \{0\}$ and $x' - x \ne 0$, the element $x' - x$ does not stabilize $Y$, so there exists $y \in Y$ with $y + x' - x \notin Y$. Replace $Y$ by its translate $Y' = Y - y + x$: the sizes $|Y'| = |Y|$ and $|X + Y'| = |X + Y|$ and the stabilizer $\operatorname{stab}(X + Y') = \{0\}$ are unchanged, and now $x \in X \cap Y'$ while $x' \notin Y'$, so $\emptyset \ne X \cap Y' \subsetneq X$. Rename $Y'$ back to $Y$.

Portions. Call a nonempty subset $Z \subseteq X + Y$, with finite stabilizer $H = \operatorname{stab}(Z)$, a portion if

$$|Z| + |H| \ge |X \cap Y| + |(X \cup Y) + H|.$$

Set $Z_0 = (X \cap Y) + (X \cup Y)$. Since $X \cap Y \ne \emptyset$ and every pair $(u, v) \in (X \cap Y) \times (X \cup Y)$ has either $u \in X, v \in Y$ or $v \in X, u \in Y$, $Z_0$ is a nonempty subset of $X + Y$, and the pair $(X \cap Y, X \cup Y)$ has strictly smaller induction measure:

$$|Z_0| + |X \cap Y| \le |X + Y| + |X \cap Y| < |X + Y| + |X|.$$

By the inductive hypothesis applied to $(X \cap Y, X \cup Y)$ with $H_0 = \operatorname{stab}(Z_0)$,

$$|Z_0| \ge |(X \cap Y) + H_0| + |(X \cup Y) + H_0| - |H_0| \ge |X \cap Y| + |(X \cup Y) + H_0| - |H_0|,$$

so $Z_0$ is a portion. Among all portions, choose a portion $Z \subseteq X + Y$ whose stabilizer $H = \operatorname{stab}(Z)$ has $|H|$ minimal (hence minimal under inclusion).

The trivial exit: $H = \{0\}$. Then $|X + Y| \ge |Z| \ge |X \cap Y| + |X \cup Y| - 1 = |X| + |Y| - 1$, and we are done.

The nontrivial branch: $H \ne \{0\}$ — for a contradiction. Since $\operatorname{stab}(X + Y) = \{0\} \ne H$, the sumset $X + Y$ is not a union of $H$-cosets, so there exist $a \in X$ and $b \in Y$ such that the $H$-coset $C := a + b + H$ satisfies $C \not\subseteq X + Y$. Define

$$X_1 = X \cap (a + H), \quad Y_1 = Y \cap (b + H), \quad X_2 = X \cap (b + H), \quad Y_2 = Y \cap (a + H),$$

so $a \in X_1 \ne \emptyset$ and $b \in Y_1 \ne \emptyset$. For $i \in \{1, 2\}$ with $X_i, Y_i \ne \emptyset$, set $Z_i = Z \cup (X_i + Y_i) \subseteq X + Y$ and $H_i = \operatorname{stab}(X_i + Y_i)$.

The key observation. Whenever $X_i, Y_i \ne \emptyset$, we have $\operatorname{stab}(Z_i) = H_i \subsetneq H$ and $|Z_i| = |Z| + |X_i + Y_i|$:

  1. $Z$ is disjoint from $C$ and $0 < |X_i + Y_i| < |H|$: Because $Z$ is a union of $H$-cosets and $Z \subseteq X + Y$ while $C \not\subseteq X + Y$, $Z$ cannot meet $C$, so $Z \cap C = \emptyset$. Meanwhile, $X_i + Y_i$ is a nonempty subset of $C \cap (X + Y) \subsetneq C$, so $0 < |X_i + Y_i| < |C| = |H|$ and $|Z_i| = |Z| + |X_i + Y_i|$.
  2. $H_i \subseteq H$ is a proper subgroup: Pick $p_0 \in X_i + Y_i \subseteq C$. For any $g \in H_i$, $g + p_0 \in X_i + Y_i \subseteq C$, so $g \in C - p_0 = H$. If $H_i = H$, then $X_i + Y_i$ would be a nonempty $H$-invariant subset of the single $H$-coset $C$, forcing $X_i + Y_i = C \subseteq X + Y$, a contradiction. Thus $H_i \subsetneq H$.
  3. $\operatorname{stab}(Z_i) = H_i$: Every $g \in H_i \subseteq H$ stabilizes both $Z$ (as $H = \operatorname{stab}(Z)$) and $X_i + Y_i$, so $H_i \subseteq \operatorname{stab}(Z_i)$. Conversely, let $g \in \operatorname{stab}(Z_i)$. Because $H$ is a subgroup of $G$, translation by $g$ permutes the $H$-cosets of $G$, and for every $H$-coset $D$ we have $|Z_i \cap (g + D)| = |(g + Z_i) \cap (g + D)| = |Z_i \cap D|$. Since $Z$ is a union of $H$-cosets disjoint from $C$ and $Z_i \cap C = X_i + Y_i$, $C$ is the unique $H$-coset of $G$ whose intersection with $Z_i$ has cardinality strictly between $0$ and $|H|$ (every other $H$-coset meets $Z_i$ in size $0$ or $|H|$). Therefore $g + C = C$, which gives $g \in H$. Since $g \in H = \operatorname{stab}(Z)$, we have $g + Z = Z$, and intersecting $g + Z_i = Z_i$ with $C$ gives $g + (X_i + Y_i) = X_i + Y_i$, so $g \in H_i$.

Because $\operatorname{stab}(Z_i) = H_i \subsetneq H$, the minimality of $|H|$ implies that $Z_i$ is not a portion:

$$|Z_i| + |H_i| < |X \cap Y| + |(X \cup Y) + H_i|.$$

Furthermore, the inductive hypothesis applies to $(X_i, Y_i)$: since $Z$ is a nonempty union of $H$-cosets, $|H| \le |Z|$, and $Z \subsetneq Z_i \subseteq X + Y$ gives $|X_i + Y_i| < |H| \le |Z| < |X + Y|$ while $|X_i| \le |X|$, so $|X_i + Y_i| + |X_i| < |X + Y| + |X|$. Induction on $(X_i, Y_i)$ with stabilizer $H_i = \operatorname{stab}(X_i + Y_i)$ gives

$$|X_i + Y_i| \ge |X_i + H_i| + |Y_i + H_i| - |H_i|.$$

Equation (1). Subtract the non-portion inequality for $Z_i$ from the portion inequality for $Z$, using $|Z_i| = |Z| + |X_i + Y_i|$ and the inductive bound on $|X_i + Y_i|$:

$$|(X \cup Y) + H| - |(X \cup Y) + H_i| < (|Z| + |H|) - (|Z_i| + |H_i|) = |H| - |X_i + Y_i| - |H_i| \le |H| - |X_i + H_i| - |Y_i + H_i|. \quad (1)$$

Equation (1) holds unconditionally for $i = 1$ (since $X_1, Y_1 \ne \emptyset$), and for $i = 2$ whenever $X_2, Y_2 \ne \emptyset$.

Three degeneracies, each ruled out by (1) at $i = 1$. Since $H_1 \subseteq H$, the set $(X \cup Y) + H_1$ is a subset of $(X \cup Y) + H$, and for any $H$-coset $D$, we have $((X \cup Y) + H_1) \cap D = ((X \cup Y) \cap D) + H_1$. Inspect the cosets $a + H$ (which lies in $(X \cup Y) + H$ since $a \in X$) and $b + H$ (which lies in $(X \cup Y) + H$ since $b \in Y$):

  • If $Y_2 = \emptyset$: then $(X \cup Y) \cap (a + H) = X_1 \cup Y_2 = X_1$, so the number of elements of $a + H$ lying in $((X \cup Y) + H) \setminus ((X \cup Y) + H_1)$ is $|H| - |X_1 + H_1| > |H| - |X_1 + H_1| - |Y_1 + H_1|$ (as $|Y_1 + H_1| \ge |Y_1| \ge 1$), contradicting (1) at $i = 1$.
  • If $X_2 = \emptyset$: then $(X \cup Y) \cap (b + H) = X_2 \cup Y_1 = Y_1$, so the uncovered count on $b + H$ is $|H| - |Y_1 + H_1| > |H| - |X_1 + H_1| - |Y_1 + H_1|$ (as $|X_1 + H_1| \ge 1$), contradicting (1) at $i = 1$.
  • If $a + H = b + H$: then $X_1 = X_2$ and $Y_1 = Y_2$, and on the single coset $a + H = b + H \subseteq (X \cup Y) + H$ we have $(X \cup Y) \cap (a + H) = X_1 \cup Y_1$, so the uncovered count on $a + H$ is $|H| - |(X_1 \cup Y_1) + H_1| \ge |H| - |X_1 + H_1| - |Y_1 + H_1|$, again contradicting the strict inequality (1) at $i = 1$.

Thus $X_2 \ne \emptyset$, $Y_2 \ne \emptyset$, and $a + H \ne b + H$, so Equation (1) holds for both $i = 1$ and $i = 2$.

Equation (2). Because $H_i \subseteq H$, the sets $(X \cup Y) + H$, $(X \cup Y) + H_i$, $H$, $X_i + H_i$, and $Y_i + H_i$ are all unions of $H_i$-cosets, so their cardinalities are multiples of $|H_i|$. Since $(X \cup Y) + H_i \subseteq (X \cup Y) + H$, the left side of (1) is a nonnegative multiple of $|H_i|$ strictly less than the multiple $|H| - |X_i + H_i| - |Y_i + H_i|$ of $|H_i|$, which forces

$$|H| - |X_i + H_i| - |Y_i + H_i| \ge |H_i|, \quad\text{and hence}\quad |H| \ge |X_i| + |Y_i| + |H_i| \quad (i = 1, 2). \quad (2)$$

Equation (3). Since $\operatorname{stab}(X + Y) = \{0\} \subsetneq H$, minimality of $|H|$ implies that $X + Y$ is not a portion, so $|X + Y| + 1 < |X \cap Y| + |X \cup Y| = |X| + |Y|$, i.e. $|X| + |Y| - |X + Y| \ge 2 > 0$. Define the uncovered parts of the two distinct cosets $a + H$ and $b + H$:

$$A = (a + H) \setminus (X_1 \cup Y_2) = (a + H) \setminus (X \cup Y), \qquad B = (b + H) \setminus (X_2 \cup Y_1) = (b + H) \setminus (X \cup Y).$$

Because $a + H$ and $b + H$ are disjoint cosets contained in $(X \cup Y) + H$, the sets $X \cup Y$, $A$, and $B$ are pairwise disjoint subsets of $(X \cup Y) + H$, giving $|(X \cup Y) + H| \ge |X \cup Y| + |A| + |B|$. Moreover, $Z_i = Z \sqcup (X_i + Y_i) \subseteq X + Y$ gives $|Z| \le |X + Y| - |X_i + Y_i|$. Substituting both into the portion inequality for $Z$ yields, for $i = 1, 2$,

$$\begin{aligned} |H| &\ge |X \cap Y| + |(X \cup Y) + H| - |Z| \\ &\ge |X \cap Y| + |X \cup Y| + |A| + |B| - |X + Y| + |X_i + Y_i| \\ &= |A| + |B| + (|X| + |Y| - |X + Y|) + |X_i + Y_i| \\ &> |A| + |B| + |X_i| + |Y_i| - |H_i|, \end{aligned} \quad (3)$$

where the last step uses $|X| + |Y| - |X + Y| > 0$ and $|X_i + Y_i| \ge |X_i + H_i| + |Y_i + H_i| - |H_i| \ge |X_i| + |Y_i| - |H_i|$.

The coset count that cannot add up. Add Equation (2) for $i = 1, 2$ and Equation (3) for $i = 1, 2$:

$$4|H| > 2\big(|A| + |B| + |X_1| + |Y_1| + |X_2| + |Y_2|\big), \quad\text{so}\quad 2|H| > |A| + |B| + |X_1| + |Y_1| + |X_2| + |Y_2|.$$

On the other hand, $a + H = A \sqcup (X_1 \cup Y_2)$ and $b + H = B \sqcup (X_2 \cup Y_1)$, so subadditivity gives $|H| = |a + H| = |A| + |X_1 \cup Y_2| \le |A| + |X_1| + |Y_2|$ and $|H| = |b + H| = |B| + |X_2 \cup Y_1| \le |B| + |X_2| + |Y_1|$. Summing these two inequalities gives

$$2|H| \le |A| + |B| + |X_1| + |Y_1| + |X_2| + |Y_2| < 2|H|,$$

a contradiction. Thus the nontrivial branch $H \ne \{0\}$ cannot occur, completing the induction. $\blacksquare$

3.4 What to learn

Two assemblies, two temperaments. The recursion is P4 in its purest form: a deterministic procedure whose two exits are the two cases of the proof, the invariants doing the bookkeeping — and its honesty clause teaches as much as its success: the invariant was too weak for the strong form, and the $\mathbb{Z}_6$ counterexample is a proof that no witness rule fixes that; some failures are structural, not tactical. DeVos's induction is the opposite temperament: no transforms, one well-chosen measure ($|X + Y| + |X|$), one new notion — the portion, which prices a piece of the sumset by its own stabilizer — and a final pair of cosets that cannot be partitioned as the arithmetic demands. The lesson to carry: when an invariant fails, the right move is sometimes not a better invariant but a different induction — DeVos never repairs the transform; he refuses it. And notice what made the strong form cheap: the portion inequality is Kneser's own bound applied to a sub-pair, the induction hypothesis doing at every level what the quotient move does once. With the strong form proved, the sumset thread is complete: staircase, C–D, Kneser, EGZ — every proof the book's.

Lecture 4 · Shadows: The Kruskal–Katona Theorem

4.1 The question, and two costumes

The last engine of the set-system thread answers a deceptively simple question: if you know how many $k$-sets you own, how few $(k - 1)$-sets must sit underneath them? The shadow $\partial\mathcal{G}$ of a $k$-uniform family $\mathcal{G}$ is the family of all $(k - 1)$-sets contained in some member of $\mathcal{G}$; the $j$-shadow $\partial_j\mathcal{G}$ is the same construction iterated down to level $j$. Shadows look like bookkeeping; they are actually a price system — and pricing families by their shadows is what finally lets this book's counting world reach the structural questions the earlier routes left flagged.

The theorem, costume one (the cascade). Kruskal (1963) and Katona (1966), independently: among all families of $N$ $k$-sets, the smallest shadow is achieved by the initial segments of the colex order — order $k$-sets by their largest element, ties broken by the next-largest, downward ($\{1,2\} \prec \{1,3\} \prec \{2,3\} \prec \{1,4\} \prec \dots$) — and take the first $N$. The cascade form makes the minimum computable: write $N$ in its $k$-binomial representation

$$N = \binom{a_k}{k} + \binom{a_{k-1}}{k-1} + \dots + \binom{a_i}{i} \qquad (a_k > a_{k-1} > \dots > a_i \ge i \ge 1),$$

built greedily ($a_k$ is the largest $a$ with $\binom{a}{k} \le N$, then descend a level), and then the minimum shadow size is $\binom{a_k}{k-1} + \binom{a_{k-1}}{k-2} + \dots + \binom{a_i}{i-1}$. This chapter cites the cascade theorem rather than proving it — it belongs to the same world as the compression philosophy of Chapter 7's shifting lecture (a canonical initial segment beats every deformation), raised to a complete classification.

Costume two (the real parameter — the one this book uses). Lovász's version prices a family by a single number: if $|\mathcal{G}| = \binom{x}{k}$ with $x$ real and $x \ge k \ge 1$, then $|\partial\mathcal{G}| \ge \binom{x}{k-1}$. For each integer $k \ge 1$, the real binomial polynomial $\binom{x}{k} = x(x - 1)\cdots(x - k + 1)/k!$ (with $\binom{x}{0} := 1$) interpolates the integer binomials and is continuous and strictly increasing for real $x \ge k - 1$ (since each factor $x - i$ is nonnegative and strictly increasing on $[k - 1, \infty)$, and positive on $(k - 1, \infty)$). The two costumes are one theorem: the cascade pins the exact minimum integer-wise; the real form trades a little sharpness for portability — no bookkeeping, one price per family, pluggable into inductions (both §4.2 and §4.3 rely on that).

The machine census as referee. Cascade versus colex initial segments: agreement on all $781$ sizes ($k = 2, 3, 4$; every $N \le \binom{12}{k}$); and $\operatorname{cascade}(10, 3) = 10 = \binom{5}{2}$ — the ten triples on a $5$-set have exactly ten pairs underneath them. The real form, exhaustively: every one of the $32,767$ nonempty $2$-uniform families on $[6]$ and every one of the $1,048,575$ $3$-uniform families on $[6]$ satisfies the bound (plus $24,000$ sampled families at $(7, 3), (7, 4), (8, 3), (8, 4)$ — zero violations), and equality happens exactly when $x$ is an integer and $\mathcal{G}$ is the complete family $K_x^k$ — all $k$-subsets of a fixed $x$-set: all $99$ exhaustive equality cases are precisely these, $57$ at $k = 2$ ($15$ single edges + $20$ triangles + $15$ four-vertex cliques + $6$ five-vertex + $1$ six-vertex) and $42$ at $k = 3$ ($20$ single triples + $15 + 6 + 1$ complete families above them).

(Checkpoint: at $k = 2$ the shadow is the vertex set. The four edges $\{1,2\}, \{1,3\}, \{1,4\}, \{2,3\}$ have $|\mathcal{G}| = 4 = \binom{x}{2}$, so $x = (1 + \sqrt{33})/2 \approx 3.37$, and the shadow $\{1, 2, 3, 4\}$ has size $4 \ge 3.37$. The triangle $\{1,2\}, \{1,3\}, \{2,3\}$ has $x = 3$ and shadow $\{1, 2, 3\}$ of size $3 = \binom{3}{1}$ — equality, and indeed the triangle is the complete family on $\{1, 2, 3\}$, as the equality structure demands.)

4.2 The clique form, and the proof (full)

The route to a complete proof is one more change of costume — from shadows to cliques. Fix $r \ge 1$ and a family $\mathcal{G}$ of $r$-subsets of a vertex set $V$. Call an $(r + 1)$-set $X$ a clique of $\mathcal{G}$ if every $r$-subset of $X$ belongs to $\mathcal{G}$, and write $K(\mathcal{G})$ for the number of cliques. (The statement below assumes $|\mathcal{G}| = \binom{x}{r}$ with $x \ge r$, i.e. a nonempty family.)

Theorem (clique form; statement Lovász — from the cascade theorem —, short proof by Keevash, 2008). If $|\mathcal{G}| = \binom{x}{r}$ with $x$ real and $x \ge r \ge 1$, then $K(\mathcal{G}) \le \binom{x}{r+1}$.

Proof. We induct on $r \ge 1$.

Base $r = 1$. $\mathcal{G}$ is a family of $x = |\mathcal{G}|$ singletons; every pair drawn from those $x$ vertices forms a $2$-clique, so $K(\mathcal{G}) = \binom{x}{2}$ with equality.

Step ($r \ge 2$). For each vertex $v \in V$, define its link $L(v) = \{T \subseteq V \setminus \{v\} : |T| = r - 1 \text{ and } T \cup \{v\} \in \mathcal{G}\}$. The map $T \mapsto T \cup \{v\}$ is a bijection from $L(v)$ to the members of $\mathcal{G}$ containing $v$, so $|L(v)| = d(v)$, the degree of $v$. Write $K(v)$ for the number of cliques of $\mathcal{G}$ containing $v$. If $d(v) = 0$, then $K(v) = 0$. If $d(v) \ge 1$, then $d(v) \ge 1 = \binom{r-1}{r-1}$, so by continuity and strict monotonicity of $\binom{\cdot}{r-1}$ on $[r - 1, \infty)$ there is a unique real $y_v \ge r - 1$ with $d(v) = \binom{y_v}{r-1}$. We then have two ceilings on $K(v)$:

  1. The link ceiling. A clique $X$ containing $v$ has the form $X = S \cup \{v\}$ with $|S| = r$, and $X$ is a clique of $\mathcal{G}$ if and only if $S \in \mathcal{G}$ and every $(r - 1)$-subset $T \subset S$ lies in $L(v)$ — in particular, $S$ is an $r$-clique of the $(r - 1)$-uniform family $L(v)$. Since $y_v \ge r - 1 \ge 1$, the inductive hypothesis applied to $L(v)$ gives $$K(v) \le K(L(v)) \le \binom{y_v}{r} = \binom{y_v}{r-1}\frac{y_v - r + 1}{r} = d(v)\frac{y_v - r + 1}{r}.$$
  2. The degree ceiling. The map $X \mapsto X \setminus \{v\}$ sends cliques of $\mathcal{G}$ containing $v$ injectively into members of $\mathcal{G}$ avoiding $v$. Thus $$K(v) \le |\mathcal{G}| - d(v) = \binom{x}{r} - d(v).$$

The per-vertex price. We claim $K(v) \le (x/r - 1)d(v)$ for every vertex $v \in V$. For $d(v) = 0$ both sides are $0$; for $d(v) \ge 1$ there are two cases:

  • If $y_v \le x - 1$ (equivalently $d(v) \le \binom{x-1}{r-1}$): ceiling 1 gives $K(v) \le d(v)(y_v - r + 1)/r \le d(v)(x - r)/r = (x/r - 1)d(v)$.
  • If $y_v > x - 1$ (equivalently $d(v) > \binom{x-1}{r-1}$): ceiling 2 together with the polynomial Pascal identity $\binom{x}{r} - \binom{x-1}{r-1} = \binom{x-1}{r}$ gives $$K(v) \le \binom{x}{r} - d(v) < \binom{x}{r} - \binom{x-1}{r-1} = \binom{x-1}{r} = \binom{x-1}{r-1}\frac{x - r}{r} < d(v)\left(\frac{x}{r} - 1\right),$$ since $x - r \ge 0$. (In particular, this second case is always strictly slack when $x > r$, and impossible when $x = r$ since $|\mathcal{G}| = 1 \implies d(v) \le 1 = \binom{r-1}{r-1}$.)

Summing. Double counting vertex–clique and vertex–edge incidences gives $(r + 1)K(\mathcal{G}) = \sum_{v \in V} K(v)$ and $\sum_{v \in V} d(v) = r|\mathcal{G}| = r\binom{x}{r}$. Hence

$$(r + 1)K(\mathcal{G}) = \sum_{v \in V} K(v) \le \left(\frac{x}{r} - 1\right)\sum_{v \in V} d(v) = (x - r)\binom{x}{r} = (r + 1)\binom{x}{r+1}.$$

Dividing by $r + 1$ gives $K(\mathcal{G}) \le \binom{x}{r+1}$. $\blacksquare$

Equality (for $x \ge r \ge 1$). If $x = r$, then $|\mathcal{G}| = \binom{r}{r} = 1$, which is already the complete family $K_r^r$ on its $r$ vertices, with $K(\mathcal{G}) = 0 = \binom{r}{r+1}$. For $x > r$ (and $r \ge 2$), equality $K(\mathcal{G}) = \binom{x}{r+1}$ forces $K(v) = (x/r - 1)d(v)$ for every vertex $v$. Since the second case $y_v > x - 1$ is strictly slack when $x > r$, every active vertex ($d(v) > 0$) must sit in the first case with equality $y_v = x - 1$, meaning $d(v) = \binom{x-1}{r-1}$. If $n'$ vertices are active, then $r\binom{x}{r} = \sum_{v \in V} d(v) = n'\binom{x-1}{r-1}$, so $n' = r\binom{x}{r}/\binom{x-1}{r-1} = x$. Thus $x = n'$ is an integer, the union of $\mathcal{G}$ has $x$ vertices, and $\binom{x}{r}$ distinct $r$-subsets of an $x$-element vertex set must be all of them: $\mathcal{G} = K_x^r$. Conversely, $K_x^r$ attains $K(K_x^r) = \binom{x}{r+1}$. (Note that for $r = 1$, every nonempty $1$-uniform family has integer size $x = |\mathcal{G}|$ and is automatically $K_x^1$.)

Corollary (the shadow form — Lovász's costume). Let $\mathcal{F}$ be a $k$-uniform family ($k \ge 1$) with $|\mathcal{F}| = \binom{x}{k}$ for a real $x \ge k$. Then $|\partial\mathcal{F}| \ge \binom{x}{k-1}$.

Proof. For $k = 1$, $\mathcal{F}$ is nonempty so $\partial\mathcal{F} = \{\emptyset\}$ has size $1 = \binom{x}{0}$. Assume $k \ge 2$, and set $\mathcal{G} = \partial\mathcal{F}$, which is $(k - 1)$-uniform. Since $|\mathcal{F}| = \binom{x}{k} \ge 1$, $\mathcal{F}$ contains at least one $k$-set $F$, whose $k$ subsets of size $k - 1$ all lie in $\mathcal{G}$; thus $|\mathcal{G}| \ge k > 1 = \binom{k-1}{k-1}$. By continuity and strict monotonicity of $\binom{\cdot}{k-1}$ on $[k - 1, \infty)$, there is a unique real $y \ge k - 1 \ge 1$ with $|\mathcal{G}| = \binom{y}{k-1}$. Every $F \in \mathcal{F}$ has all its $(k - 1)$-subsets in $\partial\mathcal{F} = \mathcal{G}$, so every $F \in \mathcal{F}$ is a $k$-clique of $\mathcal{G}$. By the clique theorem applied to $\mathcal{G}$,

$$\binom{x}{k} = |\mathcal{F}| \le K(\mathcal{G}) \le \binom{y}{k}.$$

Since $\binom{\cdot}{k}$ is strictly increasing on $[k - 1, \infty)$ and $x, y \ge k - 1$, this forces $y \ge x$, and hence $|\partial\mathcal{F}| = \binom{y}{k-1} \ge \binom{x}{k-1}$. $\blacksquare$

The $j$-form, by induction on the price. The same argument iterates to every level $1 \le j < k$: $|\mathcal{G}| = \binom{x}{k}$ implies $|\partial_j\mathcal{G}| \ge \binom{x}{j}$. One application gives $|\partial\mathcal{G}| \ge \binom{x}{k-1}$; now price $\partial\mathcal{G}$ by its own parameter — $|\partial\mathcal{G}| = \binom{x'}{k-1}$ with $x' \ge x$ — and apply again: $|\partial_{k-2}\mathcal{G}| \ge \binom{x'}{k-2} \ge \binom{x}{k-2}$; iterate down to level $j$. The engine is that each application prices the current family by its own real parameter, and parameters only grow as you descend. Machine check, exhaustive: at $(6, 3)$ both $j = 1$ and $j = 2$ hold for all $1,048,575$ families (zero violations), equality on the $42$ complete families; at $(6, 2)$, $j = 1$ holds for all $32,767$ families, equality on the $57$ complete families. $\blacksquare$

4.3 Daykin's mirror: EKR a third way (full)

Now the payoff — the theorem this book has proved completely once (the circle method, Chapter 7's Lecture 3) and cited once (the shifting route, its closing step): a second complete proof, with no circles, no shifting, and no averaging — one disjointness observation, one $j$-form application, one monotone function. Daykin's observation (1974) is that complementation turns intersection facts into containment facts, and containment is what shadows measure.

Let $\mathcal{F}$ be a nonempty intersecting $k$-uniform family on $[n]$ with $k \ge 1$ and $n \ge 2k$, and pass to complements: $\mathcal{F}^* = \{[n] \setminus F : F \in \mathcal{F}\}$, uniform of size $n - k \ge k$. Take the $k$-shadow of $\mathcal{F}^*$ (with $\partial_k \mathcal{F}^* := \mathcal{F}^*$ when $n - k = k$) and read it in plain language:

$$\partial_k\mathcal{F}^* = \{k\text{-sets } S : S \subseteq [n] \setminus F \text{ for some } F \in \mathcal{F}\} = \text{the } k\text{-sets disjoint from a member of } \mathcal{F}.$$

The mirror disjointness. $\mathcal{F} \cap \partial_k\mathcal{F}^* = \emptyset$. Indeed, a member $F \in \mathcal{F}$ lying in $\partial_k\mathcal{F}^*$ would be disjoint from some $F' \in \mathcal{F}$ — impossible in an intersecting family, including the case $F' = F$, since a $k$-set is never disjoint from itself ($k \ge 1$). Both $\mathcal{F}$ and $\partial_k\mathcal{F}^*$ are $k$-uniform, so

$$|\mathcal{F}| + |\partial_k\mathcal{F}^*| \le \binom{n}{k}. \quad (*)$$

One application of the $j$-form. Write $|\mathcal{F}^*| = |\mathcal{F}| = \binom{x}{n-k}$ with $x \ge n - k \ge k$. The $j$-form at level $j = k$ gives $|\partial_k\mathcal{F}^*| \ge \binom{x}{k}$. Feeding this into $(*)$:

$$\binom{x}{n-k} + \binom{x}{k} \le \binom{n}{k}.$$

Now define $h(t) = \binom{t}{n-k} + \binom{t}{k}$ and watch two facts do all the work. First, $h$ is strictly increasing for $t \ge n - k$, since both binomials increase there. Second, Pascal at the integer point $n - 1$:

$$h(n - 1) = \binom{n-1}{n-k} + \binom{n-1}{k} = \binom{n-1}{k-1} + \binom{n-1}{k} = \binom{n}{k}.$$

So $\binom{x}{n-k} + \binom{x}{k} \le h(n - 1)$ with $h$ increasing forces $x \le n - 1$, and therefore

$$|\mathcal{F}| = \binom{x}{n-k} \le \binom{n-1}{n-k} = \binom{n-1}{k-1}. \quad \blacksquare$$

That is EKR — the book's second complete proof. At $n = 2k$ the mirror is the complementary-pair argument of Chapter 7's Lecture 4: $\mathcal{F}^*$ is then $k$-uniform, a $k$-set inside the complement of a $k$-set is that complement, so $\partial_k\mathcal{F}^* = \mathcal{F}^*$ and $(*)$ reads $2|\mathcal{F}| \le \binom{2k}{k}$ — one member per complementary pair, Chapter 7's §4.1 re-derived.

Machine record. Exhaustive on $[6]$: every one of the $192$ intersecting $2$-uniform families (the empty family included) and all $59,049$ intersecting $3$-uniform families satisfy $(*)$; the maximum $5$ at $(6, 2)$ is achieved by the $6$ stars (the $n > 2k$ regime), the maximum $10$ at $(6, 3)$ by $1,024$ families (the $n = 2k$ regime). One honest nuance the census surfaces: mirror-equality in $(*)$ is not the same as maximality — at $(6, 2)$ it holds for $26$ families, the $6$ stars and also the $20$ triangles, which are sub-maximum (size $3$) but still split $\binom{6}{2} = 15$; at $(6, 3)$ it holds for all $1,024$ maxima. The EKR bound comes from $h$'s monotonicity, not from mirror-equality alone: a tight mirror can still sit at a loose $x$.

With this, flag (i) of the appendix — the shifting route's closing induction — is retired: EKR now has two complete proofs in this book (Chapter 7's circle-method Lecture 3; the mirror, here), and the shifting route's closing induction is cited for what it is — the field's standard third route, carrying none of this book's weight. (D. E. Daykin, "Erdős–Ko–Rado from Kruskal–Katona", J. Combin. Theory Ser. A 17 (1974) 254–255.)

4.4 The shade route to uniqueness — the missing brick

The mirror tempts an overreach: uniqueness by the same road. Suppose $n > 2k$ and $|\mathcal{F}| = \binom{n-1}{k-1}$. Then $(*)$ forces $|\partial_k\mathcal{F}^*| \le \binom{n}{k} - \binom{n-1}{k-1} = \binom{n-1}{k}$, while the $j$-form gives $|\partial_k\mathcal{F}^*| \ge \binom{x}{k}$: so $x = n - 1$, and equality holds in the $j$-form, many levels deep — the shadow drops from uniformity $n - k$ all the way down to level $k$. If deep $j$-form equality forced $\mathcal{F}^*$ to be the complete family $K_{n-1}^{n-k}$ — all $(n - k)$-sets inside one fixed $(n - 1)$-set — then every member of $\mathcal{F}$ would contain the missing vertex $z$, and the star would follow: uniqueness proved.

The gap, closed in the next lecture: §4.2's equality analysis is proved for the shadow one level down and iterates level by level, and the seemingly deeper statement — "a family sitting at the cascade's minimum across many levels at once must be complete" — in fact follows from that same clique-equality analysis, applied once at the level adjacent to uniformity. That is the deep cascade-uniqueness lemma, built in four steps in §5.2. The Hilton–Milner gateway. Once stars are the unique maximum ($n > 2k$), the next question writes itself: how big can an intersecting family with an empty core — no element common to all members — be? Hilton–Milner (1967): $|\mathcal{F}| \le \binom{n-1}{k-1} - \binom{n-k-1}{k-1} + 1$, tight at the family of all $k$-sets containing $x$ and meeting a fixed $Y$ ($x \notin Y, |Y| = k$), together with $Y$ itself. The machine census at $(7, 3)$ confirms the shape of the world: Bron–Kerbosch over the $35$ triples finds $6,127$ maximal intersecting families; the maximum $15$ is achieved by the $7$ stars; among empty-core families the maximum is $13 = \binom{6}{2} - \binom{3}{2} + 1$, the HM formula, achieved by $175$ families — and the census splits them into two shapes: $140$ of the HM type ($7$ choices of $x$, $20$ of $Y$) and $35$ of a second shape, the $k$-sets meeting a fixed triple $W$ in at least $2$ points, which at $k = 3$ ties the HM family in size. The tie is a small-$k$ phenomenon: at $k \ge 4$ the two shapes separate — sizes $70$ and $75$ at $(10, 4)$, $51$ and $53$ at $(9, 4)$, $288$ and $316$ at $(12, 5)$, the HM formula winning each time in this regime (Hilton–Milner's theorem) — and the shape comparison is genuinely subtle: it is the doorstep of the next theorem.

Ahlswede–Khachatrian: the complete answer (citation gateway). For $n < 2k$ every two $k$-sets intersect, so the maximum is trivially $\binom{n}{k}$ — larger than any star; EKR's regime $n \ge 2k$ is where the star $\binom{n-1}{k-1}$ wins. The complete answer for all $(n, k)$ is Ahlswede–Khachatrian's complete intersection theorem (1997): the maximum is $\max_{r \ge 0} |F_r|$, where $F_r$ is the family of $k$-sets meeting the initial segment $[2r + 1]$ in at least $r + 1$ points. The star is $r = 0$; the Hilton–Milner world is $r = 1$; the sequence continues — at $(7, 3)$ the sizes read $[15, 13, 10, 0]$, at $(5, 3)$ they read $[6, 7, 10, 0]$ and the winner is $r = 2$ with $10 = \binom{5}{3}$, the whole level, as $n < 2k$ demands. This chapter records the theorem as a gateway — stated, sampled by machine, proved nowhere here — and points the reader at Chapter 7's ◐15 for the exploration.

Union-closed lore: the frontier one theorem away. A family $\mathcal{A}$ is union-closed if $A \cup B \in \mathcal{A}$ for all $A, B \in \mathcal{A}$. Frankl's 1979 conjecture: in any finite union-closed family with at least one nonempty member, some element lies in at least half the members. It is open still — one of the great stubborn problems — and the best proved fraction is Gilmer's constant $(3 - \sqrt{5})/2 \approx 0.3819660112501051$ (Gilmer 2022; improved slightly by subsequent authors), a breakthrough obtained by information-theoretic means. Two facts this chapter's own tools can verify. First, the free case: a union-closed family containing a singleton $\{x\}$ already satisfies the conjecture for $x$ — pair each set avoiding $x$ with its union with $\{x\}$; the map is injective, $\cup$-closedness keeps the partner inside the family, and the avoiding sets are thereby outnumbered. Second, the census: on $[3]$, all $121$ nonempty union-closed families ($120$ with a nonempty member; $\{\emptyset\}$ alone is vacuous); on $[4]$, all $4,959$ ($4,958$); the singleton lemma on the $4,126$ singleton-containing families of $[4]$ — zero failures anywhere. (Survey: arXiv:2306.12351.)

4.5 What to learn

Shadow pricing completes the chapter's engine collection. The real parameter $x$ is a price: a $k$-family costing $\binom{x}{k}$ gets no discount at any lower level — every $j$-shadow costs at least $\binom{x}{j}$ — and the complete families are the only exact price tags, the colex initial segments the only exact minimizers. Three routes to EKR now live in this book: averaging over circles (Chapter 7's Lecture 3), deforming by shifting (its Lecture 5, the last step cited), and pricing the complement mirror (this lecture) — and the third is by far the cheapest, which is a lesson in itself: before building machinery, ask what the dual object sees for free. What remains flagged, honestly: the deep-level cascade uniqueness and the thin range it serves — the closing lecture builds the first and completes the second, retiring the appendix's last flag. And the gateways installed here point beyond the course: Hilton–Milner for empty cores, Ahlswede–Khachatrian for all $n$, Gilmer's constant for union-closed families — the current frontier of the counting world this book has been teaching.

Lecture 5 · Uniqueness Completed: The Shade Route

The last flag closes. Lecture 4 priced shadows, proved the clique form with its equality analysis, and used Daykin's mirror for a second complete proof of EKR — then stopped honestly at uniqueness: the mirror pins the size of a maximum family, but the brick it lacked was the statement that a family sitting at the cascade's minimum across many levels at once must be complete. This lecture builds that brick — the deep cascade-uniqueness lemma, in four steps from §4.2's own equality analysis — and spends it on the EKR uniqueness theorem for every $n > 2k$, thin range included. No circles, no shifting, no middle-$J$ transport: the mirror, the $j$-form, and one squeeze.

5.1 From mirror-equality to the exact price

Recall the mirror (§4.3): $\mathcal{F}$ intersecting and $k$-uniform on $[n]$, $n > 2k$, $\mathcal{F}^* = \{[n] \setminus F : F \in \mathcal{F}\}$ uniform of size $n - k \ge k$, the disjointness $|\mathcal{F}| + |\partial_k\mathcal{F}^*| \le \binom{n}{k}$, and the increasing function $h(t) = \binom{t}{n-k} + \binom{t}{k}$ with $h(n - 1) = \binom{n}{k}$. Writing $|\mathcal{F}^*| = |\mathcal{F}| = \binom{x}{n-k}$, the $j$-form feeds $|\partial_k\mathcal{F}^*| \ge \binom{x}{k}$ into the mirror, and $h$ increasing forces $x \le n - 1$: the EKR bound $|\mathcal{F}| \le \binom{n-1}{k-1}$ — Daykin's proof, complete.

Now suppose the family is maximum: $|\mathcal{F}| = \binom{n-1}{k-1}$ ($k \ge 1$). Then the parameter is pinned from both sides. The floor: $\binom{x}{n-k} = |\mathcal{F}| = \binom{n-1}{n-k}$ with $\binom{\cdot}{n-k}$ increasing gives $x \ge n - 1$; the cap: $x \le n - 1$. So $x = n - 1$ — cap meets floor — and the two bounds on the shadow meet in the middle: $|\partial_k\mathcal{F}^*| \ge \binom{n-1}{k}$ from the $j$-form and $|\partial_k\mathcal{F}^*| \le \binom{n}{k} - |\mathcal{F}| = \binom{n-1}{k}$ from the mirror, so

$$|\partial_k\mathcal{F}^*| = \binom{n-1}{k}:$$

the mirror of a maximum family sits at the $j$-form's floor at level $k$, many levels below its uniformity $n - k$. One more bookkeeping device and the brick is assembled. For each level $j$ with $k \le j \le n - k$, write $x_j$ for the own real parameter of $\partial_j\mathcal{F}^*$ — that is, $|\partial_j\mathcal{F}^*| = \binom{x_j}{j}$ — so $x_{n-k} = x = n - 1$ and $x_k = n - 1$ (the shadow at level $k$ costs $\binom{n-1}{k}$). The $j$-form applied to the level-$j$ family reads $|\partial_{j-1}\mathcal{F}^*| \ge \binom{x_j}{j-1}$; comparing with the definition of $x_{j-1}$ and using that binomials increase: $x_{j-1} \ge x_j$ — as the level descends, the parameter never decreases. The chain

$$x_{n-k} \le x_{n-k-1} \le \dots \le x_k$$

is pinned at both ends by $n - 1$, so every level's parameter is $n - 1$: $|\partial_j\mathcal{F}^*| = \binom{n-1}{j}$ for all $k \le j \le n - k$. The parameters agree all the way down — but agreeing parameters do not yet say complete. The bridge is the next section's lemma.

5.2 The deep cascade-uniqueness lemma (four steps)

Everything rests on one corollary of §4.2's equality analysis, worth stating on its own:

One-level corollary. Let $\mathcal{G}$ be $r$-uniform ($r \ge 2$) with $|\mathcal{G}| = \binom{x}{r}$ for a real $x \ge r$. If $|\partial\mathcal{G}| = \binom{x}{r-1}$ — equality at the level adjacent to uniformity — then $x$ is an integer and $\mathcal{G} = K_x^r$.

Proof. Every member of $\mathcal{G}$ is an $r$-clique of its own $(r - 1)$-uniform shadow $\partial\mathcal{G}$, so $|\mathcal{G}| \le K(\partial\mathcal{G})$. Since $|\partial\mathcal{G}| = \binom{x}{r-1}$ with $x \ge r > r - 1 \ge 1$, the clique form of §4.2 applied to $\partial\mathcal{G}$ gives $K(\partial\mathcal{G}) \le \binom{x}{r} = |\mathcal{G}|$. Thus $K(\partial\mathcal{G}) = \binom{x}{r}$ holds with equality. By §4.2's equality characterization (applied to the $(r - 1)$-uniform family $\partial\mathcal{G}$ with parameter $x > r - 1$), $x$ is an integer and $\partial\mathcal{G} = K_x^{r-1}$ on some $x$-element vertex set $U$ (for $r - 1 = 1$, $\partial\mathcal{G}$ is a set of $x = |\partial\mathcal{G}|$ singletons, which is also $K_x^1$ with $x \in \mathbb{Z}$). Every member of $\mathcal{G}$ has all its $(r - 1)$-subsets inside $U$, hence is itself a subset of $U$; since $|\mathcal{G}| = \binom{x}{r}$, $\mathcal{G}$ must consist of all $r$-subsets of $U$, so $\mathcal{G} = K_x^r$. $\blacksquare$

Lemma (deep cascade uniqueness). Let $\mathcal{G}$ be $r$-uniform ($r \ge 2$) with $|\mathcal{G}| = \binom{x}{r}$ for a real $x \ge r$. If for some integer level $1 \le j_0 < r$ the $j_0$-shadow satisfies $|\partial_{j_0}\mathcal{G}| = \binom{x}{j_0}$ — equality pinned at a positive lower level — then $x$ is an integer and $\mathcal{G} = K_x^r$.

Proof. (1) The chain. For each level $j \in \{j_0, \dots, r\}$, let $x_j \ge j$ be the real parameter of $\partial_j\mathcal{G}$ defined by $|\partial_j\mathcal{G}| = \binom{x_j}{j}$ (with $\partial_r\mathcal{G} := \mathcal{G}$, so $x_r = x$). Applying the one-step shadow bound to $\partial_j\mathcal{G}$ gives $\binom{x_{j-1}}{j-1} = |\partial_{j-1}\mathcal{G}| \ge \binom{x_j}{j-1}$, and since $\binom{\cdot}{j-1}$ is strictly increasing on $[j - 1, \infty)$ for every $j - 1 \ge j_0 \ge 1$, we obtain $x_r \le x_{r-1} \le \dots \le x_{j_0}$. (2) Both ends equal $x$. By hypothesis, $\binom{x_{j_0}}{j_0} = |\partial_{j_0}\mathcal{G}| = \binom{x}{j_0}$; since $j_0 \ge 1$, strict monotonicity of $\binom{\cdot}{j_0}$ on $[j_0 - 1, \infty)$ forces $x_{j_0} = x$. (3) The squeeze. The monotone chain $x = x_r \le x_{r-1} \le \dots \le x_{j_0} = x$ is constant, so $x_{r-1} = x$, i.e. $|\partial\mathcal{G}| = \binom{x}{r-1}$. (4) The adjacent-level corollary fires. By the one-level corollary, $x$ is an integer and $\mathcal{G} = K_x^r$. $\blacksquare$

That is the whole "uniqueness theory of the binomial cascade" the shade route was missing: not a deeper theorem, but the observation that the equality analysis of §4.2 plus a monotone chain is the deep statement. Equality pinned at any positive depth propagates up to the adjacent level, and the adjacent level decides.

Machine record. The lemma says deep equality $\iff$ complete, and the census confirms both directions at every reachable size, zero exceptions. Deep means: $|\mathcal{G}| = \binom{u}{k}$ with $u = |\partial_1\mathcal{G}|$ the union size, and $|\partial_j\mathcal{G}| = \binom{u}{j}$ at every level $1 \le j < k$ — the real parameter resolves to the integer $u$ (this is the shortcut the lab uses: no bisection, exact integer arithmetic). The counts: at $(6, 3)$, of the $1,048,575$ families $42$ are deep, and all $42$ are complete — $20$ single triples, $15$ $K_4^3$, $6$ $K_5^3$, and $1$ $K_6^3$, one complete family per choice of union set; at $(6, 4)$, $32,767$ families, $22$ deep, all complete; at $(7, 5)$, $2,097,151$ families, $29$ deep, all complete — $21$ $K_5^5 + 7$ $K_6^5 + 1$ $K_7^5$. And at $r = 2$ with $x = 5, n = 7$, a graph costume: of the $352,716$ ten-edge graphs on $[7]$, $21$ carry at least ten triangles — the clique-form equality $K(\mathcal{G}) = \binom{5}{3}$ — and every one of them is $K_5$ plus two isolated vertices: the complete family $K_5^2$, in its $21$ placements. Deep equality and completeness coincide at every censusable size, which is what a proved lemma and an honest census should agree on. (The lab, Part 5, runs all four hunts with the integer shortcut.)

5.3 The star theorem, completed for every $n > 2k$

Theorem (EKR uniqueness, complete range). Let $\mathcal{F}$ be an intersecting $k$-uniform family on $[n]$ with $k \ge 1$, $n > 2k$, and $|\mathcal{F}| = \binom{n-1}{k-1}$. Then $\mathcal{F}$ is a star: all members share one fixed element.

Proof. Assemble the pieces. (1) Cap meets floor (§5.1): $x = n - 1$ and $|\partial_k\mathcal{F}^*| = \binom{n-1}{k}$. (2) The squeeze (§5.2): the parameters of the intermediate shadows are pinned at $n - 1$ across the whole range $[k, n - k]$; since $n > 2k$ and $k \ge 1$, the adjacent level $n - k - 1 \ge k \ge 1$ lies in that range, so $|\partial\mathcal{F}^*| = \binom{n-1}{n-k-1}$. (3) The one-level corollary: $\mathcal{F}^* = K_{n-1}^{n-k}$ — every member of $\mathcal{F}^*$ lies inside one fixed $(n - 1)$-set, which must be $[n] \setminus \{z\}$ for some $z$. (4) Translate back: $F \in \mathcal{F}$ has $[n] \setminus F \in \mathcal{F}^* \subseteq K_{n-1}^{n-k}$, so $[n] \setminus F \subseteq [n] \setminus \{z\}$, so $z \in F$: every member of $\mathcal{F}$ contains $z$, and $|\mathcal{F}| = \binom{n-1}{k-1}$ is the full count of $k$-sets through $z$. $\mathcal{F}$ is the star at $z$. $\blacksquare$

With Chapter 7's circle method (the bound) and its uniqueness lecture (the range its induction reached), this closes the EKR arc over the whole of $n > 2k$ — including the thin range $2k < n < 3k$, which the circle method crossed by a middle-$J$ transport the book never needed to build. The transport is thereby bypassed, not disproved: Katona's classical proof of the uniqueness theorem walks that road, and the shade route reaches the same summit from the other side. Flag (ii) retires here, and the forward pointer Chapter 7's Lecture 4 planted is landed.

The mirror partition, at equality. For the star itself the accounting is exact — worth reading as a check that the boundary of the proof is the boundary of the theorem. The star's mirror is the complete family $\mathcal{F}^* = K_{n-1}^{n-k}$ inside $V_0 = [n] \setminus \{z\}$, with $|\mathcal{F}^*| = \binom{n-1}{k-1}$, and — because $k \le n - k$ — its $k$-shadow is all the $\binom{n-1}{k}$ $k$-sets inside $V_0$. Every $k$-set of $[n]$ contains $z$ or avoids it: a disjoint cover,

$$\binom{n-1}{k-1} + \binom{n-1}{k} = \binom{n}{k} \text{ — Pascal, machine-checked at } (9, 4)\ 56 + 70 = 126,\ (5, 2)\ 4 + 6 = 10,\ (7, 3)\ 15 + 20 = 35,\ (8, 3)\ 21 + 35 = 56.$$

The $(9, 4)$ budget, honestly. The theorem covers $(9, 4)$: the nine stars, size $56 = \binom{8}{3}$, are the only intersecting $4$-families of that size. A census proof is out of reach — the book's depth-first hunt over the $126$ four-sets of $[9]$ ran some thirty million nodes and never produced a non-star of size $56$; its best empty-core partial, $53$, is Hilton–Milner's bound at $(9, 4)$ (§4.4's gateway), the largest an empty-core family can be. The census is evidence; the proved lemma is the proof. ◐15 inherits the hunt.

5.4 What to learn

The shade route is the book's last path up EKR and the cheapest of the three: no averaging, no shifting, no transport — one disjointness observation, one priced shadow, one squeeze. Its engine pairing deserves a name: §4.2's equality analysis was proved for one level, and the deep lemma is nothing but the observation that a monotone chain with pinned endpoints is constant — the squeeze does the work that a deeper theorem might have been asked to do. That is the general lesson about "genuinely deeper" bricks: sometimes the deeper statement is the shallow one, iterated by an invariant. And the specific lesson: when a proof stops for want of a uniqueness statement, price the dual object — the complement mirror — and ask what its shadows cost. The three flags the restructure left open are now closed: (iii) by the assembly (Lecture 3), (i) by the mirror (Lecture 4), (ii) here. The counting world this book has been teaching now runs from Sperner to the thin range with every load-bearing proof on the table; what remains beyond the course is gateway material, honestly labeled — Hilton–Milner, Ahlswede–Khachatrian, the union-closed frontier.

A8. Grid lemma (D1): Write $f(x, y) = \sum_{i=0}^{|A|-1} c_i(y) x^i$, where each coefficient $c_i(y)$ is a polynomial in $y$ of degree $< |B|$. def deep_census(n, k):
    """Deep equality via the integer shortcut: |G| = C(u,k) with u the union
    size, and every j-shadow exactly C(u, j).  Deep ⟺ complete, by 5.2."""
    if k < 1 or n < k: return
    sets = [m for m in range(1 << n) if bin(m).count("1") == k]
    t = len(sets)
    deep = complete = 0
    by_u = {}
    for mask in range(1, 1 << t):
        fam = [sets[i] for i in range(t) if mask >> i & 1]
        union = 0
        for f in fam: union |= f
        u = bin(union).count("1")
        if len(fam) != comb(u, k): continue            # parameter must be u
        cur, ok = fam, True
        for j in range(k - 1, 0, -1):
            sh = set()
            for f in cur:
                for e in range(n):
                    if f >> e & 1: sh.add(f & ~(1 << e))
            if len(sh) != comb(u, j): ok = False; break
            cur = sorted(sh)
        if ok:
            deep += 1
            complete += len(fam) == comb(u, k)        # automatic: deep => complete
            by_u[u] = by_u.get(u, 0) + 1
    print(f"({n},{k}): families {(1 << t) - 1}, deep {deep}, complete {complete}, by_u {by_u}")
