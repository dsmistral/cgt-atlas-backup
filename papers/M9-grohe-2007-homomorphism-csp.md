- Abstract or faithful summary (summarized, flagged sketch): a complexity-theoretic classification of homomorphism problems for graphs and, more generally, relational structures obtained by restricting the left-hand side structure. For a class C of structures, HOM(C, -) asks whether an input structure maps homomorphically to a fixed structure from C. Main theorem (under the parameterized-complexity assumption FPT != W[1]): HOM(C, -) is in polynomial time if and only if the cores of all structures in C have bounded tree-width. The tractability side runs a dynamic program over tree decompositions; the hardness side uses parameterized reductions.
