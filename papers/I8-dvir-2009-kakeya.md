# I8 - Dvir (2009): On the size of Kakeya sets in finite fields

- Metadata (web-verified 2026-10-13): Z. Dvir, "On the size of Kakeya sets in finite fields", J. Amer. Math. Soc. 22(4): 1093-1097 (2009), DOI 10.1090/S0894-0347-08-00607-3, arXiv:0803.2336. Sources: AMS journal page (open PDF); arXiv abstract page.
- Summary (general-knowledge level, flagged sketch): a Kakeya set in F_q^n (a set containing a line in every direction) has size at least c_n q^n, with c_n depending only on n. The finite-field Kakeya conjecture, open for years against sophisticated Fourier/sum-product attacks, falls to a one-page polynomial argument.
- Decisive moves: (1) [P22 HIT] the one-page engine: if the set were too small, a nonzero polynomial of degree < q would vanish on all of it; the line-in-every-direction property forces vanishing along entire lines, and a derivative / leading-homogeneous-part argument propagates the vanishing; the degree bookkeeping of the polynomial method yields the size lower bound; (2) lineage note: the proof converted the polynomial method from a combinatorics tool into a headline method; within a decade it returns as I9 (CLP over Z_4) and I10 (slice rank).
