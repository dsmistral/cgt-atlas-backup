# C2 - Otter (1948): The number of trees

- Metadata (web-verified 2026-10-13): R. Otter, "The number of trees", Annals of Mathematics (2) 49(3): 583-599 (1948). Open PDF located: users.math.msu.edu/users/magyarp/math880/Otter-Trees.pdf (MSU instructor copy).
- Summary (general-knowledge level, flagged sketch): the asymptotic count of unlabeled (non-isomorphic) trees: t_n ~ C alpha^n n^{-5/2}, alpha about 2.955765. Otter derives the functional equation for the ordinary generating function of unlabeled rooted trees and reads the asymptotics off the singular behavior of its solution.
