# B8 - Saxton-Thomason (2015): Hypergraph containers

- Metadata (web-verified 2026-10-13): D. Saxton, A. Thomason, Inventiones mathematicae 201(3): 925-992, 2015, DOI 10.1007/s00222-014-0562-8. Sources: Springer; ADS; CoLab listing. Note: independently developed from B7, as both papers state.
- Summary (publisher abstract, quoted-level): for every r-uniform hypergraph G, a relatively small collection C of vertex subsets such that every independent set of G is contained in some member of C and no member is large; the collection is in various respects optimal and reveals an underlying structure to the independent sets.
