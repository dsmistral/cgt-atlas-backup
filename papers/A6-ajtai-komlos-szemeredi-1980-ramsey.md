# A6 - Ajtai-Komlos-Szemeredi (1980): A note on Ramsey numbers

- Metadata (web-verified 2026-10-13): M. Ajtai, J. Komlos, E. Szemeredi, J. Combin. Theory Ser. A 29(3): 354-360, November 1980, DOI 10.1016/0097-3165(80)90030-8. CORRECTION: the seed row said JCT-B 1981; it is JCT-A 1980. Sources: ScienceDirect listing; Szemeredi publication list (renyi.hu); Rutgers research listing.
- Summary (general-knowledge level, flagged sketch): every triangle-free graph on n vertices with average degree d has an independent set of size at least c times n log d over d - hence R(3,t) <= c t^2/log t, the first correct order of magnitude for the upper bound. The proof selects vertices at random and cleans up - an iterative probabilistic selection.
- Decisive moves: (1) [P12] random selection of a candidate independent set; (2) [P10] expectation analysis of the edges surviving inside the sample; (3) [P14] cleanup/alteration of the sampled set; (4) the result read as a Ramsey upper bound.
