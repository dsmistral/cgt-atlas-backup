# I1 - Sperner (1928): Ein Satz uber Untermengen einer endlichen Menge

- Metadata (web-verified 2026-10-13): E. Sperner, "Ein Satz uber Untermengen einer endlichen Menge", Mathematische Zeitschrift 27: 544-548 (1928), DOI 10.1007/BF01171114. Sources: SpringerLink DOI page; EUDML open copy https://eudml.org/doc/167993.
- Summary (general-knowledge level, flagged sketch): the founding theorem of extremal set theory: an antichain (Sperner family) of subsets of an n-element set has at most C(n, floor(n/2)) members, with equality exactly for the middle level(s). The paper opens the Sperner-property program for posets at large.
- Decisive moves: (1) [P9 partial] the engine is a replacement / push-toward-the-middle argument: repeatedly exchange sets for sets of adjacent size without shrinking the family, so weight migrates to middle levels - a pigeonhole-flavored predecessor of shifting; (2) [P23 partial] the clean modern engine (LYM double counting, Lubell-Yamamoto-Meshalkin) is retrospective - the original replacement step is only partially shifting-flavored, so P23 is credited partial only. Mirror of the H1 Turan treatment: original engine and retrospective modern engine credited separately.
