# H12 - Szemeredi-Trotter (1983): Extremal problems in discrete geometry

- Metadata (web-verified 2026-10-13): E. Szemeredi and W. T. Trotter, "Extremal problems in discrete geometry", Combinatorica 3: 381-392 (1983), DOI 10.1007/BF02579194. Sources: SpringerLink (Combinatorica 3, 381-392), Semantic Scholar, Wikipedia (Szemeredi-Trotter theorem page).
- Summary (general-knowledge level, flagged sketch): the point-line incidence bound: the number of incidences between n points and m lines is at most C (n^{2/3} m^{2/3} + n + m), with the unit-distance and distinct-distances consequences. The theorem founded discrete geometry as an extremal field.
