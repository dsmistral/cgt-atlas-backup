# A1 - Erdos (1947): Some remarks on the theory of graphs

- Metadata (web-verified 2026-10-13): P. Erdos, Bull. Amer. Math. Soc. 53(4): 292-294, April 1947. Open PDF: ams.org (S0002-9904-1947-08785-1). Sources: projecteuclid.org listing; ams.org PDF; MIT course notes citation.
- Summary (general-knowledge level, flagged sketch): first probabilistic-method paper - lower bound for diagonal Ramsey numbers: color K_n edges randomly with 2 colors; each fixed k-set is monochromatic with probability 2^{1-C(k,2)}; if the expected number of monochromatic k-cliques is below 1, a coloring with none exists, so R(k,k) > n.
