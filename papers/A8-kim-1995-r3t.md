# A8 - Kim (1995): The Ramsey number R(3,t) has order of magnitude t^2/log t

- Metadata (web-verified 2026-10-13): J. H. Kim, Random Structures and Algorithms 7(3): 173-207, 1995. CORRECTION: the seed row said JAMS; it is RSA. Fulkerson Prize 1997 (AMS Notices). Open course-hosted PDF located (people.tamu.edu). Sources: Wiley listing; AMS Notices Fulkerson announcement; Semantic Scholar.
- Summary (publisher abstract, quoted-level): proves R(3,t) >= (1-o(1)) c t^2/log t, which together with the Ajtai-Komlos-Szemeredi upper bound pins the order of magnitude. The main result is an upper bound on independence numbers of triangle-free graphs, tight up to constants - the lower-bound construction builds a triangle-free graph with no large independent set.
- Decisive moves: (1) [CAND-A2] semi-random construction - edges are inserted in a controlled random process that maintains triangle-freeness while pushing density up (the nibble philosophy); (2) [P10]+[P4] potential-function tracking of the process densities (differential-equation-style bookkeeping); (3) [P14] final alteration - delete the few high-degree vertices at the end; (4) [P11] the result is an explicit-enough construction beating all previous lower bounds.
- New-pattern candidates: CAND-A2 (semi-random/nibble construction with parameter tracking) - second P43 candidate: distinct from plain [P12] sampling because the process is adaptive; cross-batch test at L6 (Rodl nibble) and L9 (Pippenger-Spencer).
