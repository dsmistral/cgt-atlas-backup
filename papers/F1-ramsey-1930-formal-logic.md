# F1 - Ramsey (1930): On a problem of formal logic

- Metadata (web-verified 2026-10-13): F. P. Ramsey, "On a Problem of Formal Logic", Proceedings of the London Mathematical Society (2) s2-30(1) (1930): 264-286, DOI 10.1112/plms/s2-30.1.264. Sources: Wiley LMS Online Library; Oxford Academic. Posthumous publication (Ramsey died January 1930).
- Summary (general-knowledge level, flagged sketch): the paper's stated purpose is a decidability problem of first-order logic; en route it proves the combinatorial theorems "most conveniently set out beforehand": the infinite Ramsey theorem (every r-coloring of the k-subsets of an infinite set has an infinite monochromatic subset) and the finite version, with the first Ramsey-number bounds.
- Decisive moves: (1) [P9] pigeonhole/partition as theorem - from a colored complete structure, repeatedly pass to a large same-color neighborhood: the canonical Ramsey move; (2) [P4] the double induction on (subset size k, number of colors r) - the recursion that defines Ramsey numbers; (3) [P26] compactness - the finite statement derived from the infinite one; the founding combinatorial instance of the finite-from-infinite move.
