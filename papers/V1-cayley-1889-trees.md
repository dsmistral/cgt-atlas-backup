- Summary (flagged sketch, the open historical literature and the standard histories): the labelled-tree count's origin. Cayley states the number of labelled trees on n vertices is n^(n-2), and extends the count to the degree-refined multinomial form (the number of labelled trees in which vertex i has degree d_i is (n-2)! / prod (d_i - 1)!, the degrees summing to 2n-2), crediting Borchardt for the route. The note's own argument is a sketch by modern standards; the formula's first appearance predates it in Borchardt's 1860 determinant computation (uncorpus'd), and the bijection the count is now canonically proved by - Prufer's 1918 code - is retrospective (uncorpus'd).
