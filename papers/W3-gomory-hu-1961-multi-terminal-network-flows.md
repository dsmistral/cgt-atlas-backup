- Summary (flagged sketch, the combinatorial-optimization canon): the multi-terminal cut problem's founding paper. The problem: the minimum s-t cut value for every vertex pair, previously one max-flow computation per pair. The result: a flow-equivalent tree (the Gomory-Hu tree) whose tree paths carry every pairwise minimum-cut value - constructible with n-1 max-flow computations. The two decisive devices: the non-crossing-cuts observation (for any two pairs, minimum cuts can be chosen so neither crosses the other - the strict-side relationship) and condensation (identifying vertex sets already separated by a computed cut, shrinking the graph between flow computations; each step merges the vertex count by one).
