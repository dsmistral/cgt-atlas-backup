- Abstract or faithful summary (summarized, flagged sketch): the paper develops coding theory axiomatically around codes and their duals and proves the MAPPING THEOREM relating the weights in a code A to those in an image-code B (the publisher's abstract notes a corollary: "a formula for the sum of the squares of the weights of all code elements"). The load-bearing descendant for this survey is the ASSMUS-MATTSON CRITERION attributed to this work by the standard textbooks: when the dual code has few distinct non-zero weights, the codewords of each weight in the code (and symmetrically the dual) carry t-designs - the WORDS-AS-DESIGNS engine is born.
