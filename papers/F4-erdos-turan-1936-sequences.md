# F4 - Erdos-Turan (1936): On some sequences of integers

- Metadata (web-verified 2026-10-13): P. Erdos, P. Turan, "On some sequences of integers", Journal of the London Mathematical Society 11(4) (1936): 261-264, DOI 10.1112/jlms/s1-11.4.261. Sources: Wikipedia (Erdos conjecture on arithmetic progressions, citation with an open PDF link); JLMS/Wiley.
- Summary (general-knowledge level, flagged sketch): the conjecture-seeding paper: it poses the Erdos-Turan conjecture - every set of integers with positive natural density contains arbitrarily long arithmetic progressions (per Wikipedia's reading: infinitely many 3-term progressions as the first case) - together with partial results toward it. The conjecture drove the field for four decades: k=3 by Roth (F5), the general case by Szemeredi (F6).
- Decisive moves: (1) [P25] the reformulation that opened arithmetic combinatorics - van der Waerden's partition statement recast as a DENSITY statement; replacing "one color class is large" by "the set itself has positive density" carries the whole proof program that followed; (2) the survey's recorded role "conjecture seeding" confirmed - the paper's decisive contribution is the problem and the density viewpoint, not a proof technique; (3) partial results toward the conjecture recorded at flag level.
