Chapter 6 · Linear-Algebraic Methods

Part of the Combinatorics & Graph Theory Atlas (see the Atlas canvas for the chapter map and progress report).

The great discovery of 20th-century combinatorics: many counting bounds are secretly dimension bounds. Encode sets as vectors, and "you can't have too many" becomes "vectors can't exceed the dimension of the space". This edition is a lecture course in four lectures — Fisher's inequality two ways, Oddtown and Eventown (where the field chooses the answer), the polynomial method, and the friendship theorem — every proof complete, every claimed number machine-checked. The polynomial method — a one-line proof of Oddtown's descendants and the engine behind the best known Ramsey lower bounds — gets a full lecture of its own, and returns in Chapter 8, running on the Hamming cube. The eigenvalue half of the subject — eigenvalues as averaging machines, spectral Turán, two-distance sets, and the modern toolkit of interlacing, the Hoffman bounds, Lovász theta, and Delsarte's linear program — is the subject of Chapter 8, Spectral Methods and the Modern Toolkit; this chapter closes exactly where that one picks up.

Lecture 1 · Fisher's Inequality, Two Ways

Problem. A_1, …, A_m are distinct subsets of an n-element set; every pair intersects in exactly λ points; and no |A_i| equals λ. Then m ≤ n.

Two engines solve this, one getting m ≤ n + 1 and the other closing the last notch. They are worth learning as a pair: the first is the seed of the Frankl–Wilson theory (Lecture 3); the second is the Gram-matrix machine you will reuse all chapter.

1.1 Bose's polynomials — honest, and one short of the goal

To each set A_i associate the polynomial in n variables x_1, …, x_n (one per ground element):

p_i(x) = Σ_{k ∈ A_i} x_k − λ.

Evaluate at the 0/1 vectors v_j: p_i(v_j) = |A_i ∩ A_j| − λ. For i ≠ j that is λ − λ = 0; for i = j it is |A_i| − λ ≠ 0. So the evaluation matrix (p_i(v_j)) is diagonal with nonzero diagonal entries — invertible — and the p_i are linearly independent.

Where do they live? Each p_i is a linear combination of 1, x_1, …, x_n: a space of dimension n + 1. Independence forces

m ≤ n + 1.

One notch short — and honestly so: nothing in the argument uses that the coefficients of the x_k in p_i are all 1. Machine check on the two classical tight examples: the Fano plane's evaluation matrix is 2I (each line has |A| − λ = 3 − 1 = 2 on the diagonal), determinant 2⁷ = 128; the 4-point near-pencil's is diag(2, 1, 1, 1), determinant 2.

1.2 The Gram matrix — positive definite, rank ≤ n, done

Take the characteristic vectors v_i ∈ R^n and the m×m matrix of dot products M = (v_i · v_j) = (|A_i ∩ A_j|):

M = λJ + D, where D = diag(|A_1| − λ, …, |A_m| − λ), all diagonal entries positive.

Claim 1: M is positive definite. For any x ≠ 0:
xᵀMx = λ(Σ_i x_i)² + Σ_i (|A_i| − λ)x_i².
The first term is ≥ 0 (λ ≥ 1); the second is > 0 on any coordinate with x_i ≠ 0. So xᵀMx > 0: M is positive definite, and rank M = m.

Claim 2: rank M ≤ n. M = VᵀV where V stacks the v_i as rows (V is m×n), and rank(VᵀV) ≤ rank V ≤ n.

Combining: m = rank M ≤ n. ∎

✎ Checkpoint — determinants, computed two ways. The determinant lemma det(λJ + D) = det(D)·(1 + λ·Σ_i 1/d_i), with d_i = |A_i| − λ, prices both tight examples. Fano plane (seven 3-point lines on seven points, λ = 1, d_i = 2): det = 2⁷·(1 + 7/2) = 128·4.5 = 576 = 24². Near-pencil on 4 points (one 3-point line plus the three 2-point lines through the fourth point; D = diag(2,1,1,1)): det = 2·(1 + 1/2 + 1 + 1 + 1) = 9. Both check against direct elimination; both families have m = n, so Fisher is tight. And Sylvester's criterion runs live on the Fano Gram: its leading principal minors are 3, 8, 20, 48, 112, 256, 576 — all positive, positive definiteness confirmed without writing a single quadratic form.

1.3 Corollary — de Bruijn–Erdős (P19 applied to geometry)

n non-collinear points determine at least n distinct lines.
Proof. For each point p let A_p be the set of lines through p. Any two points share exactly one line, so |A_p ∩ A_q| = 1 = λ. The A_p are distinct (two points with identical line sets would make every line through p pass through q — impossible with a non-collinear third point), and |A_p| ≥ 2 ≠ λ. Fisher: n points ≤ N lines. ∎

✎ Checkpoint. Enumerate the linear spaces on 4 labeled points (any two points on exactly one line, not all collinear): there are exactly 5 — four near-pencils (choose the point off the 3-point line) and one affine plane (all six pairs as lines). The brute-force census is Exercise ◆11; every one of the five has lines ≥ points, as de Bruijn–Erdős demands.

What you now own: the evaluation-matrix reflex (a polynomial per set, vanishing on the others) and the Gram template — dot-product pattern ⇒ positive definiteness ⇒ rank = m ⇒ m ≤ n — a machine you can retarget at dozens of theorems (exercises 3 and 7; Chapter 8's two-distance lecture runs it in geometry).

Lecture 2 · Oddtown and Eventown: The Field Chooses the Answer

Problem (Oddtown). A family of subsets of an n-set, each of odd size, with even pairwise intersections. Then the family has at most n members.

2.1 Independence over F_2 (P19′)

Take characteristic vectors v_i in the vector space F_2ⁿ — work mod 2, because the problem is stated in parities. Then
v_i · v_i = |A_i| ≡ 1 (odd), and v_i · v_j ≡ 0 (even) for i ≠ j.
Suppose Σ c_i v_i = 0 is a linear dependence. Dot with v_j: every cross term dies, and the only survivor is c_j·(v_j · v_j) = c_j. So c_j = 0 for all j: the v_i are linearly independent, and F_2ⁿ has only n independent vectors. ∎

The census confirms the bound is tight: on [3] the maximum Oddtown has 3 members, on [4] it has 4 (Exercise 1 — the four 3-subsets of [4] do it).

2.2 The twist — Eventown, and the field's revenge

If instead all sizes and all intersections are even, the family can have 2^{⌊n/2⌋} members: partition the ground set into pairs and take all unions of pairs. Every set has even size; every intersection is even. So flipping one parity changes the answer from linear to exponential. The rank argument explains why it must collapse:

Eventown upper bound. Over F_2, Eventown's vectors satisfy v_i · v_j = 0 for all i, j — including i = j, since every |A_i| is even. So the bilinear form vanishes on the entire span W of the family: for x = Σ a_i v_i and y = Σ b_j v_j, x·y = Σ_{i,j} a_i b_j (v_i·v_j) = 0. Every vector of W is orthogonal to every vector of W, i.e. W ⊆ W⊥, whence dim W ≤ n − dim W, i.e. dim W ≤ n/2. The family sits inside W, so |F| ≤ 2^{dim W} ≤ 2^{⌊n/2⌋}. ∎ (Exercise 2; census: maximum 2 on [3], 4 on [4] — both exactly the formula.)

2.3 The same trick over any prime

Nothing is special about 2. Fix a prime p and a residue k ≢ 0 (mod p): if every |A_i| ≡ k and every pairwise intersection ≡ 0 (mod p), the same dotting argument over F_p gives v_i·v_i = k ≠ 0 and v_i·v_j = 0 — independence again, so m ≤ n for every prime. Machine census for p = 3, k = 1 on [4]: maximum family size 4 = n, attained by the singletons. The lesson generalizes: the modulus is not decoration — it is the theorem (Exercise 4).

2.4 One more parity flip — symmetric differences

Suppose instead all pairwise symmetric differences are even: |A_i △ A_j| ≡ 0 (mod 2) for all i, j. Since |A △ B| = |A| + |B| − 2|A ∩ B| ≡ |A| + |B| (mod 2), every |A_i| has the same parity — so the whole family sits inside one parity class of 2^{n−1} sets, and that is the sharp bound (Exercise 8; census: maximum 8 = 2³ on [4], attained by all the odd sets). Three parity conditions, three answers: n, 2^{⌊n/2⌋}, 2^{n−1}.

What you now own: the reflex of doing inner products over the field the congruences point to (P19′), and the habit of asking how the answer changes with the modulus — the contrast is usually the real theorem.

Lecture 3 · Polynomials That Count: Ray-Chaudhuri–Wilson, Frankl–Wilson, and Ramsey Graphs

The evaluation-matrix idea of Lecture 1 was deliberately wasteful: the polynomials p_i = Σ_{k∈A_i}x_k − λ lived in a space of dimension n + 1, but we never asked what the smallest natural space is. This lecture asks, and the dividends are the strongest intersection theorems known — and, via a construction, quasipolynomial lower bounds for Ramsey numbers.

3.1 The multilinear lemma

On the cube {0,1}^n every function f : {0,1}^n → F (any field) is given by exactly one multilinear polynomial (each variable to degree ≤ 1): x_i² = x_i kills higher powers, and the monomials Π_{i∈S} x_i (S ⊆ [n]) are linearly independent as functions — evaluating at the points 1_T ordered by |T| gives a triangular matrix with 1s on the diagonal. So the space of functions of degree ≤ s has dimension

Σ_{i=0}^{s} C(n, i) — monomials only, one per subset of size ≤ s.

3.2 The non-uniform warm-up: Bose again, generalized

Let A_1, …, A_m be distinct sets whose pairwise intersections all lie in a set L = {ℓ_1, …, ℓ_s} of s forbidden... allowed values, with no |A_i| in L. Define

f_i(x) = Π_{ℓ ∈ L}(|A_i ∩ x| − ℓ), where |A_i ∩ x| means Σ_{k∈A_i} x_k.

Then f_i(v_j) = 0 for i ≠ j (the intersection lies in L, some factor dies) and f_i(v_i) = Π_ℓ(|A_i| − ℓ) ≠ 0. Evaluation matrix invertible ⇒ independence; the f_i are multilinear of degree ≤ s, so

m ≤ Σ_{i≤s} C(n, i).

Bose's m ≤ n + 1 is the case s = 1 with L = {λ}. Fisher's m ≤ n (uniformity not required!) is the Gram matrix's extra notch.

3.3 Ray-Chaudhuri–Wilson: the slice trick

Theorem (RCW). A family of k-subsets of [n] whose pairwise intersections all lie in L, |L| = s, has at most C(n, s) members.

Proof. The same polynomials f_i work — for distinct k-sets, |A_i ∩ A_j| ≤ k − 1 < k, so we may delete k from L if it crept in, and then f_i(v_i) = Π_{ℓ∈L}(k − ℓ) ≠ 0 exactly because k ∉ L. Independence is free; the new content is a better estimate of the ambient dimension. The vectors v_j of k-sets live on the slice Σ_j x_j = k, and on that slice a low-degree monomial can be rewritten in terms of higher-degree ones: for any S with |S| < k,

x_S = (1/(k − |S|)) Σ_{j ∉ S} x_{S∪j}.

(Proof: on the slice, k·x_S = x_S·Σ_j x_j = |S|·x_S + Σ_{j∉S} x_{S∪j}; rearrange.) Iterating, every multilinear function of degree ≤ s on the slice — s ≤ k − 1, so every step has |S| < k — is a combination of the degree-exactly-s monomials, of which there are C(n, s). The independent f_i fit there: m ≤ C(n, s). ∎

The slice identity is the whole trick: uniformity converts "degree ≤ s" into "degree exactly s", saving the sum over lower degrees. Machine tightness checks (n = 6, k = 3): for L = {0, 2} the maximum family has 4 members (bound C(6,2) = 15); for L = {0, 1} it is again 4 (Exercise ◆10 closes this one by hand and finds the truth beneath the bound); for L = {1, 2} the maximum is 10 = C(5,2) — all triples containing a fixed point — the bound C(6,2) = 15 is honest but not always attained.

3.4 Frankl–Wilson: Fermat does the bookkeeping (P22 over F_p)

Theorem (Frankl–Wilson, modular form). Fix a prime p. If every |A_i| ≡ k (mod p) and every pairwise intersection |A_i ∩ A_j| ≢ k (mod p), then

m ≤ Σ_{i=0}^{p−1} C(n, i).

Proof. Work over F_p and define, for each set, the Fermat polynomial

p_A(x) = 1 − (|A ∩ x| − k)^{p−1}.

Fermat's little theorem: t^{p−1} ≡ 1 if t ≢ 0, and ≡ 0 if t ≡ 0 (mod p). So p_A(v_A) = 1 − (|A| − k)^{p−1} = 1 − 0 = 1 (sizes are ≡ k), and p_A(v_B) = 1 − (|A∩B| − k)^{p−1} = 1 − 1 = 0 for B ≠ A (intersections are ≢ k). Evaluation matrix = identity: independence for free. After multilinearization, p_A is a combination of 1 and the monomials Π_{i∈S}x_i with |S| ≤ p − 1 (each monomial of (Σ_{i∈A}x_i − k)^{p−1} uses at most p − 1 distinct variables). Count the room: Σ_{i≤p−1} C(n, i). ∎

For p = 2 the Fermat polynomial is p_A(x) = 1 − (|A∩x| − k): the independence argument is Oddtown's, in disguise — the polynomial method did not replace the linear algebra; it organized it.

3.5 The payoff: explicit Ramsey graphs

Turn the theorem into graphs: let the vertices be the k-subsets of [m] (all of size ≡ k mod p), joining A, B when |A ∩ B| ≢ k (mod p). A clique is then a family whose pairwise intersections avoid the class k mod p — Frankl–Wilson caps it; an independent set is a family whose pairwise intersections all do fall in a single other residue class — RCW caps it. Two worked instances, fully machine-checked:

p = 2, m = 5, k = 3. Vertices: the ten 3-subsets of [5]; join iff |A ∩ B| is even, i.e. (distinct 3-sets meet in 1 or 2 points) iff |A ∩ B| = 2. Complementing each vertex turns this into the graph on 2-subsets where adjacency means intersecting — the complement of the Kneser graph KG(5,2), better known as the complement of the Petersen graph. The machine finds ω = 4 (a maximum clique is the set of four triples inside a fixed 4-set, e.g. all triples of {2,3,4,5}) and α = 2. The theory's caps — Frankl–Wilson Σ_{i≤1}C(5,i) = 6 for cliques, RCW C(5,1) = 5 for independent sets — are honest but loose here: 6 and 5 versus the true 4 and 2.

p = 3, m = 7, k = 4. Vertices: the thirty-five 4-subsets of [7]; join iff |A ∩ B| ≢ 1 (mod 3) — distinct 4-sets meet in 1, 2 or 3 points, so this joins exactly the pairs meeting in 2 or 3. Machine: ω = 15 (all 4-sets avoiding a fixed point — any two of them share ≥ 2 points), α = 2; caps: Frankl–Wilson Σ_{i≤2}C(7,i) = 29, RCW C(7,1) = 7. Again valid, again loose.

✎ Checkpoint — parameters must not degenerate. Try p = 3, m = 7, k = 5: two distinct 5-subsets of [7] meet in 3 or 4 points — residues 0 and 1 mod 3, never 2 = k mod 3. So every pair gets joined: the construction collapses to K₂₁ and proves nothing. The worked example switched to k = 4 for exactly this reason: the parameters must let intersections actually hit the forbidden residue class. Check a purported construction for degeneracy before believing its bounds.

The Ramsey corollary (cited, not proven here). Run the same construction at scale — vertices the k-subsets of [m] with k ≈ m/2, p chosen so that the caps Σ_{i≤p−1}C(m, i) stay polynomially small while the vertex count C(m, k) grows exponentially. Frankl and Wilson (1981) optimized the parameters and proved

R(k, k) ≥ exp(c · log²k / log log k)

— a quasipolynomial bound that stood for a quarter century, until Barak–Rao–Shaltiel–Wigderson (2006) improved it. The two worked graphs above are this construction at toy scale; the full optimization is cited to the papers, flagged as beyond this chapter's scope.

What you now own: the multilinear lemma, the slice trick (uniformity as a dimension discount), Fermat polynomials as bookkeeping, and the reflex of testing a construction's parameters for degeneracy before trusting its bounds.

Lecture 4 · The Friendship Theorem

Problem. If in a graph every two distinct vertices have exactly one common neighbor, then some vertex is adjacent to all others — and the graph is a "windmill": triangles glued at one central vertex.

The proof has three load-bearing parts, each complete here (the middle one was a flagged sketch in the reference literature for years; it is a degree-class argument, and it assembles cleanly).

4.1 Claim 1 — non-adjacent vertices have equal degrees

Claim 1. If x ≁ y then d(x) = d(y).
Proof. Let z be the unique common neighbor of x and y. Map each u ∈ N(x), u ≠ z, to the unique common neighbor α(u) of the pair (u, y). Note α(u) ∈ N(y), and α(u) ≠ x (x is not adjacent to y), and α(u) ≠ u (u ≁ y). If α(u_1) = α(u_2) = w with u_1 ≠ u_2, then w is adjacent to u_1 and u_2, and so is x — the pair (u_1, u_2) would have the two common neighbors x and w. So α is injective from N(x)∖{z} into N(y)∖{z}. The mirror construction (swap x and y) is an injection the other way, so |N(x)∖{z}| = |N(y)∖{z}|, and adding z back: d(x) = d(y). ∎

Contrapositive, worth enshrining: distinct degrees force adjacency. (Machine: the claim holds in every graph of the census below — 120 friendship graphs, zero exceptions.)

4.2 Claim 2 — no universal vertex is impossible (the ERS brick)

Claim 2. Every friendship graph has a universal vertex.
Proof. Suppose not. Every degree lies in {1, …, n − 2}. If some degree class is a singleton {x}, then x is adjacent to every vertex of different degree — that is, to every other vertex: universal, contradiction. So every class has ≥ 2 members; in particular (n pigeons, ≤ n − 2 nonempty classes) some class B, of common degree k, has two distinct members b_1, b_2.

Now watch the cross-class edges. Every w ∉ B has degree ≠ k, so w is adjacent to every vertex of B (Claim 1's contrapositive). In particular every w ∉ B is a common neighbor of the pair (b_1, b_2) — which has exactly one common neighbor. So |V ∖ B| ≤ 1.

Two cases. If V ∖ B = {z}: z is adjacent to all of B (distinct degrees), so d(z) = n − 1 — universal, contradiction. If V ∖ B = ∅: the graph is k-regular, and the spectral lemma below (§4.4) forces k = 2, n = 3 — the triangle, in which every vertex is universal. Contradiction again. ∎

4.3 Assembly — the universal vertex pins down the windmill

Let u be universal. Put H = G − u. If H contained a path w–x–y with w ≠ y, the pair (w, y) would have common neighbors x and u — two, contradiction. If H contained a triangle w–x–y, the pair (w, x) would have common neighbors y and u — two again. So H has maximum degree ≤ 1: a matching plus isolated vertices. But an isolated vertex z of H has N(z) = {u}, while N(u) = V ∖ {u} — the pair (z, u) has zero common neighbors. Contradiction. So H is a perfect matching: n is odd, n = 2t + 1, and G is exactly t triangles sharing u: the windmill W_t. ∎

Figure 1 draws W_4; check all three pair types: two vertices from different blades share only u; the two vertices of one blade share only u; and the pair (u, a_i) shares only the blade-partner b_i.

4.4 The spectral lemma — friendship graphs are (almost) never regular

Lemma. A k-regular friendship graph exists only for k = 2, n = 3 (the triangle).
Proof. Let A be the adjacency matrix. "Exactly one common neighbor per pair" is a matrix equation: (A²)_{uv} = 1 for u ≠ v and (A²)_{uu} = d(u) = k on the diagonal:

A² = J + (k − 1)I.

Regularity gives A𝟙 = k𝟙; on the hyperplane 𝟙⊥ (dimension n − 1), A² acts as (k−1)I, so A's eigenvalues there are ±√(k−1) with multiplicities a, b (a + b = n − 1). The trace of A is 0:

k + (a − b)√(k − 1) = 0.

If k − 1 is not a perfect square, the surd is irrational and both terms vanish separately: k = 0 — impossible (k ≥ 1). So k − 1 = t², k = t² + 1, and k + (a − b)t = 0 gives (b − a)t = t² + 1. Then t | t² + 1 forces t | 1, so t = 1, k = 2. (For k = 1 the equation itself reads 1 + (a−b)·0 = 0 — already impossible.) A connected 2-regular graph is a cycle C_n, and C_n for n ≥ 4 has pairs with two common neighbors or none; so n = 3. ∎

A second, counting proof of the regular case: length-2 walks between distinct ordered pairs number n(n − 1) — one per pair — and also Σ_w d(w)(d(w) − 1) = n·k(k − 1). So n − 1 = k(k − 1): n = k(k − 1) + 1. For k = 2: n = 3 ✓.

4.5 Census, spectra, and the shape of the answer

Machine census, all labeled graphs on n = 3 … 7 vertices: friendship graphs number 1, 0, 15, 0, 105 — every single one a windmill with a universal vertex, Claim 1 holding throughout. The count is no accident: a windmill on n = 2t + 1 vertices is determined by its hub (n choices) plus a perfect matching of the remaining n − 1 vertices ((n − 2)!! ways): 5·3!! = 15, 7·5!! = 105 ✓.

The windmill's spectrum is explicit (Exercise 6 derives it): W_t has eigenvalues 1 (t − 1 times), −1 (t times), and (1 ± √(1+8t))/2. So W_2 carries {(1±√17)/2, 1, −1, −1} and W_3 carries {3, 1, 1, −1, −1, −1, −2}. Non-regular friendship graphs satisfy the matrix equation in its honest form A² = J + (D − I) with D = diag(degrees) — the lab verifies it entry by entry on W_2, and on the triangle it reads A² = I + J with det A = 2.

What you now own: the common-neighbor bijection (Claim 1), the degree-class split (Claim 2 — pigeonhole plus one adjacency observation), the assembly, and the reflex of writing combinatorial information as a matrix equation before thinking.

def fp_rank(rows, p):                  # Gaussian elimination over F_p (p prime)
    M = [r[:] for r in rows]; r0, rank = 0, 0
    for c in range(len(M[0])):
        pvt = next((i for i in range(r0, len(M)) if M[i][c] % p), -1)
        if pvt < 0: continue
        M[r0], M[pvt] = M[pvt], M[r0]
        inv = pow(M[r0][c], p - 2, p)  # Fermat inverse
        M[r0] = [(a * inv) % p for a in M[r0]]
        for i in range(len(M)):
            if i != r0 and M[i][c] % p:
                f = M[i][c]
                M[i] = [(a - f * b) % p for a, b in zip(M[i], M[r0])]
        r0 += 1; rank += 1
    return rank

def vec(A, n): return [1 if i in A else 0 for i in range(n)]

A5. Let z be the unique common neighbor of the non-adjacent x, y. A7. Partition lower bound. Suppose the edges of K_n are partitioned into complete bipartite graphs K_{A_i, B_i}, i = 1…r. The partition says: each unordered pair is separated by exactly one biclique, i.e. Σ_i (a_ib_iᵀ + b_ia_iᵀ) = J − I (a_i = 1_{A_i} etc.). For x ∈ V = 𝟙⊥: xᵀ(J−I)x = −||x||², so Σ_i 2 s_{A_i}s_{B_i} = −||x||², where s_A(x) = Σ_{u∈A}x_u. Now the vectors z_i = |B_i|a_i − |A_i|b_i lie in V (z_i·𝟙 = |A_i||B_i| − |A_i||B_i| = 0). Summing: −||x||²/2 = Σ_i s_{A_i}s_{B_i} ≥ 0 — forcing x = 0, a contradiction. So r ≥ n − 1. The staircase {i} | {i+1, …, n}, i = 1 … n−1, partitions K_n into exactly n − 1 bicliques: tight. ∎ Cover upper bound. Give vertex v the binary address of v−1 in ⌈log₂n⌉ bits, and let biclique i take A = addresses with bit i equal to 0, B = bit i equal to 1: every edge has differing addresses, hence differing bits somewhere, and is covered — ⌈log₂n⌉ bicliques suffice (they overlap; that is the difference between a cover and a partition). A14. The Gram matrix G = (|A_i ∩ A_j|) is λJ + D with D = diag(|A_1| − λ, …, |A_m| − λ), and the hypothesis makes every diagonal entry positive. So s is a positive integer, d = s² + 1, and (b − a)s = −(s² + 1): s divides s² + 1, hence s divides 1, hence s = 1. A16. Flip columns — multiply column j by the sign of the (1, j) entry — and HHᵀ is unchanged with row 1 now all +. Row 2's balance: a + b = n/2. Row 3's balance: a + c = n/2. So b = c. The orthogonality of rows 2 and 3: a + d = b + c — with b = c, that is a + d = 2b. Total: n = (a + d) + (b + c) = 2b + 2b = 4b. So n is a multiple of 4; back-substituting, a = b = c = d = n/4 — every sign pattern occupies exactly a quarter of the columns.
